Slide 14

\textbf{Primal Network Simplex}

\textit{Updating dual variables}

$In \ \mathcal{I}$ (tree containing the root node):

\textit{nothing is changed:}

$\tilde{y}_b = y_b$

$\tilde{z}_{ij} = z_{ij}$  $(i,j) \in \mathcal{I}$


\textbf{Description:}

This slide describes how the dual variables are updated during a primal pivot step in the Network Simplex Method.  The text specifically addresses the dual variables within the tree $\mathcal{I}$ that contains the root node.  The notation $\tilde{y}_b$ and $\tilde{z}_{ij}$ represent the updated values of the dual variables $y_b$ and $z_{ij}$, respectively, after the pivot step.  The statement "nothing is changed" indicates that the dual variables within this particular tree remain unchanged during the pivot operation.  This is a crucial aspect of the algorithm, as it ensures that the dual solution remains feasible and consistent with the updated primal solution.
