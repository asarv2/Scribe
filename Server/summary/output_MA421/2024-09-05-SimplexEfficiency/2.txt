\section*{Worst Case Example: Klee-Minty (1970)}

\subsection*{[Iv]}

The example is quite simple to state:

\begin{equation*}
\label{eq:1}
maximize \sum_{j=1}^{n} 2^{n-j} x_j
\end{equation*}
\begin{equation*}
\label{eq:2}
subject \ to \sum_{j=1}^{n} 2^{i-j} x_j + x_i \le 100^{i-1} \quad i = 1, 2, \dots, n
\end{equation*}
\begin{equation*}
\label{eq:3}
x_j \ge 0 \quad j = 1, 2, \dots, n.
\end{equation*}

It is instructive to look closely at the constraints. The first three constraints are

\begin{align*}
x_1 &\le 1 \\
4x_1 + x_2 &\le 100 \\
8x_1 + 4x_2 + x_3 &\le 10,000.
\end{align*}

\textbf{Description:}

This slide presents a worst-case example for the Simplex method in linear programming, known as the Klee-Minty example (1970).  It defines a maximization problem with a specific objective function and a set of constraints.  The constraints are defined recursively, with each constraint involving variables from previous constraints.  The example is designed to demonstrate the potential for the Simplex method to take a very large number of iterations in the worst case. The slide highlights the constraints, showing how they are structured.  This is a crucial part of the example, as it demonstrates the specific structure that leads to the worst-case behavior.
