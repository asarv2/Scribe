\textbf{Sensitivity Analysis (what if $c$, $b$ change)}

\vspace{0.5cm}

$(P) \quad \text{max} \quad \mathcal{S} = c^T x$
\vspace{0.5cm}
s.t. $\quad Ax \le b$
\vspace{0.5cm}
$\quad x \ge 0$

\vspace{0.5cm}

$(D) \quad \text{min} \quad \mathcal{S} = b^T y$
\vspace{0.5cm}
s.t. $\quad A^T y \ge c$
\vspace{0.5cm}
$\quad y \ge 0$

\vspace{0.5cm}

at opt. $\mathcal{S} = c^T x^* = b^T y^*$

\vspace{0.5cm}

If only $c$ changes:

$\Delta \mathcal{S} = (\Delta c)^T x^*$

\vspace{0.5cm}

If only $b$ changes:

$\Delta \mathcal{S} = (\Delta b)^T y^*$

$y^*$: Shadow prices

\vspace{0.5cm}

$\mathcal{S}^* = c_B^T B^{-1} b$

$\Delta \mathcal{S}^* = c_B^T (\Delta B^{-1}) b + c_B^T B^{-1} (\Delta b)$
