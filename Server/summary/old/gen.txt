Key Terms and Definitions
Primal Problem (P): A linear programming problem seeking to maximize a linear objective function subject to linear constraints. Mathematically represented as: Maximize CX subject to AX ≤ b and X ≥ 0. (X represents the decision variables, C the coefficients of the objective function, A the constraint matrix, and b the right-hand side vector.)
Dual Problem (D): A linear programming problem derived from the primal problem, seeking to minimize a different linear objective function subject to different linear constraints. Mathematically represented as: Minimize bTY subject to ATY ≥ CT and Y ≥ 0. (Y represents the dual variables, b the right-hand side vector of the primal, A the constraint matrix, and C the coefficients of the primal objective function.)
Simplex Method: An iterative algorithm used to solve linear programming problems, including both primal and dual problems. It systematically moves from one feasible solution to another, improving the objective function value until an optimal solution is found.
Dual Simplex Method: A variation of the simplex method specifically designed for solving dual problems. It starts from a feasible dual solution and iteratively improves it.
Feasible Solution: A solution to a linear programming problem that satisfies all the constraints.
Optimal Solution: A feasible solution that maximizes (in the primal) or minimizes (in the dual) the objective function.
Entering Variable: In the simplex method, the variable that enters the basis in the next iteration, chosen to improve the objective function value.
Leaving Variable: In the simplex method, the variable that leaves the basis in the next iteration, chosen to maintain feasibility.
Basic Variables: Variables that are part of the current basis in the simplex method.
Non-basic Variables: Variables that are not part of the current basis in the simplex method.
Matrix Representation: A way to express the primal and dual problems using matrices and vectors, making the relationships between them clearer.
Complementary Slackness: A theorem stating the relationship between the optimal solutions of the primal and dual problems. It provides conditions that must be satisfied by the optimal primal and dual variables. Specifically, if a primal variable is positive, its corresponding dual constraint must be binding (equality), and vice versa.
Weak Duality: A theorem stating that if a feasible solution exists for the primal problem, then a feasible solution exists for the dual problem, and the objective function value of the primal is always less than or equal to the objective function value of the dual.
Strong Duality: A theorem stating that if the primal problem has an optimal solution, then the dual problem also has an optimal solution, and the optimal objective function values of both problems are equal.
Duality Gap: The difference between the optimal objective function values of the primal and dual problems. Strong duality states that the duality gap is zero if an optimal solution exists for either problem.
Diet Problem: A specific type of linear programming problem where the goal is to determine the optimal combination of foods to meet nutritional requirements at minimum cost.
Infeasible Problem: A problem where no feasible solution exists.
Unbounded Problem: A problem where the objective function can be improved indefinitely without violating any constraints.
Neg Transpose Property: The relationship between the primal and dual problems where the constraint matrix of the dual is the negative transpose of the constraint matrix of the primal.
