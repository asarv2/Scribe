Summary

Key Terms

  • Dictionary Dictionary: A representation of a linear programming problem where basic variables are expressed as functions of non-basic variables.
  • Auxiliary Problem Auxiliary Problem: A modified linear programming problem introduced to find a feasible starting point for the Simplex method when the origin is not feasible.
  • Complementary Slackness Complementary Slackness: A condition that holds at the optimal solution of a linear programming problem and its dual, stating that the product of a primal variable and its corresponding dual slack variable is zero.
  • Smallest Ball Problem Smallest Ball Problem: Finding the smallest radius ball that encloses a set of points in a d-dimensional space.
  • Machine Scheduling Machine Scheduling: The problem of assigning jobs to machines to minimize the total completion time.
  • Knapsack Problem Knapsack Problem: The problem of selecting a subset of items with weights and values to maximize the total value without exceeding a weight capacity.
  • Cutting Stock Problem Cutting Stock Problem: The problem of cutting large rolls of material into smaller rolls to minimize waste.
  • Sparse Solutions of Linear System Sparse Solutions of Linear System: Finding a solution to a linear system with a limited number of non-zero elements.
  • $l_1$ Norm $l_1$ Norm: The sum of the absolute values of the elements of a vector.
  • Subtrees (Ι and ΙΙ) Subtrees (Ι and ΙΙ): Two disjoint trees resulting from removing a leaving arc from a spanning tree in the dual network simplex method.
  • Parametric Self-Dual Method Parametric Self-Dual Method: A method that interweaves primal and dual pivot steps to solve linear programming problems by reducing a perturbation parameter.

Problem Types

  • Finding an Initial Feasible Solution Finding an Initial Feasible Solution: The problem of finding a feasible solution to start the Simplex method, especially when the origin is not feasible. An auxiliary problem is introduced to find a feasible starting point.
  • Handling Infeasible Origins Handling Infeasible Origins: Addressing situations where the origin (0,0) is not a feasible solution to the linear programming problem. This requires the use of an auxiliary problem to find a feasible starting point for the Simplex method.
  • Deriving Complementary Slackness from Primal-Dual Relationships Deriving Complementary Slackness from Primal-Dual Relationships: This problem involves demonstrating the complementary slackness conditions by manipulating the equations representing the primal and dual objective functions.
  • Understanding Complementary Slackness Understanding Complementary Slackness: This problem involves understanding and applying the complementary slackness conditions, which relate the optimal solutions of the primal and dual problems.
  • Finding the Smallest Enclosing Ball Finding the Smallest Enclosing Ball: This problem aims to find the smallest radius ball that contains all given points in a d-dimensional space.
  • Machine Scheduling Machine Scheduling: Determining the optimal order to process printing jobs on different machines to minimize the total processing time.
  • Knapsack Problem Knapsack Problem: Selecting a subset of items with weights and values to maximize the total value while not exceeding a weight capacity.
  • Cutting Stock Problem Cutting Stock Problem: Determining how to cut large rolls of paper into smaller rolls of various widths to minimize waste while meeting customer demands.
  • Sparse Solutions of Linear System Sparse Solutions of Linear System: Finding a solution to an underdetermined system of linear equations that has a limited number of non-zero elements.
  • Applying the Primal Simplex Method to Network Flows Applying the Primal Simplex Method to Network Flows: This problem involves using the primal simplex method to iteratively improve a feasible tree solution until an optimal solution is found.
  • Dual Network Simplex Method Dual Network Simplex Method: This problem involves finding an optimal solution starting from a dual feasible but not necessarily primal feasible solution.
  • Handling Infeasible Solutions Handling Infeasible Solutions: This problem addresses strategies for finding feasible solutions when the initial solution is infeasible, either primal or dual.
  • Setting up a Linear Program for Solution Setting up a Linear Program for Solution: This problem involves formulating a linear program in matrix form, identifying the basis and non-basic variables, and preparing it for solution using an algorithm like the simplex method.

Algorithm Solutions

  • Auxiliary Problem Auxiliary Problem: Introduce a new variable $x_0$ and modify constraints to create a new problem where the origin is feasible. Solve this auxiliary problem to find a feasible solution for the original problem. If the optimal solution to the auxiliary problem has $x_0 = 0$, then this solution is feasible for the original problem.
  • Complementary Slackness Complementary Slackness: If $x^$ is optimal for (P) and $\lambda^$ is optimal for (D), then $x^_i \lambda^_i = 0$ for all $i$
  • Machine Scheduling Machine Scheduling: $\min \pi$ s.t. $\sum_{i \in M} x_{ij} = 1$ for $j \in J$, $\sum_{j \in J} d_{ij} x_{ij} \le \pi$ for $i \in M$, $x_{ij} \in \{0, 1\}$ for all $i, j$
  • Knapsack Problem Knapsack Problem: maximize $\sum_{j=1}^n c_j x_j$ subject to $\sum_{j=1}^n a_j x_j \le b$, $x_j \in \{0, 1\}$, $j = 1, 2, \dots, n$
  • Cutting Stock Problem Cutting Stock Problem: $\min x_1 + x_2 + \dots + x_{12}$ subject to constraints based on cutting patterns $P_i$ and demand for each roll width
  • Sparse Solutions of Linear System Sparse Solutions of Linear System: $\min \|x\|_1$ s.t. $Ax = b$
  • Primal Simplex Method for Network Flows Primal Simplex Method for Network Flows: Iteratively identify an entering variable (arc with most negative reduced cost), a leaving variable (arc in the cycle formed by the entering variable and the spanning tree), update the spanning tree, and update primal and dual variables until all dual slacks are non-negative.
  • Network Simplex Method (Dual) Network Simplex Method (Dual): Find a spanning tree T. Iteratively choose a leaving arc with $x_{ij} < 0$. The entering arc bridges the two subtrees in the opposite direction of the leaving arc and has the smallest dual slack.
  • Two-Phased Network Simplex Method Two-Phased Network Simplex Method: Artificially alter costs to ensure dual feasibility of an initial tree solution, then use the primal network simplex method to find an optimal solution. Alternatively, alter supplies to ensure primal feasibility, find a dual feasible solution, and then use the dual network simplex method to optimize.
  • Parametric Self-Dual Network Simplex Method Parametric Self-Dual Network Simplex Method: Intertwine primal and dual pivots to reduce a perturbation parameter μ from ∞ to 0.
