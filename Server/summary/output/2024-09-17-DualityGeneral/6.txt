\section*{Equality Constraints}

\begin{itemize}
    \item \textbf{Primal Problem (P)}
    \begin{align*}
        \max \xi(x) &= f_0(x) \\
        \text{s.t.} \quad g_j(x) &= 0, \quad j=1,2,\dots,n
    \end{align*}
    \item \textbf{Dual Problem (D)}
    \begin{align*}
        \min \xi(\mu) &= \max_{x \in \mathbb{R}^n} [f_0(x) - \sum_{j=1}^n \mu_j g_j(x)]
    \end{align*}
    \item \textbf{Weak Duality}
    \begin{align*}
        \max_{x \in \mathcal{G}} \xi(x) &\le \min_{\mu} \xi(\mu)
    \end{align*}
\end{itemize}

\textbf{Description:}

This slide formally defines the primal and dual problems in the context of linear programming, focusing on equality constraints.  It explicitly shows the objective function and constraints for both problems.  The primal problem (P) is to maximize the objective function $\xi(x) = f_0(x)$ subject to the equality constraints $g_j(x) = 0$ for $j = 1, 2, \dots, n$.  The dual problem (D) is to minimize the function $\xi(\mu)$ which is defined as the maximum of the Lagrangian function over all possible values of $x$.  The key takeaway is the statement of the Weak Duality Theorem, which states that the optimal value of the primal problem ($\max_{x \in \mathcal{G}} \xi(x)$) is always less than or equal to the optimal value of the dual problem ($\min_{\mu} \xi(\mu)$).  This is a fundamental result in linear programming duality.
