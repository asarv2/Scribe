Slide 10

\textbf{Portfolio Selection (Markowitz Model)}

\newline
\textit{[LV] ch. 13}

\newline
(1) $R_i$ - (annual) return of $i^{th}$ investment (a random Variable)

\newline
(2) $X_i$ - proportion of investment in $i$ ($X_i \ge 0$, $\sum_{j} X_j = 1$)

\newline
$\max \sum_{j} X_j R_j$  \hspace{0.5cm} (random)

\newline
$\max \sum_{j} X_j \overline{R_j} - \epsilon \sum_{j} X_j \tilde{R_j}$ \hspace{0.5cm} (average return - risk)

\newline
$\tilde{R_j} = R_j - \overline{ER_j}$ \hspace{0.5cm} (fluctuation)


\textbf{Description:}

This slide extends the portfolio selection model from the previous slide.  It introduces a new objective function that now includes a risk term.  The objective is to maximize the expected return of the portfolio ($\sum_{j} X_j \overline{R_j}$) while minimizing the portfolio's risk ($\sum_{j} X_j \tilde{R_j}$).  The new term $\tilde{R_j}$ represents the fluctuation of the return of investment $j$ around its expected return $\overline{ER_j}$.  This modification to the objective function allows for the optimization of portfolios that balance expected return with risk.  The slide is likely part of a lecture or presentation explaining how to use linear programming to optimize investment portfolios, considering both return and risk.
