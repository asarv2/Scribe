\textbf{Sparse Solutions of Linear System}

\newline
\textit{[EMG] p. 167}

\newline
Sparse solution of underdetermined system of linear equations

\newline
Given an $m \times n$ matrix $A$ with $m < n$, a vector $b \in \mathbb{R}^m$, and an integer $r$, find an $x \in \mathbb{R}^n$ such that $Ax = b$ and $|supp(x)| \le r$

\newline
if one exists.

\newline
($|supp(x)| = \# \{i: x_i \ne 0\}$)

\newline
$\min \|x\|_1$

\newline
s.t.
\newline
$Ax = b$

\textbf{Description:}

This slide illustrates the $l_1$ norm minimization problem in a 2-dimensional space.  The graph shows a diamond shape, which represents the set of all vectors $x = (x_1, x_2)$ that satisfy the constraint $\|x\|_1 = |x_1| + |x_2| = 1$.  The vertices of the diamond are at (1,0), (-1,0), (0,1), and (0,-1).  The problem is to find the vector $x$ within this diamond that minimizes the $l_1$ norm while satisfying the constraint $Ax = b$.  This visual representation helps to understand the geometry of the problem and how the $l_1$ norm minimization leads to a sparse solution.
