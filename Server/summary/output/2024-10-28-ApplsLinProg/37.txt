\textbf{Sparse Solutions of Linear System}

\newline
\textit{[EMG] p. 167}

\newline
Sparse solution of underdetermined system of linear equations

\newline
Given an $m \times n$ matrix $A$ with $m < n$, a vector $b \in \mathbb{R}^m$, and an integer $r$, find an $x \in \mathbb{R}^n$ such that $Ax = b$ and $|supp(x)| \le r$

\newline
if one exists.

\newline
($|supp(x)| = \# \{i: x_i \ne 0\}$)

\newline
$\min \|x\|_1$

\newline
s.t.
\newline
$Ax = b$

\newline
Geometric Interpretation:

\newline
\begin{itemize}
\item The set of solutions to $Ax = b$ is an affine subspace.
\item The $l_1$ norm minimization problem finds the solution in the affine subspace that is closest to the origin in the $l_1$ norm.
\end{itemize}

\newline

\newline
$\|x\|_1 = |x_1| + |x_2| = 1$

\newline
The solution is at the intersection of the line $Ax = b$ and the diamond $\|x\|_1 = 1$.
