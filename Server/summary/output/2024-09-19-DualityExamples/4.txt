\textbf{Description:}

This slide builds upon the previous slide's table representation of the diet problem.  It now includes a new row at the bottom of the table, labeled with the costs ($c_j$) of each food ($F_j$).  This bottom row is crucial for the objective function in the linear programming formulation of the diet problem.  The table now explicitly shows the coefficients for the objective function, which is to minimize the total cost of the food consumed.  The values in the table ($a_{ij}$) represent the amount of nutrient $i$ in one unit of food $j$.  The values in the bottom row ($c_j$) represent the cost of each food.  The values in the rightmost column ($b_i$) represent the minimum required intake of each nutrient.  This complete table is now ready to be used to formulate the linear programming problem.
