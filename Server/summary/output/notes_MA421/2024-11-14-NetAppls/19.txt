\section*{Shortest Path Problem (Bellman's Eqn)}

Approximation/Iteration:
\begin{itemize}
    \item $k = 0$, $v_r^{(0)} = 0$, $v_i^{(0)} = +\infty$, $i \neq r$
    \item $k \ge 0$, $v_r^{(k)} = 0$, $v_i^{(k+1)} = \min_j \{c_{ij} + v_j^{(k)}\}$, $i \neq r$
    \item $v_i^{(k)}$ = shortest path from $i$ to $r$, with $\le k$ arcs.
    \item Needs at most $m$ iterations, $m = \#$ of nodes
\end{itemize}

**Description:**

This slide continues the iterative approximation method for finding the shortest path using Bellman's equation.  The notation $v_i^{(k)}$ represents an approximation of the shortest distance from node $i$ to the destination node $r$ at iteration $k$.  The initial step ($k = 0$) sets the distance to the destination node $r$ to zero ($v_r^{(0)} = 0$) and the distances to all other nodes to infinity ($v_i^{(0)} = +\infty$, $i \neq r$).  Subsequent iterations ($k \ge 0$) update the distance estimates for each node ($v_i^{(k+1)}$) by considering the shortest path from the source to node $i$ that passes through an adjacent node $j$.  The cost of the edge from $i$ to $j$ is $c_{ij}$, and $v_j^{(k)}$ is the shortest distance from node $j$ to the destination node $r$ at iteration $k$.  This iterative process continues until the shortest distances converge.  The slide also states that the algorithm needs at most $m$ iterations, where $m$ is the number of nodes in the graph.  This is a dynamic programming approach to solving the shortest path problem.  The notation is consistent with the previous slides, which have shown a graph structure for the shortest path problem.  The addition of the statement about the maximum number of iterations is important for understanding the algorithm's termination condition.
