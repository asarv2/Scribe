\textbf{Sparse Solutions of Linear System}

\newline
\textit{[EMG] p. 167}

\newline
Sparse solution of underdetermined system of linear equations

\newline
Given an $m \times n$ matrix $A$ with $m < n$, a vector $b \in \mathbb{R}^m$, and an integer $r$, find an $x \in \mathbb{R}^n$ such that $Ax = b$ and $|supp(x)| \le r$

\newline
if one exists.

\newline
($|supp(x)| = \# \{i: x_i \ne 0\}$)

\newline
Recovery of Signals with noise:

\newline
$w \in \mathbb{R}^k \implies$ encode $\implies z = Q w$

\newline
$z \implies$ transmit $\implies z_2 = z + x$ (noise: only a few zeros)

\newline
Given $z_2$, how to recover $z$?

\newline
$Az = Q w + x$

\newline
$A \tilde{z} = A Q w + A x = b$ given

\newline
$\tilde{z} = z + x \implies z = \tilde{z} - x$

\newline
Find $x$ with as few non-zeros as possible
