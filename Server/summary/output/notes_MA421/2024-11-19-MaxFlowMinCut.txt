\textbf{Proof of Max Flow = Min Cut}

\begin{itemize}
    \item Let $x_{ij}^*$ be a (optimal) max flow
    \item Let $C^*$ be those nodes that some more flow can be pushed from $s$.
    \item $t \notin C^*$ (By default, $s \in C^*$)
\end{itemize}

\textbf{Claim}
Flow ($C^*$ to $C^{*c}$) = $K(C^*)$
$\sum_{i \in C^*, j \notin C^*} x_{ij}^* = \sum_{i \in C^*, j \notin C^*} u_{ij}$

\textbf{Description:}

This slide presents the proof of the max-flow min-cut theorem.  It outlines the steps in the proof.  The first bullet points define the optimal maximum flow ($x_{ij}^*$) and the set of nodes ($C^*$) that can receive additional flow from the source ($s$).  The second bullet point states that the sink ($t$) is not in the set $C^*$.  The claim states that the flow from the set $C^*$ to its complement ($C^{*c}$) is equal to the capacity of the cut $C^*$, which is expressed as a summation of the capacities of the edges crossing the cut.  This is a crucial step in the formal proof of the theorem.  The notation $x_{ij}^*$ represents the optimal flow values, and $u_{ij}$ represents the capacities of the edges.  The sets $C^*$ and $C^{*c}$ are subsets of the nodes in the network.

Slide 12

\textbf{Ford - Fulkerson Algorithm (Augmented Path)}

\textbf{Implementations}

Our description of the augmenting path method does not specify a way of searching
for the arcs $ij$ such that $i \in C, j \notin C, x_{ij} < u_{ij}$, and the arcs $ji$ such that $j \in C, i \in C$.
For Ford and Fulkerson did specify a way of doing that. In their terminology,
nodes in $C$ are called labeled and nodes outside $C$ are called unlabeled; the source is labeled
but unscanned and all the remaining nodes are unlabeled. Scanning a labeled node
$i$ means examining all the arcs $ij$ and, whenever such an arc satisfies $x_{ij} < u_{ij}, j \notin C$, setting $j \in C, p(j) = i$. The search may be described as in Box 22.1.

\textbf{BOX 22.1} Search for an Augmenting Path

Step 0. Mark $s$ as labeled, unscanned; mark the remaining nodes as
unlabeled.

Step 1. If all the labeled nodes are scanned then stop [the set $C$ of labeled
nodes satisfies (22.7) and (22.8)]; otherwise, choose a labeled unscanned
node $i$.

Step 2. Scan $i$. If $i$ has become labeled then stop (an $x$-augmenting path
has been found); otherwise return to step 1.


\textbf{Description:}

This slide describes the implementation details of the Ford-Fulkerson algorithm for finding the maximum flow in a network.  It explains how to search for augmenting paths. \textbf{Max Flow Min Cut (LP Formulation)}

\begin{align*}
\min -x_{ts} \\
\text{s.t.} \quad x_{ts} &= \sum_{j} x_{sj} \\
\sum_{i} x_{it} &= x_{ts} \\
\sum_{j} x_{kj} &= \sum_{i} x_{ik} \quad k \neq s, t \\
0 \le x_{ij} &\le u_{ij} \\
(u_{ts} &= +\infty)
\end{align*}

\textbf{Description:}

This slide presents the linear programming (LP) formulation of the maximum flow problem.  The objective function is to minimize $-x_{ts}$, which is equivalent to maximizing $x_{ts}$.  The constraints ensure flow conservation at each node and limit the flow on each edge to its capacity.  The constraint $x_{ts} = \sum_{j} x_{sj}$ represents the flow into the sink node $t$ from the source node $s$.  The constraint $\sum_{i} x_{it} = x_{ts}$ represents the flow out of the sink node $t$.  The constraint $\sum_{j} x_{kj} = \sum_{i} x_{ik}$ represents flow conservation at all intermediate nodes $k$.  The constraint $0 \le x_{ij} \le u_{ij}$ limits the flow on each edge $ij$ to its capacity $u_{ij}$.  The constraint $u_{ts} = +\infty$ indicates that the flow along the fictitious arc from the source to the sink has no capacity limit.  This LP formulation is used to solve the maximum flow problem.
