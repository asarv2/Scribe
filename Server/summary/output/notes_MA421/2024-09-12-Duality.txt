Slide 1

\textbf{Primal and Dual Problems}

\begin{itemize}
    \item[(P)]
    \begin{align*}
        \max \ \sum(x) &= c^T x \\
        \text{subject to} \quad Ax &\le b \\
        x &\ge 0
    \end{align*}
    \item[(D)]
    \begin{align*}
        \min \ \sum(y) &= b^T y \\
        \text{subject to} \quad A^T y &\ge c \\
        y &\ge 0
    \end{align*}
    \begin{center}
        $\iff$
    \end{center}
    \begin{align*}
        \max \ -\sum(y) &= -b^T y \\
        \text{subject to} \quad (A^T)y &\le c \\
        y &\ge 0
    \end{align*}
\end{itemize}

\textbf{Description:}

This slide introduces the primal and dual problems in linear programming.  It shows the standard forms of both problems.  The primal problem (P) seeks to maximize a linear function ($c^T x$) subject to linear inequality constraints ($Ax \le b$) and non-negativity constraints ($x \ge 0$). The dual problem (D) seeks to minimize a different linear function ($b^T y$) subject to different linear inequality constraints ($A^T y \ge c$) and non-negativity constraints ($y \ge 0$).  Importantly, the slide highlights the equivalence between the dual problem and a maximization problem with the opposite objective function and reversed inequality constraints.  The arrow between the two dual problem formulations indicates the transformation. This is a fundamental concept in linear programming, as solving one problem can often provide information about the solution to the other.  The slide is likely the first step in a lecture series on duality in linear programming.


Slide 2

\textbf{Primal and Dual Problems}

\begin{itemize}
    \item[(P)]
    \begin{align*}
        \max \ \sum_{j} c_j x_j &= c^T x \\
        \text{subject to} \quad \sum_{j} a_{ij} x_j &\le b_i, \quad i = 1, \dots, m \\
        x_j &\ge 0, \quad j = 1, \dots, n
    \end{align*}
    \item[(D)]
    \begin{align*}
        \min \ \sum_{i} b_i y_i &= b^T y \\
        \text{subject to} \quad \sum_{i} a_{ij} y_i &\ge c_j, \quad j = 1, \dots, n \\
        y_i &\ge 0, \quad i = 1, \dots, m
    \end{align*}
\end{itemize}

\textbf{Theorem 5.1: Weak Duality}
\begin{center}
    $\sum_{j} c_j x_j \le \sum_{i} b_i y_i$
\end{center}

\textbf{Description:}

This slide builds upon the previous one by providing a more detailed representation of the primal and dual linear programming problems.  It explicitly shows the summation notation for the constraints, making the relationship between the primal and dual variables more apparent.  The indices ($i$ and $j$) are introduced, indicating the rows and columns of the constraint matrix $A$.  Crucially, the slide introduces Theorem 5.1, "Weak Duality," which states that the objective function value of the primal problem is always less than or equal to the objective function value of the dual problem for any feasible solutions to both problems. This is a fundamental result in linear programming duality theory. The slide likely follows the previous slide, which introduced the primal and dual problems in a more general form, and now provides a more specific and practical formulation.  The use of summation notation and explicit indices is a key step in understanding the mathematical structure of the problems.

If (P) has an optimal solution ($x_j^*$)
\newline
Then (D) also has an optimal solution ($y_i^*$)
\newline
and
\newline
$(\mathcal{S}^* = \sum_{j} c_j x_j^* = \sum_{i} b_i y_i^* (\mathcal{S}^*))$
\newline
i.e. duality gap = 0
\newline
(The proof gives a formula for $y_i^*$)

\textbf{Description:}

This slide states the Strong Duality Theorem for linear programming.  It asserts that if the primal problem (P) has an optimal solution, then the dual problem (D) also has an optimal solution, and the optimal values of the objective functions for both problems are equal.  This is a stronger result than the Weak Duality Theorem, which only guarantees an upper bound on the dual objective function value.  The slide likely follows a discussion of the simplex method and the negative transpose property, and now introduces the concept of strong duality, which is a fundamental result in linear programming.  The notation $\mathcal{S}^*$ represents the optimal value of the objective function for the primal problem.  The notation $x_j^*$ and $y_i^*$ represent the optimal values of the primal and dual variables, respectively. The final statement suggests that the proof of the theorem provides a way to calculate the optimal dual variables given the optimal primal variables.
