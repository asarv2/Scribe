\textbf{Description:}

This is a lecture slide on the efficiency of the Simplex method in linear programming.  It presents two tables (Tables 4.1 and 4.2) that show the average number of iterations required by different rules (Largest-Coefficient Rule and Largest-Increase Rule) for various problem sizes (m and n).  The tables are indexed by the number of constraints (m) and the number of variables (n).  The values in the tables represent the average number of iterations needed to solve the linear programming problem. The slide also includes a handwritten statement about the worst-case and average-case performance of the Simplex method, along with the conditions under which these results hold.  The source of the data in the tables is cited.
