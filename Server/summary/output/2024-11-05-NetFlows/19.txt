\textbf{Spanning Trees and Bases}

For example, let node "g" be the root node in the spanning tree in Figure 14.6. Starting with it, we compute the dual variables as follows:

\begin{itemize}
    \item across arc (g,e): $y_e - y_g = 19 \implies y_e = 19$
    \item across arc (g,b): $y_b - y_g = 33 \implies y_b = 33$
    \item across arc (b,c): $y_c - y_b = 65 \implies y_c = 98$
    \item across arc (f,b): $y_b - y_f = 48 \implies y_f = -15$
    \item across arc (f,a): $y_a - y_f = 56 \implies y_a = 41$
    \item across arc (a,d): $y_d - y_a = 28 \implies y_d = 69$
\end{itemize}
