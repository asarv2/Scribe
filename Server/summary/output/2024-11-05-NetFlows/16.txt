\textbf{Spanning Trees and Bases}

\textbf{Example 14.1}

Consider the network in Figure 14.12.  We want to find a spanning tree.

\begin{enumerate}
    \item Select a root node.  Let's choose node $f$.
    \item Remove the row corresponding to the root node from the incidence matrix $A$.  This gives us $\tilde{A}$.
    \item Remove the entry corresponding to the root node from the supply/demand vector $b$.  This gives us $\tilde{b}$.
\end{enumerate}

\textbf{Finding a Basis}

A square submatrix of $\tilde{A}$ is a basis if and only if the arcs to which its columns correspond form a spanning tree.
