\section*{Shortest Path Problem (Bellman's Eqn)}

$v_i$ = shortest distance from $i$ to $r$

$v_i = \min_{j} \{c_{ij} + v_j\}$
$v_r = 0$

\end{document}

**Description:**

This slide presents Bellman's equation for the shortest path problem.  $v_i$ represents the shortest distance from node $i$ to the destination node $r$.  The equation $v_i = \min_{j} \{c_{ij} + v_j\}$ defines how to calculate the shortest distance to a node $i$ by considering all possible paths that end at node $i$.  The cost of the edge from node $i$ to node $j$ is $c_{ij}$, and $v_j$ is the shortest distance from node $j$ to the destination node $r$.  The equation $v_r = 0$ sets the shortest distance from the destination node $r$ to itself to zero.  This is a recursive definition, crucial for dynamic programming algorithms that solve the shortest path problem.  The notation is consistent with the previous slides, which have shown a graph structure for the shortest path problem.
