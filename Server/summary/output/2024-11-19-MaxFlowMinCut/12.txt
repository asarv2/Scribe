\textbf{Ford - Fulkerson Algorithm (Augmented Path)}

\textbf{Implementations}

Our description of the augmenting path method does not specify a way of searching
for the arcs $ij$ such that $i \in C, j \notin C, x_{ij} < u_{ij}$, and the arcs $ji$ such that $j \in C, i \in C$.
For Ford and Fulkerson did specify a way of doing that. In their terminology,
nodes in $C$ are called labeled and nodes outside $C$ are called unlabeled; the source is labeled
but unscanned and all the remaining nodes are unlabeled. Scanning a labeled node
$i$ means examining all the arcs $ij$ and, whenever such an arc satisfies $x_{ij} < u_{ij}, j \notin C$, setting $j \in C, p(j) = i$. The search may be described as in Box 22.1.

\textbf{BOX 22.1} Search for an Augmenting Path

Step 0. Mark $s$ as labeled, unscanned; mark the remaining nodes as
unlabeled.

Step 1. If all the labeled nodes are scanned then stop [the set $C$ of labeled
nodes satisfies (22.7) and (22.8)]; otherwise, choose a labeled unscanned
node $i$.

Step 2. Scan $i$. If $i$ has become labeled then stop (an $x$-augmenting path
has been found); otherwise return to step 1.


\textbf{Description:}

This slide describes the implementation details of the Ford-Fulkerson algorithm for finding the maximum flow in a network.  It explains how to search for augmenting paths.  The algorithm labels nodes in the network and scans arcs to find paths where flow can be increased.  The algorithm's steps are outlined in Box 22.1.  The algorithm's logic is crucial for finding the maximum flow in a network.  The notation $x_{ij}$ represents the flow along edge $ij$, and $u_{ij}$ represents the capacity of edge $ij$.  The set $C$ contains labeled nodes, and $C^c$ is the complement of $C$.  The algorithm is part of a larger presentation on linear programming and network flow problems.
