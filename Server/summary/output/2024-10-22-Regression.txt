\section*{Regression}

\textbf{Given} $x_1, x_2, ..., x_m$  $\{$ $x_i \in \mathbb{R}$\}

\begin{enumerate}
    \item
    \begin{equation*}
    \min_x \frac{1}{m} \sum_{i=1}^m (x-x_i)^2 \implies x = \frac{x_1 + ... + x_m}{m}
    \end{equation*}
    \textit{(mean)}
    \item
    \begin{equation*}
    \min_x \frac{1}{m} \sum_{i=1}^m |x-x_i| \implies x = \text{median}
    \end{equation*}
    \item
    \begin{equation*}
    \min_x \left( \max_{i} |x-x_i| \right) \implies x = \frac{\min x_i + \max x_i}{2}
    \end{equation*}
    \textit{"mid-range"}
\end{enumerate}

\end{document}

It shows how to calculate the mean, median, and mid-range values as estimators for a central tendency.  The notation indicates that $x_1, x_2, ..., x_m$ are data points, and $x$ is the value being estimated.  The slide uses $L^2$-error, $L^1$-error, and $L^\infty$-error as the error functions.  The slide number and the use of (1), (2), and (3) suggest this is part of a larger lecture series on regression or linear programming.  The handwritten style and the use of mathematical notation indicate a lecture setting.

```latex
\documentclass{article}

\begin{document}

\textbf{L\textsuperscript{2} Regression (Least Square)}

\begin{equation*}
\min_{(x_1, \dots, x_n)} \sum_{i=1}^m \left| (b_i - \sum_{j=1}^n a_{ij} x_j) \right|^2
\end{equation*}

\begin{equation*}
\min \left\| b - AX \right\|_2^2
\end{equation*}

$AX = b$ (might not be solvable)

$A^T A \hat{X} = A^T b$ (normal equation, always solvable)

$\hat{X} = (A^T A)^{-1} A^T b$ (if $(A^T A)^{-1}$ exists)

\end{document}
```

The slide highlights the normal equation ($A^T A \hat{X} = A^T b$) as a way to solve for the optimal parameters ($\hat{X}$), which is always solvable.  The final equation shows the solution for $\hat{X}$ in terms of matrix operations, requiring the inverse of $(A^T A)$.  The handwritten style and mathematical notation indicate a lecture setting. \textbf{Lagrangian Formulation of SVM}

```latex
\begin{equation*}
\min_{\alpha} \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j x_i^T x_j - \sum_{i=1}^N \alpha_i
\end{equation*}

s.t.
\begin{equation*}
\sum_{i=1}^N \alpha_i y_i = 0
\end{equation*}
\begin{equation*}
0 \le \alpha_i \le C, \quad \forall i
\end{equation*}

\end{document}
```

\textbf{Description:}

This slide presents the Lagrangian formulation of the Support Vector Machine (SVM) problem.  It shows the objective function for minimizing a quadratic form involving the Lagrange multipliers ($\alpha_i$) and the data points ($x_i$).  The constraints ensure that the sum of the Lagrange multipliers weighted by the target values ($y_i$) is zero, and that the Lagrange multipliers are bounded between 0 and C.  The handwritten style and mathematical notation indicate a lecture setting.  The context implies that this is part of a linear programming lecture, where the goal is to derive the dual form of the SVM optimization problem.  The slide number (11 of 22) suggests this is a later part of the lecture, building on the previous discussion of SVMs and their geometric interpretation.  The Lagrangian formulation is a crucial step in solving the SVM problem using quadratic programming techniques.  The parameter C is a regularization parameter that controls the trade-off between maximizing the margin and minimizing the classification error.
