Slide 8

(I) Improve (0) ($x_1=0$, $x_2=0$)

$\max \mathcal{Z} = 3x_1 + 2x_2$
subject to
$\omega_1 = 12 + x_1 - 3x_2$
$\omega_2 = 8 - x_1 - x_2$
$\omega_3 = 10 - 2x_1 + x_2$
$x_1, x_2, x_3, \omega_1, \omega_2, \omega_3 \ge 0$

Set $x_1 = 3$, $\implies$
$\omega_1: \quad 12 + x_1 - 3x_2 = 12 + 3 - 3(0) = 15$
$\omega_2: \quad 8 - x_1 - x_2 = 8 - 3 - 0 = 5$
$\omega_3: \quad 10 - 2x_1 + x_2 = 10 - 2(3) + 0 = 4$
$\implies \mathcal{Z} = 3(3) + 2(0) = 9$

$A = (x_1=3, x_2=0, w_3=0)$

\textbf{Description:}

This slide demonstrates the first iteration of the Simplex method, moving from the initial vertex (0,0) to a new vertex.  It shows how to increase $x_1$ while keeping $x_2$ at zero, based on the "max. coeff. rule".  The calculation shows the impact of this change on the slack variables ($\omega_1$, $\omega_2$, $\omega_3$) and the objective function ($\mathcal{Z}$).  The result is a new vertex A with coordinates ($x_1=3$, $x_2=0$) and a corresponding objective function value of 9.  The context suggests this is a step-by-step demonstration of the Simplex method's iterative process.
