\section*{(General) Vector Space $V$}

$V$ is called a vector space as long as you can define vector addition and scalar mult.
such that properties 1 - 8 hold.

\begin{enumerate}
    \item $\vec{u} + \vec{v} = \vec{v} + \vec{u}$
    \item $(\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})$
    \item $\alpha (\beta \vec{u}) = (\alpha \beta) \vec{u}$
    \item $\alpha (\vec{u} + \vec{v}) = \alpha \vec{u} + \alpha \vec{v}$
    \item $(\alpha + \beta) \vec{u} = \alpha \vec{u} + \beta \vec{u}$
    \item There is $\vec{0}$ such that $\vec{0} + \vec{u} = \vec{u}$
    \item For each $\vec{u}$, there is $-\vec{u}$ such that $\vec{u} + (-\vec{u}) = \vec{0}$
    \item $1\vec{u} = \vec{u}$
\end{enumerate}
