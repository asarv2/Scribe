\textbf{Linear Dependence and Independence}

Given a list of vectors, $\ell = \{u_1, u_2, \dots, u_k\}$

\textbf{Def 1:}

$\ell$ is called linearly dependent if one (some)
of the vectors can be written as lin. comb.
of the rest. (For example, $u_i = \sum_{j \neq i} c_j u_j$)

$\ell$ is called linearly independent if none
of the vectors can be written as lin. comb.
of the rest.


\textbf{Description:}

This slide introduces the concepts of linear dependence and independence for a set of vectors.  It defines a set of vectors as linearly dependent if at least one vector in the set can be expressed as a linear combination of the other vectors in the set.  Conversely, a set of vectors is linearly independent if no vector can be expressed as a linear combination of the other vectors.  The example given, $u_i = \sum_{j \neq i} c_j u_j$, illustrates a linearly dependent set, where one vector is a linear combination of the others.  This is a fundamental concept in linear algebra, often used in the context of linear programming to determine the dimensionality of the problem.
