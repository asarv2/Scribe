\section*{Matrix Multiplication}

\textit{"Formula"}
\begin{equation*}
(AX)_i = \sum_{k=1}^n a_{ik} x_k
\end{equation*}

\textit{Linearity Properties}
\begin{enumerate}
    \item $A(\alpha X + \beta Y) = \alpha AX + \beta AY$
    \item $(\alpha A + \beta B) X = \alpha AX + \beta BX$
\end{enumerate}

\textbf{Description:}

This slide continues the discussion of matrix multiplication, focusing on the linearity properties.  It defines how the $i$-th element of the resulting vector $AX$ is calculated using a summation.  The slide then presents two key linearity properties of matrix multiplication:  distributivity over vector addition (property 1) and distributivity over scalar multiplication (property 2).  These properties are fundamental to understanding how linear transformations behave under combinations of vectors and scalars.  The context suggests this is part of a larger lecture on linear programming, where matrix operations are crucial for defining and solving problems.
