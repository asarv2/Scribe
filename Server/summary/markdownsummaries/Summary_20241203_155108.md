
--- Key Terms ---
Linear programming involves optimizing a linear objective function subject to linear constraints.  The following terms describe key concepts and methods within this field:

* **Simplex Method:** An iterative algorithm that solves linear programming problems by systematically moving from one feasible solution to another, improving the objective function value at each step until an optimal solution is found.

* **Slack Variable:** A non-negative variable added to a less-than-or-equal-to constraint to convert it into an equality constraint.

* **Feasible Region:** The set of all points satisfying all constraints of a linear programming problem.

* **Basic Variable:** In the simplex method, a variable expressed as a function of non-basic variables in a given iteration.

* **Non-basic Variable:** In the simplex method, a variable set to zero in a given iteration.

* **Pivot Operation:** The process of exchanging a basic and a non-basic variable in the simplex method to move to a new vertex of the feasible region.

* **Dictionary:** A representation of a linear programming problem where basic variables are expressed as functions of non-basic variables.

* **Auxiliary Problem:** A modified linear programming problem used to find an initial feasible solution when the origin is not feasible in the original problem.

* **Largest-Coefficient Rule & Largest-Increase Rule:**  Pivot rules in the simplex method that select the entering variable based on the largest coefficient in the objective function row or the largest increase in the objective function value, respectively.

* **Klee-Minty Example:** A worst-case example demonstrating the simplex method's potential exponential time complexity for certain pivot rules.

* **Bland's Rule, Lexicographic Method, Randomized Pivot Rule:** Pivot rules designed to prevent cycling and ensure termination of the simplex method.

* **Smoothed Complexity:** A complexity measure considering the effect of small random perturbations on algorithm input.

* **Interior Method:** A class of linear programming algorithms traversing the interior of the feasible region, unlike the boundary-following simplex method.

* **Primal Problem & Dual Problem:**  A pair of linear programming problems, where the dual problem is derived from the primal and provides a bound on the primal's optimal solution.  The primal problem is typically a maximization problem, while the dual is a minimization problem.

* **Weak Duality & Strong Duality:** Theorems describing the relationship between the objective function values of feasible solutions to the primal and dual problems. Weak duality states that the primal objective function value is always less than or equal to the dual objective function value (for maximization problems). Strong duality states that if either problem has an optimal solution, then so does the other, and their optimal objective function values are equal.

* **Complementary Slackness:** A condition holding at optimality for primal and dual solutions, stating that the product of each primal variable and its corresponding dual slack variable is zero.

* **Negative Transpose Property:** The property that the coefficient matrix of the dual problem is the negative transpose of the coefficient matrix of the primal problem.

* **Objective Function:** The function to be maximized or minimized in a linear programming problem.

* **Constraints:** Restrictions or limitations on the values of the variables in a linear programming problem.

* **Equality Constraints & Inequality Constraints:** Constraints expressed as equalities or inequalities, respectively.

* **Feasible Region:** The set of all points satisfying the constraints of a linear programming problem.

* **Sensitivity Analysis & Parametric Analysis:** Techniques used to analyze how changes in objective function coefficients or constraint values affect the optimal solution.

* **Optimal Solution:** The set of variable values that maximizes (or minimizes) the objective function while satisfying all constraints.

* **Basic Variables & Non-basic Variables:**  Variables categorized within the simplex method; basic variables are non-zero and determine the current solution, while non-basic variables are set to zero.

* **Reduced Costs:** Values indicating how much the objective function would change if a non-basic variable were to become basic.

* **Right-hand Side (RHS) Values:** The constants on the right-hand side of the constraints in a linear programming problem.

* **Basis Matrix (B) & Inverse of the Basis Matrix (B⁻¹):** Matrices used in the simplex method; the basis matrix is formed by the columns corresponding to basic variables, and its inverse is used for efficient calculations.

* **Matrix Operations:** Mathematical operations involving matrices, extensively used in the simplex method.

* **Simplex Tableau:** A tabular representation of the linear programming problem used in the simplex method.

* **Dictionary:** A representation of the simplex tableau used to track variable values and the objective function during simplex iterations.

* **Auxiliary Problem:** A modified linear programming problem used to find an initial feasible solution for the simplex method when the origin is not feasible.

* **Convex Set, Convex Combination, Convex Hull:** Geometric concepts related to the feasible region in linear programming; a convex set contains all line segments between any two points within the set, a convex combination is a weighted average of points, and the convex hull is the smallest convex set containing a given set of points.

* **Caratheodory Theorem & Separation Theorem:** Theorems establishing properties of convex sets, crucial for understanding the structure of the feasible region.

* **Farkas' Lemma:** A fundamental theorem providing conditions for the existence or non-existence of solutions to systems of linear inequalities.

* **Mean, Median, Mid-range:** Measures of central tendency used in data analysis and regression.

* **Linear Regression, L² Regression (Least Squares), L¹ Regression, L∞ Regression:**  Methods for modeling the relationship between variables, differing in their error minimization approaches.

* **Binary Classification & Linear Separability:** Concepts in machine learning; binary classification involves categorizing data into two classes, and linear separability refers to the ability to separate these classes with a hyperplane.

* **Maximum Margin Classifier & Support Vector Machine (SVM):** Machine learning algorithms that find the optimal hyperplane to separate data points, maximizing the margin between classes.

* **Support Vectors:** Data points closest to the hyperplane in an SVM.

* **Maximum Inscribed Circle in a Convex Polyhedron & Smallest Ball Problem:** Geometric optimization problems.

* **Hyperplane:** A subspace of one dimension less than its ambient space.

* **Monthly Demands, Average Demand, Production at month i (Xᵢ), Surplus at end of Month i (Sᵢ), Cost of Changing Production, Cost of Storage:**  Variables and parameters used in production planning problems.

* **Annual Return of ith Investment (Rᵢ), Proportion of Investment in i (Xᵢ), Fluctuation (R̃ⱼ):** Variables and parameters used in portfolio optimization problems.

* **Smallest Enclosing Ball Problem, Maximum Weight Matching, Cutting Stock Problem, Sparse Solution of Underdetermined System of Linear Equations:** Examples of optimization problems that can be formulated and solved using linear programming techniques.

* **Integer Programming & Relaxed Problem:**  Integer programming extends linear programming by requiring integer solutions; the relaxed problem is the corresponding linear program without the integer constraints.

* **Branch and Bound & Gomory Cuts:** Methods for solving integer programming problems.

* **Network Flow:** The study of flows through a network, often modeled as a directed graph with capacities and costs on the arcs.

* **Nodes (N) & Arcs (A):**  Components of a network; nodes represent locations, and arcs represent connections between nodes.

* **Supply/Demand ($b_i$), Flow ($X_{ij}$), Cost ($C_{ij}$):** Parameters defining a network flow problem; supply/demand represents net flow at each node, flow represents the amount transported along an arc, and cost represents the cost per unit of flow along an arc.

* **Balanced Equation:** An equation representing flow conservation at each node.

* **Incidence Matrix (A) & Rank(A):** The incidence matrix represents the network structure, and its rank indicates the number of linearly independent equations.

* **Primal Problem (P) & Dual Problem (D):** The original minimization problem and its associated maximization problem in network flow.

* **Path & Cycle:** Sequences of connected nodes in a network; a cycle is a closed path.

* **Tree & Spanning Tree:** A tree is a connected graph without cycles; a spanning tree is a tree that includes all nodes in a network.

* **Tree Solution:** A solution to a network flow problem where the flow along arcs not in the spanning tree is zero.

* **Basis Matrix (B):** A square submatrix of the incidence matrix corresponding to a spanning tree.

* **Complementary Slackness:** A condition relating primal and dual variables, indicating optimality.

* **Primal Simplex Method:** The standard simplex method applied to network flow problems.

* **Network Simplex Method:** A specialized simplex method for solving network flow problems.

* **Dual Network Simplex:** A dual simplex method specialized for network flow problems.

* **Transportation Problem, Dummy Node, Incidence Matrix, Upper Bounded Transshipment Problem:**  Specific types of network flow problems.

* **Shortest Path Problem, Bellman's Equation, Dijkstra's Algorithm:**  Methods for finding the shortest path between two nodes in a network.

--- Algorithm Solutions ---
This summary covers various algorithms for solving linear programs (LPs) and related problems, emphasizing key concepts and insights.  The core concept is iteratively improving a solution until optimality is reached, often by moving between feasible solutions.

* **Simplex Method:**  This iterative algorithm solves LPs by moving from one vertex of the feasible region to another, improving the objective function at each step until an optimal solution is found.  This involves pivot operations and rules for selecting entering and leaving variables.

* **Handling Infeasible Origins:**  For LPs with infeasible origins, an auxiliary problem is introduced to shift the feasible region, enabling the application of the simplex method.

* **Pivot Operation:** This fundamental operation in the simplex method interchanges a basic and non-basic variable, representing a move to an adjacent vertex in the feasible region.

* **Variable Selection Rules:**  Various rules exist for selecting entering and leaving variables in the simplex method, including the largest-coefficient rule, the largest-increase rule, and Bland's rule (to avoid cycling).  Randomized pivot rules are also employed.

* **Duality Theory:**  Weak duality states that the primal objective function value is always less than or equal to the dual objective function value for feasible solutions. Strong duality asserts that, if an optimal solution exists for the primal problem, then an optimal solution exists for the dual problem, and their objective function values are equal.  Complementary slackness provides a necessary and sufficient condition for optimality, relating primal and dual solutions.  These concepts extend to general LPs using Lagrangian functions and multipliers.

* **Sensitivity Analysis:** This technique assesses the impact of changes in objective function coefficients or constraint values on the optimal solution and objective function value.  Shadow prices, representing the rate of change in the optimal objective function value per unit change in a constraint's right-hand side, are crucial in this analysis.

* **Dual Simplex Method:** This algorithm starts with a dual-feasible, but potentially primal-infeasible, solution and iteratively improves primal feasibility while maintaining dual feasibility.

* **Matrix Representation of LPs:**  Linear programs can be efficiently represented using matrices, facilitating the use of matrix operations within the simplex method.  This involves expressing the objective function and constraints in matrix notation and partitioning variables into basic and non-basic sets.

* **Graphical Solution Method:** For LPs with two variables, a graphical method allows for visualization of the feasible region and identification of the optimal solution.

* **Integer Linear Programming:**  Algorithms like branch and bound and Gomory cuts are used to solve integer programming problems, addressing the challenge of integer constraints. Branch and bound recursively partitions the feasible region, while Gomory cuts iteratively add constraints to eliminate non-integer solutions.

* **Network Flow Problems:** Specialized algorithms, such as the primal and dual network simplex methods, efficiently solve network flow problems.  These methods leverage the network structure, utilizing spanning trees and augmenting paths.  The max-flow min-cut theorem establishes a fundamental relationship between the maximum flow and minimum cut in a network.  Algorithms like Dijkstra's and Bellman-Ford solve shortest path problems, a special case of network flow.

* **Convexity and Related Theorems:**  Concepts of convex sets, convex combinations, and convex hulls are fundamental to understanding the properties of the feasible region in linear programming.  Theorems like Caratheodory's theorem and the separation theorem provide insights into the structure of convex sets.  Farkas' Lemma provides conditions for the feasibility or infeasibility of linear systems.

* **Regression Techniques:**  Different regression methods, such as L¹, L², and L∞ regression, minimize different norms of the residual vector, each with its own solution approach.  Support Vector Machines (SVMs) aim to find the maximum margin hyperplane separating data points, formulated as a quadratic programming problem.  The smallest enclosing ball problem seeks the smallest ball containing a set of points.

* **Applications of Linear Programming:**  Linear programming finds applications in diverse areas, including ice cream production planning, workforce planning, portfolio selection (Markowitz model), maximum weight matching, machine scheduling, knapsack problems, cutting stock problems, and finding sparse solutions to linear systems.
