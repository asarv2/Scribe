
--- Key Terms ---
This summary covers key concepts in linear programming, network flows, and related optimization techniques.

* **Slack Variable:** A variable added to a less-than-or-equal-to inequality constraint to convert it into an equality constraint, representing the difference between the constraint's left and right sides.
* **Feasible Region:** The set of all points satisfying all constraints of a linear programming problem.
* **Vertex:** A point where two or more constraint boundaries intersect within the feasible region; optimal solutions in the Simplex method are found at vertices.
* **Basic Variable:** In the Simplex method, a variable expressed as a function of non-basic variables within a dictionary.
* **Non-basic Variable:** In the Simplex method, a variable set to zero in a given iteration.
* **Dictionary:** A representation of a linear programming problem where basic variables are functions of non-basic variables, used iteratively in the Simplex method to find the optimal solution.
* **Auxiliary Problem:** A modified linear programming problem used to find a feasible starting point for the Simplex method when the origin is infeasible in the original problem.
* **Largest-Coefficient Rule & Largest-Increase Rule:** Pivot rules in the Simplex method selecting the entering variable based on either the largest coefficient in the objective function row or the largest increase in the objective function value, respectively.
* **Klee-Minty Example:** A worst-case scenario for the Simplex method, illustrating exponential time complexity for certain pivot rules.
* **Bland's Rule & Lexicographic Method:** Pivot rules designed to prevent cycling and ensure termination in the Simplex method.
* **Smoothed Complexity:** A measure of algorithm complexity considering the effect of small random input perturbations.
* **Interior Method:** A class of linear programming algorithms traversing the interior of the feasible region, unlike the boundary-following Simplex method.
* **Primal Problem & Dual Problem:**  A pair of linear programming problems; the primal maximizes an objective function subject to constraints, while the dual minimizes a related objective function, offering insights into the primal's solution.
* **Weak Duality:** The theorem stating that the primal problem's objective function value is always less than or equal to the dual problem's value for any feasible solutions.
* **Negative Transpose Property:** The property where the dual problem's coefficient matrix is the negative transpose of the primal problem's coefficient matrix.
* **Complementary Variables:** Pairs of primal and dual variables (and their slack variables) where at least one variable in each pair must be zero at optimality.
* **Strong Duality Theorem:** The theorem stating that if a linear programming problem has an optimal solution, its dual also has an optimal solution, and their optimal objective function values are equal.
* **Complementary Slackness:** A condition stating that for optimal primal and dual solutions, the product of each primal variable and its corresponding dual slack variable (and vice versa) is zero.
* **Lagrange Multiplier & Lagrangian Function:** A variable and function, respectively, used to incorporate constraints into optimization problems.
* **Diet Problem:** A classic linear programming problem minimizing diet cost while meeting nutritional requirements.
* **Matrix Notation for Linear Programming:** A compact matrix and vector representation of linear programming problems.
* **Simplex Iterates:** The sequence of solutions generated by the Simplex method.
* **Augmented Matrix:** A matrix formed by adding a column of constants to the coefficient matrix of a linear system.
* **Basic Variables & Non-Basic Variables:**  Variables categorized in the Simplex method; basic variables are solved for by setting non-basic variables to zero.
* **Partitioning of Variables:** The process of separating variables into basic and non-basic sets.
* **Simplex Tableau:** A tabular representation of Simplex method iterations.
* **Entering Variable & Leaving Variable:** Variables changing their status (basic to non-basic or vice versa) during Simplex iterations.
* **Optimal Solution:** A feasible solution maximizing or minimizing the objective function.
* **Reduced Costs:** Values indicating the objective function's change if a non-basic variable becomes basic.
* **Parametric Analysis & Sensitivity Analysis:** Techniques studying how changes in a linear programming problem's parameters affect the optimal solution.
* **Shadow Price:** The rate of change in the optimal objective function value per unit change in a constraint's right-hand side.
* **Basis Matrix & Non-basis Matrix:** Matrices formed by columns of the constraint matrix corresponding to basic and non-basic variables, respectively.
* **Convex Set, Convex Combination, Convex Hull:**  Geometric concepts related to sets of points and their properties.
* **Caratheodory Theorem & Separation Theorem:** Theorems describing properties of convex sets.
* **Farkas' Lemma:** A theorem providing a condition for the infeasibility of a system of linear inequalities.
* **L², L¹, L∞ Regression:** Regression methods minimizing different measures of error.
* **Linear Separability, Maximum Margin Classifier, Support Vector Machine (SVM), Support Vectors:** Concepts related to classification algorithms.
* **Lagrangian Formulation of SVM & Geometric Interpretation of SVM:** Methods for understanding and solving SVM problems.
* **SVM Optimization as a QP Problem:** Formulating SVM as a quadratic programming problem.
* **Maximum Inscribed Circle in a Convex Polyhedron & Smallest Ball Problem:** Geometric optimization problems.
* **Distance of a Point from a Hyperplane:** A formula calculating the distance between a point and a hyperplane.
* **Production Planning, Average Demand, Cost of Changing Production, Cost of Storage:** Components of production planning models.
* **Workforce Planning:** Determining optimal employee numbers to meet labor demands.
* **Portfolio Selection (Markowitz Model):** A financial model optimizing investment portfolios.
* **Maximum Weight Matching, Machine Scheduling, Knapsack Problem, Cutting Stock Problem:** Combinatorial optimization problems.
* **Sparse Solutions of Linear System:** Finding solutions with few non-zero elements.
* **Fredholm Alternatives:** A statement of mutually exclusive possibilities regarding the solvability of a linear system.
* **Integer Programming, Relaxed Problem, Branch-and-Bound, Depth-First Search, Pruning:** Concepts in integer programming.
* **Gomory Cuts:** Constraints added to cut off non-integer solutions.
* **Network, Node, Arc, $b_i$, $X_{ij}$, $C_{ij}$:** Components of network flow problems.
* **Balanced Equation, Incidence Matrix (A), Cost Vector (c), Supply/Demand Vector (b), $A_{ij}$(k,l), Rank(A):** Mathematical representations of network flows.
* **Primal Problem (P), Dual Problem (D), Path, Cycle, Tree, Spanning Tree, Tree Solution, Root Node:** Network flow concepts.
* **Basis Matrix (B), Non-basis Matrix (N), Reduced Cost, Dual Slack, $z_{ij}$, $y_i$, $\tilde{X}$, $\mu$**:  Variables and matrices used in network simplex methods.
* **Transportation Problem, Dummy Node, Upper Bounded Transshipment Problem:** Specific types of network flow problems.
* **Shortest Path Problem, Bellman's Equation, Dijkstra's Algorithm:** Algorithms for finding shortest paths.
* **Max Flow, Cut, Cut Capacity, Max-Flow Min-Cut Theorem, Augmenting Path, Ford-Fulkerson Algorithm, Fictitious Arc:** Concepts related to maximum flow problems.
* **$jb_j$**: A value related to flow constraints in network flow problems.

--- Problem Types ---
This summary outlines the core problem types encountered in linear programming and related optimization techniques.  The problems span foundational concepts, algorithmic efficiency, duality theory, and applications.

* **Finding an Initial Feasible Solution:**  This problem addresses the challenge of finding a feasible starting point for the Simplex method, particularly when the origin is infeasible, often requiring an auxiliary problem.

* **Handling Infeasible Origins:** This involves adapting the Simplex method when the origin lies outside the feasible region.

* **Optimizing with Multiple Variables:** This problem demonstrates the application and increased complexity of the Simplex method as the number of variables increases.

* **Representing Solutions with Dictionaries:** This focuses on using dictionaries (systems of equations) to represent linear programming problems and their solutions, highlighting the pivoting process.

* **Analyzing Simplex Method Efficiency:** This involves analyzing the number of iterations required by the Simplex method, considering average-case and worst-case scenarios, and comparing different pivot rules.

* **Understanding Worst-Case Simplex Behavior:** This problem explores the exponential worst-case performance of the Simplex method, illustrated by the Klee-Minty example.

* **Evaluating Alternative Pivot Rules:** This involves comparing the efficiency of different pivot rules (largest-coefficient, largest-increase, Bland's rule) for the Simplex method.

* **Empirical and Theoretical Analysis of Simplex Performance:** This encompasses both empirical data analysis of average-case performance and exploration of theoretical bounds on the number of iterations, including smoothed complexity.

* **Polynomial-Time Algorithms for Linear Programming:** This problem discusses the existence of polynomial-time algorithms (e.g., interior-point methods) and their contrast with the Simplex method's performance.

* **Formulating and Applying Primal and Dual Problems:** This involves formulating primal and dual linear programs, applying the weak and strong duality theorems, and analyzing the four possible outcomes of primal and dual problems.  The negative transpose property and complementary slackness theorem are also key aspects.

* **Lagrangian Formulation and Duality:** This problem type focuses on using the Lagrangian function to derive dual problems, prove weak and strong duality, and apply complementary slackness, extending to problems with both equality and inequality constraints.

* **Duality Applications in Specific Problems (e.g., Diet Problem):** This involves formulating and interpreting primal and dual problems within the context of real-world applications, such as the diet problem.

* **Matrix Representation and Simplex Method:** This problem type focuses on representing linear programs in matrix notation, performing simplex iterations using matrix operations, and illustrating complementary slackness in this context.

* **Sensitivity Analysis:** This involves determining the range of changes in objective function coefficients and constraint values that maintain the optimality of the current solution.

* **Convexity and Convex Hulls:** This problem type defines convex sets and convex combinations, characterizes convex sets using convex combinations, defines and characterizes the convex hull of a set, and introduces Caratheodory's Theorem.

* **Applications of Linear Programming (e.g., Regression, Portfolio Selection):** This involves formulating and solving real-world problems such as L² regression, binary classification, and portfolio optimization using linear programming techniques.

* **Farkas' Lemma and Existence of Solutions:** This problem type explores the conditions for the existence of non-negative solutions to systems of linear equations (`Ax = b`) and inequalities (`Ax ≤ b`), culminating in the proof of Farkas' Lemma.

* **Integer Programming:** This involves formulating integer programming problems, exploring the limitations of rounding, applying the branch and bound method (including depth-first search), and using Gomory cuts.

* **Network Flow Problems:** This encompasses formulating network flow problems as linear programs, analyzing incidence matrices, finding feasible tree solutions, applying complementary slackness, and using the primal simplex method for network flows.

* **Network Simplex Method:** This involves finding spanning trees, primal and dual feasible solutions, modifying spanning trees and variables, updating primal and dual flows, selecting entering and leaving arcs, proving cost reduction, handling disconnected trees, and choosing entering arcs in the dual simplex method.

* **Applications of Network Flows (e.g., Transportation, Shortest Path, Maximum Flow):** This involves formulating and solving various network flow problems, including transportation problems with inequality constraints, upper-bounded transshipment problems, shortest path problems (using Bellman's and Dijkstra's algorithms), and maximum flow problems (including the Max-Flow Min-Cut Theorem and the Ford-Fulkerson algorithm).

* **Economic Interpretation of Network Simplex:** This involves finding "fair prices" in a network flow problem, identifying profitable shipping opportunities, adjusting shipments to maintain feasibility, and finding feasible solutions on a spanning tree.  This builds upon the duality concepts.


--- Algorithm Solutions ---
This summary outlines several algorithms for solving linear programming (LP) problems and related optimization challenges.  These methods leverage the fundamental properties of LP solutions, such as the optimality occurring at a vertex of the feasible region.

* **Graphical Method:** Solves small-scale LPs by visually identifying the optimal solution at a vertex of the feasible region defined by the constraints.

* **Simplex Method:** Iteratively improves a feasible solution by moving from one vertex of the feasible region to another, improving the objective function at each step until optimality is reached.  This can be implemented using matrix operations.

* **Auxiliary Problem Method:** Addresses infeasible LPs by introducing an auxiliary variable to find a feasible starting point before applying the simplex method.

* **Dual Problem Formulation:**  Constructs a dual LP problem from a primal LP, where the optimal objective function values of both problems are equal (strong duality).  The dual problem's structure is derived by transposing the constraint matrix and exchanging objective function coefficients with constraint right-hand sides.  Variations exist for different primal problem structures, including those with unbounded variables.

* **Branch and Bound:** Solves integer programming problems by recursively partitioning the feasible region, solving relaxed linear programs for subproblems, and pruning unpromising branches to find the optimal integer solution.

* **Network Flow Problem Formulation:** Models network flow problems as LPs, minimizing total cost subject to flow conservation constraints at each node and non-negativity constraints on arc flows.

* **Network Simplex Method:**  Efficiently solves network flow problems by iteratively improving a feasible solution on a spanning tree, adjusting flows along arcs to maintain feasibility and improve the objective function.  This involves calculating "fair prices" and identifying profitable arcs.  A parametric self-dual variant further refines this approach.

* **Linear Programming Formulation of Max Flow:**  Formulates the maximum flow problem as an LP, maximizing flow along a fictitious arc from sink to source subject to flow conservation and capacity constraints.
