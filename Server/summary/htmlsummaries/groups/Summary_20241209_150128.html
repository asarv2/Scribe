Key Terms

Fundamental AI Concepts

  • Turing Test: An operational test for intelligent behavior, the Imitation Game, where a human interrogator tries to distinguish between a human and a machine based on their text-based responses.
  • Inductive Reasoning: The process of deriving general principles from specific observations.
  • Linear Regression: A machine learning algorithm used to model the relationship between a dependent variable and one or more independent variables by fitting a linear equation to observed data.
  • Model: A mathematical representation of a system or process, used to make predictions or understand relationships between variables.
  • Overfitting: A phenomenon in machine learning where a model learns the training data too well, resulting in poor generalization to unseen data.
  • Loss Function: A function that quantifies the difference between the predicted and actual values in a machine learning model.
  • Decision Boundary: A line or surface that separates different classes of data points in a classification problem.
  • Stochastic Gradient Descent: An iterative optimization algorithm that updates model parameters using the gradient calculated from a randomly selected subset of the training data.
  • Logistic Regression: A statistical model that uses a logistic function to model the probability of a binary outcome.
  • Empirical Risk Minimizer: A learning principle that aims to find the model that minimizes the average loss over the training data.
  • Gradient Descent: An iterative optimization algorithm that updates model parameters by moving in the direction of the negative gradient of the loss function.
  • Perceptron Loss: A loss function used in the perceptron algorithm, which is zero if the prediction is correct and equal to the negative of the margin otherwise.
  • Hinge Loss: A loss function used in support vector machines (SVMs), which is zero if the margin is greater than 1 and equal to 1 - margin otherwise.
  • Logistic Loss: A loss function used in logistic regression, which is based on the log-likelihood of the data given the model parameters.
  • Multiple Linear Regression: A statistical method used to model the relationship between a dependent variable and two or more independent variables.
  • Binary Classification: A machine learning task where the goal is to classify data points into one of two categories.
  • Personas: Representative archetypes of users or customers, created to help teams understand and cater to different user needs and behaviors.
  • Intelligent Agent: A system that perceives its environment and takes actions that maximize its chances of success.
  • Logic Reasoning: A cornerstone of Artificial Intelligence; the process of using rules of deduction to derive a conclusion from given assumptions.
  • Propositional Logic: The simplest logic, illustrating basic ideas using propositional symbols and logical connectives to form sentences.
  • Satisfying Assignment: An assignment of truth values to variables in a propositional formula that makes the formula evaluate to true.
  • Boolean Satisfiability Problem (SAT): The problem of determining whether a given propositional formula is satisfiable.
  • Literal: A propositional variable or its negation.
  • Clause: A disjunction of literals.
  • Conjunctive Normal Form (CNF): A propositional formula that is a conjunction of clauses.
  • Valid Sentence: A sentence that is true in all models (also known as a tautology).
  • Satisfiable Sentence: A sentence that is true in at least one model.
  • Unsatisfiable Sentence: A sentence that is true in no models.
  • 3-Satisfiability (3-SAT): A restricted version of the SAT problem where each clause contains exactly three literals.
  • Equisatisfiable: Two formulas are equisatisfiable if they have the same set of satisfying assignments.
  • Classical Planning: The process of finding a sequence of actions that achieves a desired goal.
  • Combinatorial Design: The creation of complex mathematical structures with desirable properties, such as Latin squares or Steiner systems.

Linear Algebra for AI

  • Matrix: A rectangular array of numbers, symbols, or expressions arranged in rows and columns.
  • Linear Transform: A function that maps vectors from one vector space to another, satisfying $T(u + v) = T(u) + T(v)$ and $T(cu) = cT(u)$ for all vectors $u$, $v$ and scalars $c$.
  • Matrix Multiplication: An operation that combines two matrices to produce a third matrix, where the element at row $i$ and column $j$ of the resulting matrix is the dot product of the $i$-th row of the first matrix and the $j$-th column of the second matrix. The inner dimensions must match.
  • Matrix Inverse: For a square matrix $A$, its inverse $A^{-1}$ is a matrix such that $AA^{-1} = A^{-1}A = I$, where $I$ is the identity matrix.
  • Matrix Transposition: An operation that swaps the rows and columns of a matrix. The transpose of matrix $A$ is denoted as $A^T$.
  • Derivative: A measure of how a function changes with respect to a change in its input.
  • Partial Derivative: A derivative of a function of multiple variables with respect to one of those variables, holding the others constant.
  • Sigmoid Function: A mathematical function that maps any input value to an output value between 0 and 1. Often used as an activation function in neural networks.
  • Matrix Factorization: A technique to decompose a large matrix into the product of two smaller matrices, revealing latent factors that capture underlying relationships in the data.
  • Dimensionality Reduction: Techniques that transform data from a higher-dimensional space to a lower-dimensional space, reducing the number of attributes while retaining important information.
  • Low Rank Matrix Approximations: Approximating a high-rank matrix with a lower-rank matrix, effectively reducing the dimensionality of the data while preserving essential information.

Neural Networks

  • Perceptron: A fundamental unit in neural networks that takes multiple inputs, applies weights to them, sums the weighted inputs, and produces an output based on a threshold.
  • ImageNet: A large dataset of images used for training and evaluating image recognition models. It contains millions of images across thousands of categories.
  • AlexNet: One of the first deep convolutional neural networks to achieve high accuracy in image recognition competitions, notably the ImageNet challenge. It was a significant milestone in the development of deep learning.
  • ConvNet: Short for Convolutional Neural Network.
  • Artificial Neuron: A mathematical model of a biological neuron, used as a building block in artificial neural networks. It takes weighted inputs, sums them, and applies an activation function to produce an output.
  • Convolution Layer: A layer in a convolutional neural network that applies a filter (kernel) to the input data to extract features. The filter slides across the input, performing element-wise multiplication and summation at each position.
  • Pooling Layer: A layer in a convolutional neural network that reduces the spatial dimensions of the feature maps, typically by applying a max or average pooling operation. This helps to reduce computational cost and make the network more robust to small variations in the input.
  • Convolution Filter: A small matrix of weights used in a convolutional layer to extract features from the input data. The filter is convolved with the input data to produce an output feature map.
  • Multidimensional Convolution: A convolution operation applied to input data with multiple channels (e.g., RGB channels in an image). Each channel is processed independently by a corresponding filter, and the results are combined.
  • Local Receptive Field: The small region of the input data that a neuron in a convolutional layer is connected to. This leads to sparse connectivity and reduces the number of parameters in the network.
  • Sparse Connectivity: A characteristic of convolutional neural networks where each neuron is connected to only a small subset of neurons in the previous layer, unlike fully connected networks.
  • Parameter Sharing: A key characteristic of convolutional layers where the same set of weights (the filter) is used across all spatial locations in the input. This significantly reduces the number of parameters in the network.
  • Max Pooling: A pooling operation that selects the maximum value within a defined region (e.g., 2x2) of the input feature map.
  • Average Pooling: A pooling operation that calculates the average value within a defined region (e.g., 2x2) of the input feature map.
  • Back-propagation: An algorithm used to train neural networks by calculating the gradient of the loss function with respect to the network's weights and then updating the weights to minimize the loss.
  • MNIST: A large database of handwritten digits used for training and testing in machine learning, particularly in image recognition.
  • CIFAR-10: A large dataset of 32x32 color images, commonly used for benchmarking image classification models. It contains 10 classes with 6000 images per class.
  • LeNet-5: A convolutional neural network architecture specifically designed for the MNIST dataset. It consists of convolutional, pooling, and fully connected layers.

Machine Learning Models & Techniques

  • Reinforcement Learning: A type of machine learning where an agent learns to make decisions by interacting with an environment and receiving rewards or penalties.
  • Training Data: The subset of data used to train a machine learning model.
  • Held Out Data: A subset of data used for hyperparameter tuning and model selection.
  • Test Data: A subset of data used to evaluate the performance of a trained machine learning model on unseen data.
  • Evaluation Function: A function used to assess the performance of a machine learning model.
  • Model Complexity: A measure of the capacity of a model to fit complex patterns in data. High complexity can lead to overfitting.
  • Bias: The error introduced by approximating a real-world problem with a simplified model. High bias leads to underfitting.
  • Variance: The error introduced by the model's sensitivity to small fluctuations in the training data. High variance leads to overfitting.
  • Hyperparameters: Parameters that control the learning process of a machine learning model, but are not learned from the data itself.
  • Regularization: A technique used to prevent overfitting by adding a penalty term to the loss function that discourages large weights.
  • Regularization Coefficient ($\lambda$): A hyperparameter that controls the strength of the regularization penalty.
  • Learning Curves: Graphs that show the training and testing performance of a model as a function of the training set size or model complexity.
  • S-fold Cross Validation: A model evaluation technique that divides the data into S folds, using each fold once as a validation set and the rest as a training set.
  • Data Analysis Pipeline: The sequence of steps involved in collecting, preparing, modeling, and evaluating data.
  • Embeddings: A low-dimensional representation of data points, often obtained through dimensionality reduction techniques like matrix factorization, that captures the essential relationships between data points.
  • Collaborative Filtering: A recommender system technique that predicts user preferences based on the preferences of similar users.
  • Recommender Systems: Systems that predict user preferences for items, such as movies or products, based on past user behavior and other relevant data.
  • Bias-Variance Tradeoff: The trade-off between model complexity and prediction accuracy. High complexity models can overfit the training data (high variance), while low complexity models may underfit (high bias).
  • Netflix Prize: A competition offering a $1 million prize for improving the accuracy of Netflix's movie recommendation system.
  • Clustering: The process of grouping a set of objects into classes of similar objects. Objects within a cluster should be similar, and objects from different clusters should be dissimilar.
  • Supervised Learning: A machine learning paradigm where the algorithm learns from labeled data (input-output pairs) to predict outputs for new inputs.
  • Unsupervised Learning: A machine learning paradigm where the algorithm learns from unlabeled data to discover underlying patterns or structures.
  • K-means clustering: A popular clustering algorithm that aims to partition $n$ observations into $k$ clusters in which each observation belongs to the cluster with the nearest mean (cluster center or centroid).
  • Hamming distance: A distance metric used for comparing strings of equal length. It counts the number of positions at which the corresponding symbols are different.
  • Matching coefficient: A similarity measure between two binary vectors. It is calculated as the number of matching bits divided by the total number of bits.
  • Euclidean distance: The straight-line distance between two points in Euclidean space. For two points $x$ and $y$ in $p$-dimensional space, it is defined as $d_E(x, y) = \sqrt{\sum_{i=1}^p (x_i - y_i)^2}$.
  • Inertia: In K-means clustering, the sum of squared distances of samples to their closest cluster center.
  • Purity: A measure of the extent to which clusters contain objects of a particular class. It's calculated as the average of the maximum number of elements of any class within each cluster.

Image Processing & Computer Vision

  • Image Classification: The task of assigning a predefined category label to an image.
  • Semantic Gap: The difference between how humans perceive images (semantically) and how computers represent them (numerically).
  • Viewpoint Variation: The challenge in image classification caused by changes in the camera's or object's position and orientation.
  • Illumination: The challenge in image classification caused by variations in lighting conditions.
  • Deformation: The challenge in image classification caused by changes in the object's shape or pose.
  • Occlusion: The challenge in image classification where parts of an object are hidden or obscured.
  • Background Clutter: The challenge in image classification where distracting elements in the background hinder object recognition.
  • Invariant Features: Features that remain consistent across different variations of an object (e.g., different viewpoints, lighting, or poses).
  • Bag of Features: An image representation method where an image is represented by the frequencies of "visual words" (local features).
  • Visual Words: Basic visual elements extracted from images, representing key features used in Bag of Features.
  • Textons: Basic elements or features that characterize texture.
  • Nearest Neighbor (NN) Classifier: A classification algorithm that assigns the label of the nearest training data point to each test data point.
  • Noise: Random variations or unwanted disturbances in image data.
  • Salt and pepper noise: Random occurrences of black and white pixels in an image.
  • Impulse noise: Random occurrences of white pixels in an image.
  • Gaussian noise: Variations in intensity drawn from a Gaussian normal distribution.
  • Mean Filtering: A noise reduction technique that replaces each pixel with the average of its neighboring pixels.
  • Moving Average: A method for smoothing data by averaging values within a sliding window.
  • Weighted Moving Average: A moving average where neighboring values are weighted differently.
  • Image Filtering: The process of computing a function of the local neighborhood at each pixel in an image.
  • Identity Filter: An image filter that leaves the image unchanged.
  • Sharpening: An image enhancement technique that increases the contrast between edges and details.
  • Category Models: Representations of different object categories in a model space, often based on feature vectors.
  • Codewords: Visual features extracted from an image, often represented as small image patches.
  • Edge Detection: A technique in image processing used to identify points of rapid change in image intensity.
  • Edges: Curves in an image where brightness changes significantly.
  • Feature Vector: A vector representing the features extracted from an image or data point.
  • Finite Difference: A method for approximating the derivative of a function using discrete values.
  • Gaussian Pyramid: A multi-resolution representation of an image, created by repeatedly blurring and subsampling the image.
  • Image Gradient: A vector representing the direction and magnitude of the greatest rate of change in image intensity.
  • Intensity Function: A function that maps each pixel in an image to its intensity value.
  • Intensity Profile: A plot of intensity values along a scanline of an image.
  • Model Space: A multi-dimensional space where each point represents a category model.
  • Perceptual Organization: The process of grouping pixels into objects based on visual cues like edges.
  • Vision Pyramid: A hierarchical representation of an image at multiple resolutions.

Data Analysis & Preprocessing

  • EigenSNPs: Eigenvectors obtained from Principal Component Analysis (PCA) applied to Single Nucleotide Polymorphisms (SNPs) data, representing the principal components of genetic variation.

Optimization & Search

  • Minimax Search: A search algorithm for two-player zero-sum games that aims to find the best move for the current player, assuming the opponent also plays optimally.
  • Alpha-Beta Pruning: A technique to reduce the search space in Minimax search by avoiding the evaluation of branches that cannot affect the optimal decision.
  • Game Tree: A tree-like structure representing all possible sequences of moves in a game, with leaf nodes representing outcomes.
  • Recursion: A process where a function calls itself, eventually terminating in a base case.
  • Base Case: The simplest form of a recursive problem, providing a direct solution without further recursion.
  • Recursive Case: The part of a recursive function or process that breaks down a larger problem into smaller, similar subproblems, each step closer to the base case.
  • Breadth First: A graph traversal algorithm that visits all the nodes at the same level before moving to the next level.
  • Depth First: A graph traversal algorithm that explores a branch as far as possible before backtracking.
  • Binary Search Tree: A tree data structure where each node has at most two children, and the left child is less than the parent, while the right child is greater than the parent.
  • Search Tree: A tree data structure used to represent the possible states and actions in a search problem.
  • State: A description of the configuration of the environment in a search problem.
  • Action: Activities that move from one state to another in a search problem.
  • Search Algorithm: A procedure that determines which actions should be tried in which order to find a solution in a search problem.
  • Successor Function: A function that maps a state to its possible successor states.
  • World State: A complete description of every detail of the environment.
  • Search State: A simplified representation of the environment, containing only the details needed for planning.
  • Rational Agent: An agent that acts to maximize its expected goal achievement, given its available information.

Fairness and Ethics in AI

  • Disparate Treatment: A type of discrimination where decisions are (partly) based on a subject's protected attribute information.
  • Disparate Impact: A type of discrimination where outcomes disproportionately hurt (or benefit) people with certain sensitive attribute values.
  • Bias in Data Models: The unintentional perpetuation of existing societal biases in algorithms, particularly those that learn from data.
  • Proxies for Discrimination: Seemingly neutral data points that can act as stand-ins for discriminatory factors, such as race, gender, or religion.
  • Anonymized Data: Data that has had identifying information removed; however, it may still be possible to re-identify individuals.
  • Privacy: The state of being free from unwanted observation or intrusion; in data science, it refers to the protection of personal information.
  • Security: Measures taken to protect data from unauthorized access, use, disclosure, disruption, modification, or destruction.
  • Fairness through Blindness: A method to mitigate bias in algorithms by ignoring irrelevant or protected attributes during model training.
  • Group Fairness: A fairness criterion that aims to equalize outcomes for different groups, such as minorities and majorities.
  • Individual Fairness: A fairness criterion that aims to treat similar individuals similarly, regardless of group membership.
  • Interpretable Results: Results from an AI algorithm that are easily understandable and explainable, increasing trust and transparency.

Knowledge Representation & Reasoning

  • SAT Solving: The process of determining whether a Boolean formula is satisfiable, meaning there exists an assignment of truth values to its variables that makes the formula evaluate to true.
  • General Automated Reasoning: A process that uses a model generator to create a model from a problem instance and then uses a general inference engine to find a solution.
  • Exponential Complexity Growth: The rapid increase in computational complexity as the size of a problem increases, often characterized by an exponential function.
  • Partial Assignment: An assignment of truth values to a subset of the variables in a Boolean formula, leaving some variables unassigned.
  • Simplification of a formula by an evaluated literal: A process of reducing a CNF formula by assigning a truth value to a variable and removing clauses that become true or literals that become false.
  • Pure Literal Rule: A rule in SAT solving that states that if a variable appears only positively or only negatively in a formula, it can be assigned a truth value that satisfies all clauses containing it.
  • Unit Propagation (BCP): A technique in SAT solving that assigns truth values to variables based on unit clauses (clauses with only one literal).
  • Resolution Rule: An inference rule in propositional logic that allows deriving a new clause from two clauses containing a literal and its negation.
  • Clause Learning: A technique in SAT solving where the reason for a conflict is learned and added as a new clause to prevent similar conflicts in the future.
  • Heavy-tailed behavior: A phenomenon in SAT solvers where the runtime distribution is skewed, with a few runs taking significantly longer than the average.
  • Hamiltonian Path Problem: A problem of finding a path in a graph that visits each vertex exactly once.
  • Graph Coloring: The problem of assigning colors to the vertices of a graph such that no two adjacent vertices have the same color.

Algorithm Solutions

Linear Algebra

  • Matrix Addition: $A + B = C$, where $c_{ij} = a_{ij} + b_{ij}$
  • Matrix Scalar Multiplication: $k \cdot A = B$, where $b_{ij} = k \cdot a_{ij}$
  • Matrix Multiplication: $C_{ij} = \sum_{k=1}^{n} a_{ik}b_{kj}$
  • Matrix Transposition: Swapping rows and columns of a matrix $A$ to obtain $A^T$.
  • Solving Linear Equations with Invertible Matrices: $Ax = b \implies x = A^{-1}b$

Calculus & Optimization

  • Derivative of Sigmoid Function: $\frac{d}{dx} \sigma(x) = \frac{e^{-x}}{(1 + e^{-x})^2}$
  • Multiple Linear Regression: Find the optimal coefficients $\beta^$ that minimize the sum of squared errors between the observed and predicted values. This is done by solving the equation $\beta^ = (X^TX)^{-1}X^Ty$, where $X$ is the design matrix, $y$ is the vector of observed values, and $\beta$ is the vector of coefficients.
  • Logistic Regression: Minimize the logistic loss function $F(w) = \sum_{i=1}^{N} \log(1 + e^{-y_iw^Tx_i})$ using stochastic gradient descent. The update rule is $w \leftarrow w + \alpha(\sigma(-y_nw^Tx_n)y_nx_n)$, where $\alpha$ is the learning rate and $\sigma$ is the sigmoid function.
  • Finite Difference: $\frac{df}{dx} [x, y] \approx F[x + 1, y] - F[x, y]$
  • Regularized Linear Regression: $E(w) = RSS(w) + \lambda R(w)$, where $R(w) = ||w||_2^2 = w_1^2 + ... + w_k^2$ or $R(w) = ||w||_1 = |w_1| + ... + |w_k|$.

Machine Learning Fundamentals

  • Perceptron Algorithm: Iteratively update the weight vector $w$ by adding $y_nx_n$ if the data point $x_n$ is misclassified, where $y_n$ is the true label and $x_n$ is the feature vector. If the data is linearly separable, this algorithm will find a separating hyperplane.
  • Bag of Features: Represent images by frequencies of "visual words" (Bags of features)
  • Nearest Neighbor Classifier: Assign label of nearest training data point to each test data point
  • S-fold Cross Validation: Split training data into $S$ equal parts; use each part as validation data, others as training data; choose hyperparameter with best average performance.
  • K-means Clustering: The algorithm iteratively assigns data points to the nearest cluster centroid, then recalculates the centroids as the mean of the points in each cluster, repeating until convergence.

Deep Learning Fundamentals

  • Max Pooling: This operation involves dividing the input feature map into non-overlapping regions (e.g., 2x2 squares) and selecting the maximum value within each region as the output. This reduces the spatial dimensions of the feature map while retaining the most prominent features.
  • Average Pooling: This operation involves dividing the input feature map into non-overlapping regions (e.g., 2x2 squares) and calculating the average value within each region as the output. This reduces the spatial dimensions of the feature map while retaining a summary of the features.
  • ReLU Activation Function: This function outputs the input if it is positive, and 0 otherwise. Mathematically, it is defined as $f(x) = max(0, x)$
  • Backpropagation: This algorithm calculates the gradient of the loss function with respect to the network's weights and uses this gradient to update the weights iteratively, aiming to minimize the loss and improve the network's accuracy.

Image Processing

  • Moving Average Filter: Replace each pixel with an average of all the values in its neighborhood
  • Weighted Moving Average Filter: Add weights to the moving average to give different importance to neighboring pixels
  • Image Sharpening: $f_{sharp} = f + \alpha(f - f_{blur})$
  • Image Gradient Magnitude: $||\nabla f|| = \sqrt{(\frac{\partial f}{\partial x})^2 + (\frac{\partial f}{\partial y})^2}$
  • Image Gradient Direction: $\theta = \tan^{-1}(\frac{\partial f}{\partial x} / \frac{\partial f}{\partial y})$
  • Anisotropic Gaussian: $G_{\sigma_x, \sigma_y}(x, y) = \frac{1}{2\pi\sigma_x\sigma_y} \cdot e^{-\frac{1}{2}((\frac{x^2}{\sigma_x^2}) + (\frac{y^2}{\sigma_y^2}))}$
  • Isotropic Gaussian: $G_\sigma(x, y) = \frac{1}{2\pi\sigma^2} \cdot e^{-\frac{r^2}{2\sigma^2}}$
  • Convolution: A convolution operation involves sliding a filter (kernel) across an input image, performing element-wise multiplication between the filter and the corresponding input region, and summing the results to produce a single output value. This process is repeated for every possible position of the filter on the input image, resulting in an output feature map.

Recommender Systems

  • Modeling Systematic Biases in Recommender Systems: $r_{ij} \approx \mu + b_i + b_j + u_i \cdot v_j$, where $\mu$ is the overall mean rating, $b_i$ is the bias for user $i$, $b_j$ is the bias for movie $j$, and $u_i \cdot v_j$ represents the user-movie interaction.

Search Algorithms

  • Minimax Search: A recursive algorithm for two-player zero-sum games that explores the game tree to find the best move for the current player, assuming the opponent also plays optimally. It alternates between maximizing the score for the current player and minimizing the score for the opponent.
  • Alpha-Beta Pruning: An optimization technique for Minimax search that reduces the search space by avoiding the evaluation of branches that cannot affect the optimal decision. It uses alpha and beta values to prune branches.
  • Breadth First Search: Visits nodes level by level. Check the current node, add children to a queue.
  • Depth First Search: Traverses down a branch. Check current node, then left, then right (other orders are possible).

Algorithm Design Paradigms

  • Recursive Problem Solving: Do part of the work and reduce the rest into a similar but smaller problem.

SAT Solvers

  • Conversion to CNF: This algorithm transforms a logical expression into Conjunctive Normal Form (CNF) by applying logical equivalences to eliminate implications, biconditionals, and negations, and then using distributivity to flatten the expression into a conjunction of clauses.
  • Naïve Solver: A recursive algorithm that explores all possible variable assignments to determine satisfiability of a propositional formula. It checks for immediate satisfiability or unsatisfiability, then recursively calls itself with assignments of true and false to an unassigned variable, backtracking if both fail.
  • DPLL Algorithm: A recursive algorithm that extends the Naïve Solver by incorporating Boolean Constraint Propagation (BCP) to efficiently identify and resolve unit clauses, significantly reducing the search space.
  • Resolution Rule: An inference rule that derives a new clause ($α ∨ β$) from two clauses ($x ∨ α$) and ($¬x ∨ β$) containing a literal ($x$) and its negation ($¬x$).
  • Clause Learning: A technique used in advanced SAT solvers where, upon backtracking from a conflict, a new clause is learned to prevent similar conflicts in the future. This clause represents the "reason" for the conflict, effectively pruning the search space.

Bias and Fairness in ML

  • Fairness through Blindness: Ignore protected attributes during model training and prediction.
  • Group Fairness: $P(\text{outcome } o | S) = P(\text{outcome } o | T)$, where $S$ and $T$ are two groups. This is insufficient as a notion of fairness.
  • Individual Fairness: Treat similar individuals similarly; similar individuals should be treated similarly for the purpose of the classification task and should be similarly distributed over outcomes.
  • Detecting and removing bias from models: Keep bias features in data during training, remove what was learned from these bias features after training.

Distance Metrics

  • Euclidean Distance: $d_E(x, y) = \sqrt{\sum_{i=1}^{p} (x_i - y_i)^2}$, where $x$ and $y$ are $p$-dimensional vectors.
  • Hamming Distance: Counts the number of differing bits between two binary vectors.
  • Matching Coefficient: Hamming distance normalized by the number of attributes/bits.

Clustering Evaluation

  • Purity: $purity(C, G) = \frac{1}{N} \sum_{i=1}^{K} \max_{j} N_j \in G_i$, where $N$ is the total number of data points, $K$ is the number of clusters, and $N_j$ is the number of points of class $j$ in cluster $i$.
