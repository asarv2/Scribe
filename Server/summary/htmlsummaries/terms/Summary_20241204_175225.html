Summary

Key Terms

  • Slack Variable: A variable added to a less-than-or-equal-to inequality constraint to transform it into an equality constraint. The slack variable represents the difference between the left-hand side and the right-hand side of the inequality.
  • Feasible Region: The set of all points that satisfy all the constraints of a linear programming problem.
  • Vertex: A point where two or more constraint boundaries intersect in the feasible region of a linear programming problem. In the Simplex method, optimal solutions are found at vertices.
  • Basic Variable: In the Simplex method, a variable that is expressed in terms of non-basic variables in a dictionary. Basic variables are set to values that satisfy the constraints.
  • Non-basic Variable: In the Simplex method, a variable that is set to zero in a given iteration of the algorithm. The values of the basic variables are determined by the values of the non-basic variables.
  • Pivot Operation: The process of exchanging a basic variable with a non-basic variable in the Simplex method. This operation moves from one vertex to another in the feasible region.
  • Dictionary: A representation of a linear programming problem in a tabular format, where basic variables are expressed as functions of non-basic variables. It is used in the Simplex method to systematically move from one vertex to another.
  • Auxiliary Problem: A modified linear programming problem introduced to find an initial feasible solution when the origin is not feasible in the original problem. It involves adding a new variable to shift the feasible region.
  • Largest-Coefficient Rule: A pivot rule in the Simplex method that selects the entering variable with the largest coefficient in the objective function row of the dictionary.
  • Largest-Increase Rule: A pivot rule in the Simplex method that selects the entering variable that results in the largest increase in the objective function value.
  • Klee-Minty Example: A worst-case example for the Simplex method, demonstrating that the number of iterations can grow exponentially with the problem size.
  • Bland's Rule: A pivot rule in the Simplex method designed to prevent cycling, ensuring termination.
  • Lexicographic Method: A method for choosing the leaving variable in the Simplex method that ensures termination.
  • Smoothed Complexity: A framework for analyzing the complexity of algorithms by considering the average-case performance after small random perturbations to the input.
  • Interior-Point Method: A class of algorithms for linear programming that traverse the interior of the feasible region, in contrast to the Simplex method which follows the boundary.
  • Primal Problem: A linear programming problem in its standard maximization form, aiming to maximize a linear objective function subject to linear inequality constraints and non-negativity constraints.
  • Dual Problem: A linear programming problem derived from the primal problem, typically in minimization form, with constraints and objective function related to the primal problem through matrix transposition and sign changes.
  • Weak Duality: A theorem stating that for any feasible solutions to the primal and dual problems, the objective function value of the primal problem is always less than or equal to the objective function value of the dual problem.
  • Strong Duality: A theorem stating that if a linear programming problem has an optimal solution, then its dual problem also has an optimal solution, and the optimal objective function values of both problems are equal.
  • Negative Transpose Property: The property that the coefficient matrix of the dual problem is the negative transpose of the coefficient matrix of the primal problem. This property is preserved throughout the simplex method iterations.
  • Complementary Slackness: A condition stating that for optimal primal and dual solutions, the product of each primal variable and its corresponding dual slack variable is zero, and the product of each dual variable and its corresponding primal slack variable is zero.
  • Lagrange Multiplier: A variable introduced in the Lagrangian function to incorporate constraints into an optimization problem.
  • Lagrangian Function: A function that combines the objective function and constraints of an optimization problem using Lagrange multipliers.
  • Weak Duality Theorem: A theorem stating that the optimal value of the primal problem is always less than or equal to the optimal value of the dual problem.
  • Strong Duality Theorem: A theorem stating that if the primal problem has a finite optimal solution, then the dual problem also has a finite optimal solution, and their optimal values are equal.
  • Diet Problem: A classic linear programming problem where the goal is to minimize the cost of a diet while meeting minimum nutritional requirements.
  • \textbf{Standard Form (Linear Programming)}: A linear programming problem expressed with a maximization objective function, less-than-or-equal-to constraints, and non-negativity constraints on all variables.
  • \textbf{Simplex Iterates}: The sequence of solutions generated by the simplex method during its iterative process.
  • \textbf{Augmented Matrix}: A matrix formed by combining the coefficient matrix of the constraints with the identity matrix, representing the introduction of slack variables.
  • \textbf{Basic Variables}: A set of linearly independent variables in a linear programming problem that can be uniquely determined from the constraints, given values for the non-basic variables.
  • \textbf{Non-Basic Variables}: The variables in a linear programming problem that are set to zero to determine the values of the basic variables.
  • \textbf{Simplex Tableau}: A tabular representation of the simplex method's matrix operations, used to update the objective function and basic variables during iterations.
  • \textbf{Complementary Slackness}: A condition in linear programming that relates the primal and dual variables, stating that at optimality, either a primal variable or its corresponding dual variable must be zero.
  • \textbf{Optimal Solution}: The solution to a linear programming problem that maximizes (or minimizes) the objective function while satisfying all constraints.
  • Shadow Price: The rate of change in the optimal objective function value for a unit change in the right-hand side of a constraint.
  • Reduced Costs: The vector $z_N = (B^{-1}N)^T c_B - c_N$, representing the change in the objective function value per unit increase in a non-basic variable. A non-negative $z_N$ indicates optimality.
  • Complementary Slackness Conditions: Conditions that relate the primal and dual optimal solutions. Specifically, for each constraint, either the constraint is binding (equality holds) or the corresponding dual variable is zero (and vice versa).
  • Sensitivity Analysis: The study of how changes in the parameters of a linear programming problem (e.g., objective function coefficients, constraint coefficients, or right-hand side values) affect the optimal solution.
  • Basis Matrix ($B$): A submatrix of the constraint matrix $A$ formed by the columns corresponding to the basic variables.
  • Non-basis Matrix ($N$): A submatrix of the constraint matrix $A$ formed by the columns corresponding to the non-basic variables.
  • Dual Simplex Method: A variant of the simplex method that starts with a dual feasible solution and iteratively moves towards primal feasibility while maintaining dual feasibility, ultimately finding an optimal solution for both the primal and dual problems.
  • Dual Based Phase I Algorithm: A method used to find an initial feasible solution for the dual problem when the origin is not dual feasible. It modifies the dual problem to ensure feasibility at the origin, then solves the modified dual problem using the dual simplex method.
  • Entering Variable: In the simplex method, the non-basic variable selected to become a basic variable in the next iteration, typically chosen based on the most negative reduced cost.
  • Leaving Variable: In the simplex method, the basic variable selected to become a non-basic variable in the next iteration, chosen to maintain feasibility by ensuring that all basic variables remain non-negative.
  • Elementary Matrix: A matrix obtained by performing a single elementary row operation (such as swapping two rows, multiplying a row by a non-zero scalar, or adding a multiple of one row to another) on an identity matrix. Used in the simplex method to efficiently update the basis matrix.
  • Convex Set: A set $S \subseteq \mathbb{R}^m$ such that for any $z_1, z_2 \in S$, $\lambda z_1 + (1-\lambda) z_2 \in S$ for all $0 \le \lambda \le 1$.
  • Convex Combination: A weighted sum of points $z_1, z_2, \dots, z_n \in \mathbb{R}^m$ of the form $\sum_{i=1}^n \lambda_i z_i$, where $\lambda_i \ge 0$ for all $i$ and $\sum_{i=1}^n \lambda_i = 1$.
  • Convex Hull: For a set $S \subseteq \mathbb{R}^m$, the convex hull of $S$, denoted $\text{Conv}(S)$, is the intersection of all convex sets containing $S$. It is the smallest convex set containing $S$.
  • Caratheodory Theorem: If $z \in \text{Conv}(S)$, then $z$ can be written as a convex combination of at most $m+1$ points from $S$.
  • Separation Theorem: Let $P$ and $\bar{P}$ be two disjoint nonempty polyhedra in $\mathbb{R}^n$. Then there exist disjoint half-spaces $H$ and $\bar{H}$ such that $P \subset H$ and $\bar{P} \subset \bar{H}$.
  • Farkas' Lemma: The system $Ax \le b$ has no solution if and only if there exists a vector $y \ge 0$ such that $y^T A = 0$ and $y^T b < 0$.
  • $L^2$ Regression (Least Square): Minimizes the sum of squared errors between observed and predicted values.
  • $L^1$ Regression: Minimizes the sum of absolute errors between observed and predicted values.
  • $L^\infty$ Regression: Minimizes the maximum absolute error between observed and predicted values.
  • Linear Separability: A dataset is linearly separable if there exists a hyperplane that perfectly separates the data points into two classes.
  • Maximum Margin Classifier: A classifier that maximizes the minimum distance from the hyperplane to the closest data points.
  • Support Vector Machine (SVM): A classification algorithm that finds the hyperplane that maximizes the margin between classes.
  • Support Vectors: The data points closest to the hyperplane in an SVM.
  • Lagrangian Formulation of SVM: A method to reformulate the SVM optimization problem using Lagrange multipliers.
  • Geometric Interpretation of SVM: Understanding SVM optimization through the geometric concept of maximizing the margin between classes.
  • SVM Optimization as a QP Problem: Formulating the SVM problem as a quadratic programming problem.
  • Maximum Inscribed Circle in a Convex Polyhedron: Finding the largest circle that can fit inside a convex polyhedron.
  • Distance of a Point from a Hyperplane: The formula to calculate the distance between a point and a hyperplane.
  • Smallest Ball Problem: Finding the smallest radius ball that contains all given points.
  • Monthly Demands: The predicted sales of ice cream for each month of the year, used as input for the production planning problem.
  • Average Demand: The average monthly sales of ice cream over the entire year, used as a reference point in production planning.
  • Production Level: The amount of ice cream produced in a given month.
  • Surplus: The excess amount of ice cream remaining at the end of a month after meeting the demand.
  • Cost of Changing Production: The cost associated with adjusting the production level from one month to the next.
  • Cost of Storage: The cost of storing surplus ice cream from one month to the next.
  • Required Labor Hours: The predicted number of labor hours needed for each month in a workforce planning problem.
  • Regular Employees: Employees with a fixed hourly wage, used in workforce planning.
  • Temporary Employees: Employees hired on a temporary basis, with a higher hourly wage than regular employees.
  • Portfolio Selection: The problem of choosing the optimal proportions of different investments to maximize return and minimize risk.
  • Annual Return: The return of an investment over a year, considered a random variable in portfolio selection.
  • Proportion of Investment: The fraction of a portfolio invested in a particular asset.
  • Average Return: The expected return of an investment, calculated as the average of historical returns.
  • Risk: The uncertainty or variability associated with the return of an investment or portfolio.
  • Fluctuation: The deviation of an investment's return from its average return.
  • Variance: A measure of the dispersion or spread of the returns of an investment or portfolio.
  • Covariance: A measure of the joint variability of two investments' returns.
  • Smallest Enclosing Ball Problem: The problem of finding the smallest ball (hypersphere) that contains a given set of points.
  • Maximum Weight Matching: The problem of finding a matching in a weighted graph that maximizes the total weight of the edges in the matching.
  • Machine Scheduling: The problem of assigning jobs to machines to minimize the total completion time.
  • Knapsack Problem: The problem of selecting a subset of items with weights and values to maximize the total value while not exceeding a weight limit.
  • Cutting Stock Problem: The problem of cutting large rolls of material into smaller rolls of specified widths to minimize waste.
  • Sparse Solutions of Linear System: The problem of finding a solution to a system of linear equations that has a limited number of non-zero elements.
  • $l_1$ Norm: The sum of the absolute values of the elements of a vector.
  • Support: The set of indices corresponding to non-zero elements of a vector.
  • Integer Programming: A mathematical optimization problem where the objective function and constraints are linear, but the variables are restricted to integer values.
  • Relaxed Problem: The linear programming problem obtained by removing the integer constraints from an integer programming problem.
  • Branch-and-Bound: A method for solving integer programming problems by recursively partitioning the feasible region into smaller subproblems and bounding the optimal solution within each subproblem.
  • Enumeration Tree: A tree structure used in the Branch-and-Bound algorithm to represent the partitioning of the feasible region and the exploration of subproblems.
  • Pruning: The process of eliminating branches in the enumeration tree that cannot lead to a better solution than the best integer solution found so far.
  • Gomory Cuts: Additional linear constraints added to an integer programming problem to cut off non-integer solutions from the feasible region of the relaxed problem.
  • Network Flow: A mathematical model representing the flow of commodities through a network, often formulated as a linear program.
  • Incidence Matrix: A matrix representing the connections between nodes and arcs in a network flow problem. Each column represents an arc, and each row represents a node. The entries indicate the direction of flow.
  • Balanced Equation: An equation representing the conservation of flow at each node in a network, where the total inflow equals the total outflow plus the net supply or demand at that node.
  • Root Node: A designated node in a network used as a reference point for simplifying the representation of the network flow problem, often by removing its corresponding row from the incidence matrix.
  • Tree Solution: A solution to a network flow problem where the flow along arcs in a spanning tree is zero.
  • Spanning Tree: A tree that connects all nodes in a network.
  • Reduced Cost: The cost of increasing the flow along an arc, taking into account the effect on other arcs and nodes in the network.
  • Network: A graph consisting of a set of nodes (N) and a set of edges (A).
  • Primal Flow: A flow in a network that satisfies the flow conservation constraints.
  • Dual Flow: A set of dual variables that satisfy the dual constraints of the network flow problem.
  • Dual Slack: The difference between the cost of an arc and the difference in dual variables between its endpoints.
  • Reconnecting Arc: An arc that connects two disconnected trees in the dual network simplex method.
  • Transportation Problem: A network flow problem where the goal is to minimize the cost of transporting goods from multiple sources to multiple destinations, subject to supply and demand constraints. The constraints are often inequalities, representing upper bounds on supply and lower bounds on demand.
  • Dummy Node: A node added to a network flow model to handle inequality constraints. It represents either excess supply or unmet demand, allowing the conversion of inequality constraints into equality constraints.
  • Upper Bounded Transshipment Problem: A network flow problem where the flow along each arc is constrained by an upper bound, in addition to the usual supply and demand constraints.
  • Shortest Path Problem: A graph problem where the goal is to find the path of minimum weight (or cost) between two specified nodes in a weighted graph.
  • Bellman's Equation: A recursive equation used to solve the shortest path problem. It expresses the shortest distance to a node as the minimum of the distances to its neighbors, plus the cost of the edge connecting them.
  • Dijkstra's Algorithm: A greedy algorithm for finding the shortest paths from a single source node to all other nodes in a graph with non-negative edge weights.
  • Max Flow: The maximum amount of flow that can be sent from a source node to a sink node in a network, subject to capacity constraints on the edges.
  • Min Cut: A partition of the nodes in a network into two sets, one containing the source and the other containing the sink, such that the sum of the capacities of the edges crossing from the source set to the sink set is minimized.
  • Max-Flow Min-Cut Theorem: The theorem states that the maximum flow in a network is equal to the minimum capacity of any cut in the network.
  • Cut: A partition of the nodes in a network into two disjoint sets, one containing the source node and the other containing the sink node.
  • Cut Capacity: The sum of the capacities of all edges that go from the source set to the sink set in a cut.
  • Augmenting Path: A path in a network from the source to the sink along which flow can be increased.
  • Ford-Fulkerson Algorithm: An algorithm for finding the maximum flow in a network by iteratively finding augmenting paths and increasing the flow along them.

Problem Types

  • Finding an Initial Feasible Solution: The Simplex method requires an initial feasible solution. If the origin is not feasible, an auxiliary problem is introduced to find a feasible solution to the original problem.
  • Handling Infeasible Origins: The origin $(0, 0)$ may not satisfy all constraints in a linear programming problem. Techniques like introducing an auxiliary problem are used to find a feasible starting point.
  • Optimizing in Higher Dimensions: The Simplex method is extended to solve linear programming problems with more than two variables, requiring iterative pivoting operations to move between vertices of the feasible region in higher-dimensional space.
  • Using Dictionaries to Represent Solutions: The Simplex method uses dictionaries to represent the current solution and to perform pivot operations efficiently. Each dictionary corresponds to a vertex of the feasible region.
  • Worst-Case Analysis of the Simplex Method: The Klee-Minty example demonstrates that the Simplex method can require an exponential number of iterations in the worst case, depending on the pivot rule used.
  • Impact of Pivot Rules on Simplex Method Efficiency: Different pivot rules (e.g., largest-coefficient, largest-increase) significantly affect the number of iterations required by the Simplex method, with some rules exhibiting exponential worst-case behavior while others perform better in practice.
  • Empirical Analysis of Simplex Method Performance: Empirical studies show that the number of iterations in the Simplex method tends to grow polynomially with the problem size in practice, even though worst-case examples exist.
  • Theoretical Bounds on Simplex Method Iterations: Theoretical analysis of randomized pivot rules provides bounds on the expected number of iterations, which are better than exponential but not polynomial.
  • Smoothed Complexity of the Simplex Method: The smoothed complexity analysis suggests that small random perturbations to the input data can significantly improve the performance of the Simplex method, leading to a polynomial number of iterations with high probability.
  • Existence of Polynomial-Time Algorithms for Linear Programming: Polynomial-time algorithms for linear programming exist, such as interior-point methods, which contrast with the Simplex method's potential for exponential worst-case behavior.
  • Verifying Optimality using Complementary Slackness: This problem focuses on using the complementary slackness conditions ($x_j z_j = 0$ and $w_i y_i = 0$) to verify whether a given primal and dual feasible solution pair is optimal.
  • Demonstrating the Negative Transpose Property in Simplex Iterations: This problem involves showing that the negative transpose relationship between the primal and dual tableaux is maintained throughout the simplex method iterations.
  • Proving Strong Duality: This problem involves proving that if the primal problem has an optimal solution, then the dual problem also has an optimal solution, and the optimal objective function values are equal. The proof utilizes the structure of the simplex tableau at optimality and the relationships between primal and dual variables.
  • Relating Primal and Dual Objective Functions: This problem involves demonstrating the relationship between the primal and dual objective functions, showing how the primal objective function is always less than or equal to the dual objective function, and proving their equality at optimality.
  • Formulating the Lagrangian for Equality Constraints: This problem involves constructing the Lagrangian function $L(x, \mu) = f_0(x) - \sum_{j=1}^n \mu_j g_j(x)$ to incorporate equality constraints $g_j(x) = 0$ into the optimization problem.
  • Formulating the Lagrangian for Inequality and Equality Constraints: This problem involves constructing the Lagrangian function $L(x, \lambda, \mu) = f_0(x) - \sum_{i=1}^m \lambda_i f_i(x) - \sum_{j=1}^n \mu_j g_j(x)$ to incorporate both inequality constraints $f_i(x) \le 0$ and equality constraints $g_j(x) = 0$ into the optimization problem.
  • Establishing Weak Duality: This problem involves proving that the optimal value of the primal problem is less than or equal to the optimal value of the dual problem, i.e., $\max_{x \in \mathcal{G}} \xi(x) \le \min_{\lambda \ge 0, \mu} \xi(\lambda, \mu)$.
  • Establishing Strong Duality: This problem involves proving that under certain conditions, the optimal values of the primal and dual problems are equal, i.e., $\xi(x^) = \xi(\lambda^)$.
  • Deriving the Dual Problem from the Lagrangian: This problem involves deriving the dual problem by analyzing the maximum of the Lagrangian function with respect to the primal variables. This involves determining when the maximum is finite and its value.
  • Applying Complementary Slackness: This problem involves using the complementary slackness condition ($x^_i \lambda^_i = 0$ for all $i$) to verify the optimality of solutions to the primal and dual problems.
  • Formulating the Diet Problem as a Linear Program: This problem involves translating a real-world scenario (the diet problem) into a mathematical model that can be solved using linear programming techniques. The model includes an objective function (minimizing cost) and constraints (meeting minimum nutrient requirements).
  • Formulating the Dual of the Diet Problem: This problem focuses on constructing the dual linear program corresponding to the primal diet problem. The dual problem offers an alternative perspective on the same optimization problem, often with a different interpretation (maximizing profit from selling nutrient pills).
  • Representing the Diet Problem using Tables: This problem involves representing the parameters and variables of the diet problem in a tabular format to facilitate the formulation of the linear program. The table organizes the nutrient content of foods and their costs, making it easier to visualize the relationships between variables and constraints.
  • Representing Linear Programs in Matrix Notation: This problem focuses on expressing linear programming problems using matrices and vectors, facilitating the application of the simplex method.
  • Partitioning Variables into Basic and Non-Basic Sets: This problem involves separating the variables of a linear program into basic and non-basic sets, a crucial step in the simplex algorithm. The constraints are then rewritten in terms of these sets.
  • Expressing the Objective Function in Terms of Basic and Non-Basic Variables: This problem describes the process of rewriting the objective function of a linear program using the basic and non-basic variable partitions, enabling efficient updates during simplex iterations.
  • Updating the Simplex Tableau Using Matrix Operations: This problem involves performing matrix operations to update the simplex tableau during each iteration of the simplex method. This includes updating the objective function and the values of the basic variables.
  • Understanding Complementary Slackness in the Simplex Method: This problem explores the relationship between primal and dual variables in the simplex method, specifically the concept of complementary slackness.
  • Solving a Linear Program Graphically: This problem involves using a graphical method to find the optimal solution to a linear program by identifying the intersection of the objective function line with the feasible region.
  • Illustrating Simplex Iterations with a Numerical Example: This problem uses a specific numerical example to demonstrate the iterative steps of the simplex method, including variable entry and exit from the basis.
  • Deriving the Dual Problem from the Primal Problem: This problem focuses on deriving the dual linear program from a given primal linear program. The derivation involves techniques such as forming the Lagrangian and manipulating inequalities to obtain the dual objective function and constraints.
  • Handling Unrestricted Variables in Linear Programming: This problem addresses how to handle linear programs where variables are not restricted to be non-negative. A method of splitting each unrestricted variable into the difference of two non-negative variables is presented.
  • Proving Weak Duality: This problem involves demonstrating that the objective function value of any feasible solution to the primal problem is less than or equal to the objective function value of any feasible solution to the dual problem.
  • Sensitivity Analysis: Determining how changes in the constraint values affect the optimal solution and objective function value.
  • Applying the Basis and Non-Basis Method: Using the basis and non-basis method to solve linear programming problems, involving matrix operations on the basis and non-basis matrices.
  • Deriving and Utilizing the Dual Problem: Formulating and solving the dual problem to gain insights into the primal problem's solution and sensitivity.
  • \textbf{Solving Primal and Dual Problems Simultaneously}: This problem focuses on the relationship between the primal and dual linear programs, demonstrating that their optimal objective function values are equal at optimality.
  • \textbf{Applying the Dual Simplex Method}: This problem involves solving a linear program using the dual simplex method, starting with a dual-feasible but primal-infeasible solution and iteratively improving the solution until primal feasibility and optimality are achieved.
  • \textbf{Implementing a Dual Based Phase I Algorithm}: This problem describes a method to find an initial feasible solution for a linear program when the origin is infeasible for both the primal and dual problems. It involves modifying the problem to create a dual-feasible starting point.
  • \textbf{Representing the Simplex Method in Matrix Form}: This problem involves expressing the simplex method's iterations using matrix notation, including updating the basis and non-basis matrices and calculating the entering and leaving variables.
  • Proving the equivalence of a convex set and its convex combinations: This problem focuses on demonstrating that a set is convex if and only if it contains all convex combinations of its points. The proof involves showing both directions of the implication.
  • Defining and proving properties of the convex hull: This problem involves defining the convex hull of a set as the smallest convex set containing the original set and proving that it's equivalent to the set of all convex combinations of finitely many points from the original set. The proof uses the definition of convexity and involves showing both inclusions.
  • Proving the Caratheodory Theorem: This problem involves proving that any point in the convex hull of a set in $\mathbb{R}^m$ can be expressed as a convex combination of at most $m+1$ points from the original set. The proof uses linear programming techniques.
  • Proving the Separation Theorem: This problem focuses on proving that two disjoint nonempty polyhedra in $\mathbb{R}^n$ can be separated by two disjoint half-spaces. The proof relies on Farkas' Lemma.
  • Proving Farkas' Lemma: This problem involves proving that a system of linear inequalities $Ax \le b$ has no solution if and only if there exists a non-negative vector $y$ such that $y^T A = 0$ and $y^T b < 0$. The proof often uses duality in linear programming.

Different versions of Farkas' Lemma provide conditions for the existence or non-existence of such a solution, depending on whether non-negativity constraints are imposed on $x$.
  • Integer Programming: This problem involves finding the optimal solution to a linear program where some or all of the variables are restricted to integer values.

  • Network Flow Problems with Inequality Constraints: This problem type focuses on network flow problems where the total flow out of a source node is less than or equal to the supply at that node, and the total flow into a destination node is greater than or equal to the demand at that node. Dummy nodes are introduced to handle excess supply or unmet demand.
  • Upper Bounded Transshipment Problem: This problem type extends the standard network flow problem by adding upper bounds on the flow along each arc. Slack variables are introduced to handle these upper bounds.
  • Shortest Path Problem: This problem aims to find the path with the minimum total cost or distance between a source node and a destination node in a network. It can be formulated as a linear program or solved using algorithms like Bellman-Ford or Dijkstra's algorithm.
  • \textbf{Finding the Maximum Flow in a Network}: This problem involves determining the largest possible flow from a source node to a sink node in a network, subject to capacity constraints on the edges. The max-flow min-cut theorem is used to solve this problem.
  • \textbf{Formulating the Maximum Flow Problem as a Linear Program}: This problem focuses on expressing the maximum flow problem in a network as a linear program, defining the objective function and constraints in terms of flow variables and edge capacities.
  • \textbf{Proving the Max-Flow Min-Cut Theorem using Linear Programming}: This problem involves demonstrating the equivalence between the maximum flow in a network and the minimum capacity of a cut separating the source and sink nodes, using the linear programming formulation of the maximum flow problem.
  • \textbf{Implementing the Ford-Fulkerson Algorithm}: This problem involves understanding and implementing the Ford-Fulkerson algorithm, which iteratively finds augmenting paths to increase the flow in a network until the maximum flow is reached. The algorithm's steps, including node labeling and arc scanning, are detailed.
  • Finding Fair Prices in Network Simplex: This problem involves determining a set of prices $y_i$ at each node $i$ in a network such that $y_i + c_{ij} = y_j$ for each arc $ij$ in a spanning tree $T$, representing fair market prices consistent with shipping costs.
  • Identifying Profitable Shipping Opportunities for Competitors: This problem focuses on finding an arc $ij$ in a network where $y_i + c_{ij} < y_j$, indicating a profitable opportunity for a competitor to undercut the current market prices by shipping along that arc.
  • Adjusting Shipments to Maintain Feasibility: This problem involves adjusting shipments along the arcs of a spanning tree $T$ after introducing a new arc to maintain the feasibility of the solution, ensuring that the flow balance is maintained throughout the network.

Algorithm Solutions

  • Simplex Method: Iteratively move from one vertex of the feasible region to another by setting non-basic variables to zero and choosing a new set of (non)basic variables to improve the objective function value. This is equivalent to moving from vertex to vertex in the feasible region.
  • Auxiliary Problem: When the origin is not feasible, introduce a new variable $x_0$ and modify the constraints to create an auxiliary problem that maximizes $-x_0$. Solve this auxiliary problem to find a feasible solution for the original problem. If the optimal solution has $x_0 = 0$, then a feasible solution to the original problem is found.
  • Largest-Coefficient Rule: Choose the variable with the largest coefficient in the objective function row to enter the basis.
  • Largest-Increase Rule: Choose the variable whose entrance into the basis brings about the largest increase in the objective function.
  • Bland's Rule: Choose the variable with the smallest index among those eligible to enter the basis.
  • Randomized Pivot Rule: Randomly permute the indices of the variables; then use Bland's rule for entering and the lexicographic method for leaving variables.
  • Weak Duality: $c^T x \le b^T y$
  • Strong Duality: If (P) has an optimal solution ($x^$), then (D) has an optimal solution ($y^$) and $c^T x^ = b^T y^$.
  • Complementary Slackness: Primal feasible $x$ and dual feasible $y$ are optimal if and only if $x_j z_j = 0$ for $j = 1, \dots, n$ and $w_i y_i = 0$ for $i = 1, \dots, m$.
  • Lagrangian Function: $L(x,\lambda,\mu) = f_0(x) - \sum_{i=1}^m \lambda_i f_i(x) - \sum_{j=1}^n \mu_j g_j(x)$
  • Primal Problem (Diet Problem): $\text{Minimize } Z(x) = \sum_{j} c_j x_j \text{ subject to } \sum_{j} a_{ij} x_j \ge b_i, x_j \ge 0$
  • Dual Problem (Diet Problem): $\text{Maximize } Z(y) = \sum_{i} b_i y_i \text{ subject to } \sum_{i} y_i a_{ij} \le c_j, y_i \ge 0$
  • Simplex Method in Matrix Form: The simplex method iteratively improves a feasible solution by exchanging basic and non-basic variables until an optimal solution is found. This involves updating the objective function and constraints using matrix operations, specifically involving the basis matrix $B$ and its inverse $B^{-1}$, and the non-basic variable matrix $N$. The objective function is expressed as $\mathcal{Z} = \mathbf{c}_B^T B^{-1} \mathbf{b} + (\mathbf{c}_N^T - \mathbf{c}_B^T B^{-1} N) \mathbf{x}_N$, where $\mathbf{c}_B$ and $\mathbf{c}_N$ are the cost vectors for basic and non-basic variables, respectively, and $\mathbf{b}$ is the right-hand side vector of the constraints.
  • Sensitivity Analysis: This technique analyzes how changes in the parameters of a linear programming problem (e.g., objective function coefficients, constraint coefficients, or right-hand side values) affect the optimal solution and objective function value. It often involves calculating the range of parameter changes that maintain the current optimal basis.
  • Shadow Price: The shadow price of a constraint is the rate of change in the optimal objective function value with respect to a unit change in the right-hand side of that constraint. It is given by the corresponding optimal dual variable.
  • Dual Based Phase I Algorithm: This algorithm addresses infeasible linear programs by first finding a dual feasible solution and then iteratively improving it to achieve primal feasibility, ultimately leading to an optimal solution.
  • Caratheodory's Theorem: If $z \in \text{Conv}(S)$, then $z$ can be written as a convex combination of at most $m+1$ points from $S$.
  • Farkas' Lemma: The system $Ax \le b$ has no solution if and only if there exists a vector $y \ge 0$ such that $y^T A = 0$ and $y^T b < 0$.
  • Separation Theorem: Let $P$ and $\bar{P}$ be two disjoint nonempty polyhedra in $\mathbb{R}^n$. Then there exist disjoint half-spaces $H$ and $\bar{H}$ such that $P \subset H$ and $\bar{P} \subset \bar{H}$.
  • $L^2$ Regression (Least Square): $\min_{(x_1, \dots, x_n)} \sum_{i=1}^m \left| (b_i - \sum_{j=1}^n a_{ij} x_j) \right|^2$ or $\min \left\| b - AX \right\|_2^2$, solved by $A^T A \hat{X} = A^T b$ (normal equation) and $\hat{X} = (A^T A)^{-1} A^T b$ (if $(A^T A)^{-1}$ exists).
  • $L^1$ Regression: $\min_{x_1, \dots, x_n} \sum_{i=1}^m |b_i - \sum_{j=1}^n a_{ij} x_j|$ or $\min_X \|b - AX\|_1$, solved by introducing slack variables $\hat{\varepsilon}_i$ such that $-\hat{\varepsilon}_i \le b_i - \sum_{j=1}^n a_{ij} x_j \le \hat{\varepsilon}_i$ and minimizing $\sum_{i=1}^m \hat{\varepsilon}_i$.
  • $L^\infty$ Regression: $\min_{x_1, \dots, x_n} \max_{i} |b_i - \sum_{j=1}^n a_{ij} x_j|$ or $\min_X \|b - AX\|_\infty$, solved by introducing a slack variable $\delta$ such that $-\delta \le b_i - \sum_{j=1}^n a_{ij} x_j \le \delta, \quad \forall i$ and minimizing $\delta$.
  • Lagrangian Formulation of SVM: $\min_{\alpha} \frac{1}{2} \sum_{i=1}^N \sum_{j=1}^N \alpha_i \alpha_j y_i y_j x_i^T x_j - \sum_{i=1}^N \alpha_i$ subject to $\sum_{i=1}^N \alpha_i y_i = 0$ and $0 \le \alpha_i \le C, \quad \forall i$.
  • Smallest Ball Problem: Given points $p_1, \dots, p_n \in \mathbb{R}^d$, find a ball of the smallest radius that contains all the points.
  • Ice Cream Production Planning: $\min \sum_{i=1}^{12} 50(Y_i + Z_i) + 20 \sum_{i=1}^{12} S_i$ s.t. $X_i + S_{i-1} - S_i = d_i$, $X_i - X_{i-1} = Y_i - Z_i$, $X_0 = 0$, $S_0 = 0$, $S_{12} = 0$, $X_i, Y_i, Z_i, S_i \ge 0$
  • Workforce Planning: $\min 25 \sum_{i=1}^{12} Y_i + (17.5 \times 12) X$ s.t. $a_i - X \le Y_i$, $0 \le Y_i$, $X \ge 0$
  • Portfolio Selection (Markowitz Model): $\max \mu \sum_{j} x_j \overline{r_j} - \frac{\epsilon}{2} \sum_{i} \sum_{j} x_i x_j \sigma_{ij}$ s.t. $\sum_{j} x_j = 1$, $x_j \ge 0$
  • Maximum Weight Matching: $\max \sum_{e \in E} w_e x_e$ s.t. $\sum_{e \in \delta(v)} x_e = 1$ for all vertices $v$, $x_e \in \{0, 1\}$ for all edges $e$
  • Machine Scheduling: $\min \pi$ s.t. $\sum_{i \in M} x_{ij} = 1$ for $j \in J$, $\sum_{j \in J} d_{ij} x_{ij} \le \pi$ for $i \in M$, $x_{ij} \in \{0, 1\}$ for all $i, j$
  • Knapsack Problem: maximize $\sum_{j=1}^n c_j x_j$ subject to $\sum_{j=1}^n a_j x_j \le b$, $x_j \in \{0, 1\}$, $j = 1, 2, \dots, n$
  • Cutting Stock Problem: $\min \sum_{i=1}^{12} x_i$ subject to constraints based on cutting patterns $P_i$ and demand for different widths
  • Sparse Solutions of Linear System: $\min \|x\|_1$ s.t. $Ax = b$
  • Branch and Bound: This algorithm solves integer programming problems by recursively partitioning the feasible region into subproblems, solving the relaxed linear program for each subproblem, and pruning branches that cannot yield a better solution than the best integer solution found so far. A depth-first search strategy is often employed to find integer feasible solutions early, enabling pruning and improving efficiency.
  • Gomory Cuts: This algorithm solves integer programming problems by iteratively adding new constraints (Gomory cuts) to the relaxed linear program. These cuts are derived from the fractional parts of the basic variables in the optimal dictionary of the relaxed problem and are designed to eliminate non-integer solutions while preserving integer feasible solutions. The process is repeated until an integer optimal solution is found.
  • Network Flow Problem Formulation: The network flow problem is formulated as a linear program with the objective function $\text{min} \sum_{(i,j) \in \mathcal{A}} C_{ij} X_{ij}$ subject to flow conservation constraints $\sum_{i} x_{ik} - \sum_{j} x_{kj} = -b_k$ at each node $k$ and non-negativity constraints $X \ge 0$.
  • Primal Simplex Method for Network Flows: The primal simplex method is adapted for network flows by iteratively updating a spanning tree. An entering variable (arc) with the most negative reduced cost is selected, and a leaving variable (arc) is identified from the cycle formed by the entering arc and the current spanning tree. The spanning tree is updated, and primal and dual variables are recalculated until all dual slacks are non-negative.
  • Finding a Spanning Tree Basis: A square submatrix of the modified incidence matrix $\tilde{A}$ (incidence matrix with a root node row removed) forms a basis if and only if the corresponding arcs form a spanning tree. This basis is used to solve for primal flows using $X_B = -B^{-1} N X_N - B^{-1} \tilde{b}$, where $X_B$ are basic variables (flow on arcs in the spanning tree), $X_N$ are non-basic variables (flow on arcs not in the spanning tree), $B$ is the basis matrix, and $N$ is the non-basis matrix.
  • Dual Variable Calculation from Spanning Tree: Given a spanning tree, dual variables are calculated iteratively starting from a root node using the dual flow equation $y_j - y_i + z_{ij} = c_{ij}$ for arcs $(i,j)$ in the spanning tree, where $z_{ij} = 0$. Dual slacks for arcs not in the spanning tree are then computed using $z_{ij} = y_j - y_i + c_{ij}$.
  • Parametric Self-Dual Network Simplex Method: This method interweaves primal and dual pivots to reduce a perturbation parameter $\mu$ from $\infty$ to 0, finding an optimal solution.
  • Bellman's Equation: $v_i = \min_{j} \{c_{ij} + v_j\}$, $v_r = 0$
  • Ford-Fulkerson Algorithm: This algorithm iteratively finds augmenting paths in a network and updates the flow along these paths to increase the total flow from the source to the sink until no more augmenting paths can be found.
  • Max-Flow Min-Cut Theorem: The maximum flow from the source to the sink in a network is equal to the minimum capacity of any cut in the network.
  • Linear Programming Formulation of Max Flow: The maximum flow problem can be formulated as a linear program with an objective function to maximize the flow from source to sink, subject to constraints ensuring flow conservation at each node and respecting edge capacities. A fictitious arc from sink to source with infinite capacity is often added.
