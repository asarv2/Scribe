\begin{itemize}[leftmargin=*]%

\item \href{\url{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%252Fcontent\%252Fenforced\%252F1095467-wl.202510.CS.24300.001\%252F05L2-ML\%20Basics.pdf\%253Fou\%253D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667}#page=27}{\textbf{Perceptron Loss}}: Minimize the perceptron loss function $l(z) = \max\{0, -z\}$, where $z = y(w^Tx)$. \item \href{\url{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%252Fcontent\%252Fenforced\%252F1095467-wl.202510.CS.24300.001\%252F05L2-ML\%20Basics.pdf\%253Fou\%253D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667}#page=31}{\textbf{Logistic Regression}}: Minimize the logistic loss function $F(w) = \sum_{i=1}^{N} \log(1 + e^{-y_iw^Tx_i})$. The update rule for stochastic gradient descent is $w \leftarrow w + \alpha(\sigma(-y_nw^Tx_n)y_nx_n)$, where $\sigma(z) = \frac{1}{1 + e^{-z}}$ is the sigmoid function and $\alpha$ is the learning rate.%
\end{itemize}
