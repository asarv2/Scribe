\begin{itemize}[leftmargin=*]%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=4}{\textbf{Clustering}}: The process of grouping a set of objects into classes of similar objects. Objects within a cluster should be similar, and objects from different clusters should be dissimilar.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=21}{\textbf{K-means clustering}}: A commonly used clustering algorithm that partitions objects into $K$ disjoint subsets, assuming the objects are $p$-dimensional vectors and using a distance measure (typically Euclidean distance) between them.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=17}{\textbf{Euclidean distance}}: The most commonly used distance measure for continuous data, defined as $d_E(x, y) = \sqrt{\sum_{i=1}^{p} (x_i - y_i)^2}$, where $p$ is the number of attributes/dimensions.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=19}{\textbf{Hamming distance}}: A distance measure used for bit/binary vectors that counts the number of bits that differ. It can be generalized to discrete data to count mismatches.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=19}{\textbf{Matching coefficient}}: A normalized Hamming distance, obtained by dividing the Hamming distance by the number of attributes/bits.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=33}{\textbf{Inertia}}: In the context of K-means, the sum of squared distances from each point to its cluster centroid. Minimizing inertia is the goal of K-means optimization.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=44}{\textbf{Purity}}: A measure of the extent to which clusters contain objects of a particular class. It's calculated as $\text{purity}(C, G) = \frac{1}{N} \sum_{i=1}^{K} \max_j N_j \in G_i$, where $N$ is the total number of points, $K$ is the number of clusters, and $N_j$ is the number of examples of class $j$ in cluster $i$.%
\end{itemize}

\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F08L2-Feature Extraction.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=43}{\textbf{Anisotropic Gaussian}}: $G_{\sigma_x, \sigma_y}(x, y) = \frac{1}{2\pi\sigma_x\sigma_y} \cdot e^{-\frac{1}{2}((\frac{x^2}{\sigma_x^2}) + (\frac{y^2}{\sigma_y^2}))}$%

\subsection{Artificial Intelligence Fundamentals}%
\label{subsec:ArtificialIntelligenceFundamentals}%
\begin{itemize}[leftmargin=*]%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F02L2-Intro.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=22}{\textbf{Minimax Search}}: A recursive algorithm for two-player zero-sum games that explores the game tree to find the best move for the current player, assuming the opponent also plays optimally. It alternates between maximizing the score for the current player and minimizing the score for the opponent.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F02L2-Intro.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=23}{\textbf{Alpha-Beta Pruning}}: An optimization technique for Minimax search that reduces the search space by avoiding the evaluation of branches that cannot affect the optimal decision. It uses alpha and beta values to prune branches.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F14L1-DepthFS.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=3}{\textbf{Recursion}}: A method that calls itself, eventually terminating in a base case. The recursive case must be ``smaller`` in some sense, closer to the base case.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F14L1-DepthFS.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=4}{\textbf{Recursive Problem Solving}}: Do part of the work and reduce the rest into a similar but smaller problem.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F14L1-DepthFS.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=8}{\textbf{Structural Recursion}}: Traversal of recursive data structures like trees using Breadth-First Search or Depth-First Search.%
\end{itemize}

\subsection{SAT Solvers}%
\label{subsec:SATSolvers}%
\begin{itemize}[leftmargin=*]%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F13L1-Logic.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=17}{\textbf{Conversion to CNF}}: This algorithm transforms a logical expression into Conjunctive Normal Form (CNF) by applying logical equivalences to eliminate implications, biconditionals, and negations, and then using distributivity to flatten the expression into a conjunction of clauses.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F13L1-Logic.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=15}{\textbf{SAT Problem}}: This problem determines if a given propositional formula (often in CNF) is satisfiable, meaning there exists an assignment of truth values to its variables that makes the formula true.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F13L1-Logic.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=24}{\textbf{3-SAT Reduction}}: This algorithm reduces a general SAT problem to a 3-SAT problem by transforming clauses with more than three literals into a conjunction of clauses with exactly three literals using auxiliary variables. The resulting formula is equisatisfiable with the original.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F15L2-SAT.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=17}{\textbf{DPLL}}: A recursive algorithm that improves upon the Naïve\_SAT algorithm by incorporating Boolean Constraint Propagation (BCP) to efficiently identify and resolve unit clauses, significantly reducing the search space.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F15L2-SAT.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=20}{\textbf{BCP}}: A sub-algorithm within DPLL that repeatedly identifies and assigns values to literals in unit clauses (clauses with only one unassigned literal), leading to a cascading effect of assignments and conflict detection.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F15L2-SAT.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=32}{\textbf{Resolution Rule}}: An inference rule that derives a new clause from two existing clauses containing a literal and its negation. The new clause combines the remaining literals from the original clauses using logical OR.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F15L2-SAT.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=35}{\textbf{Clause Learning}}: A technique used to learn from conflicts encountered during the DPLL search. When a conflict occurs, a clause is learned that prevents the algorithm from repeating the same mistake in the future.%
\end{itemize}

\subsection{Model Evaluation and Selection}%
\label{subsec:ModelEvaluationandSelection}%
\begin{itemize}[leftmargin=*]%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F10L1-CrossValidation.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=25}{\textbf{S-fold Cross Validation}}: Split training data into $S$ equal parts; use each part as validation data, others as training data; choose hyperparameter with best average performance.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F12L2-distance-clusters.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=44}{\textbf{Purity}}: $purity(C, G) = \frac{1}{N} \sum_{i=1}^{K} \max_{j} N_j \in G_i$, where $N$ is the total number of data points, $K$ is the number of clusters, and $N_j$ is the number of examples of class $j$ in cluster $i$.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F16L2-ethics.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=25}{\textbf{Fairness through Blindness}}: Ignore protected attributes during model training and prediction.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F16L2-ethics.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=26}{\textbf{Group Fairness}}: $P(\text{outcome } o | S) = P(\text{outcome } o | T)$, where $S$ and $T$ are two groups.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F16L2-ethics.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=27}{\textbf{Individual Fairness}}: Treat similar individuals similarly; similar individuals should have similar outcomes.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F16L2-ethics.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=34}{\textbf{Removing Bias from Models}}: Keep bias features in the data during training, then remove what was learned from these features after training.%
\end{itemize}
