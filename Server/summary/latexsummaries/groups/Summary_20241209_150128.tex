\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F07L2-Vision.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=38}{\textbf{Moving Average Filter}}: Replace each pixel with an average of all the values in its neighborhood%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F07L2-Vision.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=40}{\textbf{Weighted Moving Average Filter}}: Add weights to the moving average to give different importance to neighboring pixels%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F07L2-Vision.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=55}{\textbf{Image Sharpening}}: $f_{sharp} = f + \alpha(f - f_{blur})$%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F08L2-Feature Extraction.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=17}{\textbf{Image Gradient Magnitude}}: $||\nabla f|| = \sqrt{(\frac{\partial f}{\partial x})^2 + (\frac{\partial f}{\partial y})^2}$%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F08L2-Feature Extraction.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=34}{\textbf{Image Gradient Direction}}: $\theta = \tan^{-1}(\frac{\partial f}{\partial x} / \frac{\partial f}{\partial y})$%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F08L2-Feature Extraction.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=43}{\textbf{Anisotropic Gaussian}}: $G_{\sigma_x, \sigma_y}(x, y) = \frac{1}{2\pi\sigma_x\sigma_y} \cdot e^{-\frac{1}{2}((\frac{x^2}{\sigma_x^2}) + (\frac{y^2}{\sigma_y^2}))}$%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F08L2-Feature Extraction.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=43}{\textbf{Isotropic Gaussian}}: $G_\sigma(x, y) = \frac{1}{2\pi\sigma^2} \cdot e^{-\frac{r^2}{2\sigma^2}}$%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F09L1-cnn.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=6}{\textbf{Convolution}}: A convolution operation involves sliding a filter (kernel) across an input image, performing element-wise multiplication between the filter and the corresponding input region, and summing the results to produce a single output value. This process is repeated for every possible position of the filter on the input image, resulting in an output feature map.%
\end{itemize}

\subsection{Search Algorithms}%
\label{subsec:SearchAlgorithms}%
\begin{itemize}[leftmargin=*]%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F02L2-Intro.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=22}{\textbf{Minimax Search}}: A recursive algorithm for two-player zero-sum games that explores the game tree to find the best move for the current player, assuming the opponent also plays optimally. It alternates between maximizing the score for the current player and minimizing the score for the opponent.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F02L2-Intro.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=23}{\textbf{Alpha-Beta Pruning}}: An optimization technique for Minimax search that reduces the search space by avoiding the evaluation of branches that cannot affect the optimal decision. It uses alpha and beta values to prune branches.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F14L1-DepthFS.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=8}{\textbf{Breadth First Search}}: Visits nodes level by level. Check the current node, add children to a queue.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F14L1-DepthFS.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=8}{\textbf{Depth First Search}}: Traverses down a branch. Check current node, then left, then right (other orders are possible).%
\end{itemize}

\subsection{SAT Solvers}%
\label{subsec:SATSolvers}%
\begin{itemize}[leftmargin=*]%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F13L1-Logic.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=17}{\textbf{Conversion to CNF}}: This algorithm transforms a logical expression into Conjunctive Normal Form (CNF) by applying logical equivalences to eliminate implications, biconditionals, and negations, and then using distributivity to flatten the expression into a conjunction of clauses.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F15L2-SAT.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=18}{\textbf{Naïve Solver}}: A recursive algorithm that explores all possible variable assignments to determine satisfiability of a propositional formula. It checks for immediate satisfiability or unsatisfiability, then recursively calls itself with assignments of true and false to an unassigned variable, backtracking if both fail.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F15L2-SAT.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=17}{\textbf{DPLL Algorithm}}: A recursive algorithm that extends the Naïve Solver by incorporating Boolean Constraint Propagation (BCP) to efficiently identify and resolve unit clauses, significantly reducing the search space.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F15L2-SAT.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=32}{\textbf{Resolution Rule}}: An inference rule that derives a new clause ($α ∨ β$) from two clauses ($x ∨ α$) and ($¬x ∨ β$) containing a literal ($x$) and its negation ($¬x$).%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F15L2-SAT.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=35}{\textbf{Clause Learning}}: A technique used in advanced SAT solvers where, upon backtracking from a conflict, a new clause is learned to prevent similar conflicts in the future. This clause represents the "reason" for the conflict, effectively pruning the search space.%
\end{itemize}

\subsection{Bias and Fairness in ML}%
\label{subsec:BiasandFairnessinML}%
\begin{itemize}[leftmargin=*]%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F16L2-ethics.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=25}{\textbf{Fairness through Blindness}}: Ignore protected attributes during model training and prediction.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F16L2-ethics.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=26}{\textbf{Group Fairness}}: $P(\text{outcome } o | S) = P(\text{outcome } o | T)$, where $S$ and $T$ are two groups. This is insufficient as a notion of fairness.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F16L2-ethics.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=27}{\textbf{Individual Fairness}}: Treat similar individuals similarly; similar individuals should be treated similarly for the purpose of the classification task and should be similarly distributed over outcomes.%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=%2Fcontent%2Fenforced%2F1095467-wl.202510.CS.24300.001%2F16L2-ethics.pdf%3Fou%3D1095467&lang=en-us&container=d2l-fileviewer-rendered-pdf&fullscreen=d2l-fileviewer-rendered-pdf-dialog&height=667#page=34}{\textbf{Detecting and removing bias from models}}: Keep bias features in data during training, remove what was learned from these bias features after training.%
\end{itemize}
