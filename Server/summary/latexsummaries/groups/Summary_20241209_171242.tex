\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F07L2-Vision.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=30}{\textbf{Nearest Neighbor Classifier}}: Assign label of nearest training data point to each test data point%
\item \href{https://purdue.brightspace.com/d2l/common/assets/pdfjs-d2l-dist/1.0.14-legacy/web/viewer.html?file=\%2Fcontent\%2Fenforced\%2F1095467-wl.202510.CS.24300.001\%2F10L1-CrossValidation.pdf\%3Fou\%3D1095467\&lang=en-us\&container=d2l-fileviewer-rendered-pdf\&fullscreen=d2l-fileviewer-rendered-pdf-dialog\&height=667#page=17}{\textbf{Regularized Linear Regression}}: $E(w) = RSS(w) + \lambda R(w)$, where $R(w) = ||w||_2^2 = w_1^2 + ... + w_k^2$ or $R(w) = ||w||_1 = |w_1| + ... + |w_k|$.%
