# Slide 7

**Why edges?**

Grouping pixels into objects ("perceptual organization")

**Overall Context:**

The slide is part of a lecture on AI Basics, specifically focusing on edge detection. The images illustrate how edge detection can be used to group pixels into objects, a fundamental concept in image processing and computer vision. The left image is a complex, realistic image, while the right image is a simplified version highlighting the edges of the tiger.  This simplification demonstrates how edge detection can extract the essential information needed to recognize an object, even in the presence of complex background details.
