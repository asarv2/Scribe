# Slide 24

**Corner detection the math**

Consider shifting the window W by (u, v)
How do the pixels in W change?

ϕ<sub>0</sub> = [I(0,0), I(0,1), ..., I(n, n)]
ϕ<sub>1</sub> = [I(0 + u,0 + v), I(0 + u,1 + v), ..., I(n + u, n + v)]

Write pixels in window as a vector:
E(u, v) = ||ϕ<sub>0</sub> −ϕ<sub>1</sub>||<sup>2</sup>
= ∑<sub>(x,y)∈W</sub> (I(x, y) −I(x + u, y + v))<sup>2</sup>
