# Slide 3

**Bag of Features Object Recognition**

How do we use Bag of Features for object categorization?

**category models**

*   _Model space_

    A 3D scatter plot is shown in the right-hand side of the slide.  The plot shows several small, light-pink circles and several small, light-teal circles.  The circles are scattered in a 3D space, with the axes not explicitly labeled.  The plot is meant to represent a model space, where each point represents a category model.  The different colors of the circles visually separate the different categories.  The 3D scatter plot is used to illustrate how different categories of objects are represented in a model space based on their extracted features.


*   _Class 1_

    A series of bar graphs are shown in the left-hand side of the slide.  Each bar graph represents a set of features extracted from an image.  The x-axis represents the different features, and the y-axis represents the frequency of each feature.  The graphs are stacked vertically, with the topmost graph labeled "Class 1" and the bottommost graph labeled "Class N."  The graphs are in light-pink color.  The bar graphs are used to illustrate the feature vectors for different classes of objects.


*   _Class N_

    Another series of bar graphs are shown in the left-hand side of the slide.  These graphs are similar to the "Class 1" graphs, but they are in light-teal color.  The graphs are stacked vertically, with the topmost graph labeled "Class N" and the bottommost graph labeled "Class 1."  The graphs are used to illustrate the feature vectors for different classes of objects.


**Description of the slide:**

This slide builds upon the previous slide's introduction to Bag of Features by demonstrating how category models are created and represented in a model space.  The bar graphs on the left side of the slide visually represent the feature vectors for different object categories (Class 1 and Class N).  The 3D scatter plot on the right side of the slide represents the model space, where each point corresponds to a category model based on its feature vector.  The slide aims to illustrate the process of using Bag of Features to categorize objects by mapping their feature vectors into a model space.
