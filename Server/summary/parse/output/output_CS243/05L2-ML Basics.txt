# The very first ML problem – linear regression

This only shows (w*, l*) is a stationary point, can you prove it is actually the minima?
We ask, which w, l minimizes this distance?
r = (ws<sub>1</sub> + l - p<sub>1</sub>)<sup>2</sup> + ... + (ws<sub>N</sub> + l - p<sub>N</sub>)<sup>2</sup>
Minimizing a quadratic function... Calculus!

∂r/∂w = 2s<sub>1</sub>(s<sub>1</sub>w + l - p<sub>1</sub>) + ... + 2s<sub>N</sub>(s<sub>N</sub>w + l - p<sub>N</sub>) = 0
∂r/∂l = 2(s<sub>1</sub>w + l - p<sub>1</sub>) + ... + 2(s<sub>N</sub>w + l - p<sub>N</sub>) = 0
Gives
w* = σ<sup>2</sup><sub>SP</sub> / σ<sup>2</sup><sub>SS</sub>,  l* = ¯P - w*¯S

Where Averages, Variance, and Covariance
¯P = 1/N Σ<sub>i=1</sub><sup>N</sup> p<sub>i</sub> and ¯S = 1/N Σ<sub>i=1</sub><sup>N</sup> s<sub>i</sub>
σ<sup>2</sup><sub>SP</sub> = 1/N Σ<sub>i=1</sub><sup>N</sup> (s<sub>i</sub> - ¯S)(p<sub>i</sub> - ¯P)
σ<sup>2</sup><sub>SS</sub> = 1/N Σ<sub>i=1</sub><sup>N</sup> (s<sub>i</sub> - ¯S)<sup>2</sup>

     [ β₁ ]
     [ β₂ ]

     [ ϵ₂ ]

(empirical risk minimizer)
