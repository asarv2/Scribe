# Slide 55

**Sharpening**

`f<sub>sharp</sub> = f + α(f − f<sub>blur</sub>)`
= (1 + α)f − αf<sub>blur</sub>
= (1 + α)(w * f) − α(v * f)
= ((1 + α)w − αv) * f
