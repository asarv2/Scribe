```markdown
Applying PCA
New data vectors are formed by projecting the data onto the first few principal components (i.e., top m eigenvectors)
x = [x<sub>1</sub>, x<sub>2</sub>, ..., x<sub>p</sub>] (original instance data)
A = [a<sub>1</sub>, a<sub>2</sub>, ..., a<sub>p</sub>] (principal component vectors)
x′<sub>1</sub> = a<sub>1</sub> ⋅ x = Σ<sub>j=1</sub><sup>p</sup> a<sub>1j</sub>x<sub>j</sub>
...
x′<sub>m</sub> = a<sub>m</sub> ⋅ x = Σ<sub>j=1</sub><sup>p</sup> a<sub>mj</sub>x<sub>j</sub> for m ≤ p
x′ = [x′<sub>1</sub>, x′<sub>2</sub>, ..., x′<sub>m</sub>] (transformed instance)
If m = p then data is transformed
If m < p then transformation is lossy and dimensionality is reduced
```
