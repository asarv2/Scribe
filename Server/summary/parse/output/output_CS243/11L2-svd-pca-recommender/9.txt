```markdown
Low Rank Matrix Approximations
Consider an n × d matrix X, which represents set of n examples, each with d attributes.
What’s a good notion of dimensionality reduction for these matrices?
Reduce the rank of the matrix (from d to k<d):
Linear algebra—the following are equivalent definitions for the rank of a matrix X to be k:
• The largest linearly independent subset of columns of X has size k,
ie. all d columns of X arise as linear combinations of only k different n-vectors
• The largest linearly independent subset of rows of X has size k,
ie. all n rows of X arise as linear combinations of only k different d-vectors
• X can be written as the product of a (n × k) matrix A and a (k × d) matrix B.
```
