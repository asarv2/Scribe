**Tuning on Held-Out Validation Data**

Now we've got two kinds of unknowns

*   Parameters: the probabilities P(X|Y), P(Y)
*   Hyperparameters:
    *   e.g., the amount / type of smoothing to do: k, α

What should we learn where?

*   Learn parameters from training data
*   Tune hyperparameters on (different) validation data.
*   Why?
    *   For each value of the hyperparameters, estimate model on training data and test on the held-out validation data
    *   Choose the best values and do a final test on the test data
