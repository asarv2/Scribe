**Convert Any Functions to CNF**

* CNF(p) = p
* CNF(-p) = ¬p
* CNF(φ → ψ) = CNF(¬φ) ⊗ CNF(ψ)
* CNF(φ ∧ ψ) = CNF(φ) ∧ CNF(ψ)
* CNF(φ ∨ ψ) = CNF(φ) ⊗ CNF(ψ)
* CNF(φ ↔ ψ) = CNF(φ → ψ) ∧ CNF(ψ → φ)
* CNF(¬¬φ) = CNF(φ)
* CNF(¬(φ → ψ)) = CNF(φ) ∧ CNF(¬ψ)
* CNF(¬(φ ∧ ψ)) = CNF(¬φ) ⊗ CNF(¬ψ)
* CNF(¬(φ ∨ ψ)) = CNF(¬φ) ∧ CNF(¬ψ)
* CNF(φ ↔ ψ) = CNF(φ ∧ ¬ψ) ⊗ CNF(ψ ∧ ¬φ)

where (C<sub>1</sub> ∧ ... ∧ C<sub>n</sub>) ⊗ (D<sub>1</sub> ∧ ... ∧ D<sub>m</sub>) is defined as
(C<sub>1</sub> ∨ D<sub>1</sub>) ∧ ... ∧ (C<sub>n</sub> ∨ D<sub>m</sub>) where C<sub>1</sub>, ..., C<sub>n</sub>, D<sub>1</sub>, ..., D<sub>m</sub> are clauses.
