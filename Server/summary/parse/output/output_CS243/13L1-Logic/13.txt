**Validity and satisfiability**

A sentence is valid if it is true in all models (aka tautologies)
e.g., True, A ∨¬A, A ⇒ A, (A ∧ (A ⇒ B)) ⇒ B
A sentence is satisfiable if it is true in some model, e.g., A
A sentence is unsatisfiable if it is true in no models, e.g., A∧¬A
