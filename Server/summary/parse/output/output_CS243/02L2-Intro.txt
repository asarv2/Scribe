# Minimax Search

**Text Content:**

* **Headline:** Minimax Search

* **Description:**
    * **Minimax:** A search algorithm for two-player zero-sum games.
    * **Goal:** Find the best move for the current player, assuming the opponent also plays optimally.
    * **Evaluation Function:** Assigns a numerical score to each game state.
