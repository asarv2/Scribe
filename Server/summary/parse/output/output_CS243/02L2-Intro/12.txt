# Search Tree Sizes

Tic-tac-toe: 10<sup>5</sup>
Checkers: 10<sup>31</sup>
Chess: 10<sup>123</sup>
Backgammon: 10<sup>144</sup>
Go: 10<sup>360</sup>

Atoms in your body ~ 10<sup>28</sup>

Assume that a computer evaluates 1 million board configurations per second.

It would take 0.1 seconds to search the entire tic-tac-toe game tree but it would still take 10<sup>18</sup> years to search the full checkers tree.

Search alone is impossible, we need machine learning.
