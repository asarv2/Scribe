# Minimax Search

**Text Content:**

* **Headline:** Minimax Search

* **Description:**
    * **Minimax:** A search algorithm for two-player zero-sum games.
    * **Goal:** Find the best move for the current player, assuming the opponent also plays optimally.
    * **Evaluation Function:** Assigns a numerical score to each game state.
    * **Recursive Search:** Explores the game tree to find the best move.
    * **Max/Min:** Alternates between maximizing the score for the current player and minimizing the score for the opponent.
    * **Pruning:** Techniques to reduce the search space, such as alpha-beta pruning.
