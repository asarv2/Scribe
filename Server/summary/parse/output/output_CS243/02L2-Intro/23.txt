# Alpha-Beta Pruning

**Text Content:**

* **Headline:** Alpha-Beta Pruning

* **Description:**
    * **Motivation:**  Reduce the search space in Minimax search.
    * **Idea:**  Avoid evaluating branches that cannot affect the optimal decision.
    * **Alpha:**  The best value found so far for the maximizing player.
    * **Beta:** The best value found so far for the minimizing player.
    * **Pruning:** If a branch's value is guaranteed to be worse than the current best value for the opponent, it's not explored.
    * **Example:**  Illustrate the pruning process with a simple game tree.
