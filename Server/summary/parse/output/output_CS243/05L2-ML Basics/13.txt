# What if we fit a curve?

Given the blue points.
Ordinary linear regression gives the red line.
Fit this function (green curve):
y = w<sub>0</sub> + w<sub>1</sub>x + w<sub>2</sub>x<sup>2</sup> + w<sub>3</sub>x<sup>3</sup>
Treat (x, x<sup>2</sup>, x<sup>3</sup>) as the new independent variables!
