# The very first ML problem – linear regression

Idea: find the line closest to all points!
How do you define "close"?
Given points (s<sub>1</sub>, p<sub>1</sub>), ..., (s<sub>N</sub>, p<sub>N</sub>),
Sum of total distances from the line:
(w s<sub>1</sub> + l - p<sub>1</sub>)<sup>2</sup> + ... + (w s<sub>N</sub> + l - p<sub>N</sub>)<sup>2</sup>
Find the line to minimize this distance!
min<sub>w,l</sub> (w s<sub>1</sub> + l - p<sub>1</sub>)<sup>2</sup> + ... + (w s<sub>N</sub> + l - p<sub>N</sub>)<sup>2</sup>
