# The very first ML problem – linear regression

Find the line which passes (s<sub>1</sub>, p<sub>1</sub>) and (s<sub>2</sub>, p<sub>2</sub>)
How to solve this problem?

Suppose the line given by
p = ws + l

Because (s<sub>1</sub>, p<sub>1</sub>) and (s<sub>2</sub>, p<sub>2</sub>) are on the line, we have:
p<sub>1</sub> = ws<sub>1</sub> + l
p<sub>2</sub> = ws<sub>2</sub> + l

Solving the two linear equations gives you w and l
