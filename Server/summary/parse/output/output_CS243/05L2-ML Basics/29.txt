**What is the gradient of Perceptron loss?**

l<sub>perceptron</sub>(z) = max{0, -z}

**Objective:** F(w) = Σ<sub>i=1</sub><sup>n</sup> max{0, -y<sub>i</sub>w<sup>T</sup>x<sub>i</sub>}

**What is ∇F(w)?**

∇F(w) = Σ<sub>i=1</sub><sup>N</sup> -1[y<sub>i</sub>w<sup>T</sup>x<sub>i</sub> ≤ 0]y<sub>i</sub>x<sub>i</sub>

**Feeling Lazy (stochastic gradient descent):**

*   Randomly select one data point wrongly classified (y<sub>n</sub>w<sup>T</sup>x<sub>n</sub> ≤ 0)
*   Then follow the gradient direction given by the single-point: y<sub>n</sub>x<sub>n</sub>
