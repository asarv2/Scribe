**Perceptron vs. logistic regression**

**Perceptron**

Repeat:
* Pick a data point x<sub>n</sub>, uniformly at random
* If sign(w<sup>T</sup>x<sub>n</sub>) ≠ y<sub>n</sub>, then
  w ← w + y<sub>n</sub>x<sub>n</sub>


**Logistic Regression**

Repeat:
* Pick a data point x<sub>n</sub>, uniformly at random
* Update w according to
  w ← w + ασ(−y<sub>n</sub>w<sup>T</sup>x<sub>n</sub>)y<sub>n</sub>x<sub>n</sub>

**Description:**

This slide compares the Perceptron algorithm and logistic regression.  It shows the update rules for both algorithms.  The Perceptron algorithm updates the weight vector `w` by adding the product of the true label (y<sub>n</sub>) and the feature vector (x<sub>n</sub>) if the prediction is incorrect.  Logistic regression, on the other hand, updates `w` using the sigmoid function applied to the dot product of the weight vector and the feature vector.  The sigmoid function is crucial for logistic regression, as it maps the dot product to a probability between 0 and 1.
