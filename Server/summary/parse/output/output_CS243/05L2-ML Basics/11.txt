# What if we have multiple independent variables?

Formal mathematical form:

yᵢ = β₀ + β₁xᵢ₁ + ... + βₚxᵢₚ + ϵᵢ = xᵢᵀβ + ϵᵢ, for i = 1,...,n

Or using matrix notation:

y = Xβ + ϵ

Where:

```
y =  [ y₁ ]
     [ y₂ ]
     [  ⋮ ]
     [ yₙ ]

X =  [ x₁ᵀ ]
     [ x₂ᵀ ]
     [  ⋮  ]
     [ xₙᵀ ]
     = [ 1  x₁₁  x₁₂  ...  x₁ₚ ]
       [ 1  x₂₁  x₂₂  ...  x₂ₚ ]
       [  ⋮  ⋮  ⋮  ⋱  ⋮  ]
       [ 1  xₙ₁  xₙ₂  ...  xₙₚ ]

β = [ β₀ ]
     [ β₁ ]
     [ β₂ ]
     [  ⋮ ]
     [ βₚ ]

ϵ = [ ϵ₁ ]
     [ ϵ₂ ]
     [  ⋮ ]
     [ ϵₙ ]
```

Can prove the optimal β* which minimizes the distances is: β* = (XᵀX)⁻¹Xᵀy
