**Encode Hamiltonian Path Problem into SAT**

* Encode Hamiltonian Path Problem into SAT
* Enforcing that the path consists of real edges
    * ¬(h<sub>iu</sub> ∧ h<sub>(i+1)v</sub>) if there is not an edge between u and v
* Simple do a "∧" (logical OR) between all pairs of formulas.
This completes our formulation of the Hamiltonian path instance in SAT!

h<sub>ij</sub>: The i<sup>th</sup> vertex visited in the path is vertex j
