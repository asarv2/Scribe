**Partial Assignment**

A partial assignment on V is a partial function that associates to some Boolean variables of V a truth value (either true or false) and can be undefined for the others.

Under a partial assignment on V, a clause C on V can be:

* **true** if one of its literals is true,
* **false** (or conflicting) if all its literals are false,
* **undefined** (or unresolved) if it is neither true nor false.

**Remarks**

* Partial assignments allow us to construct assignments for a set of clauses incrementally, that is, one clause after another.
* The SAT solving algorithms to be presented next use partial assignments.
* They all start with an empty assignment (that is, the truth values of all Boolean variables are not defined) and try to extend this assignment, assigning one Boolean variable after another.


**Description:**

This slide defines a "partial assignment" in the context of SAT solving.  It explains that a partial assignment is a function that assigns truth values (true or false) to some, but not necessarily all, Boolean variables.  The remaining variables are left undefined.  The slide then defines how a clause (a logical OR of literals) evaluates under a partial assignment:

* **True:** If at least one literal in the clause is assigned the value true.
* **False:** If all literals in the clause are assigned the value false.
* **Undefined:** If the clause cannot be determined to be true or false based on the partial assignment.

The "Remarks" section further clarifies the use of partial assignments in SAT solvers.  They allow for incremental assignment of truth values to variables, starting with an empty assignment (no variables assigned) and progressively assigning one variable at a time.
