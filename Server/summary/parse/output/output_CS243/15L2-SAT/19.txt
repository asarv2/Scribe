**The Pure Literal Rule**

Given a propositional CNF formula φ for which we check whether φ is satisfiable or not, if a variable is always positive (that is, never appears with a ¬) or always negative (that is, always appears with a ¬) in φ, one only needs to set it to one value: true for positive variables, false for negative variables.

Such variables are called pure.


**Description:**

This slide describes a rule for simplifying the search space in a SAT solver.  It states that if a variable in a CNF formula (φ) always appears either positively or negatively, then the solver can immediately assign a value to that variable (true for positive, false for negative).  This is a simple optimization technique that reduces the number of possible assignments that need to be explored.  There are no figures on this slide.
