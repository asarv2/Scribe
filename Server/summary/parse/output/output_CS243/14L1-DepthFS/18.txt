# Slide 18

**Mazes – A first problem**

How do we represent a maze in terms of search?

* What is a "State"?
* What "Actions" can we take
* How will we search the states?

**(Diagram):**

A tree diagram is presented, illustrating possible states and actions in a maze.  The central node, a light-blue rectangle, is labeled "(x, y)".  From this central node, four branches extend downward, each representing a possible action:  "L" (left), "R" (right), "U" (up), and "D" (down).  Each of these branches leads to a new light-blue rectangle, representing a new state.  The new states are labeled as follows:

* **L:** (x-1, y)
* **R:** (x+1, y)
* **U:** (x, y-1)
* **D:** (x, y+1)

Further branching occurs from these new states, again with four possible actions (L, R, U, D) leading to new states.  The diagram visually represents the possible paths through a maze, where each node represents a location (x, y) and the branches represent possible moves.  The diagram is positioned centrally on the slide and is oriented vertically.  The purpose of the diagram is to illustrate the concept of state space exploration in a maze problem, showing how possible moves create a tree of potential states.
