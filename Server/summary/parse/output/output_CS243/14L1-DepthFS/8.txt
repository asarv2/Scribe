# Slide 8

**Structural Recursion: Traversal**

Breadth First visits a level at a time:
* 36, 10, 78, 3, 21, 55, 105, ...
* Check the current node,
add children to a queue

Depth First traverses down a branch:
* 36, 10, 3, 1, 6, 21, 15, 28, ...
* Check current node,
then left, then right (other orders are possible)
