# Slide 14

**Problem Solving as Search**

Search: Exploration of possibilities
* Abstraction of general problem solving method

Basic ingredients:
* States: describe configuration of environment
* Actions: activities which move you from one state to another
* Search algorithm: determines which actions should be tried in which order to find solution
