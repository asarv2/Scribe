# Slide 7

**Recursive Data Structures**

Recursion is useful with some data structures like a LinkedList, Tree, or Graph.

Consider a Tree:

* Base Case: a null, or empty root node
* Recursive Case: A node with links to 1 or more subtrees

Processing the tree recursively:

* If the root node is null, done
* Otherwise, process the root node and children

**Activities:**

* Printing all elements
* Summing elements
* Finding a specific element
* Identifying a "best" element
