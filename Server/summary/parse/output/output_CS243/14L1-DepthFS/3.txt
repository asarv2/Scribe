**A quick review of recursion**

Recursion is a self reference, eventually terminating in a base case

**Methods:**

* A method can call itself
* Example Fibonacci

**Data Structures:**

* A data structure can reference itself
* Example: LinkedList is a node that points to a LinkedList
* Example: Trees are nodes that point to Trees
