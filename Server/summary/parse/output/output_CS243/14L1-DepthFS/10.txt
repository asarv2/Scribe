**Structural Recursion: a Binary Tree Example**

Searching for the value X in this tree is easy.
First Examine the current value, V.
If V == X : return True
If there are no children, X is not in this tree,
return False
If X < V, Search the left tree for X
If X > V, Search the right tree for X
