# Slide 5

**Recursion must eventually end**

The method does not always call itself
The data structure does not always link to another data structure
There are two main pieces to any recursive approach

* **The Base Case** - what can you do right now, in this call.
* **The Recursive Case** - the same problem/method/data structure, but smaller

The Recursive Case needs to be "smaller" in some sense: closer to the base case.


**Description:**

The base case represents the simplest form of the problem, providing a direct solution without further recursion.  The recursive case describes how to break down a larger problem into smaller, similar subproblems, each step closer to the base case.  The overall design is straightforward and informative, providing a concise summary of the key concepts related to recursion.
