**K-means clustering**

One of the most commonly-used clustering algorithms, because it is easy to implement and quick to run

The goal is to partition the objects into K disjoint subsets

Assumes the objects (instances) to be clustered are p-dimensional vectors

Uses a distance measure between the objects (typically Euclidean distance)
