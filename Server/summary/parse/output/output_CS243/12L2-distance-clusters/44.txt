**Evaluation via Class Labels: Purity**

Purity: a measure of the extent to which cluster/groups (G) contain objects of a particular class (C)

* Each cluster is assigned the class according to the most numerous class of its elements
* The purity of each cluster  i in G is determined by the number of examples of class j (N<sub>j</sub>) inside each cluster:

purity(C, G) =  1/N * Σ<sub>i=1</sub><sup>K</sup> max<sub>j</sub> N<sub>j</sub> ∈ G<sub>i</sub>

High purity is easy to achieve when the number of clusters is large
