**Evaluation via Class Labels: Similarity**

Based on premise that any pair of objects in the same
cluster should have the same class and vice versa

Construct the "observed" similarity matrix
* Based on cluster membership
* Entry i,j is 1 if i and j are in the same cluster, 0 otherwise

Construct the "ideal" similarity matrix
* Based on class values
* Entry i,j is 1 if i and j are in the same class, 0 otherwise

Measure correlation between these two matrices

**Description of what you see:**

This slide describes a method for evaluating clustering results using similarity matrices, specifically when class labels are available.  It outlines the steps to construct both an "observed" similarity matrix and an "ideal" similarity matrix based on cluster membership and class values, respectively.  The "observed" matrix (table) shows the similarity between data points based on their assigned clusters.  The "ideal" matrix (table) shows the similarity between data points based on their true class labels.  The correlation between these two matrices is then used as an objective measure of the quality of the clustering.  The example matrices show a 3x3 similarity matrix for three data points.  The slide is part of a section on evaluating clustering results using objective metrics.  The tables are crucial for understanding how the similarity between data points is defined in each case.  The premise is that if data points are in the same cluster, they should also be in the same class.  The correlation between the two matrices will quantify how well the clustering algorithm matched these expectations.
