# Slide 15

**Image derivatives**

How can we differentiate a digital image *F[x, y]***?

* We can take a discrete derivative! (Finite difference)

$\frac{df}{dx} [x, y] \approx F[x + 1, y] - F[x, y]$

How would you implement this as a linear filter?

* $H_x \frac{df}{dy} \quad [-1 \quad +1]$

* $H_y \frac{df}{dy} \quad [-1 \quad +1]$

**Description of what you see:**

This slide discusses how to calculate derivatives of a digital image.  The text explains that a discrete derivative (finite difference) can be used to approximate the derivative of the image intensity function.  The formula $\frac{df}{dx} [x, y] \approx F[x + 1, y] - F[x, y]$ is presented, showing how the difference between the intensity values at adjacent pixels in the x-direction approximates the derivative.  The slide also introduces the concept of implementing this as a linear filter, using the filters $H_x$ and $H_y$ with the corresponding kernels [-1 +1] and [-1 +1].  The slide is part of a lecture on image processing, specifically focusing on how to calculate derivatives of images to extract features like edges.  The source is credited at the bottom.
