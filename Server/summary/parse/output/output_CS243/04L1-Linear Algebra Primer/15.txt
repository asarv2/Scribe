**Multiplication Example**

```
(1  2  3) (7  8) = (1*7 + 2*9 + 3*11  1*8 + 2*10 + 3*12) = (58  64)
(4  5  6) (9 10)   (4*7 + 5*9 + 6*11  4*8 + 5*10 + 6*12)   (139 154)
```

However, in matrix multiplication A⋅B ≠ B⋅A

```
(7  8) (1  2  3) = (7*1 + 8*4  7*2 + 8*5  7*3 + 8*6) = (39  54  69)
(9 10) (4  5  6)   (9*1 + 10*4 9*2 + 10*5 9*3 + 10*6)   (49  68  87)
(11 12) (   )      (11*1 + 12*4 11*2 + 12*5 11*3 + 12*6)   (59  82 105)
```

In some cases, you may not be able to multiply in both orders, e.x. 2x3 and 3x4
