**Some other points on Linear Transforms**

Because it's based in applying the matrix via multiplication

T(0) = 0

For any vectors v<sub>1</sub>, v<sub>2</sub>, ..., v<sub>k</sub> in R<sup>n</sup> and scalars c<sub>1</sub>, c<sub>2</sub>, ..., c<sub>k</sub> we have

T(c<sub>1</sub>v<sub>1</sub> + c<sub>2</sub>v<sub>2</sub> + ... + c<sub>k</sub>v<sub>k</sub>) = c<sub>1</sub>T(v<sub>1</sub>) + c<sub>2</sub>T(v<sub>2</sub>) + ... + c<sub>k</sub>T(v<sub>k</sub>)

Including another transform U : R<sup>n</sup> → R<sup>m</sup>

(T + U)(x) = T(x) + U(x)

A Linear Transform can reduce dimensionality, but not grow it
