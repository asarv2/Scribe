**But it is a Linear Transform...**

As its a linear transform, this means T : R<sup>n</sup> → R<sup>m</sup> satisfies

T(u + v) = T(u) + T(v)
T(cu) = cT(u)

For all vectors u, v and scalars c

If we represent T(x) = Ax, using matrix multiplication to apply this transform, we have:

T(u + v) = A(u + v) = Au + Av = T(u) + T(v)
T(cu) = A(cu) = cAu = cT(u)
