**Adding, subtracting, and scalar multiplication**

Addition and Subtraction are element-wise operations
the matrices should be the same dimensions

**A + B = C** where  c<sub>ij</sub> = a<sub>ij</sub> + b<sub>ij</sub>

```
( 1  2 )   ( 5  6 )   ( 1+5  2+6 )   ( 6  8 )
( 3  4 ) + ( 7  8 ) = ( 3+7  4+8 ) = (10 12)
```

Scalar multiplication multiplies each element

**k ⋅ A = B** where b<sub>ij</sub> = k ⋅ a<sub>ij</sub>

```
2 ⋅ ( 1  2 ) = ( 2⋅1  2⋅2 ) = ( 2  4 )
    ( 3  4 )   ( 2⋅3  2⋅4 )   ( 6  8 )
```
