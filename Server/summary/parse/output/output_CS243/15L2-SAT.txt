**Satisfiability of a CNF formula**

**Notations**

* Let C<sub>1</sub>, ..., C<sub>m</sub> be clauses over a finite set V of Boolean variables P<sub>1</sub>, ..., P<sub>n</sub>.
* Define φ = C<sub>1</sub> ∧ ... ∧ C<sub>m</sub>
* Let v be an assignment on V.

**Observations**

* The CNF formula φ is satisfiable by v if, and only if, the clause C<sub>i</sub>, for all i ∈ {1, ..., m}, is satisfiable by v.
* A clause C<sub>i</sub>, for some i ∈ {1, ..., m}, is satisfiable by v if, and only if, at least one of its literals evaluates to true by v.

**Consequences**

* To check whether or not v satisfies φ, we may not need to know the truth values of all literals in all clauses.
* For instance, if v(p) = true and v(q) = false, we can see that the formula (p∨q∨¬r)∧(¬q∨s∨q) is satisfied without considering v(r) and v(s).


**Description:**

This slide defines the concept of satisfiability for a Conjunctive Normal Form (CNF) formula.  It introduces the notation and key concepts related to CNF formulas, clauses, and variable assignments.  The slide is structured to explain the logical conditions for a CNF formula to be satisfiable by a given variable assignment.  The example at the end illustrates how knowing the truth values of some variables can determine the satisfiability of the formula without needing to consider all variables.  The slide is clear and concise, providing a foundational definition for the topic.

**Partial Assignment**

A partial assignment on V is a partial function that associates to some Boolean variables of V a truth value (either true or false) and can be undefined for the others.

Under a partial assignment on V, a clause C on V can be:

* **true** if one of its literals is true,
* **false** (or conflicting) if all its literals are false,
* **undefined** (or unresolved) if it is neither true nor false.

**Remarks**

* Partial assignments allow us to construct assignments for a set of clauses incrementally, that is, one clause after another.
* The SAT solving algorithms to be presented next use partial assignments.
* They all start with an empty assignment (that is, the truth values of all Boolean variables are not defined) and try to extend this assignment, assigning one Boolean variable after another.


**Description:**

This slide defines a "partial assignment" in the context of SAT solving.  It explains that a partial assignment is a function that assigns truth values (true or false) to some, but not necessarily all, Boolean variables.  The remaining variables are left undefined.  The slide then defines how a clause (a logical OR of literals) evaluates under a partial assignment:

* **True:** If at least one literal in the clause is assigned the value true.
* **False:** If all literals in the clause are assigned the value false.
* **Undefined:** If the clause cannot be determined to be true or false based on the partial assignment.

The "Remarks" section further clarifies the use of partial assignments in SAT solvers.  They allow for incremental assignment of truth values to variables, starting with an empty assignment (no variables assigned) and progressively assigning one variable at a time.  This is a crucial concept in how SAT solvers work.  There are no figures on this slide.

**Simplification of a formula by an evaluated literal**

For the CNF formula φ and a Boolean variables p, we denote by φ|<sub>p</sub> the formula obtained from φ by replacing all occurrences of p by true and simplifying the result by removing:

* all true clauses,
* all false literals from undefined clauses.

The operation that maps (φ, p) to φ|<sub>p</sub> is called the simplification of φ at p.

Similarly, we define φ|<sub>¬p</sub> as the formula obtained from φ by replacing all occurrences of p by false and simplifying the result by removing:

* all true clauses,
* all false literals from undefined clauses.

The operation that maps (φ, p) to φ|<sub>¬p</sub> is called the simplification of φ at p.

Example:

φ = (p∨q∨¬r)∧(¬p∨¬r)  →  φ|<sub>p</sub> = q∨¬r.


**Description:**

This slide describes a simplification technique for CNF (Conjunctive Normal Form) formulas.  It introduces the concept of simplifying a formula based on the truth value of a specific Boolean variable.

* **φ|<sub>p</sub>:** This notation represents the simplified formula φ where the variable 'p' is assigned the value 'true'.  The simplification process involves removing clauses that become trivially true and removing literals that become trivially false.

* **φ|<sub>¬p</sub>:** This notation represents the simplified formula φ where the variable 'p' is assigned the value 'false'.  The simplification process is similar to φ|<sub>p</sub>, but with 'p' set to false.

* **Example:** The example shows how a specific CNF formula (φ) is simplified when 'p' is assigned the value 'true' (φ|<sub>p</sub>).  The result is a simplified formula (q∨¬r).

The slide is focused on the logical simplification of CNF formulas based on the truth value of a specific variable, which is a key step in many SAT solving algorithms.  There are no figures on this slide.

**Principles of SAT solving algorithms**

The SAT solving algorithms presented hereafter are based on the following ideas:

First, each algorithm is stated as a recursive function taking a propositional formula φ and a partial assignment v as arguments.

Second, these functions may modify their arguments:

* the partial assignment can be extended,
* the formula φ can be simplified at the newly assigned literal.

Third, before extending the assignment v and simplifying the formula φ, the function checks whether φ can be proved to be true or false, whatever are the values of the remaining unassigned Boolean variables.


**Description:**

This slide outlines the fundamental principles behind SAT solving algorithms.  It describes a recursive approach where algorithms operate on a propositional formula (φ) and a partial assignment (v).  The key points are:

1. **Recursive Function:** Algorithms are defined as recursive functions that take both the formula and the partial assignment as input.

2. **Argument Modification:** The functions can modify both the partial assignment (extend it) and the formula (simplify it).  Simplifying the formula is crucial for efficiency, as it reduces the search space.

3. **Pre-Check:** Before making any changes, the algorithm checks if the formula is already definitively true or false, given the current partial assignment.  This pre-check can significantly reduce unnecessary work.

The slide is a high-level overview of the general approach used in SAT solvers, setting the stage for the specific algorithms that might be discussed in subsequent slides.  There are no figures on this slide.

**Naïve Solver**

Input: A propositional formula φ on a finite set V and a partial assignment v on V such that only variables unassigned by v occur in φ.
Output: true if φ is satisfiable, false otherwise.

Naive_SAT(φ, v) {
  1. if every clause of φ has a true literal, return true;
  2. if any clause of φ has all false literals, return false;
  3. choose an p ∈ V that is unassigned in v;
  4. assign p to true, that is, let v(p) = true;
  5. if Naive_SAT(φ|<sub>p</sub>, v) returns true, then return true;  # this is a recursive call
  6. assign p to false, that is, let v(p) = false;
  7. if Naive_SAT(φ|<sub>¬p</sub>, v) returns true, then return true; # this is a recursive call
  8. unassign v(p); # backtracking takes place here
  9. return false;
}


**Description:**

This slide presents a recursive algorithm for solving the Satisfiability (SAT) problem, called "Naïve Solver."  The algorithm takes a propositional formula (φ) and a partial assignment (v) as input.  The algorithm recursively tries different assignments to variables until either a satisfying assignment is found or all possibilities are explored.

* **Input:** The input is a formula φ and a partial assignment v.  The formula φ is a set of clauses (conjunctions of literals).  The partial assignment v assigns truth values to some variables in the formula.

* **Output:** The output is true if the formula is satisfiable (a complete assignment exists that makes all clauses true) and false otherwise.

* **Algorithm (Naive_SAT):** The algorithm is presented as a recursive function.  It checks if all clauses are already satisfied (step 1) or if any clause is unsatisfiable (step 2).  If neither of these conditions is met, it selects an unassigned variable (step 3), tries assigning it true (step 4 and 5), and recursively calls itself with the simplified formula (φ|<sub>p</sub>).  If this recursive call returns true, the algorithm returns true.  Otherwise, it tries assigning the variable false (step 6 and 7), and recursively calls itself with the simplified formula (φ|<sub>¬p</sub>).  If this recursive call returns true, the algorithm returns true.  If both assignments fail, it backtracks by unassigning the variable (step 8) and returns false (step 9).

The slide is a clear presentation of a basic recursive algorithm for SAT solving, illustrating the core concepts of backtracking and simplification.  There are no figures on this slide.

**The Pure Literal Rule**

Given a propositional CNF formula φ for which we check whether φ is satisfiable or not, if a variable is always positive (that is, never appears with a ¬) or always negative (that is, always appears with a ¬) in φ, one only needs to set it to one value: true for positive variables, false for negative variables.

Such variables are called pure.


**Description:**

This slide describes a rule for simplifying the search space in a SAT solver.  It states that if a variable in a CNF formula (φ) always appears either positively or negatively, then the solver can immediately assign a value to that variable (true for positive, false for negative).  This is a simple optimization technique that reduces the number of possible assignments that need to be explored.  There are no figures on this slide.

**Unit Propagation**

Unit propagation (a.k.a Boolean constraint propagation or BCP) is a key component to fast SAT solving.

* Whenever all the literals in a clause are false except one, the remaining literal must be true in any satisfying assignment; such a clause is called a unit clause.
* Therefore, the algorithm can assign it to true immediately.
* After assigning a variable, there are often many unit clauses.
* Setting a literal in a unit clause often creates other unit clauses, leading to a cascade.

Based on those observations, we define a sub-algorithm BCP as follows.

BCP(φ, υ)
* Repeatedly search for unit clauses, and set unassigned literal to required value.
* If a literal is assigned to a conflicting value, then return false else return true.

**Davis-Putnam-Logemann-Loveland (DPLL) Algorithm**

**Input:** A propositional formula φ on a finite set V and a partial assignment v on V such that only variables unassigned by v occur in φ.
**Output:** true if φ is satisfiable, false otherwise.

DPLL(φ, v) {
  1. if every clause of φ has a true literal, return true;
  2. if any clause of φ has all false literals, return false;
  3. if BCP(φ, v) returns false, then return false;
  4. choose an p ∈ V that is unassigned in v;
  5. assign p to true, that is, let v(p) = true;
  6. if DPLL(φ|<sub>p</sub>, v) returns true, then return true;
  7. assign p to false, that is, let v(p) = false;
  8. if DPLL(φ|<sub>¬p</sub>, v) returns true, then return true;
  9. unassign v(p);  # backtracking takes place here
 10. return false;
}


**Description:**

This slide presents the Davis-Putnam-Logemann-Loveland (DPLL) algorithm for solving the satisfiability problem (SAT).  It's a recursive algorithm that takes a propositional formula (φ) and a partial assignment (v) as input.  The algorithm systematically explores possible assignments to variables to determine if a satisfying assignment exists.  The key steps are:

1. **Base Cases:**  Checks if all clauses are satisfied (step 1) or if any clause is unsatisfiable (step 2).

2. **Boolean Constraint Propagation (BCP):**  Performs unit propagation to simplify the formula (step 3).  If BCP detects a conflict, it immediately returns false.

3. **Variable Selection:** Chooses an unassigned variable (step 4).

4. **Recursive Calls:** Recursively calls DPLL with the simplified formula (φ|<sub>p</sub>) after assigning the chosen variable to true (step 5 and 6) and then with the simplified formula (φ|<sub>¬p</sub>) after assigning the chosen variable to false (step 7 and 8).

5. **Backtracking:** If both recursive calls fail, the algorithm backtracks by unassigning the variable (step 9) and returns false (step 10).

The slide clearly outlines the recursive structure and key steps of the DPLL algorithm, which is a fundamental algorithm in SAT solving.
