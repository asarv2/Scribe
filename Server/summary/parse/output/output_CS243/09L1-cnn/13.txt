# Rectified linear unit, ReLU

Rectified Linear Function, f(x) = max(0,x)
f(u) = max(0, u)

![Graph of ReLU function](https://i.imgur.com/a700000.png)


**Description:**

This slide introduces the Rectified Linear Unit (ReLU) activation function.

* **Title:** "Rectified linear unit, ReLU" is displayed at the top of the slide.

* **Definition:** The text "Rectified Linear Function, f(x) = max(0,x)" defines the ReLU function.  This means the output of the function is the maximum value between 0 and the input.  The function is also defined as f(u) = max(0, u).

* **Graph:** A graph of the ReLU function is shown.  The x-axis is labeled "u," and the y-axis is labeled.  The graph is a piecewise linear function.  For input values less than or equal to 0, the output is 0.  For input values greater than 0, the output is equal to the input.  The graph starts at the origin (0, 0) and increases linearly with a slope of 1 for positive input values.  The graph is a straight line from the origin to positive infinity.  The graph visually represents the ReLU function's behavior.  The graph is positioned in the right half of the slide.


**Overall:** The slide introduces the ReLU activation function, its mathematical definition, and its graphical representation.  The graph is essential for understanding how the function transforms input values.
