* **Convolution filter (Sobel Gx):** A 3x3 grid of numbers (-1, -2, -1; 0, 0, 0; 1, 2, 1) is shown.  This is a convolution filter, specifically the Sobel Gx filter, used for edge detection.  It is positioned over the source pixel grid, and the numbers in the filter are used to calculate the output value.  The filter is positioned in the top left of the source pixel grid.

* **Destination pixel:** A 2x2 grid of numbers (31, 7, 44, 33; 65, 35, 40, 46; 46, 29, 32, 30; 24, 49, 8, 64) is shown.  This represents the output of the convolution operation.  The numbers in this grid are the results of applying the convolution filter to the source pixel grid.  The output grid is positioned to the right of the source pixel grid and the convolution filter.

* **Output:** A 2x2 grid of numbers (65, 46; 46, 64) is shown.  This is the output of the pooling layer.  The pooling layer reduces the size of the input grid by applying a pooling function (e.g., max pooling).  The output grid is positioned to the right of the input grid.
