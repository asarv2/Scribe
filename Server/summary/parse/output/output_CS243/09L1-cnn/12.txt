# Why convolution? Not fully connected?

**Parameter Sharing**

* Convolution shares the same parameters across all spatial locations.

**Traditional matrix multiplication**

* Does not share any parameters.


**Top Diagram (Convolution):**

* **Top Layer (S):**  Five circles (S<sub>1</sub>, S<sub>2</sub>, S<sub>3</sub>, S<sub>4</sub>, S<sub>5</sub>) represent neurons in a layer.
* **Bottom Layer (X):** Five circles (X<sub>1</sub>, X<sub>2</sub>, X<sub>3</sub>, X<sub>4</sub>, X<sub>5</sub>) represent neurons in a layer.
* **Connections:**  The connections between the neurons in the top and bottom layers are shown as lines.  Notice that each neuron in the top layer is connected to only a few neurons in the bottom layer.  This demonstrates the sparse connectivity characteristic of convolution.


**Bottom Diagram (Traditional Matrix Multiplication):**

* **Top Layer (S):** Five circles (S<sub>1</sub>, S<sub>2</sub>, S<sub>3</sub>, S<sub>4</sub>, S<sub>5</sub>) represent neurons in a layer.
* **Bottom Layer (X):** Five circles (X<sub>1</sub>, X<sub>2</sub>, X<sub>3</sub>, X<sub>4</sub>, X<sub>5</sub>) represent neurons in a layer.
* **Connections:** The connections between the neurons in the top and bottom layers are shown as lines.  Notice that each neuron in the top layer is connected to *every* neuron in the bottom layer.  This demonstrates the dense connectivity characteristic of traditional matrix multiplication.


**Description:**

This slide compares the parameter sharing in convolution with traditional matrix multiplication in the context of neural networks.  The top diagram illustrates how convolution uses the same parameters across different spatial locations, leading to sparse connectivity.  The bottom diagram illustrates how traditional matrix multiplication does not share parameters, resulting in dense connectivity.  The diagrams visually represent the key difference in how these two approaches connect neurons, highlighting the efficiency of convolution in processing data like images.
