# How do you train (back-propagation)

1.  **Input layer:**  (labeled with 1)  The input layer is at the bottom of the diagram.  It's a layer of nodes (circles) labeled with an "X".  These nodes represent the input data to the neural network.

2.  **Hidden layer(s):** (labeled with 2)  The hidden layer(s) are in the middle of the diagram.  They are layers of interconnected nodes (circles).  The connections between the nodes are represented by lines, and each line has a weight (labeled "W") associated with it.  These layers process the input data and transform it.

3.  **Output layer:** (labeled with 3) The output layer is at the top of the diagram.  It's a layer of nodes (circles) that produce the network's output.

4.  **Difference in desired values:** (text below the output layer) This text indicates that the output layer's values are compared to the desired output values to calculate the error.

5.  **Backprop output layer:** (labeled with 5) This layer is the final layer in the backpropagation process.  It receives the error signal from the output layer and propagates it backward through the network to adjust the weights.


**Diagram Description:**

The diagram is a graphical representation of a multi-layer perceptron (MLP) neural network.  It shows the flow of information from the input layer through the hidden layers to the output layer.  The lines connecting the nodes represent weighted connections, and the weights are labeled "W".  The arrows indicate the direction of data flow.  The diagram is crucial for understanding the backpropagation algorithm, which is used to train the neural network by adjusting the weights to minimize the difference between the predicted output and the desired output.  The colors and numbers help to identify the different layers and components of the network.  The URL at the bottom of the slide provides a link to a resource that explains backpropagation in more detail.


**Overall:** The slide introduces the concept of backpropagation, a crucial algorithm for training neural networks.  The diagram visually represents the flow of information and the layers involved in the process.
