\section*{Linear Combination and Span}

\noindent
\textbf{7.} Given $\mathcal{L} = \{\vec{u}_1, \vec{u}_2, ..., \vec{u}_k\} \subseteq R^n$.
\newline
\noindent
A vector $\vec{v} \in R^n$ is said to be a linear combination of $\mathcal{L}$ if there are scalars $c_1, c_2, ..., c_k$ such that
\newline
\noindent
$\vec{v} = c_1 \vec{u}_1 + c_2 \vec{u}_2 + ... + c_k \vec{u}_k$

--- Description ---

This slide introduces the concepts of linear combinations and spans of vectors.  It defines a linear combination of vectors from a set $\mathcal{L}$ as a vector $\vec{v}$ that can be expressed as a sum of scalar multiples of the vectors in $\mathcal{L}$.  The example shows a 2-dimensional case where $\vec{v}$ is a linear combination of $\vec{u}_1$ and $\vec{u}_2$.  The figure visually represents this combination.  The red arrow represents $\vec{v}$, and the black arrows represent $\vec{u}_1$ and $\vec{u}_2$.  The slide number is 5 of 14, indicating its place in a sequence of linear programming lectures.  The context suggests that these concepts are being introduced as a prerequisite for more advanced topics in linear programming, potentially related to the representation and manipulation of constraints.
