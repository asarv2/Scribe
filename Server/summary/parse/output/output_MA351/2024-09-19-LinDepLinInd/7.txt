\textbf{Consequences (Properties) of Linear Dependence}

(III) If $\ell = \{u_1, u_2, \dots, u_k\}$ is linearly dependent, then any vector $\vec{v} \in Span(\ell)$ can be represented in an infinitely many ways as lin. comb. of the $u_i$'s.  i.e. the representation is not unique.

For example, $\vec{v} = 2u_1 - u_2 + 2u_3 = 3u_1 - 3u_2 + 3u_3 = -u_1 + 3u_2 + u_3$
( $3u_1 - 4u_2 + u_3 = 0$)
( $2(3u_1 - 4u_2 + u_3) = 0$)


\textbf{Description:}

This slide continues the discussion of linear dependence, emphasizing the non-uniqueness of vector representations.  It reiterates that if a set of vectors ($\ell$) is linearly dependent, any vector within the span of those vectors can be expressed as a linear combination of the original vectors in infinitely many ways.  The example explicitly demonstrates this non-uniqueness by showing how the same vector $\vec{v}$ can be expressed as different linear combinations of the linearly dependent vectors $u_1$, $u_2$, and $u_3$.  This is a crucial concept in linear programming, as it highlights the potential for alternative representations within the problem's solution space.  The equations shown are examples of how different combinations of the original vectors can yield the same result.
