\textbf{Consequences (Properties) of Linear Dependence}

(II) If $\ell = \{u_1, u_2, \dots, u_k\}$ is linearly dependent, then $\ell$ can be reduced to $\ell' \subseteq \ell$ such that $Span(\ell) = Span(\ell')$.

For example: $u_1 = (0, 2)$, $u_2 = (0, 1)$, $u_3 = (2, 3, 4)$.
$3u_1 + (-4)u_2 + u_3 = \vec{0}$

$\implies u_3 = 3u_1 + 4u_2$

Let $\vec{v} = 5u_1 + 2u_2 + 3u_3$
$= 5u_1 + 2u_2 + 3(3u_1 + 4u_2)$
$= (5 + 9)u_1 + (2 + 12)u_2$
$= 14u_1 + 14u_2$
$= 14(u_1 + u_2)$
$\implies \vec{v} \in Span(u_1, u_2)$


\textbf{Description:}

This slide continues the discussion of linear dependence and its implications.  It demonstrates how a linearly dependent set of vectors can be reduced to a smaller, linearly independent set that spans the same vector space.  The example uses the same vectors as in the previous slide, showing that $u_3$ can be expressed as a linear combination of $u_1$ and $u_2$.  The key takeaway is that if a set of vectors is linearly dependent, one or more vectors can be removed without changing the span of the set.  This is crucial in linear programming because it allows for simplification of the problem by removing redundant constraints or variables.  The final part of the slide shows how any vector in the original span can be expressed as a linear combination of the reduced set of vectors.
