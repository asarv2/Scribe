\textbf{The Simplex Algorithm: Summary}

\vspace{0.5cm}

\begin{itemize}
    \item Start with a standard form linear programming problem.
    \item Construct the initial simplex tableau.
    \item Apply the pivot selection rules (entering and leaving variables).
    \item Perform the pivot operation to update the tableau.
    \item Repeat steps 3 and 4 until an optimal solution is found or it's determined that no optimal solution exists.
\end{itemize}
