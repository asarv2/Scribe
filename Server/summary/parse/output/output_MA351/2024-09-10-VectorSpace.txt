\section*{Vectors in $R^n$}

$\vec{u} = \begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{pmatrix}, \quad \vec{v} = \begin{pmatrix} y_1 \\ y_2 \\ \vdots \\ y_n \end{pmatrix} \in R^n$

\section*{Vector Addition}

$\vec{u} + \vec{v} = \begin{pmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{pmatrix} + \begin{pmatrix} y_1 \\ y_2 \\ \vdots \\ y_n \end{pmatrix} = \begin{pmatrix} x_1 + y_1 \\ x_2 + y_2 \\ \vdots \\ x_n + y_n \end{pmatrix}$

\section*{Properties of Vector Add. \& Scalar Mult.}

$(\vec{u} + \vec{v} \in R^n, \quad \alpha \vec{u} \in R^n)$

\begin{enumerate}
    \item $\vec{u} + \vec{v} = \vec{v} + \vec{u}$
    \item $(\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})$
    \item $\alpha (\beta \vec{u}) = (\alpha \beta) \vec{u}$
    \item $\alpha (\vec{u} + \vec{v}) = \alpha \vec{u} + \alpha \vec{v}$
    \item $(\alpha + \beta) \vec{u} = \alpha \vec{u} + \beta \vec{u}$
\end{enumerate}

\end{document}

\section*{(General) Vector Space $V$}

$V$ is called a vector space as long as you can define vector addition and scalar mult.
such that properties 1 - 8 hold.

\begin{enumerate}
    \item $\vec{u} + \vec{v} = \vec{v} + \vec{u}$
    \item $(\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})$
    \item $\alpha (\beta \vec{u}) = (\alpha \beta) \vec{u}$
    \item $\alpha (\vec{u} + \vec{v}) = \alpha \vec{u} + \alpha \vec{v}$
    \item $(\alpha + \beta) \vec{u} = \alpha \vec{u} + \beta \vec{u}$
    \item There is $\vec{0}$ such that $\vec{0} + \vec{u} = \vec{u}$
    \item For each $\vec{u}$, there is $-\vec{u}$ such that $\vec{u} + (-\vec{u}) = \vec{0}$
    \item $1\vec{u} = \vec{u}$
\end{enumerate}

\end{document}

This slide defines a vector space, $V$.  It lists the eight defining properties that must hold for a set of vectors to be considered a vector space.
