**Hypothesis tests about the one-sample population mean 8.2-8.3 (continued)**

Let X<sub>1</sub>, ..., X<sub>n</sub> represent a random sample of size n from some population.

* Null hypothesis H<sub>0</sub>: μ = μ<sub>0</sub>, where μ<sub>0</sub> is called null value.
* Three possible alternative hypotheses
    1. H<sub>a</sub>: μ > μ<sub>0</sub>, the population mean is greater than μ<sub>0</sub>
    2. H<sub>a</sub>: μ < μ<sub>0</sub>, the population mean is less than μ<sub>0</sub>
    3. H<sub>a</sub>: μ ≠ μ<sub>0</sub>, the population mean is not μ<sub>0</sub>

**Case 1: Normal distribution with known variance σ<sup>2</sup> (continued)**

Exactly the same result holds for one-sided test H<sub>0</sub>: μ ≤ μ<sub>0</sub>, H<sub>a</sub>: μ > μ<sub>0</sub>.
For two-sided test H<sub>0</sub>: μ = μ<sub>0</sub>, H<sub>a</sub>: μ ≠ μ<sub>0</sub>, we can obtain some approximated lower bound n ≥ (σ(Z<sub>α/2</sub> + Z<sub>β</sub>)/(μ<sub>0</sub> - μ′))<sup>2</sup>.

**In practice, how to determine the unknown μ′?**

**Statistical versus Practical significance**

* statistical significance = small p-value = μ′ is not exactly 0 (even if it is 0.00000001)
* practical significant = μ′ is a large value.

In practical science study, we want to have statistically significant result only when there is practical significant.
