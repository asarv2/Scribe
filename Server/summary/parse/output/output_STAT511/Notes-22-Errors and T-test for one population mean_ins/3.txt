**Test procedure and calculation of type I and type II error probabilities**

**Example 22.1**

X has the following probability mass function 𝑝(𝑥; 𝜃), where 𝜃 takes value either 0, 1 or 2:

| 𝑝(𝑥; 𝜃) | x=1 | x=2 | x=3 |
|---|---|---|---|
| 𝜃= 0 | 0.85 | 0.1 | 0.05 |
| 𝜃= 1 | 0.1 | 0.4 | 0.5 |
| 𝜃= 2 | 0.3 | 0.6 | 0.1 |

Assume we have only one data point X, we conduct the following hypotheses testing:

H<sub>0</sub>: 𝜃= 0 vs H<sub>1</sub>: 𝜃≠0

a. The test statistic is just X itself, and the rejection region is {𝑥= 3}, then

𝛼 = 𝑃(𝑥= 3  when H<sub>0</sub> is true) = 𝑃(𝑥= 3 | 𝜃= 0)

𝛽(1) = 𝑃( 𝑥= {1, 2} |  𝜃= 1 )

𝛽(2)= 𝑃( 𝑥= {1, 2} |  𝜃= 2 )


b. The test statistic is just X itself, and the rejection region is {x=2 or 3}, then

𝛼 = 𝑃(𝑥= 2 or 3  | 𝜃= 0)

𝛽(1) = 𝑃( 𝑥= 1 |  𝜃= 1 )

𝛽(2)= 𝑃( 𝑥= 1 |  𝜃= 2 )

Suppose compressive strength for specimens of this mixture is normally distributed with σ=60. Let µ denote the true average compressive strength.

a. What are the appropriate null and alternative hypotheses?

H<sub>0</sub>: 𝜇= 1300 vs. H<sub>a</sub>: 𝜇> 1300
