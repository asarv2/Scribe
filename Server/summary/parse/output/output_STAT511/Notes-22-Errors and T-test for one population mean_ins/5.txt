**Hypothesis tests about the one-sample population mean 8.2-8.3**

Let X<sub>1</sub>, ..., X<sub>n</sub> represent a random sample of size n from some population.

* Null hypothesis H<sub>0</sub>: μ = μ<sub>0</sub>, where μ<sub>0</sub> is called null value.
* Three possible alternative hypotheses
    1. H<sub>a</sub>: μ > μ<sub>0</sub>, the population mean is greater than μ<sub>0</sub>
    2. H<sub>a</sub>: μ < μ<sub>0</sub>, the population mean is less than μ<sub>0</sub>
    3. H<sub>a</sub>: μ ≠ μ<sub>0</sub>, the population mean is not μ<sub>0</sub>

**Case 1: Normal distribution with known variance σ<sup>2</sup>**

The Test statistic is:

TS =  (X̄ - μ<sub>0</sub>) / (σ/√n)  ~ N(0,1)

One reason we choose this test statistic is that if we want to control the type I error, then the test statistic should have a tractable sampling distribution under null hypothesis.


Type I error:

α = P((X̄ - μ<sub>0</sub>) / (σ/√n) ∈ Reject Region | μ = μ<sub>0</sub>) = P(Z ∈ Reject Region)

As for type II error:

β(μ) = P((X̄ - μ<sub>0</sub>) / (σ/√n) ∉ Reject Region) = P(N(√n(μ - μ<sub>0</sub>)/σ, 1) ∉ Reject Region)


Rejection region and p-value:

1. {Z > z<sub>1-α</sub>}, p-value = P(Z > z<sub>TS</sub>) if H<sub>a</sub>: μ > μ<sub>0</sub>
2. {Z < z<sub>α</sub>}, p-value = P(Z < z<sub>TS</sub>) if H<sub>a</sub>: μ < μ<sub>0</sub>
3. {|Z| > z<sub>1-α/2</sub>}, p-value = 2 × P(Z > |z<sub>TS</sub>|), if H<sub>a</sub>: μ ≠ μ<sub>0</sub>

This choice of rejection region is intuitively appealing to the alternative hypotheses setting, also tries to minimize the type II error subject to α.
