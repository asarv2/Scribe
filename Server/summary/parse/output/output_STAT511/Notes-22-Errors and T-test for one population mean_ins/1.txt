**Hypothesis Testing**

The framework of hypothesis testing consists of the following:

* **Step 1.** A pair of hypotheses, H<sub>0</sub> versus H<sub>a</sub>, on a parameter of interest (population level)
* **Step 2.** A test statistic (based on sample data)
* **Step 3.** A decision rule (whether to reject H<sub>0</sub> or not). If p-value is small, H<sub>0</sub> is rejected. Otherwise, for p-value is large, H<sub>0</sub> is not rejected.
* **Step 4.** Conclusions

**Review the examples:**

* 21.5 (one-sided small sample Z test)
* 21.6 (one-sided large sample Z test)
* 21.7 (two-sided small sample Z test)

**Two errors that can be committed in a testing procedure:**

* If we reject H<sub>0</sub> when in fact H<sub>0</sub> is true or make a false discovery, this is called a Type I error.
* If we fail to reject H<sub>0</sub> when in fact H<sub>1</sub> is true or miss an opportunity to make a discovery, this is called a Type II error.


|  | H<sub>0</sub> true | H<sub>1</sub> true |
|---|---|---|
| **Do not reject H<sub>0</sub>** | Correct (Probability = 1 - α) | Type II error (Probability = β) |
| **Reject H<sub>0</sub>** | Type I error (Probability = α) | Correct (Probability = Power) |


A good testing procedure commits less errors, or more precisely, has a low chance to commit either error.
