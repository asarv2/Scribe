**ANOVA Test** used when the response is numerical and the explanatory variable is categorical taking 3 or more values. This explanatory variable divides the population into groups. In ANOVA, we use a two-stage process to reduce the number of tests necessary.

1. We begin by using an overall F test to determine whether there are any differences among the means.

2. If there are, then we conduct a set of follow-up tests with the appropriate control of overall type I error that will check each pair of means for significant differences.
