**Confidence interval for 𝐸(𝑌|𝑥∗) = 𝛽0 + 𝛽1 ⋅𝑥∗**

**Prediction interval:** Find an interval such that

𝑃(𝑌∈[𝐿, 𝑈] | 𝑥∗) = 1 −𝛼

In comparison, the previous confidence interval is 𝑃{𝐸(𝑌) ∈[𝐿, 𝑈]|𝑥∗} = 1 −𝛼

Note that, by independence

𝑌−(𝛽̂0 + 𝛽̂1 ∙𝑥∗) = 𝑌−𝑁(𝛽0 + 𝛽1𝑥∗, 𝜎² [1/𝑛 + (𝑥∗−𝑥̅)²/𝑆𝑥𝑥])

∼𝑁(0, 𝜎² [1 + 1/𝑛 + (𝑥∗−𝑥̅)²/𝑆𝑥𝑥])

Therefore, the PI is

(𝛽̂0 + 𝛽̂1 ∙𝑥∗) ± 𝑡𝛼/2,𝑛−2√MSE [1 + 1/𝑛 + (𝑥∗−𝑥̅)²/𝑆𝑥𝑥]


**R code:**

x<-1:10; y<- x*2+rnorm(10)+0.5
m1<-lm(y~x);

predict(m1, newdata=data.frame(x=3.5), interval="confidence", level=.95)

predict(m1, newdata=data.frame(x=3.5), interval="prediction", level=.95)
