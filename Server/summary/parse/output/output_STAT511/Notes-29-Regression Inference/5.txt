**t-testing for β₁**

*   Null hypothesis: H₀: β₁ = β₁₀
*   Alternative hypothesis: H₁: β₁ ≠ or > or < β₁₀
*   Test statistic value:  𝑡𝑟𝑠 =  𝛽̂₁ −𝛽₁₀ / (𝑠𝛽̂₁ )
*   P-value:
*   Rejection region:

We typically consider a test of linear relationship, which corresponds to H₀: β₁ = 0 (no linear relationship) or not.

Example 29.1 revisit In this example, test the negative linear relationship between mortar dry density (lb/ft³) and mortar air content.

1.  H₀: β₁ = 0 vs. H₁: β₁ < 0
2.  β̂₁ = −0.917622
    𝑠𝛽̂₁ = 0.1460
Hence the t-test statistic is
    𝑡𝑟𝑠 =  𝛽̂₁ −𝛽₁₀ / (𝑠𝛽̂₁ ) = −0.917622 −0 / 0.1460 = −6.286

**F-testing for β₁**
