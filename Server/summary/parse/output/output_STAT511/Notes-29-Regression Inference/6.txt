**Inference about the prediction**

Now we are interested in prediction, that is to predict the possible response value when a new observation 𝑥 is given.

*   Given a new 𝑥∗, we want to estimate mean response: 𝐸(𝑌|𝑥∗) = 𝛽0 + 𝛽1 ⋅𝑥∗


Point estimator: The predicted value is 𝛽̂0 + 𝛽̂1𝑥∗. Since both 𝛽̂0 and β̂1 are unbiased estimators, we have

𝐸(𝛽̂0 + 𝛽̂1 ∙𝑥∗) = 𝐸(𝛽̂0) + 𝐸(𝛽̂1 ∙𝑥∗) = 𝛽0 + 𝛽1 ∙𝑥∗


Note: the above prediction should not be used to make a prediction for an 𝑥 value much beyond the range of the data, “danger of extrapolation”.
