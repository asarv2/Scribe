**Description of the Slide:**

This slide continues the lecture on Statistical Methods, focusing on random variables and their distributions.  It presents Example 8.7, which introduces a new random variable representing the number of sick days taken by an employee.  It then revisits Example 8.1, this time explicitly calculating the probability mass function (pmf) and cumulative distribution function (cdf) for the number of heads obtained in three coin tosses.  The pmf and cdf are presented in tabular form, making it easy to understand the probabilities associated with different outcomes.  A key concept is introduced: the expected value (or mean) of a discrete random variable, defined as the weighted average of the possible values, weighted by their probabilities.  The formula for calculating the expected value is given, along with a description of how it relates to the weighted average of data points in a dataset.  The slide's structure is consistent with the previous slides, maintaining a clear and organized presentation of the concepts.  The tables are crucial for understanding the probability distributions.  The step function graph, though not fully visible, is implied by the cdf table and is a visual representation of the discrete nature of the cdf.
