# Slide 1

**Simple Linear Regression**

Inferential statistics for the association between 2 numerical variables

When there are 2 variables, we assign one variable to be the explanatory variable or independent variable, and the other the response variable or dependent variable.

* The explanatory variable is thought to "explain" the response.
* The response variable is the measurement of interest.

**Example 27.1**

1. Does sucrose level (in grams) different for different fruit type (Apple, Orange, Banana)?
    * Response variable: sucrose level, numerical.
    * Explanatory variable: fruit type, categorical.

2. Is there association between number of beers consumed & the percentage of alcohol in blood?
    * Response variable: percentage of alcohol in blood, numerical.
    * Explanatory variable: number of beers consumed, numerical.

3. How does smoking status(yes or no) associated with survival status after 20 years(yes or no)?
    * Response variable: survival status after 20 years, categorical.
    * Explanatory variable: smoking status, categorical.


Now we want to make statistical inferences of a population based on the data when there appears to be a linear relationship between the numerical explanatory variable and the numerical response variable.
i.e. the above example, study 2.

Probabilistically, we consider the explanatory variable as a fixed, nonrandom value (vector), and denote is as x; we consider the response variable as a random variable, denoted by Y (the observed value is denoted as y). And the distribution of Y depends on x.
