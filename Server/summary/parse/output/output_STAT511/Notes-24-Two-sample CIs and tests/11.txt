To test hypotheses about 𝜇<sub>1</sub> − 𝜇<sub>2</sub> when data is paired, we form the differences 𝐷<sub>1</sub>, 𝐷<sub>2</sub>, … , 𝐷<sub>𝑛</sub> and carry out a one-sample t test (based on n–1 df) on these differences.

The Paired t Test for testing 𝐻<sub>0</sub>: 𝜇<sub>𝐷</sub> = 𝐷<sub>0</sub> (where 𝐷 = 𝑋 − 𝑌 is the difference between the first and second observations within a pair, and 𝜇<sub>𝐷</sub> = 𝜇<sub>1</sub> − 𝜇<sub>2</sub>)

Test statistic value:

𝑡<sub>𝑇𝑆</sub> =  𝑑̅ − Δ<sub>0</sub>
𝑠<sub>𝐷</sub>/√𝑛

Rejection region and p-value:

* If 𝐻<sub>𝑎</sub>: 𝜇<sub>𝐷</sub> > Δ<sub>0</sub>, {𝑇 > 𝑡<sub>1−𝛼,𝑣</sub>}, and p-value = 𝑃(𝑇 > 𝑡<sub>𝑇𝑆</sub>),
* If 𝐻<sub>𝑎</sub>: 𝜇<sub>𝐷</sub> < Δ<sub>0</sub>, {𝑇 < 𝑡<sub>𝛼,𝑣</sub>}, and p-value = 𝑃(𝑇 < 𝑡<sub>𝑇𝑆</sub>),
* If 𝐻<sub>𝑎</sub>: 𝜇<sub>𝐷</sub> ≠ Δ<sub>0</sub>, { |𝑇| > 𝑡<sub>1−𝛼/2,𝑣</sub>}, and p-value = 2𝑃(𝑇 > |𝑡<sub>𝑇𝑆</sub>|),

The paired t confidence interval for 𝜇<sub>𝐷</sub> with confidence level 100(1 – 𝛼)% is

𝐷̅ ± 𝑡<sub>1−𝛼/2,𝑛−1</sub> ∙ 𝑠<sub>𝐷</sub>/√𝑛
