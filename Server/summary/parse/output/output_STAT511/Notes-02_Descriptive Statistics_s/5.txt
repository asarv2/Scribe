**We use four different properties to describe numerical variables:**

1) Shape
2) Center
3) Variability
4) Unusual observations (data points whose value differs noticeably from the other values)

**Three statistics used to measure the center of a data set**

**Mode** (the least important statistic)
* The value taken most frequently by the subjects.

**Mean**
* The "average" value of a variable.
* The population mean is denoted as μ. The average value if we know the values of all objects in a census.
* The sample mean of a data set is defined as
  x̄ = (x<sub>1</sub> + x<sub>2</sub> + ... + x<sub>n</sub>) / n = 1/n Σ<sub>i=1</sub><sup>n</sup> x<sub>i</sub>

**Median**
* The middle value of an ordered data set.
* The population median is defined as M.
* The sample median of a data set is calculated as
  M̂ = {
    The single middle value if n is odd = (n+1)/2<sup>th</sup> ordered value.
    The avg. of the two middle values if n is even = avg. of (n/2)<sup>th</sup> and (n/2 + 1)<sup>th</sup> ordered values.
