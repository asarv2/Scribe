**Evaluation of point estimator**

The point estimate value is a sampled value from the sampling distribution of estimator θ̂. A good estimator should have a sampling distribution that closely centers around true parameter, this ensures that point estimate value based on single data set is close to the true parameter.

**Definition:**

* A point estimator θ̂ is said to be an unbiased estimator of θ if E(θ̂) = θ for every possible value of θ. Unbiasedness means that on average the estimate we obtained is close to the true parameter.
* If θ̂ is not unbiased, the difference E(θ̂) – θ is called the bias of θ̂.

An estimator is called unbiased if its bias is 0.

**Propositions:**

1. When X is a binomial rv with parameters n and p, the sample proportion 𝑝̂ =  𝑋/𝑛 is an unbiased estimator of p. No matter what the true value of p is, the distribution of the estimator 𝑝̂ will be centered at the true value.

2. If X<sub>1</sub>, … , X<sub>n</sub> is a random sample from a distribution with mean μ, then X̅ is an unbiased estimator of μ.

3. Let X<sub>1</sub>, … , X<sub>n</sub> be a random sample from a distribution with mean μ and variance σ<sup>2</sup>. Then the estimator

   𝜎̂<sup>2</sup> = 𝑆<sup>2</sup> =  (1 / (n-1)) * Σ<sub>i</sub>(X<sub>i</sub> - X̅)<sup>2</sup>

   is unbiased for estimating σ<sup>2</sup>.

(Textbook P253)

4. Sample standard deviation 𝜎̂ = S is NOT unbiased. Taking the square root invalidates the property of unbiasedness: the expected value of the square root is not the square root of the expected value. However, the bias of S is small unless n is quite small.
