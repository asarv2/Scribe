**Sample size calculation for a very simple case**

* The location of a CI for μ is determined by the point estimator x̄.
* The accuracy is determined by the width of the CI, which depends on:
    * the confidence level C.
    * the original data variability σ.
    * the sample size n.

| Confidence level C | 90% | 95% | 99% |
|---|---|---|---|
| Critical value z* | 1.645 | 1.960 | 2.576 |

* If we want to control the width to be smaller than a fixed value w, (that is margin of error is smaller than w/2), the necessary sample size is at least (2 * z* * σ / w)<sup>2</sup>
The margin of error = z* * σ / √n < w/2

(z* * σ / (w/2))<sup>2</sup> < n
n = ⌈(z* * σ / (w/2))<sup>2</sup>⌉

* If we want to estimate the proportion p within a specified margin of error m, the required sample size is at least (2 * z*/w)<sup>2</sup> * p*(1 - p*). (HW8-#8.b)
    * p* is called the guessed value based on previous knowledge.
    * If we have no information, we may replace p* above with 0.5 to obtain the most conservative sample size. If p* isn’t given in the problem, use 0.5. Why?

Inequality: |a - b| ≤ ((a + b) / 2)<sup>2</sup> with equality iff a = b.

p(1 - p) ≤ [(p + (1 - p)) / 2]<sup>2</sup> = 1/4 with equality iff p = 1 - p <=> p = 0.5
