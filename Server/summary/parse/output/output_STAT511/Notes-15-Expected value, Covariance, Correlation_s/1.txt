**Expected value, Covariance and Correlation**

**Definition:** given random variables X and Y, and any function h, the expected mean of h(X,Y) is defined as

E[h(X, Y)] = ΣΣ h(x, y) * p(x, y)  
under discrete case.

E[h(X, Y)] = ∬ h(x, y) * f(x, y) dx dy  
under continuous case.

**Note:** by definition of the expected value under one variable case, E(X) = ∫ x f(x) dx. Under two variable case, define mapping h(x, y) = x,

E(X) = E[h(X, Y)] = ∬ x f(x, y) dx dy = ∫ x f<sub>X</sub>(x) dx.

There is no contradiction.

**Proposition:**

* E(X + Y) = E(X) + E(Y);
* E(aX + bY) = a * E(X) + b * E(Y);
* E[h<sub>1</sub>(X, Y) + h<sub>2</sub>(X, Y)] = E[h<sub>1</sub>(X, Y)] + E[h<sub>2</sub>(X, Y)];
* If X and Y are independent,
    * E[XY] = E(X) * E(Y)
    * E[h(X) * g(Y)] = E[h(X)] * E[g(Y)]

**Example 15.1** If X and Y are independent Uniform distribution on [0, 1]. Compute E(|X − Y|).

Since X and Y are independent, f(x, y) = f<sub>X</sub>(x) * f<sub>Y</sub>(y) = 1

E(|X − Y|) = ∬ |x − y| * f(x, y) dx dy = ∫[∫(x − y) dy<sub>0</sub><sup>1</sup> + ∫(y − x) dy<sub>1</sub><sup>x</sup>] dx<sub>0</sub><sup>1</sup> = ⋯ = 1/3

**Definition:** the covariance between X and Y is

Cov(X, Y) = E[(X − μ<sub>X</sub>) * (Y − μ<sub>Y</sub>)] = E(XY) − μ<sub>X</sub> * μ<sub>Y</sub>.

**Definition:** the correlation coefficient (standardized covariance) of X and Y, denoted by Corr(X, Y), ρ<sub>XY</sub> or just ρ, is defined by

ρ<sub>XY</sub> = Cov(X, Y) / (σ<sub>X</sub> * σ<sub>Y</sub>)
