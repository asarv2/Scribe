Sample size determination(optional)

* Consider one-side test H<sub>a</sub>: p > p<sub>0</sub>, then

β(p') = P(
p̂ - p<sub>0</sub>
√p<sub>0</sub>(1 - p<sub>0</sub>)/n
< Z<sub>α</sub>) = P(
p̂ - p'
√p<sub>0</sub>(1 - p<sub>0</sub>)/n
< Z<sub>α</sub> +
p<sub>0</sub> - p'
√p<sub>0</sub>(1 - p<sub>0</sub>)/n
)

= P(
p̂ - p'
√p'(1 - p')/n
< (Z<sub>α</sub> +
p<sub>0</sub> - p'
√p<sub>0</sub>(1 - p<sub>0</sub>)/n
)√p<sub>0</sub>(1 - p<sub>0</sub>)
√p'(1 - p')
)

≈ P(Z < (Z<sub>α</sub> +
p<sub>0</sub> - p'
√p<sub>0</sub>(1 - p<sub>0</sub>)/n
)√p<sub>0</sub>(1 - p<sub>0</sub>)
√p'(1 - p')
)

= Φ(
p<sub>0</sub> - p' + Z<sub>α</sub>√p<sub>0</sub>(1 - p<sub>0</sub>)/n
√p'(1 - p')/n
)

To control the type II error to be bounded by β, one must have

p<sub>0</sub> - p' + Z<sub>α</sub>√p<sub>0</sub>(1 - p<sub>0</sub>)/n
√p'(1 - p')/n
≥ -Z<sub>β</sub>,

This implies that minimum sample requirement:

n ≥ (
Z<sub>α</sub>√p<sub>0</sub>(1 - p<sub>0</sub>) + Z<sub>β</sub>√p'(1 - p')
p' - p<sub>0</sub>
)<sup>2</sup>


* For one-side test H<sub>a</sub>: p < p<sub>0</sub>, we have the same result for sample size calculation.

* For two-side test H<sub>a</sub>: p ≠ p<sub>0</sub>, we have an approximated sample size calculation:

n ≥ (
Z<sub>α/2</sub>√p<sub>0</sub>(1 - p<sub>0</sub>) + Z<sub>β</sub>√p'(1 - p')
p' - p<sub>0</sub>
)<sup>2</sup>
