**Hypothesis tests about the one-sample population mean 8.2-8.3**

Let X<sub>1</sub>, … , X<sub>n</sub> represent a random sample of size n from some population.

* Null hypothesis H<sub>0</sub>: μ = μ<sub>0</sub>, where μ<sub>0</sub> is called null value.
* Three possible alternative hypotheses
    1.  H<sub>a</sub>: μ > μ<sub>0</sub>, the population mean is greater than μ<sub>0</sub>
    2.  H<sub>a</sub>: μ < μ<sub>0</sub>, the population mean is less than μ<sub>0</sub>
    3. H<sub>a</sub>: μ ≠ μ<sub>0</sub>, the population mean is not μ<sub>0</sub>

**Case 1: Normal distribution with known variance σ<sup>2</sup>**

The Test statistic is: Z<sub>TS</sub> =  (X̄ - μ<sub>0</sub>) / (σ / √n)

When H<sub>0</sub> is true, the test statistic has a Z distribution.


**Case 2: Normal distribution with unknown variance for small data**

Test statistic: T<sub>TS</sub> = (X̄ - μ<sub>0</sub>) / (s / √n)

When H<sub>0</sub> is true, the test statistic has a t distribution with n – 1 df.


**Case 3: Large sample test**

When the sample size is large, the Z tests for µ are easily modified to yield valid test procedures without requiring a normal population distribution or known σ. The basic idea is based on the fact that a large n implies that the standardized variable

TS = (X̄ - μ) / (σ/√n)  and TS ≈ (X̄ - μ) / (s/√n)

has approximately a standard normal distribution.

Substitution of the null value μ<sub>0</sub> in place of μ yields the test statistic

Z<sub>TS</sub> = (X̄ - μ<sub>0</sub>) / (σ / √n) or (X̄ - μ<sub>0</sub>) / (s / √n)
