**Simple regression model**

For any fixed value of the independent variable x, the dependent variable Y is a random variable related to x through the model equation.

Yᵢ = β₀ + β₁xᵢ + εᵢ, εᵢ ~ N(0, σ²)

Where the quantities εᵢ’s in the model equation are independent normal random variables, εᵢ ~ N(0, σ²).

The variable εᵢ is usually referred to as the random deviation or random error term in the model.
Without εᵢ, any observed pair (x, y) would correspond to a point falling exactly on the line y = β₀ + β₁x, called the true (or population) regression line.

The inclusion of the random error term allows (x, y) to fall either above the true regression line (when εᵢ > 0) or below the line (when εᵢ < 0).

There are totally three parameters in this model: β₀, β₁ and σ².
