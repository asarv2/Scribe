**Hypothesis Testing**

The framework of hypothesis testing consists of the following:

* **Step 1.** A pair of hypotheses, H<sub>0</sub> versus H<sub>a</sub>, on a parameter of interest (population level)
* **Step 2.** A test statistic (based on sample data)
* **Step 3.** A decision rule (whether to reject H<sub>0</sub> or not). If p-value is small, H<sub>0</sub> is rejected. Otherwise, for p-value is large, H<sub>0</sub> is not rejected.
* **Step 4.** Conclusions

**Review the examples:**

* 21.5 (one-sided small sample Z test)
* 21.6 (one-sided large sample Z test)
* 21.7 (two-sided small sample Z test)

**Two errors that can be committed in a testing procedure:**

* If we reject H<sub>0</sub> when in fact H<sub>0</sub> is true or make a false discovery, this is called a Type I error.
* If we fail to reject H<sub>0</sub> when in fact H<sub>1</sub> is true or miss an opportunity to make a discovery, this is called a Type II error.


|  | H<sub>0</sub> true | H<sub>1</sub> true |
|---|---|---|
| **Do not reject H<sub>0</sub>** | Correct (Probability = 1 - α) | Type II error (Probability = β) |
| **Reject H<sub>0</sub>** | Type I error (Probability = α) | Correct (Probability = Power) |


A good testing procedure commits less errors, or more precisely, has a low chance to commit either error.

**A general trade-off between type I and II errors:**

For same sample size n and same test statistic, the choice of rejection region can not reduce α and β at the same time.

Because of the suggested guidelines for specifying H<sub>0</sub> and H<sub>a</sub>, a type II error is usually more serious than a type I error.

* We specify an upper bound of the probability of type I error, which is referred to as the significance level of the test, e.g., a level 0.10, 0.05, and 0.01. The corresponding test procedure is called a level α test.
* A good test statistic yields smaller β subject to the given significance level α.


**Alternative decision rule:** a rejection region is the set of all test statistic values for which H<sub>0</sub> will be rejected. The null hypothesis will then be rejected if and only if the observed or computed test statistic value falls in the rejection region.


**The framework of hypothesis testing:**

Step 1. A pair of hypotheses, H<sub>0</sub> versus H<sub>a</sub>, on a parameter of interest (population level)

Step 2. A test statistic (based on sample data)

Step 3. Alternative decision rule (whether to reject H<sub>0</sub> or not). If the computed test statistic falls in the rejection region, H<sub>0</sub> is rejected. Otherwise, for the test statistic value is out of the region, H<sub>0</sub> is not rejected.

Step 4. A statistical conclusion


**β and power**

We know α denotes the type I error probability and a specified α value is used to determine the test.

The type II error probability is denoted as β. Because there are multiple parameter values under H<sub>a</sub>, there is a different value of β for each value of the parameter consistent with H<sub>a</sub>. Most of the widely used statistical software packages are capable of calculating type II error probabilities. They generally work in terms of power, which is simply 1 – β. A small value of β (close to 0) is equivalent to large power (near 1). A powerful test is the one that has high enough power and therefore good ability to detect when the null hypothesis is false.

**Hypothesis tests about the one-sample population mean 8.2-8.3**

Let X<sub>1</sub>, ..., X<sub>n</sub> represent a random sample of size n from some population.

* Null hypothesis H<sub>0</sub>: μ = μ<sub>0</sub>, where μ<sub>0</sub> is called null value.
* Three possible alternative hypotheses
    1. H<sub>a</sub>: μ > μ<sub>0</sub>, the population mean is greater than μ<sub>0</sub>
    2. H<sub>a</sub>: μ < μ<sub>0</sub>, the population mean is less than μ<sub>0</sub>
    3. H<sub>a</sub>: μ ≠ μ<sub>0</sub>, the population mean is not μ<sub>0</sub>

**Case 1: Normal distribution with known variance σ<sup>2</sup>**

The Test statistic is:

TS =  (X̄ - μ<sub>0</sub>) / (σ/√n)  ~ N(0,1)

One reason we choose this test statistic is that if we want to control the type I error, then the test statistic should have a tractable sampling distribution under null hypothesis.


Type I error:

α = P((X̄ - μ<sub>0</sub>) / (σ/√n) ∈ Reject Region | μ = μ<sub>0</sub>) = P(Z ∈ Reject Region)

As for type II error:

β(μ) = P((X̄ - μ<sub>0</sub>) / (σ/√n) ∉ Reject Region) = P(N(√n(μ - μ<sub>0</sub>)/σ, 1) ∉ Reject Region)


Rejection region and p-value:

1. {Z > z<sub>1-α</sub>}, p-value = P(Z > z<sub>TS</sub>) if H<sub>a</sub>: μ > μ<sub>0</sub>
2. {Z < z<sub>α</sub>}, p-value = P(Z < z<sub>TS</sub>) if H<sub>a</sub>: μ < μ<sub>0</sub>
3. {|Z| > z<sub>1-α/2</sub>}, p-value = 2 × P(Z > |z<sub>TS</sub>|), if H<sub>a</sub>: μ ≠ μ<sub>0</sub>

This choice of rejection region is intuitively appealing to the alternative hypotheses setting, also tries to minimize the type II error subject to α.

**Example 22.5** A set of observations on glycerol concentration (mg/mL) for samples of standard-quality (uncertified) white wines are given here: 2.67, 4.62, 4.14, 3.81, 3.83. Suppose the desired concentration value is 4. Assume, the population is normal.

Does the sample data suggest that true average concentration is something other than the desired value?

The data give x̄ = 3.814, s = 0.718.

Assume the distribution of the variable is normal. Let's carry out a test of appropriate hypotheses using the one-sample t test with a significance level of 0.05.

μ = true average glycerol concentration.

1. H<sub>0</sub>: μ = 4 vs. H<sub>a</sub>: μ ≠ 4

2. t<sub>TS</sub> = (3.814 - 4) / (0.718 / √5) = -0.579

3. Using the tail area of -0.579 under the t-curve with df=4, we obtain a p-value of 0.594, as two times the lower tail area of -0.579.

It is still plausible that μ = 4. The deviation of the sample mean 3.814 from its expected value 4 when H<sub>0</sub> is true can be attributed just to sampling variability rather than to H<sub>0</sub> being false.

4. (1) Since p-value is greater than 0.05, fail to reject H<sub>0</sub>. (2) There's no evidence that the true average concentration is something other than the desired value at the significance level, 0.05.
