The Normal Distribution

The normal distribution (also called Gaussian distribution) is the most important one in all of probability and statistics. Many numerical populations have distributions that can be fit very closely by an appropriate normal curve. We use the Normal distribution when we have a continuous random variable with a density curve that is symmetric, unimodal and bell shaped. The Normal distribution can be completely described by its population mean (μ) and standard deviation (σ).

What are some continuous random variables that would follow an approximately Normal distribution?

Definition:
A continuous rv X is said to have a normal distribution with parameters μ and σ (or σ<sup>2</sup>), where −∞ < μ < ∞ and 0 < σ, if the pdf of X is

𝑓(𝑥; 𝜇, 𝜎) =

The statement that X is normally distributed with parameters μ and σ<sup>2</sup> is often abbreviated X~N(μ, σ<sup>2</sup>).

𝑓(𝑥;  μ, σ) is a legitimate pdf:
* Clearly 𝑓(𝑥;  μ, σ) ≥0.
* But a somewhat complicated calculus argument must be used to verify that the integral of the density function equals 1.
* It can be shown that 𝐸(𝑋) = μ and 𝑉𝑎𝑟(𝑋) = σ<sup>2</sup>, so the parameters are the mean and the standard deviation of X.

Note: The shape of the normal distribution is determined by the population mean (μ) and standard deviation (σ).
* The mean μ is always in the center of highest point. Each density curve is symmetric about μ and bell-shaped, so the center of the bell (point of symmetry) is both the mean of the distribution and the median.
* σ determines how wide the plot is. The value of σ is the distance from μ to the inflection points of the curve (the points at which the curve changes from turning downward to turning upward).

**Relating probabilities to σ (68-95-99.7 rule)**

* **68% of the observations fall within 1 standard deviation of the mean.**
    * P(μ-σ < X < μ+σ) = 68%
    * P(X < μ-σ) = P(X > μ+σ) = (1 - 68%) / 2 = 16%
* **95% of the observations fall within 2 standard deviations of the mean.**
    * P(μ-2σ < X < μ+2σ) = 95%
    * P(X < μ-2σ) = P(X > μ+2σ) = (1 - 95%) / 2 = 2.5%
* **99.7% of the observations fall within 3 standard deviations of the mean.**
    * P(μ-3σ < X < μ+3σ) = 99.7%
    * P(X < μ-3σ) = P(X > μ+3σ) = (1 - 99.7%) / 2 = 0.15%

**z-scores:** The z-score for X = x is z = (x-μ)/σ.

* The z-score is the number of standard deviations an observed value x is from μ.
* Observations larger than the mean have a positive z-score.
* Observations smaller than the mean have a negative z-score.
* Because the z-score is the number of standard deviations, it doesn't have any units. In a sense it standardizes data values.

**The Standard Normal Distribution**

Suppose the variable of interest has a normal distribution.  X = variable value of a subject (or experimental unit) selected at random from the population. We know that X ~ N(μ, σ²).

* We can use the z-score formula to standardize all variable values to standard deviations that don't depend on units.
* If X is normally distributed, then the z-scores are also normally distributed. The probability distribution of the z-score has a mean of 0 and a standard deviation of 1.
* This distribution is known as the standard Normal distribution and is represented by Z ~ N(0,1).

**Key point:** the z-score is calculated as  z = (x - μ) / σ. The z-scores of a population have a standard normal distribution.

**Definition**

A random variable having a standard normal distribution is called a standard normal random variable and will be denoted by Z. The pdf of Z is

f(z; 0, 1) = (1 / √(2π)) * e^(-z²/2)     -∞ < z < ∞

The cdf P(Z ≤ z) is denoted as Φ(z).

Appendix Table A.3 gives Φ(z), the area under the standard normal density curve to the left of z. From this table, various other probabilities involving Z can be calculated.

**Example 11.2 revisit:** Suppose X is the height of a randomly chosen woman. The distribution of heights in this population is given by X ~ N(65, 3.5<sup>2</sup>). What is the probability that a randomly selected adult female will be shorter than 68 inches?

I. Write this in mathematical notation.
P(X < 68) = ?

II. Calculate the z-score. This gives us the # standard deviations x is from μ.
z-score for 68 = (68 - 65) / 3.5 = 0.857 ≈ 0.86

III. Draw a picture: Line up the two distributions:
X ~ N(65, 3.5<sup>2</sup>) or Z ~ N(0, 1<sup>2</sup>)

IV. P(X < x) = P(Z < z)
P(X < 68) = P(Z < 0.86)

**Aside on what we did above:**

* We want to find the probability that a randomly selected individual has a characteristic.
* In this example, that characteristic is height is less than 68 inches.
* We know that this probability is the proportion of individuals in the population whose height is less than 68 inches.
* Because X = height of a randomly chosen female is a continuous random variable, we relate proportion to the area of part of the density curve for heights in this population.
* Finally, we make use of the fact that the areas are the same whether we use the density curve for the heights or the density curve for the z-scores of the weights.

**Using a Z table to find P(Z < 0.86):**

* We have reduced our problem to finding P(Z < 0.86).
* In general, to find P(Z < z), we look the probability up in what is called a Z-table. This probability is called a cumulative probability Φ(z).
* Locate the z-score you calculated (0.86) on the left column and the top row of the table.
* Then read the corresponding cumulative probability from the body of the table.
* The cumulative probabilities shown give areas under the curve to the left of each z-score.

**Basics on how to calculate all Normal probabilities**

I. First calculate  z = (x - μ) / σ.
II. Find z on the edges of the table. Look up the cumulative probability in the middle of the table.

**Key points to remember:**
* The Z table only gives you P(Z < z).
* To find any probability not of the form P(X < x) you must use formula 2, 3 or 4 given below.

**RULES:**

1. P(X ≤ x) = P(X < x) = P(Z < z) = Φ(z).
Φ(z) is called a cumulative probability and it is given in the Z table.
o P(Z ≤ 1.25) = # in middle of table associated with z-score=1.25.

2. P(X > x) = P(Z > z) = 1 - P(Z < z) = 1 - Φ(z).
o P(Z > 1.25) = 1 - Φ(1.25) = 1 - # in middle of table associated with z-score=1.25

3. P(a < X < b) = P(z<sub>a</sub> < Z < z<sub>b</sub>) =  P(Z < z<sub>b</sub>) – P(Z < z<sub>a</sub>) = Φ(b) - Φ(a).
o P(-0.38 ≤ Z ≤ 1.25) = Φ(1.25) - Φ(-0.38)
= (cumulative probability for 1.25) - (cumulative probability for -0.38)
= 0.8944 - 0.3520 = 0.5424.

4. P(X < a or X > b) = P(Z < z<sub>a</sub> or Z > z<sub>b</sub>) =  P(Z < z<sub>a</sub>) + [1 - P(Z < z<sub>b</sub>)] = Φ(z<sub>a</sub>) + 1 - Φ(z<sub>b</sub>)
o P(Z < -0.38 or Z > 1.25)
= (cumulative probability for -0.38) + [1 - (cumulative probability for 1.25)]
= Φ(-0.38) + [1 - Φ(1.25)]
