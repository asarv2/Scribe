**Main types of variables**

Numerical (Quantitative) Variables: A variable is called numerical if each variable value is a number. Two Sub-types of Numerical variables:

* **Discrete:** Numerical variables that can only take certain fixed values, with no intermediate values possible.
* **Continuous:** Continuous variables can take on any real numerical value over an interval.

Categorical (Qualitative) Variables: A variable is called categorical if the variable values represent some quality (as opposed to quantity) of the subject. Sub-types:

* **Nominal:** variables are purely qualitative and unordered (i.e. eye color).
* **Ordinal:** variables can be ranked (i.e. stage of cancer).

**Histograms: The most common graph used to describe the distribution of a numerical variable is the histogram.**


**Reading Histograms:**

* Variable values are plotted on the horizontal axis. The range of values for the left bar is 0 up to 2 but not including 2, etc.
* The height of each bar is its frequency or the proportion of subjects taking values in that range.


**NOTE:** The shape of a histogram of the same data set can vary depending on how wide the bars are. Here, the bars are 2 wide but the other histogram of sugar has bars of width 2.5. The 2 histograms of sugar look different. Same data set but the range of values for each box is slightly different.


**R code:**
```R
x <- c(7, 5, 14, 12, 1, 13, 2, 12, 10, 3, 11, 13, 3, 10, 11, 6, 10, 15, 3, 3)
hist(x); hist(x, breaks = c(0, 4, 8, 12, 16))
```

# Slide 5

**We use four different properties to describe numerical variables:**

1) Shape
2) Center
3) Variability
4) Unusual observations (data points whose value differs noticeably from the other values)

**Three statistics used to measure the center of a data set**

**Mode** (the least important statistic)
* The value taken most frequently by the subjects.

**Mean**
* The "average" value of a variable.
* The population mean is denoted as μ. The average value if we know the values of all objects in a census.
* The sample mean of a data set is defined as
  x̄ = (x<sub>1</sub> + x<sub>2</sub> + ... + x<sub>n</sub>) / n = 1/n Σ<sub>i=1</sub><sup>n</sup> x<sub>i</sub>

**Median**
* The middle value of an ordered data set.
* The population median is defined as M.
* The sample median of a data set is calculated as
  M̂ = {
    The single middle value if n is odd = (n+1)/2<sup>th</sup> ordered value.
    The avg. of the two middle values if n is even = avg. of (n/2)<sup>th</sup> and (n/2 + 1)<sup>th</sup> ordered values.


**Example 2.4:** A sample of 12 recordings of Beethoven's Symphony #9 with the random variable durations (min)

x<sub>7</sub> = 67.4, x<sub>8</sub> = 68.4,  x<sub>9</sub> = 68.8,  x<sub>10</sub> = 70.8,  x<sub>11</sub> = 75.7,  x<sub>12</sub> = 79.0.

**Resistant statistic:** A statistic is called robust or resistant if it is not strongly influenced by extreme values like outliers.
o The sample  **mean** is robust to outliers.
o The sample  **median** is not robust to outliers.

**Influential Point:** A data value is called influential if it noticeably shifts the value of the sample mean towards it.
