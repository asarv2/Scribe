**Counting Techniques**

Counting technique is used to probability calculation when the sample space is finite with equal probability, i.e., S = {𝑠<sub>1</sub>, 𝑠<sub>2</sub>, … … , 𝑠<sub>𝑁</sub>}, and P({𝑠<sub>𝑖</sub>}) = <sup>1</sup>/<sub>𝑁</sub>, then

P(A) = <sup>N(A)</sup>/<sub>N</sub>,

where N(A) is the number of elements in the event A, N is the number of outcomes in the sample space.

**How to count N(A) and N?**

**Product Rule for Ordered Pairs**

* Ordered pair: if 𝑂<sub>1</sub> and 𝑂<sub>2</sub> are objects, then the pair (𝑂<sub>1</sub>, 𝑂<sub>2</sub>) is different from the pair (𝑂<sub>2</sub>, 𝑂<sub>1</sub>)
    * Example: In a little league baseball team, Angela being the pitcher and Ben the catcher gives a different lineup from the one in which Angela is catcher and Ben is pitcher.
* Proposition: If the first element or object of an ordered pair can be selected in 𝑛<sub>1</sub> ways, and for each of these 𝑛<sub>1</sub> ways the second element of the pair can be selected in 𝑛<sub>2</sub> ways, then the number of ordered pairs is 𝑛<sub>1</sub> × 𝑛<sub>2</sub>.


**Product Rule for k-Tuples**

* k-Tuples: We will call an ordered collection of k objects a k-tuple.
    * Example: A job consists of k separate tasks, the 𝑖𝑡ℎ of which can be done in 𝑛<sub>𝑖</sub> ways for i=1,…,k, then in how many ways can the entire job be done?
* Proposition: Suppose a set consists of ordered collections of k elements (k-tuples) and that there are 𝑛<sub>1</sub> possible choices for the first element; for each choice of the first element, there are 𝑛<sub>2</sub> possible choices of the second element; ……; for each possible choice of the first k–1 elements, there are 𝑛<sub>𝑘</sub> choices of the 𝑘𝑡ℎ element. Then there are 𝑛<sub>1</sub> × 𝑛<sub>2</sub> × … … × 𝑛<sub>𝑘</sub> ≔∏<sup>𝑘</sup><sub>𝑖=1</sub> 𝑛<sub>𝑖</sub> possible k-tuples.

**Permutations and combinations**

Consider a group of *n* distinct individuals or objects ("distinct" means that there is some characteristic that differentiates any particular individual or object from any other). How many ways are there to select a subset of size *k* from the group?

* If a Little League team has 15 players on its roster, how many ways are there to select 9 players to form a starting lineup?
* If a university bookstore sells ten different laptop computers but has room to display only three of them, in how many ways can the three be chosen?

**Two different scenarios:**

* **The order of selection is important.**
    * Angela being the pitcher and Ben the catcher gives a different lineup from the one in which Angela is catcher and Ben is pitcher.
* **Order is not important.**
    * The laptop display example.

**Permutation:** An ordered subset is called a permutation.

* The number of permutations of size *k* that can be formed from the *n* individuals or objects in a group will be denoted by 𝑃<sub>𝑘,𝑛</sub>.
* The number of permutations can be determined by using our earlier counting rule for *k*-tuples.
𝑃<sub>𝑘,𝑛</sub>= 𝑛(𝑛−1) … … (𝑛−𝑘+ 1) =  𝑛! / (𝑛−𝑘)!

**Combination:** An unordered subset is called a combination.

* One way to denote the number of combinations is 𝐶<sub>𝑘,𝑛</sub>, but we shall instead use notation that is quite common in probability books: (<sup>𝑛</sup>⁄<sub>𝑘</sub>). It reads as *n* choose *k*.
𝐶<sub>𝑘,𝑛</sub>= (<sup>𝑛</sup>⁄<sub>𝑘</sub>) = 𝑛! / [(𝑛−𝑘)!𝑘!] = 𝑛× (𝑛−1) × … × 1 / [(𝑛−𝑘) × … × 1] × [𝑘× … × 1]


**Examples 5.1:** A college of engineering has 7 departments, each with one representative on the college's student council. From these 7 representatives, one is to be chosen chair, another vice-chair, and a third secretary. How many ways are there to select the 3 officers?

**In fact,**

1. The chair can be selected in any of 𝑛<sub>1</sub> = 7 ways;
2. For each way of selecting the chair, there are 𝑛<sub>2</sub> = 6 ways to select the vice-chair, and hence 7 × 6 = 42 (chair, vice-chair) pairs;
3. Finally, for each way of selecting a chair and vice-chair, there are 𝑛<sub>3</sub> = 5 ways of choosing the secretary.
