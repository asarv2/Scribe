**Descriptive Statistics Cont.**

We use four different properties to describe numerical variables:

* Shape
* Center
* Variability
* Unusual observations (data points whose value differs noticeably from the other values)

**Measures of variability of Numerical Data**

* The population variance (σ²) is defined as

σ² =  1/N * Σ<sub>i=1</sub><sup>N</sup> (x<sub>i</sub> - μ)²

|  | Population Parameter | Variance | Standard Deviation |
|---|---|---|---|
|  |  | σ² | σ |
| Sample Statistic |  | s² | s |

* Sample Variance (s²): the sample variance is the average of the square of the deviation from the sample mean.

o (x<sub>i</sub> - x̄) is the deviation of the 𝑖𝑡ℎ data value from the sample mean. The sample variance is defined as

s² = 1/(n-1) * Σ<sub>i=1</sub><sup>n</sup> (x<sub>i</sub> - x̄)² = s<sub>xx</sub> / (n-1)

o The sample variance is not resistant to outliers.

* Sample Standard Deviation (s): the sample standard deviation is the square root of the sample variance s = √s².

o The standard deviation measures how tightly the data values are clustered around the mean. The standard deviation is very close in value to the average distance of the data from x̄.

o The standard deviation is NOT resistant to outliers.

**NOTE:** The denominator in sample variance and population variance are different.

**NOTE:** Since the standard deviation is just the square root of the variance, they both give us the same information about how much the data values vary from the mean.
