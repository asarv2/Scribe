**Sampling Distributions: measuring how statistics vary from sample to sample**

* **Statistics:** a statistic is a numerical summary of the data whose value can be calculated from sample data. More specifically, any function of the sample data (X<sub>1</sub>, ..., X<sub>n</sub>) is a statistic.
* **Example:** sample mean, sample median, sample variance, or even the sample data itself.
* **Note:** prior to obtaining data, there is uncertainty as to what value of any particular statistic will result. Therefore, statistics are random variables as well, and it has its own distribution.
* **Note:** as a random variable, a statistic will be denoted by an uppercase letter; a lowercase letter is used to represent the calculated or observed value of the statistic given a fixed data.
* **The probability distribution of a statistic is sometimes referred to as its sampling distribution to emphasize that it describes how the statistic varies in value across all samples that might be selected.** The sampling distribution is completely determined by the joint distribution of X<sub>1</sub>, X<sub>2</sub>, ..., X<sub>n</sub>.

Definition: the rv’s X<sub>1</sub>, X<sub>2</sub>, ..., X<sub>n</sub> are said to form a (simple) random sample of size n if

1. The X<sub>i</sub>’s are independent rv’s.

2. Every X<sub>i</sub> has the same probability distribution.

In such case, we say X<sub>1</sub>, X<sub>2</sub>, ..., X<sub>n</sub> are independent and identically distributed (iid).


Note: this assumption of random sample provides a joint distribution for the sequence of X<sub>1</sub>, X<sub>2</sub>, ..., X<sub>n</sub>, and further defines a distribution of a statistic (a random variable).

{
 D<-rexp(n, 1); H[i]<-var(D);
}

hist(H);qqnorm(H); qqline(H)


There are 3 Distinct Distribution for a numerical variable:

* Population Distribution (theoretical distribution).
* Data Distribution – Observed distribution of data from a single sample.
* Sampling Distribution (theoretical distribution) - Probability Distribution of some statistic, it is the distribution of the set of statistic calculated from the set of all possible samples from the parent population distribution.
