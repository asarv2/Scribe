Types of possible errors and Evaluation of testing

There are totally two possible errors that can be committed in a testing procedure.

*   If we reject H<sub>0</sub> when in fact H<sub>0</sub> is true or make a false discovery, this is called a Type I error.
*   If we fail to reject H<sub>0</sub> when in fact H<sub>1</sub> is true or miss an opportunity to make a discovery, this is called a Type II error.

A good testing procedure commits less errors, or more precisely, has low chance to commit either error.
We denote:
*   α = probability of making a Type I error
*   β = probability of making a Type II error. β is a function with respect to the parameter value θ<sub>0</sub>,
    β(θ<sub>0</sub>) = P(Fail to reject H<sub>0</sub> | true parameter value is θ<sub>0</sub>).
*   Power = 1 – β = probability of reject H<sub>0</sub>, assuming H<sub>1</sub> is true
    = probability of correctly making a rejection (sensitivity of test)


A general trade-off between type I and II errors:

For same n and same test statistics, the choice of rejection region
can not reduce α and β at the same time.
Because of the suggested guidelines for specifying H<sub>0</sub> and H<sub>1</sub>, a
type II error is usually more serious than a type I error. We specify
an upper bound of the probability of type I error, which is referred to
as the significance level of the test, e.g., a level 0.10, 0.05, and
0.01. The corresponding test procedure is called a level α test.
A good test statistic yields smaller β subject to the given significance level α.
