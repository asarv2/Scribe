\section*{Other Pivoting Rules (independent of Scale)}

\subsection*{[Im\&J largest increase, steepest edge, Bland Rule -...]}

\textbf{Description:}

This slide presents a comparison of the largest-coefficient rule and the largest-increase rule for the Simplex method in linear programming.  It shows two tables (Tables 4.1 and 4.2) that provide average iteration counts for each rule on various problem sizes (m and n).  The tables are indexed by the number of constraints (m) and the number of variables (n).  The values in the tables represent the average number of iterations needed to solve the linear programming problem using each rule.  The text states that, in practice, the largest-increase rule tends to perform better than the largest-coefficient rule, requiring fewer iterations to reach a solution.  The source of the data is cited.
