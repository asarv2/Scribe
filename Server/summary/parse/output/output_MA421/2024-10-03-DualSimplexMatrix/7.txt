\section*{Simplex Method in Matrix Form \textit{[LVJ Ch.6]}}

\begin{itemize}
    \item $\max \xi(\mathbf{x}) = \mathbf{c}^T \mathbf{x}$
    \item st.
        \begin{itemize}
            \item $A \mathbf{x} \le \mathbf{b}$
            \item $\mathbf{x} \ge \mathbf{0}$
        \end{itemize}
\end{itemize}

\begin{itemize}
    \item $\max \xi(\mathbf{x}) = \mathbf{c}^T \mathbf{x} = \mathbf{c}_B^T \mathbf{x}_B + \mathbf{c}_N^T \mathbf{x}_N$
    \item $\mathbf{x}_B = \mathbf{x}_B - (\mathbf{B}^{-1} \mathbf{N}) \mathbf{x}_N$
\end{itemize}

\begin{itemize}
    \item $\xi^* = \mathbf{c}_B^T \mathbf{B}^{-1} \mathbf{b}$, $\mathbf{z}_N = (\mathbf{B}^{-1} \mathbf{N})^T \mathbf{c}_B - \mathbf{c}_N$, $\mathbf{x}_B = \mathbf{B}^{-1} \mathbf{b}$
\end{itemize}

\end{document}

\textbf{Description:}

This slide presents the simplex method in a matrix form, focusing on the mathematical representation of the problem.  It shows the objective function ($\xi(\mathbf{x}) = \mathbf{c}^T \mathbf{x}$) and the constraints ($A \mathbf{x} \le \mathbf{b}$, $\mathbf{x} \ge \mathbf{0}$) in a matrix format.  The slide then introduces the partitioning of variables into basic variables ($\mathbf{x}_B$) and non-basic variables ($\mathbf{x}_N$), and the corresponding coefficients in the objective function ($\mathbf{c}_B$ and $\mathbf{c}_N$).  The equations show how the basic variables ($\mathbf{x}_B$) are expressed in terms of the non-basic variables ($\mathbf{x}_N$) and the right-hand side vector ($\mathbf{b}$).  The slide also provides the optimal solution for the objective function ($\xi^*$) and the reduced costs ($\mathbf{z}_N$) in terms of the matrix operations.  The notation suggests a linear programming problem in a standard form, ready for application of the simplex algorithm. The reference "[LVJ Ch.6]" indicates the source of the material.
