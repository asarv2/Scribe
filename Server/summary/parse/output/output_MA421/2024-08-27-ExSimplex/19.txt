Slide 19

$\text{LV} \text{ p. } 11$
Set $x_1 = x_2 = x_3 = 0$
$\max \mathcal{Z} = 5x_1 + 4x_2 + 3x_3$
subject to
$2x_1 + 3x_2 + x_3 \le 5$
$4x_1 + x_2 + 2x_3 \le 11$
$3x_1 + 4x_2 + 2x_3 \le 8$
$x_1, x_2, x_3 \ge 0$

$\omega_1 = 5 - 2x_1 - 3x_2 - x_3$
$\omega_2 = 11 - 4x_1 - x_2 - 2x_3$
$\omega_3 = 8 - 3x_1 - 4x_2 - 2x_3$
$x_1, x_2, x_3, \omega_1, \omega_2, \omega_3 \ge 0$

Increase $x_1$, keeping $x_2 = x_3 = 0$
$\omega_1 \ge 0 \implies 5 - 2x_1 \ge 0 \implies x_1 \le \frac{5}{2} = 2.5$
$\omega_2 \ge 0 \implies 11 - 4x_1 \ge 0 \implies x_1 \le \frac{11}{4} = 2.75$
$\omega_3 \ge 0 \implies 8 - 3x_1 \ge 0 \implies x_1 \le \frac{8}{3} = 2.67$

$x_1 \le 2.5$ is the most strict

The calculations show how the constraints ($\omega_1 \ge 0$, $\omega_2 \ge 0$, $\omega_3 \ge 0$) limit the possible values of $x_1$.  The most restrictive constraint is identified as $x_1 \le 2.5$, meaning $x_1$ can be increased up to 2.5 while maintaining feasibility.  The context suggests this is a step in the Simplex method's iterative process, where the algorithm determines which variable to increase next to improve the objective function value.
