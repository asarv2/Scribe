Slide 41

Auxiliary Problem

$\max \overline{\mathcal{Z}} = -x_0$
subject to
$-x_1 + x_2 - x_0 \le -1$
$-x_1 - 2x_2 - x_0 \le -2$
$x_2 - x_0 \le 1$
$x_1, x_2, x_0 \ge 0$

(1) Must be feasible: choose $x_0$ large enough
(2) Original problem is feasible

$\max \mathcal{Z} = 0$

Add slack variables:
$\omega_1 = -1 + x_1 - x_2 + x_0$
$\omega_2 = -2 + x_1 + 2x_2 + x_0$
$\omega_3 = 1 - x_2 + x_0$
$x_1, x_2, x_0, \omega_1, \omega_2, \omega_3 \ge 0$

Set $x_1 = 0$, $x_2 = 0$
$\omega_1 = -1 + x_0$
$\omega_2 = -2 + x_0$
$\omega_3 = 1 + x_0$
$x_0 = 2 \implies \mathcal{Z} = -2$
$x_1 = 0$, $x_2 = 0$, $x_0 = 2$
$\omega_1 = 1$, $\omega_2 = 0$, $\omega_3 = 3$

Increase $x_2$, keeping $x_1 = x_0 = 0$
$\omega_1 \ge 0 \implies -1 - x_2 + x_0 \ge 0 \implies x_2 \le 1$
$\omega_2 \ge 0 \implies -2 + 2x_2 + x_0 \ge 0 \implies x_2 \le 1$
$\omega_3 \ge 0 \implies 1 - x_2 + x_0 \ge 0 \implies x_2 \le 1$

Set $x_2 = 1$, $x_1 = x_0 = 0$
$\mathcal{Z} = -1$
$\omega_1 = -1 + 0 - 1 + 0 = -2$
$\omega_2 = -2 + 0 + 2(1) + 0 = 0$
$\omega_3 = 1 - 1 + 0 = 0$

Set $x_2 = 1$, $x_1 = 0$, $x_0 = 0$
$\mathcal{Z} = -1$
$\omega_1 = -2$, $\omega_2 = 0$, $\omega_3 = 0$

Increase $x_1$, keeping $x_2 = 1$, $x_0 = 0$
$\omega_1 \ge 0 \implies -1 + x_1 - 1 + 0 \ge 0 \implies x_1 \ge 2$
$\omega_2 \ge 0 \implies -2 + x_1 + 2(1) + 0 \ge 0 \implies x_1 \ge 0$
$\omega_3 \ge 0 \implies 1 - 1 + 0 \ge 0 \implies 0 \ge 0$

Set $x_1 = 2$, $x_2 = 1$, $x_0 = 0$
$\mathcal{Z} = -5$
$\omega_1 = 0$, $\omega_2 = 0$, $\omega_3 = 0$

Optimal solution: $x_1 = 2$, $x_2 = 1$, $x_0 = 0$, $\mathcal{Z} = -5$
