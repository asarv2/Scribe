Slide 18

\textbf{Duality for General LP}

\begin{itemize}
    \item \textbf{Primal Problem (P)}
    \begin{align*}
        \max \xi(x) &= c^T x \\
        \text{s.t.} \quad Ax &\le b \\
        x &\ge 0
    \end{align*}
    \item \textbf{Dual Problem (D)}
    \begin{align*}
        \min \xi(\lambda) &= \lambda^T b \\
        \text{s.t.} \quad A^T \lambda &\ge c \\
        \lambda &\ge 0
    \end{align*}
    \item \textbf{Weak Duality}
    \begin{itemize}
        \item If $x^*$ is feasible for (P) and $\lambda^*$ is feasible for (D), then $\xi(x^*) \le \xi(\lambda^*)$.
    \end{itemize}
\end{itemize}

\textbf{Description:}

This slide presents the primal and dual problems for a general linear program (LP), along with the statement of weak duality. The primal problem (P) is to maximize the objective function $c^T x$ subject to the constraints $Ax \le b$ and $x \ge 0$.  The dual problem (D) is to minimize the function $\lambda^T b$ subject to the constraints $A^T \lambda \ge c$ and $\lambda \ge 0$.  The slide emphasizes the weak duality property, stating that if a feasible solution $x^*$ exists for the primal problem (P) and a feasible solution $\lambda^*$ exists for the dual problem (D), then the objective function value for the primal problem is always less than or equal to the objective function value for the dual problem.  This is a fundamental result in linear programming duality, providing a lower bound on the optimal value of the primal problem.  The slide is likely part of a larger presentation on duality and optimization techniques in linear programming, preparing the audience for the next steps in the derivation of the strong duality theorem.
