# Slide 3

# Subfields of Machine learning

Supervised Learning
Given paired inputs/outputs (X, y)
Goal is to learn f from training data, f(X) = y
Evaluated it on "new" (test) data.
Examples
* Classification: y is discrete (y are class labels, X refers to attributes)
* Regression: y is continuous

Unsupervised learning
Given examples of inputs X
Learn a function f to simplify the data, f(X) = y
Examples:
* Clustering: y is discrete (y are cluster memberships)
* Matrix factorization: y are continuous (y are embeddings)


---

**Description of the Slide:**

This slide, part of a lecture on Introduction to Data Science, presents a table-like structure outlining two major subfields of machine learning: Supervised Learning and Unsupervised Learning.  The slide is formatted with clear headings for each subfield.  Under each heading, it lists the key characteristics and examples of each type.

* **Supervised Learning:**  This section defines supervised learning as a process where paired input-output data (X, y) is provided. The goal is to learn a function (f) from the training data such that f(X) = y.  The learned function is then evaluated on new, unseen data.  Examples of supervised learning are classification (where the output y is discrete, representing class labels) and regression (where the output y is continuous).

* **Unsupervised Learning:** This section defines unsupervised learning as a process where only input data (X) is provided. The goal is to learn a function (f) that simplifies the data, such that f(X) = y.  Examples of unsupervised learning are clustering (where the output y is discrete, representing cluster memberships) and matrix factorization (where the output y is continuous, representing embeddings).

The slide's purpose is to introduce the fundamental concepts of supervised and unsupervised learning, highlighting the differences in the types of data used and the goals of each approach.  There are no figures on this slide.

# What is Clustering?

Clustering: the process of grouping a set of objects into classes of similar objects

* Objects within a cluster should be similar
* Objects from different clusters should be dissimilar

Clustering is the most common form of unsupervised learning

* Learning from unlabeled raw data
* A frequent and important task that finds many applications in data science

# Slide 22

**The K-means Algorithm**

Input: Dataset D, number of clusters k
Output: Set of cluster representatives C, cluster membership vector m

# Initialize cluster representatives C
Randomly assign k data points from D into each cluster
Initialize C such that c<sub>i</sub> is mean of points in i<sup>th</sup> cluster

while not converged
# Data Assignment
Reassign points in D to closest cluster mean
Update m such that m<sub>i</sub> is cluster ID of the i<sup>th</sup> point in D

# Relocation of means
Update C such that c<sub>i</sub> is mean of points in i<sup>th</sup> cluster

# Slide 31

**Python Example of K-means Clustering**

```python
import matplotlib.pyplot as plt
plt.style.use('seaborn')
from sklearn.datasets.samples_generator import make_blobs
X, y_true = make_blobs(n_samples=300, centers=4,
    cluster_std = 0.60, random_state=0)
plt.scatter(X[:, 0], X[:, 1], s=50)
from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=4)
kmeans.fit(X)
y_kmeans = kmeans.predict(X)
# returns array of predictions of cluster for each item
plt.scatter(X[:, 0], X[:, 1], c=y_kmeans, s=50, cmap='viridis')
centers = kmeans.cluster_centers_
plt.scatter(centers[:, 0], centers[:, 1], c='black', s=200, alpha=0.5)
```

# Slide 33

**How to choose k in kmeans?**

How many clusters do we need?
K-means optimization
* Minimize the sum of squared distances from each point to its cluster centroid
(this is called the inertia score in sklearn)
Naive approach to choose k:
* Try different values of k, pick one that minimizes inertia
* What is wrong with this? As k increases the inertia
score cannot increase, thus will pick k=n
Better approach:
* Pick k at the "elbow" of the plot
* Balances accuracy (low value of inertia) and complexity (small value of k)

Measure correlation between these two matrices
