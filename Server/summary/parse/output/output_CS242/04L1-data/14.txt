# XML/HTML Files

The main format for the web
XML files contain hierarchical content delineated
by tags
HTML is syntactically like XML, but sometimes
tags are not closed and tags are primarily used to
describe appearance of page
There are a number of Python parsers for XML/
HTML. We will use the BeautifulSoup library

```xml
</user-agents>
```
