# PANDAS: Looping over data

```python
for i in range(10):  # loop over first ten rows of data frame
    tmpyr = data.iloc[i,1]
    tmpage = data.iloc[i,2]
    tmpname = data.iloc[i,3]
    print(tmpname + ": current age (if still alive) =" + str(2018-tmpyr+tmpage))
```
