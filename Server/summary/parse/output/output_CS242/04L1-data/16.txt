# Intro to pandas

Pandas is a third party Python module for data analysis
* Assists in the analysis of PANal DATA (tables, data frames)
* Available in Jupyter, along with NumPy and matplotlib
Pandas is a great tool for working with tabular data
* CSV, excel, and JSON easily, XML is a little more difficult
* Allows you to manipulate data by columns, rows, filtering, grouping, etc
Everything you do in pandas, you can do in python... though it would be more difficult
