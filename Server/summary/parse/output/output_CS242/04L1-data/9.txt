# Semi-Structured Data

Collection of data items with less formal structure than relational data, but with some tags or markers to delineate semantic elements of items (i.e., properties), e.g., XML or JSON

```xml
<user-agent>
<ID>id a f 3</ID>
<String>!Susie (http://www.sync2it.com/susie)</String>
<Description>Sync2It bookmark management & clustering engine</Description>
<Type>C R</Type>
<Comment/>
<Link>http://www.sync2it.com</Link1>
<Link2/>
</user-agent>
</user-agents>
```
