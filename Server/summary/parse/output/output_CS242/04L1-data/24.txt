# loc and iloc the same thing in different ways

```
data.loc[<row indexes>, <column names>]
• Can use a number, slice, or list for row indexes
• Can only use a list of names for column names
• Includes the last element of a slice (e.g. 3:5 is 3, 4, and 5)
data.iloc[<row indexes>,<column indexes>]
• Can use a number, slice, or list for row indexes
• Can use a number, slice, or list for column indexes
• Slicing works like strings (e.g 3:5 is 3 and 4)
```

---

**Description:**

This slide, titled "loc and iloc the same thing in different ways," explains the differences between the `loc` and `iloc` methods for accessing data in a Pandas DataFrame.

* **`loc` Method:**  The slide describes how to use the `loc` method to access data.  It explains that `loc` uses *labels* (names) to select rows and columns.  Crucially, it states that row indexes can be numbers, slices, or lists, but column selection *must* use a list of column names.  The slide also highlights that `loc` includes the *last* element in a slice (e.g., 3:5 includes 3, 4, and 5).

* **`iloc` Method:** The slide describes how to use the `iloc` method to access data.  It explains that `iloc` uses *integer positions* to select rows and columns.  Importantly, it states that both row and column selection can use numbers, slices, or lists of integer positions.  The slide also notes that slicing with `iloc` works like string slicing (e.g., 3:5 selects elements 3 and 4).

* **Purpose:** The slide is designed to help users understand the difference between label-based indexing (`loc`) and integer-position-based indexing (`iloc`) in Pandas DataFrames.  This is a crucial distinction for correctly selecting data from a DataFrame.
