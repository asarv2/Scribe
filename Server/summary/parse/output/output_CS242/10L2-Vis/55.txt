**Example: Boxplot**

```python
import pandas as pd
iris = pd.read_csv('iris.dat', sep=',')
import plotly.express as px
fig = px.box(iris, x='category', y='petal-length', color='category')
import chart_studio
#chart_studio.tools.set_credentials_file(username='DemoAccount', api_key='lr1c37zw81')
py.iplot(fig, filename='CS242box', type='box')
```

**(Figure Description):**

A box plot is displayed, showing the distribution of "petal-length" across different iris categories (Iris-setosa, Iris-versicolor, and Iris-virginica).  The x-axis represents the categories, and the y-axis represents the "petal-length" values.  Each box in the plot represents the interquartile range (IQR) of the data for a specific category.  The line within the box indicates the median value.  The whiskers extend to the minimum and maximum values within 1.5 times the IQR from the box.  Points outside the whiskers are considered outliers and are plotted individually.  The boxes are colored differently for each category, making it easy to compare the distributions.  The plot is positioned centrally on the slide.  The title "Boxplot of Petal Length" is above the plot.  The labels for the categories ("Iris-setosa", "Iris-versicolor", and "Iris-virginica") are clearly visible on the x-axis.  The y-axis is labeled with the values of petal length.  The plot is designed to compare the distribution of petal length across the different iris species.
