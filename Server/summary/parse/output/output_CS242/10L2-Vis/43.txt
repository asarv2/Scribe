**Grammar of graphics**

Basic idea:

* Independently specify plot building blocks
* Combine them to create almost any kind of graphical display you want

Building blocks of a graph include:

* Data
* Aesthetic mapping (color, position, fill, shape of points, linetype, etc.)
* Geometric object (points, lines boxplot, etc.)
* Others: statistical transformations, scales, coordinate system, position adjustments, faceting
