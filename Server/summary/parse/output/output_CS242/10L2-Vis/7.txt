# `matplotlib.pyplot.scatter`

`scatter(x, y, c=None, ... marker=None, ... label=None, ...)`

*   **x, y:** scalar or list of data points
*   **c:** list of colors (variety of formats, hex values, RGB, names for common colors)
*   **marker:** list of class or shorthand for marker style
    See: [https://matplotlib.org/api/markers_api.html](https://matplotlib.org/api/markers_api.html) for a whole list
*   **label:** Name of the dataset (for a legend)
