**Combining plots with GridSpec**

```python
x = iris['sepal-length']
y = iris['petal-length']
# Set up the axes with gridspec
fig = plt.figure(figsize=(6, 6)) # Specifies a 6x6 grid to divide
grid = plt.GridSpec(4, 4, hspace=0.3, wspace=0.3)
# Main plot though the 5th row (:-1) and from after col 1 (1:)
# Histograms share the x or y axis as appropriate
main_ax = fig.add_subplot(grid[:-1, 1:])
y_hist = fig.add_subplot(grid[:-1, 0], xticklabels=[], sharey=main_ax)
x_hist = fig.add_subplot(grid[-1, 1:], yticklabels=[], sharex=main_ax)
# scatter points on the main axes
main_ax.scatter(x, y, alpha=0.4)
# histogram on the attached axes
x_hist.hist(x, 40, histtype='stepfilled', orientation='vertical')
x_hist.invert_yaxis()
x_hist.set_xlabel("Sepal Length")
y_hist.hist(y, 40, histtype='stepfilled', orientation='horizontal')
y_hist.invert_xaxis()
y_hist.set_ylabel("Petal Length")
fig.suptitle("Combined Histogram and Scatterplot of Sepal/Petal Length")
```
