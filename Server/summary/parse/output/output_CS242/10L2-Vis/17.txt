**plt.subplots**

`plt.subplots(nrows=1, ncols=1, sharex=False, sharey=False, ...)`

*   `nrows`, `ncols` define a grid of subplots and axes
*   `sharex`, `sharey` will use the same x and y limits on the axes
*   Returns the figure and a list of the axes (or single axes in the 1x1 case)
