**Why plotly?**

Plotly makes interactive, publication-quality graphs online created using Python and the Django framework
It is compatible with a number of languages/ tools: R, Python, MATLAB, Perl, Julia, Arduino


**(Figure Description):**

A box plot with a smoothed fit line is displayed.  The x-axis represents months (Jan to Nov), and the y-axis represents "Thunderstorms" (a count or measurement).  The box plot shows the distribution of thunderstorm counts for each month.  Each box represents the interquartile range (IQR) of the data for that month, with the line inside the box indicating the median.  The whiskers extend to the minimum and maximum values within 1.5 times the IQR from the box.  Points outside the whiskers are considered outliers and are plotted individually.  A smoothed fit line is overlaid on the box plots, showing a general trend in the data over time.  The line is colored blue, and the shaded area around the line represents the confidence interval.  Numerical values are displayed on the smoothed fit line, indicating the predicted thunderstorm count for each month.  The figure is positioned centrally on the slide.  The title "Box plot with Smoothed Fit" is above the plot.
