**Bar plots**

```python
means = {}
for cat in list(data.category.unique()):
    means[cat] = float(data[data.category==cat][['sepal-width']].mean())
plt.bar(means.keys(), means.values())
```

*   **`means = {}`**: Initializes an empty dictionary to store the average sepal width for each category.
*   **`for cat in list(data.category.unique()):`**: Iterates through each unique category in the 'category' column of the dataset.
*   **`means[cat] = float(data[data.category==cat][['sepal-width']].mean())`**: Calculates the mean sepal width for the current category and stores it in the `means` dictionary.  Crucially, it extracts only the 'sepal-width' column for the calculation.
*   **`plt.bar(means.keys(), means.values())`**: Creates a bar plot using Matplotlib.  The x-axis represents the categories (Iris-setosa, Iris-versicolor, Iris-virginica), and the y-axis represents the average sepal width for each category.
