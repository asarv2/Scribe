**Example: scatterplot**

```python
from plotnine import *
from plotnine.data import *
# basic scatterplot
ggplot(data=iris) +\
geom_point(mapping=aes(y = 'petal-length', x = 'sepal-length'))
# new aesthetic:
# map color to class label
ggplot(data=iris) +\
geom_point(mapping=aes(y = 'petal-length', x = 'sepal-length', color = 'category'))
# new geom: add fitted line
ggplot(data=iris, mapping=aes(y = "petal-length", x = "sepal-length")) +\
geom_point() +\
geom_smooth(span=.3, se=True)
```

**(Figure Description):**

The slide displays three scatter plots, arranged vertically.

* **Top Scatter Plot:** This scatter plot shows the relationship between "sepal-length" and "petal-length" for the Iris dataset.  The x-axis represents "sepal-length," ranging from approximately 4 to 8. The y-axis represents "petal-length," ranging from approximately 1 to 7.  Each point represents a data sample from the Iris dataset.  The points are plotted without any color differentiation.  The plot is positioned in the upper portion of the slide.

* **Middle Scatter Plot:** This scatter plot is identical to the top plot, but with a crucial difference: each point is colored according to the "category" (Iris species).  The x-axis and y-axis ranges are the same as the top plot.  The plot is positioned in the middle portion of the slide.  The color-coding allows for a visual comparison of the relationship between sepal length and petal length for each iris species.

* **Bottom Scatter Plot:** This scatter plot also shows the relationship between "sepal-length" and "petal-length" but includes a smoothed line.  The x-axis and y-axis ranges are the same as the previous plots.  A smooth curve is overlaid on the scatter plot, representing a fitted line that approximates the relationship between the two variables.  The plot is positioned in the lower portion of the slide.  The addition of the fitted line provides a visual representation of the trend in the data.
