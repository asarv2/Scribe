**Example: Boxplot**

```R
install.packages("plotly")
library("plotly")
Sys.setenv("plotly_username"="your_username")
Sys.setenv("plotly_api_key"="your_api_key")
# basic boxplot
p <- plot_ly(d, x = ~V5, y=~V3, color = ~V5, type = "box")
p
# send to plotly 
api_create(p, filename = "CS242box")
# https://plot.ly/~bgstm/1/
```

**(Figure Description):**

A box plot is displayed, showing the distribution of a variable (likely V3) across different categories (likely represented by V5).  The x-axis represents the categories, and the y-axis represents the values of the variable.  The box plot for each category visually displays the following information:

* **Box:** The box spans the interquartile range (IQR), representing the middle 50% of the data.

* **Line within the box:** The line inside the box represents the median value.

* **Whiskers:** The lines extending from the box are called whiskers.  They extend to the minimum and maximum values within 1.5 times the IQR from the box.

* **Points beyond whiskers:** Points outside the whiskers are considered outliers and are plotted individually.
