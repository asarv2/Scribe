**Using Figures, Subplots, and Axes**

Figures are the top-level containers for visualizations

*   If you are not using Jupyter notebooks you must call `plt.figure()`.
*   If you are plotting multiple graphics from one cell, you may also call `plt.figure()`.

Subplots create a grid of one or more independent graphics within a single figure

Axes hold parameters of a subplot to define each graphic.
