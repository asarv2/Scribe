**Example Histogram**

```python
plt.hist(data['sepal-width'], bins=10, rwidth=0.9, density=True)
plt.title("Histogram of Sepal Width")
plt.xlabel("Sepal Width")
```

*   **bins:** number of bins to use, default is equally spaced breaks
*   **rwidth:** relative width of the bars; by default, they leave no whitespace
*   **density:** if True, y axis will reflect probability instead of frequency counts.
