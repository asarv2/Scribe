# Anscombe's Quartet

Four datasets with identical summary statistics (mean, standard deviation, correlation, etc.) but very different visual representations.  This demonstrates the importance of visualizing data before drawing conclusions.

* **Set 1:**  A roughly linear relationship.
* **Set 2:**  A curved relationship.
* **Set 3:**  An outlier.
* **Set 4:**  A strong linear relationship with an outlier.

**Visualizations:**

The slide displays four scatter plots, each representing a different dataset (Set 1, Set 2, Set 3, and Set 4).  Each plot shows the relationship between two variables (x and y) using points.

* **Set 1:**  Scatter plot showing a moderately strong positive linear relationship.  The points are roughly clustered around a line.
* **Set 2:**  Scatter plot showing a strong curved relationship.  The points form a roughly parabolic shape.
* **Set 3:**  Scatter plot showing a strong positive linear relationship with one outlier.  The points are clustered around a line, but one point is significantly far from the others.
* **Set 4:**  Scatter plot showing a strong positive linear relationship.  The points are clustered around a line, but one point is significantly far from the others.

**Table Data:**

Below the scatter plots, a table is presented for each dataset.  The table shows the x and y values for each data point in the dataset.  The table is organized in a way that each dataset is aligned with its corresponding scatter plot.

**Purpose:**

The purpose of this slide is to illustrate the importance of data visualization.  Anscombe's Quartet demonstrates that summary statistics alone can be misleading.  Visualizing the data is crucial for understanding the underlying patterns and relationships within the data.  The slide highlights the potential for outliers and non-linear relationships to significantly affect the interpretation of data.
