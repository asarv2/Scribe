**Density Plots**

Density function estimates a continuous function
* Using a kernel function to estimate density at each point x
* Pooling information from neighboring points
Estimated density is:
*  $\hat{f}(x) = \frac{1}{n} \sum_{i=1}^n K\left(\frac{x - x^{(i)}}{h}\right)$

Two parameters:
* Kernel function K, bandwidth h
