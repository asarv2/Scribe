# Slide 17

**PCA: High level approach**

Given data matrix X with p dimensions (attributes)

* Mean center each column of X (i.e. subtract from each attribute value the mean of that attribute)
* Compute the p x p covariance matrix: Σ = X<sup>T</sup>X
* Find eigenvectors and eigenvalues of the symmetric covariance matrix Σ
The eigenvectors correspond to the principle components of X
* Select the m eigenvectors with largest eigenvalues to reduce dimensionality


---

**Description:**

This slide, part of a lecture on Principal Component Analysis (PCA) in an Intro to Data Science course, outlines the high-level steps involved in performing PCA.  The title, "PCA: High level approach," clearly indicates the topic.  The bullet points detail the procedure:

1. **Mean centering:**  The data matrix X's columns are centered by subtracting the mean of each attribute from all values in that column. This is a crucial preprocessing step in PCA to ensure that the principal components are not biased by the means of the attributes.

2. **Covariance matrix computation:** The covariance matrix Σ is calculated using the formula Σ = X<sup>T</sup>X.  This matrix quantifies the relationships between the attributes.

3. **Eigenvalue decomposition:** The eigenvectors and eigenvalues of the symmetric covariance matrix Σ are found.  Eigenvectors represent the principal components, and eigenvalues represent the variance explained by each component.

4. **Dimensionality reduction:** The m eigenvectors corresponding to the largest eigenvalues are selected.  This step reduces the dimensionality of the data by projecting it onto the principal components that capture the most variance.

The slide is straightforward and provides a concise overview of the PCA algorithm.  There are no figures on this slide.  The context of the slide is to provide a high-level overview of the PCA algorithm, likely leading into a more detailed explanation of each step in the next slides.


# Slide 18

**Applying PCA**

New data vectors are formed by projecting the data onto the first few principal components (i.e., top m eigenvectors)

x = [x<sub>1</sub>, x<sub>2</sub>, ..., x<sub>p</sub>] (original instance)

A = [a<sub>1</sub>, a<sub>2</sub>, ..., a<sub>p</sub>] (principal components)

x′<sub>1</sub> = a<sub>1</sub>x = Σ<sup>p</sup><sub>j=1</sub> a<sub>1j</sub>x<sub>j</sub>

...

x′<sub>m</sub> = a<sub>m</sub>x = Σ<sup>p</sup><sub>j=1</sub> a<sub>mj</sub>x<sub>j</sub> for m ≤ p

x′ = [x′<sub>1</sub>, x′<sub>2</sub>, ..., x′<sub>m</sub>] (transformed instance)

If m = p then data is transformed

If m < p then transformation is lossy and dimensionality is reduced

```
|R|
∑
(u,i)∈R
(r<sub>ui</sub> − r̂<sub>ui</sub>)<sup>2</sup>
```

Does not correlate with user satisfaction, but it is widely understood and easy to evaluate

**Description:**

This slide describes the scoring metric used in the Netflix Prize competition.  The formula shown, `1/|R| * Σ_{(u,i)∈R} (r<sub>ui</sub> − r̂<sub>ui</sub>)<sup>2</sup>`, calculates the root mean square error (RMSE).  It's a common metric for evaluating the accuracy of predictions, in this case, movie recommendations.  The formula sums the squared differences between the actual ratings (`r<sub>ui</sub>`) and the predicted ratings (`r̂<sub>ui</sub>`) for all user-movie pairs (`(u,i)`) in the dataset (`R`).  The result is then divided by the total number of ratings (`|R|`) to get the average error.  The slide emphasizes that while this metric is widely used and easy to calculate, it doesn't directly reflect user satisfaction with the recommendations.
