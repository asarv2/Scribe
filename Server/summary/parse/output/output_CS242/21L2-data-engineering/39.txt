# Slide 39

**Inverted Index as MapReduce**

**Input:** (filename, text) records

**Output:** list of files containing each word

**Map:**

```
foreach word in text.split():
    output(word, filename)
```

**Combine:** output unique filenames for each word

**Reduce:**

```
def reduce(word, filenames):
    output(word, sort(filenames))
```

**Description:**

This slide describes how to implement an inverted index using the MapReduce paradigm.  It outlines the input, output, map, combine, and reduce steps.

* **Input:** The input data consists of records containing a filename and the text content of that file.
* **Output:** The desired output is a list of files that contain each word.  This is an inverted index, where each word is associated with a list of files in which it appears.
* **Map:** The `Map` function iterates through the words in the text of each file. For each word, it outputs a key-value pair: (word, filename).  This step essentially creates the initial key-value pairs for the MapReduce process.
* **Combine:** The `Combine` step is a crucial optimization.  It's not explicitly part of the standard MapReduce model but is often used to reduce the amount of data shuffled between the mapper and reducer.  In this case, it would group the filenames associated with each word, eliminating duplicate filenames.
* **Reduce:** The `Reduce` function takes a word and a list of filenames as input.  It outputs the word along with a sorted list of filenames.  This step aggregates the results from the `Map` and `Combine` steps, producing the final inverted index entry for each word.

**Overall:** The slide provides a clear description of the MapReduce implementation for creating an inverted index.  The steps are well-defined, and the pseudocode for the `Map` and `Reduce` functions is provided, making it easy to understand the logic of the process.  The `Combine` step is mentioned as an optimization, but not fully detailed.
