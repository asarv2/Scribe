# Slide 46

**Hadoop distributed file system**

Files split into 128MB blocks
Blocks replicated across datanodes (often 3)
Namenode stores metadata
(e.g. file names, locations, etc)
Optimized for large files, sequential reads
Files are append-only

**Visual Representation:**

The slide contains a diagram illustrating the Hadoop Distributed File System (HDFS).  A central box labeled "Namenode" is positioned at the top of the slide, slightly left of center.  From the Namenode, several dashed lines extend downward to five rectangular boxes labeled "Datanodes."  These Datanodes are arranged horizontally, slightly below and to the right of the Namenode.

* **Namenode:** The Namenode box is a gray, rectangular server icon.  It represents the central server that manages the metadata of the file system.  The metadata includes file names, locations of data blocks, and other important information.

* **Datanodes:** The Datanodes are also gray, rectangular server icons.  They represent the storage nodes in the Hadoop cluster.  Each Datanode is connected to the Namenode by a dashed line, indicating a communication link.  Each Datanode has a small, light green box inside it.  These boxes contain numbers (e.g., 1, 2, 3, 4).  These numbers likely represent the block numbers of the file that are stored on that particular Datanode.  The numbers are repeated across multiple Datanodes, indicating that the blocks of a file are replicated across multiple servers for fault tolerance.  A light gray cloud-like shape is above the Namenode, with the word "File1" and numbers (1, 2, 3, 4) inside.  This cloud represents the file being stored, and the numbers inside indicate the blocks of the file.

* **Purpose:** The diagram visually represents the distributed nature of HDFS.  The Namenode acts as the central authority, while the Datanodes store the actual data.  The replication of data across multiple Datanodes is crucial for fault tolerance and high availability.  The numbers within the Datanodes and the cloud above the Namenode visually represent the file blocks and their replication.  The overall structure of the diagram is designed to illustrate the architecture of HDFS, showing the relationship between the Namenode and the Datanodes.
