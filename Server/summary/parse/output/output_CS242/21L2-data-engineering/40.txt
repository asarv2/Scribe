# Slide 40

**Matrix multiplication**

How to compute matrix multiplication P = MN via mapreduce?

```
P[i, k] = Σ M[i, j] • N[j, k]
j=1
```

**Description:**

This slide introduces the problem of matrix multiplication using the MapReduce paradigm.  It shows how to compute the product of two matrices (M and N) to produce a resulting matrix (P).  The slide visually represents the matrices M, N, and P, highlighting their dimensions (i x j, j x k, and i x k, respectively).  The equation `P[i, k] = Σ M[i, j] • N[j, k]` is shown, which defines the mathematical operation for calculating an element in the resulting matrix P.  The visual representation of the matrices is crucial for understanding the dimensions and the relationship between the elements of the matrices involved in the matrix multiplication.  The slide is designed to introduce the problem and the mathematical formula for matrix multiplication, preparing the audience for the MapReduce implementation of this operation.
