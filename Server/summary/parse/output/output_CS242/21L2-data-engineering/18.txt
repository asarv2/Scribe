# Example: How to count words in a textfile

```
lines = ["the wheels on the bus",
         "go round and round",
         "round and round",
         "round and round",
         "the wheels on the bus",
         "go round and round",
         "all through the town"]
def mapper_word(line):
    return [(word, 1) for word in line.split(" ")]
mapper_word(lines[0])
[('the', 1), ('wheels', 1), ('on', 1), ('the', 1), ('bus', 1)]
map(mapper_word,lines)  # apply to all lines
```

**Description of the slide:**

This slide provides Python code demonstrating a MapReduce-like word-counting operation.

* **Code:** The slide presents a Python code snippet.  It defines a list of strings (`lines`) containing a simple text.  A function `mapper_word` is defined to take a line of text and return a list of tuples. Each tuple contains a word (string) and the integer 1.  The `mapper_word` function splits each line into words using spaces as delimiters.  The code then applies the `mapper_word` function to the first element of the `lines` list, demonstrating the output of the mapper function for a single line. Finally, the code shows how to apply the `mapper_word` function to the entire `lines` list using the `map` function.

* **Purpose:** The slide illustrates how a mapper function in a MapReduce framework would process a line of text, extracting words and assigning a count of 1 to each.  The example is designed to be simple and easy to understand, showing the basic concept of transforming input text into key-value pairs.
