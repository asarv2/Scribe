# Slide 38

**Search in MapReduce**

**Input:** (lineNumber, line) records

**Output:** lines matching a given pattern

**Map:**

if (line matches pattern):
  output(line)

**Reduce:** identity function

**Alternative:** no reducer (map-only job)


**Description:**

This slide describes a MapReduce application for searching for lines in a dataset that match a specific pattern.  The input is a set of records, each containing a line number and the line itself.  The output is intended to be the lines that match a predefined pattern.  The `Map` function filters the input, emitting only the lines that match the pattern.  The `Reduce` function is an identity function, meaning it simply passes the output from the `Map` function through unchanged.  An alternative approach is a "map-only job," which skips the `Reduce` step entirely, making it suitable for scenarios where only the matching lines are needed and no further aggregation is required.  The slide is entirely text-based, focusing on the description of the MapReduce process for a search operation.
