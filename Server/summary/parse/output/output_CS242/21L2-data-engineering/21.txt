# Slide 21

# Example: How to count words in a textfile

```
the wheels on the bus
go round and round
round and round
round and round
the wheels on the bus
go round and round
all through the town
```

```
mapper()
[('the', 1), ('wheels', 1), ('on', 1), ('the', 1), ('bus', 1)]
[('go', 1), ('round', 1), ('and', 1), ('round', 1)]
[('round', 1), ('and', 1), ('round', 1)]
[('round', 1), ('and', 1), ('round', 1)]
[('the', 1), ('wheels', 1), ('on', 1), ('the', 1), ('bus', 1)]
[('go', 1), ('round', 1), ('and', 1), ('round', 1)]
[('all', 1), ('through', 1), ('the', 1), ('town', 1)]
```

```
group by key
(and, [1, 1, 1, 1])
(on, [1, 1])
(all, [1])
(bus, [1, 1])
(town, [1])
(round, [1, 1, 1, 1, 1, 1, 1, 1])
(through, [1])
(go, [1, 1])
(the, [1, 1, 1, 1, 1])
(wheels, [1, 1])
```

```
reducer()
Key: ?
Output: ?
```

**Description of the slide:**

This slide continues the example of using MapReduce to count words in a text file.  It shows the input text (a children's rhyme), the output of the mapper function (a list of key-value pairs), and the intermediate step of grouping those pairs by key.  The output of the mapper function is a list of lists, where each inner list represents the words and their counts from a single line of the input text.  The next step, "group by key," shows the intermediate result of grouping these words together.  The final part of the slide shows the `reducer()` function, which is not yet implemented, and asks for the key and output.

**Visuals:**

The slide uses a clear layout to present the example.  The input text is presented first, followed by the mapper output, and then the grouping by key.  The formatting of the key-value pairs (e.g., `(and, [1, 1, 1, 1])`) clearly shows the grouping of values associated with each unique key.  The final section, `reducer()`, is a placeholder, indicating that the next step in the MapReduce process is to combine the grouped values.  The question marks for "Key: ?" and "Output: ?" emphasize that the reducer function is not yet defined, and the final output is not yet known.  The overall structure of the slide is designed to illustrate the intermediate steps of the MapReduce process, specifically the grouping of data by key.
