# Slide 11

# Example

Given a large text file that contains data about credit card transactions
* Each line of the file contains a credit card number and an amount of money
* Determine the sum of all charges for each unique credit card number

# Approaches

* Could use hash table but memory is a problem for large files
* Counting is simple if file is sorted by card number
In this case, sorting and placement are crucial
* Similar with distributed approaches
