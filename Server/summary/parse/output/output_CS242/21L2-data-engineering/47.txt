# Slide 47

```
Python Generators
Amazon's Elastic MapReduce allows you to easily run the MapReduce algorithm on an AWS cluster.
• Web interface and command-line tools for running Hadoop jobs on Amazon compute cloud (EC2)
• Data stored in Amazon simple storage service (S3)
• Monitors job and shuts machines after use
The Python package mrjob further simplifies this process. To understand how mrjob works, you will
need to know how to use generators and iterators in Python.
• An iterator object is any object that can be iterated through in a linear fashion.
• A generator is another name for an iterator that was created similar to how we define functions,
inserting the yield keyword.
```

* **Resource Management:** The service monitors jobs and automatically shuts down machines after use, which is important for resource management and cost optimization.
* **Python Package `mrjob`:** The slide introduces the `mrjob` Python package, which simplifies the process of running MapReduce jobs in Python.
* **Iterators and Generators:** The slide explains that understanding iterators and generators is crucial for using `mrjob`.  An iterator is an object that can be iterated through linearly, and a generator is a type of iterator defined similarly to functions but using the `yield` keyword.  This is a key concept in Python for handling potentially large datasets efficiently.
