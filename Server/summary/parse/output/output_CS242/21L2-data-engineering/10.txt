# MapReduce

Programming model for data-intensive computing on commodity clusters
A simple paradigm for distributed computation where users write just two functions:

* **mapper:** An applied function to generate intermediate data
* **reducer:** A function that combines and simplifies the intermediate date appropriately

Work can be automatically farmed out to a large collection of machines
* As much as possible, computation is done on the machine where the data lives
* Node failures or "stragglers" (nodes that are slow for any reason) are automatically handled
