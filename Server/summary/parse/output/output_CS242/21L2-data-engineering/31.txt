# Slide 31

**Python: Map and Reduce Functions**

We can get some intuition on MapReduce by examining the map and reduce functions in Python (note: MapReduce ≠ map + reduce)

The map method takes a function and a list (iterable) and applies the function to each element:
map(f, [a, b, c, ...]) -> [f(a), f(b), f(c), ...]

The reduce method takes a function and a list (iterable) and iteratively applies the function to two elements (next item in the list and result of previous function)
reduce(g, [a, b, c, ...]) -> g(g(g(a,b),c), ...)
