# Slide 22

```
Mapreduce in python
def reducer_sum(key, val):
  return (key, sum(val))
testkey = 'round'
testvals = [1, 1, 1, 1, 1, 1, 1, 1]
reducer_sum(testkey, testvals)
('round', 8)
```

**Description:**

This slide presents Python code demonstrating a reducer function within a MapReduce framework.  The code defines a function `reducer_sum` that takes a key and a list of values.  The function calculates the sum of the values and returns a tuple containing the key and the sum.  The example then shows how to call the `reducer_sum` function with a sample key ('round') and a list of values ([1, 1, 1, 1, 1, 1, 1, 1]). The output of the function call is the tuple ('round', 8).  This demonstrates how the reducer function aggregates values associated with a specific key.  The code is in the context of a larger MapReduce example, where the `mapper` function would have previously produced the key-value pairs, and the `reducer` function would then combine them.  The code is presented in a way that is easy to understand and follow, highlighting the core logic of the reducer function.
