# Slide 8

# New data processing paradigm

When Google was building their first data centers
* Used clusters of off-the-shelf commodity hardware
* Machines had different speeds and failures were common given cluster sizes
Data itself was distributed (redundantly) over many machines
* faster to do computation on the machine where the data is stored
Led to the development of the MapReduce framework at Google
* Google processes 20 PB of data per day
Later made popular through the Apache Hadoop open source implementation
* Used by Yahoo!, Facebook, Amazon, ...

**Description of the slide:**

This slide discusses the evolution of data processing, focusing on the paradigm shift that occurred when Google developed the MapReduce framework.  The slide is a bulleted list, explaining how Google's approach to data centers and processing differed from previous methods.

* **Context:** The slide builds upon the previous discussion of big data and the challenges of processing large volumes of data.  It explains how the distributed nature of data and the use of commodity hardware led to the development of MapReduce, a key technology in big data processing.
* **Content:** The slide highlights the following key points:
    * **Commodity Hardware:** Google used clusters of readily available, inexpensive hardware (off-the-shelf commodity hardware).
    * **Variable Machine Speeds:** The machines in these clusters had varying processing speeds, and failures were common.
    * **Distributed Data:**  Data was distributed across multiple machines, which allowed for faster computation.
    * **MapReduce Framework:** This distributed processing approach led to the development of the MapReduce framework at Google.
    * **Large Data Volumes:** Google processes massive amounts of data (20 PB per day).
    * **Open Source Implementation:** The MapReduce framework was later popularized through the Apache Hadoop open-source implementation.
    * **Wide Adoption:** The technology is used by major companies like Yahoo!, Facebook, and Amazon.

* **Visuals:** There are no figures or images on this slide.  The content is entirely text-based, focusing on the description of the new data processing paradigm.
