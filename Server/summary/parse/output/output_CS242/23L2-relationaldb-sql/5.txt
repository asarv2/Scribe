# Anatomy of Relational Database

Database: A database consists of a set of named relations (aka tables)

Relation
* A set of tuples (aka rows, record) with identical column structure
* Each column is an attribute (names must be distinct)
* Values in each column are of uniform "type" drawn from some set (domain) such as integer, text, date, etc


---

**Description of the Slide:**

This slide, part of a lecture on Introduction to Data Science, defines the structure of a relation within a relational database.  The title "Anatomy of Relational Database" is displayed at the top, introducing the topic of the slide.  The content below defines a database as a collection of named relations (tables).  The key components of a relation are then described:

* **Relation:** A set of tuples (rows/records) with consistent column structures.
* **Columns:** Each column represents an attribute (a characteristic of the data) with unique names.
* **Data Types:** Values within each column are of a uniform data type (e.g., integer, text, date) drawn from a specific set called a domain.

This slide provides a foundational understanding of the relational database model, building upon the previous slide's introduction to relations as tables.  The slide's structure is clear and concise, using bullet points to highlight the key concepts.  There are no figures on this slide.
