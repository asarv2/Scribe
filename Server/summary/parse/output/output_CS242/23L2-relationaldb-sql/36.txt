# Left join in SQLite/Pandas

Pandas way
```python
df_person.merge(df_grades, how="left", left_on="id", right_on="person_id")
```

SQLite way
```sql
cursor.execute("SELECT * FROM person LEFT JOIN grades ON person.id = grades.person_id")
```
