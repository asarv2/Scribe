# Entity Relationships

There are several types of inter-table relationships:

* One-to-one (or one-to-zero/one)
* One-to-many (and many-to-one)
* Many-to-many

These relate one (or more) rows in a table with one (or more) rows in another table, via a foreign key

Note that these relationships are really between the "entities" that the tables represent
