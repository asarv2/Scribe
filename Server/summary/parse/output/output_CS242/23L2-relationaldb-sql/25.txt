# Querying Data From a Table

Read all the rows from a table:
```python
for row in cursor.execute('SELECT * FROM role'):
    print(row)
```

(1, 'Instructor')
(2, 'TA')
(3, 'Student')

Read table directly into a Pandas DataFrame:
```python
data = pd.read_sql_query("SELECT * FROM role", conn, index_col="id")
```

**Description of the Slide:**

This slide demonstrates how to query data from a table (specifically the `role` table) using Python and the `sqlite3` library.  The first code block shows a `for` loop iterating through the results of an SQL query (`SELECT * FROM role`).  The output of this query is printed to the console, showing the `id` and `name` values for each row in the `role` table.  The second code block shows how to read the data directly into a Pandas DataFrame using `pd.read_sql_query()`.  The `index_col="id"` argument specifies that the `id` column should be used as the index of the DataFrame.  The resulting DataFrame is displayed as a table, showing the `id` and `name` columns.  The table is formatted with clear column headers and data entries, making the data easily readable.  The purpose of this slide is to illustrate how to query data from a database table and load it into a Pandas DataFrame for further analysis in a data science context.
