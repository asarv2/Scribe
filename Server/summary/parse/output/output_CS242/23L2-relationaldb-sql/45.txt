```markdown
# Aggregation

Calculate summary values on your selection with aggregate functions: SUM, COUNT, MIN, MAX, AVG

SELECT AVG(Total)
FROM Invoice
WHERE BillingCountry = 'USA'

AVG(Total)
5.747912

Count is the only aggregation that doesn't need a single attribute specified

SELECT COUNT(*)
FROM Invoice
WHERE Total > 10

COUNT(*)
64
```
