# General Query with Grouping and Aggregation

```
SELECT s
FROM r1, ..., rN
WHERE c1
GROUP BY a1, ..., aK
HAVING c2
```

*   `s` can ONLY contain attributes `a1`, ..., `aK` and/or aggregates
*   `c1` is any condition on the attributes in `r1`, ..., `rN`
*   `c2` is any condition on the aggregate expressions

**Description:**

This slide presents a general form of an SQL query that includes grouping and aggregation.  The slide shows the structure of the query, including the `SELECT`, `FROM`, `WHERE`, `GROUP BY`, and `HAVING` clauses.  The `SELECT` clause (`s`) can only contain attributes (`a1`, ..., `aK`) from the tables (`r1`, ..., `rN`) or aggregate functions.  The `WHERE` clause (`c1`) filters the data before grouping.  The `GROUP BY` clause (`a1`, ..., `aK`) groups the data based on specified attributes.  The `HAVING` clause (`c2`) filters the grouped data based on aggregate expressions.
