# Inner join in SQLite/Pandas

Pandas way
```python
df_person = pd.read_sql_query("SELECT * FROM person", conn)
df_grades = pd.read_sql_query("SELECT * FROM grades", conn)
df_person.merge(df_grades, how="inner", left_on="id", right_on="person_id")
```

SQLite way
```sql
cursor.execute("SELECT * FROM person, grades WHERE person.id = grades.person_id")
```
OR
```sql
cursor.execute("SELECT * FROM person INNER JOIN grades ON person.id = grades.person_id")
```
