# Slide 48

Aggregation and Grouping
Aggregation and Grouping works such that
* First, the FROM and WHERE clauses gather the data
* Second, the GROUP BY attributes are grouped
* Third the SELECT clause selects the specified attributes and aggregates
Note: a WHERE clause cannot contain an expression on the aggregate values

**Description:**

This slide provides a summary of how aggregation and grouping work in SQL queries.  It describes the sequence of operations: first, data is filtered using the `FROM` and `WHERE` clauses; second, the `GROUP BY` clause groups the data based on specified attributes; and third, the `SELECT` clause selects the desired attributes and applies aggregate functions (like `SUM`, `COUNT`, `AVG`).  The note at the end clarifies that a `WHERE` clause cannot directly use aggregate functions in its filtering condition.  The slide is purely textual, with no figures.
