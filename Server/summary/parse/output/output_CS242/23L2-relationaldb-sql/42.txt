# Ordering Results

```
SELECT CustomerId, Total
FROM Invoice
WHERE BillingCountry = "USA"
ORDER BY Total DESC, InvoiceDate
LIMIT 5
```

This SQL query selects the `CustomerId` and `Total` columns from the `Invoice` table, filtering for invoices where the `BillingCountry` is "USA".  The results are then ordered in descending order based on the `Total` amount, and then ascending order based on the `InvoiceDate`.  Finally, only the top 5 results are returned.  The output shows a table with `CustomerId` and `Total` columns, presenting the top 5 customers in terms of total spending in the USA, ordered by total spending (highest first) and then by invoice date (oldest first).  The "..." indicates that there are more rows in the full result set that are not shown.
