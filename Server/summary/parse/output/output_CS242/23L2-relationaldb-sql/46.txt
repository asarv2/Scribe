# Aggregation

Count will count all records, including duplicates, unless you specify it

```sql
SELECT COUNT(BillingCountry)
FROM Invoice
WHERE Total > 10
```

```
COUNT(BillingCountry)
64
```

In this example, we probably want

```sql
SELECT COUNT(DISTINCT BillingCountry)
FROM Invoice
WHERE Total > 10
```

```
COUNT(DISTINCT BillingCountry)
24
```
