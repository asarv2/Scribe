# Distinct: Eliminating Duplicates

You may want to get all the countries to which you invoice

```sql
SELECT BillingCountry
FROM Invoice
```

However, you probably want unique elements

```sql
SELECT DISTINCT BillingCountry
FROM Invoice
```

```
BillingCountry
0	Germany
1	Norway
2	Belgium
3	Canada
4	USA
...
411	India
```
