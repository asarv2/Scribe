```markdown
# Creating a Database and Table

You can create a database and connect using this boilerplate code:
import sqlite3
conn = sqlite3.connect("people.db")
cursor = conn.cursor()
# do your stuff
conn.close()
Create a new table:
cursor.execute("""
CREATE TABLE role (
    id INTEGER PRIMARY KEY,
    name TEXT
)""")
```
