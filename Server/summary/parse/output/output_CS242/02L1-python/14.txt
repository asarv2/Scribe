# Slide 14

**Basic datatypes**

Integers (default for numbers)
z = 5 / 2  # Python 2 uses integer division, Python 3 does not
Floats
x = 3.456
Strings
"abc"       # Can use "" or '' to specify strings
'abc'
"matt's"    # Unmatched quotes can appear within the string
"""a'b"c""" # Use triple double quotes to specify multiline strings,
            # or combinations of ' and " inside a string
