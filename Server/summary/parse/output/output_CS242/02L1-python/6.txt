# Why Python?

Interpreted language
Dynamically typed: variables do not have a predefined type
Rich, built-in collection types:
* Lists, Tuples, Dictionaries (i.e., maps), Sets
Concise but unobtrusive object system
* Every value is an object
* Classes guide but do not dominate object construction

Slides adapted from UPenn CIS530 python tutorial
