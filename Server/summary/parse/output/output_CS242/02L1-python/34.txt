**for Loops and Dictionaries**

```
>>> ages = { "Sam" :4, "Mary" :3, "Bill" :2 }
>>> ages
{'Bill': 2, 'Mary': 3, 'Sam': 4}
>>> for name in ages.keys():
	 print(name, ages[name])
Bill 2
Mary 3
Sam 4
>>>
```

**Description:**

This slide demonstrates how to iterate through a dictionary using a `for` loop.  The code defines a dictionary `ages` containing names as keys and ages as values.  The `for` loop iterates over the keys of the dictionary using `ages.keys()`.  Inside the loop, `ages[name]` accesses the value associated with each key, and the code prints the key-value pair.  The output shows the names and corresponding ages printed in a formatted way.  The `>>>` symbols indicate interactive Python code execution.
