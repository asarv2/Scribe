# Slide 27

**Creating and accessing dictionaries**

```
>>> d = {'user':'bozo', 'pswd':1234}
>>> d['user']
'bozo'
>>> d['pswd']
1234
>>> d['bozo']
KeyError: bozo
>>> d['user'] = 'clown'
>>> d
{'user':'clown', 'pswd':1234}
Keys must be unique. Assigning to an existing key replaces its value.
>>> d['id'] = 45
>>> d
{'user':'clown', 'id':45, 'pswd':1234}
Dictionaries are unordered; New entry might appear anywhere in the output. (Dictionaries work by hashing)
```

**Description:**

This slide demonstrates how to create and access elements in Python dictionaries.  The examples show how to define a dictionary `d` with key-value pairs.  The code then demonstrates how to access values using their corresponding keys (`d['user']`, `d['pswd']`).  It also shows a `KeyError` when trying to access a non-existent key (`d['bozo']`).  The slide further illustrates updating a value associated with an existing key (`d['user'] = 'clown'`) and adding a new key-value pair (`d['id'] = 45`).  The output shows the updated dictionary after each operation.  The final line notes that dictionaries are unordered and that the order of entries in the output might vary.  The `>>>` symbols indicate interactive Python code execution.  The slide is part of a larger set of lecture notes on Python programming, likely within the context of an Intro to Data Science course.  The examples are presented in a clear, concise manner, providing a basic understanding of dictionaries in Python.
