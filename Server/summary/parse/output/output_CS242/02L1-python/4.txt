# Anaconda

Download Anaconda: https://www.anaconda.com/download/
Install by following the instructions on the download page.
Run Anaconda Navigator
Install Jupyter Notebook by clicking “Launch Jupyter Notebook” from anaconda GUI.
To run the notebook, start the notebook server from the command line:
jupyter notebook
You should see the notebook open in your browser
