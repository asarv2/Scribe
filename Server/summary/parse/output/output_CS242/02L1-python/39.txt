**Functions are first-class objects**

Functions can be used as any other data type. They can be:

* Arguments to functions
* Return values of functions
* Assigned to variables
* Parts of tuples, lists, etc

```python
>>> def myfun(x):
        return x * 3
>>> def applier(q, x):
        return q(x)
>>> applier(myfun, 7)
21
```

**Description:**

This slide demonstrates that functions in Python are first-class objects, meaning they can be treated like any other data type.  The example shows how a function (`myfun`) can be passed as an argument to another function (`applier`).  The function `applier` takes a function `q` and a value `x` as input, and it applies the function `q` to the value `x`.  In this case, `applier(myfun, 7)` calls `myfun` with the argument 7, resulting in the output 21.  The code is presented in a way that clearly shows the function definitions and the function call, illustrating the concept of functions as first-class objects.  The `>>>` symbols indicate interactive Python code execution.
