**Example of a One Sample Test situation**

Posit a null hypothesis H₀ and an alternative hypothesis H₁ (usually just that "H₀ is not true"),
e.g.:
* H₀: Average user engagement (time spent on site) is 30s.
* H₁: With new design (B), average user time is >30s.
Collect data *x* that will be used to test hypothesis, e.g.
* Measure user times under design B (red)
* Observed average is 37.7s
* Observed variance 51.4
