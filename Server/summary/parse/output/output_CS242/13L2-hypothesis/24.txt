# Slide 24

**Hypothesis testing framework**

Set null (H₀) and alternative (H₁) hypothesis
Pick significance level (e.g., α=0.05)
Choose test: one vs two sample, one vs two sided, paired or not
Calculate test statistic and associated p value
• p-value is the probability of observing current data (or more extreme), if the null hypothesis is true
Make a decision about whether the hypothesis is supported by comparing the p value to the significance level (e.g., if p<α then reject H₀)
