# What is Clustering?

Clustering: the process of grouping a set of objects into classes of similar objects

* Objects within a cluster should be similar
* Objects from different clusters should be dissimilar

Clustering is the most common form of unsupervised learning

* Learning from unlabeled raw data
* A frequent and important task that finds many applications in data science
