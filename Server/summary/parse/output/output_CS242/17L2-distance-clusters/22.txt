# Slide 22

**The K-means Algorithm**

Input: Dataset D, number of clusters k
Output: Set of cluster representatives C, cluster membership vector m

# Initialize cluster representatives C
Randomly assign k data points from D into each cluster
Initialize C such that c<sub>i</sub> is mean of points in i<sup>th</sup> cluster

while not converged
# Data Assignment
Reassign points in D to closest cluster mean
Update m such that m<sub>i</sub> is cluster ID of the i<sup>th</sup> point in D

# Relocation of means
Update C such that c<sub>i</sub> is mean of points in i<sup>th</sup> cluster
