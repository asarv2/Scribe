# Slide 45

**Evaluation Approach: Objective**

Evaluation via Class Labels: Similarity

Based on premise that any pair of objects in the same
cluster should have the same class and vice versa

Construct the "observed" similarity matrix
* Based on cluster membership
* Entry i,j is 1 if i and j are in the same cluster, 0 otherwise

Construct the "ideal" similarity matrix
* Based on class values
* Entry i,j is 1 if i and j are in the same class, 0 otherwise

Measure correlation between these two matrices


**Description of the Figure:**

The slide presents two tables, formatted like matrices, labeled "Observed" and "Ideal."  Each table represents a similarity matrix.  The rows and columns of both matrices are labeled "Point 1," "Point 2," and "Point 3."  The entries in the tables are either 0 or 1.  A value of 1 indicates that the corresponding data points (rows and columns) are similar (e.g., in the same class or cluster), while 0 indicates they are dissimilar.

* **Observed Matrix:**  This matrix reflects the similarity based on the *observed* clustering results.  The values in this matrix are derived from the clustering algorithm's output.

* **Ideal Matrix:** This matrix reflects the *ideal* similarity based on the known class labels.  The values in this matrix are derived from the pre-existing class labels of the data points.

The purpose of these matrices is to evaluate the quality of the clustering.  A high correlation between the "Observed" and "Ideal" matrices suggests that the clustering algorithm has successfully grouped data points with similar class labels into the same clusters.  A low correlation indicates that the clustering algorithm has not accurately reflected the underlying class structure of the data.


**Description of the Slide:**

This slide describes an objective approach to evaluating clustering results by comparing the observed similarity matrix (derived from the clustering) to an ideal similarity matrix (derived from known class labels).  The method involves constructing two similarity matrices, one based on cluster membership and the other based on class values, and then measuring the correlation between them.  A high correlation indicates a good clustering, while a low correlation suggests a poor clustering.  The slide is part of a lecture on data science, specifically focusing on evaluating clustering results using known class labels.  The tables are crucial for understanding the comparison process.
