**Distance measures**

If objects have the same fixed set of numeric attributes, then the
data objects can be thought of as points in a multi-dimensional
space, where each dimension represents a distinct attribute

Euclidean distance is the most commonly used
distance measure for continuous data:

dE(x, y) = √∑<sub>i=1</sub><sup>p</sup> (x<sub>i</sub> − y<sub>i</sub>)<sup>2</sup>

Here p is the number of attributes/dimensions

Proximity: general term to indicate similarity
and dissimilarity

Distance: measure of dissimilarity
