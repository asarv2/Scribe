# Slide 14

**Basic Approach to hypothesis testing**

Basic approach: compute the probability of observing the data under the null hypothesis (this is the p-value of the statistical test)

p = p(data | H₀ is true)

Reject the null hypothesis if the p-value is below the desired significance level (alternatively, just report the p-value itself, which is the lowest significance level we could use to reject hypothesis)

Important: p-value is p = p(data | H₀ is true) not p = p(H₀ is true | data)

# Slide 21

**Hypothesis testing errors**

Posit a null hypothesis H₀ and an alternative hypothesis H₁ (usually just that “H₀ is not true”)

Given some data x:

We will reject, or fail to reject, the null hypothesis in favor of the alternative hypothesis

|       | H₀ true | H₁ true |
|-------|----------|----------|
| Accept H₀ | Correct | Type II error (false negative) |
| Reject H₀ | Type I error (false positive) | Correct |

p(reject H₀ | H₀ true) = “significance of test”
p(reject H₀ | H₁ true) = “power of test”


---

**Description of what you see:**

This slide, part of a lecture on Intro to Data Science, discusses hypothesis testing errors.  It presents a table outlining the possible outcomes of a hypothesis test, given that either the null hypothesis (H₀) or the alternative hypothesis (H₁) is true.  The table shows four possible outcomes:

* **Accept H₀ and H₀ is true:** Correct decision.
* **Accept H₀ and H₁ is true:** Type II error (false negative).
* **Reject H₀ and H₀ is true:** Type I error (false positive).
* **Reject H₀ and H₁ is true:** Correct decision.

The slide also defines the significance of a test (p(reject H₀ | H₀ true)) and the power of a test (p(reject H₀ | H₁ true)).  The table and definitions are presented in a clear and concise manner, illustrating the concepts of Type I and Type II errors in hypothesis testing.  There are no figures on this slide.




# Slide 22

**Logic of Hypothesis testing**

Effort is made to reject the null hypothesis
If H₀ is rejected, we tentatively conclude H₁ to be the case
Otherwise we fail to reject the null (we can never prove the null to be true)
Role of evidence: Null is assumed true and a contradiction is sought in order to reject it.


---

**Description of what you see:**

This slide, part of a lecture on Intro to Data Science, explains the logic behind hypothesis testing.  The text emphasizes that the goal is to *reject* the null hypothesis (H₀), rather than prove it true.  If the null hypothesis is rejected, then the alternative hypothesis (H₁) is tentatively accepted.  Crucially, the text states that failing to reject the null hypothesis does not mean the null hypothesis is proven true; it simply means there wasn't enough evidence to reject it.  The slide's focus is on the process and the role of evidence in hypothesis testing.  There are no figures on this slide.

**Hypothesis testing framework**

Set null (H₀) and alternative (H₁) hypothesis
Pick significance level (e.g., α=0.05)

**Hypothesis testing errors**

Type I error: null is rejected when it is true (generally considered to be most serious error)
* E.g., conclude cancer drug increases life expectancy when in fact it doesn't
Type II error: null is accepted when it is false
* E.g., conclude that cancer drug does not increase life expectancy when in fact it does


|       | H₀ true | H₁ true |
|-------|----------|----------|
| Accept H₀ | Correct | Type II error (false negative) |
| Reject H₀ | Type I error (false positive) | Correct |

p(reject H₀ | H₀ true) = "significance of test"
p(reject H₀ | H₁ true) = "power of test"
