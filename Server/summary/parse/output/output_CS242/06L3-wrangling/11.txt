# Slide 11

**Data Wrangling**

Loosely refers to the tasks needed to preprocess data, including:

*   Augmentation (e.g., adding features/rows)
*   Subsetting (e.g., filtering and selecting)
*   Cleaning (e.g., find missing values/errors to correct)
*   Aggregating (e.g., grouping by values and summarizing)
*   Transforming (e.g., scaling attribute values)


---

**Description of the Slide:**

This slide, titled "Data Wrangling," is a simple, introductory slide in a data science lecture.  It defines data wrangling as the tasks needed to prepare data for analysis.  The slide lists several key tasks involved in data wrangling, including augmentation (adding features or rows), subsetting (filtering and selecting), cleaning (finding and correcting missing values or errors), aggregating (grouping and summarizing), and transforming (scaling attribute values).  The slide is entirely text-based, using bullet points to list the different tasks.  The purpose of the slide is to introduce the concept of data wrangling and the various activities it encompasses.  There are no figures or images on this slide.
