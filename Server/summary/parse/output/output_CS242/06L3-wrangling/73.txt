**Merging on Index**

In some cases, your data frame's index might match a column in another data frame.  For this, we'll need to specify what to use in each.

```
df_all = pd.merge(df_student, df_gpa, left_index=True, right_index=True)
```

Three tables are shown: `df_student`, `df_gpa`, and `df_all`.

*   **`df_student`**: This table has columns for "SID", "Name", and "Email".  Each row represents a student's ID, name, and email address.  The index of this DataFrame is likely a sequential integer, starting from 0.

*   **`df_gpa`**: This table has columns for "SID" and "GPA".  Each row represents a student's ID and their corresponding GPA.  The index of this DataFrame is likely a sequential integer, starting from 0.

*   **`df_all`**: This table is the result of merging `df_student` and `df_gpa` using their indices as the join key.  The resulting table shows the combined data, with matching index values appearing in both tables.  The combined table includes columns from both input DataFrames.
