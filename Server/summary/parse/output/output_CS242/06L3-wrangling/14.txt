**Augmenting: Adding Calculated Columns**

# add a new column called "PRICE/SQ FT ($)"
# price per square feet = list price / living space
data_zillow['PRICE/SQ FT ($)'] = data_zillow['LIST PRICE ($)'] / data_zillow['LIVING SPACE (SQ FT)']

# add a new column called AGE
# get current year (don't use 2021!)
import datetime
now = datetime.datetime.now()
current_year = now.year
# the house age in a new column AGE
data_zillow['AGE'] = current_year - data_zillow['YEAR']

**Description of the Slide:**

This slide demonstrates how to add calculated columns to a DataFrame, specifically `data_zillow`.  The code calculates the price per square foot and the age of the houses.

*   **`PRICE/SQ FT ($) = list price / living space`**: This line calculates the price per square foot by dividing the `LIST PRICE ($) ` by the `LIVING SPACE (SQ FT)` for each row. The result is stored in a new column named `PRICE/SQ FT ($)`.
*   **`AGE = current year - YEAR`**: This line calculates the age of each house by subtracting the `YEAR` from the current year. The result is stored in a new column named `AGE`.
*   **`import datetime`**: This line imports the `datetime` module, which is necessary for getting the current date and time.
*   **`now = datetime.datetime.now()`**: This line gets the current date and time.
*   **`current_year = now.year`**: This line extracts the current year from the `now` object.
*   **`data_zillow`**: This line displays the updated DataFrame, which now includes the newly calculated `PRICE/SQ FT ($) ` and `AGE` columns.
