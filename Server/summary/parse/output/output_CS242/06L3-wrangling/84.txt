# Slide 84

**`grep` Examples**

```
grep "this" *.txt
grep ^root /etc/passwd
grep "http.*html" index.html
grep -i "linux" index.html  
# case insensitive
grep -A <N> "string" FILENAME  #print N lines after (-A) or before (-B) match
grep -c "pattern" filename     #count number of lines that match
http://www.grymoire.com/Unix/Grep.html
```

---

**Description of the Slide:**

This slide provides examples of using the `grep` command-line utility.  It shows various `grep` commands, each demonstrating different search patterns and options.  The examples include:

*   `grep "this" *.txt`: Searching for the string "this" in all files ending with ".txt" in the current directory.
*   `grep ^root /etc/passwd`: Searching for lines starting with "root" in the `/etc/passwd` file.  The `^` is a regular expression anchor for the beginning of a line.
*   `grep "http.*html" index.html`: Searching for lines containing "http" followed by any characters (`.`) and ending with ".html" in the `index.html` file.  The `*` is a regular expression quantifier, meaning "zero or more occurrences of the preceding character".
*   `grep -i "linux" index.html`: Searching for the string "linux" in `index.html`, ignoring case (the `-i` option).
*   `grep -A <N> "string" FILENAME`: Printing `N` lines *after* the lines containing the string "string" in the file `FILENAME`.  The `<N>` is a placeholder for a numerical value.
*   `grep -c "pattern" filename`: Counting the number of lines in `filename` that match the pattern.

The slide also includes a URL (`http://www.grymoire.com/Unix/Grep.html`) which is a helpful resource for learning more about the `grep` command.  The slide is entirely text-based, with no figures or tables.  The purpose is to provide examples of how to use `grep` for searching and filtering text files.
