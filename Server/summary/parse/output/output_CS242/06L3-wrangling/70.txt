**Outer Joins retain all the data**

An outer join keeps all parts of your data, and fills in the rest with NaN.

```
df_join = pd.merge(df_student, df_gpa, how='outer')
```

Three tables are displayed: `df_student`, `df_gpa`, and `df_join`.

*   **`df_student`**: This table has columns for "SID", "Name", and "Email".  Each row represents a student's ID, name, and email address.

*   **`df_gpa`**: This table has columns for "SID" and "GPA".  Each row represents a student's ID and their corresponding GPA.

*   **`df_join`**: This table is the result of the outer join.  It contains all the columns from both `df_student` and `df_gpa`.  Rows that have a matching "SID" in both DataFrames will have the corresponding GPA.  Rows from either `df_student` or `df_gpa` that do *not* have a matching "SID" in the other DataFrame will have NaN values for the columns from the other DataFrame.  The order of the rows in `df_join` is determined by the order of the rows in `df_student` followed by the rows in `df_gpa` that don't have a match.

A directed arrow is shown connecting `df_student` to `df_gpa` and then to `df_join`.  This arrow visually represents the merging process.  A second arrow is shown connecting `df_gpa` to `df_join`.  This arrow visually represents the merging process.
