**Cleaning up**

We have our combined data!
... but it's messy...

Apply duplicated to the columns
```
mask = ~df_grades.columns.duplicated()
mask
array([ True,  True,  True,  True, False,  True, False,  True])
```

Use it to filter duplicate columns
```
df_grades = df_grades.loc[:, mask]
```

**Description of the Slide:**

This slide addresses the issue of duplicate columns in a DataFrame (`df_grades`).  The code `mask = ~df_grades.columns.duplicated()` creates a boolean mask that identifies columns that are not duplicates.  The `~` operator inverts the boolean values, so `True` indicates a unique column.  The code `df_grades = df_grades.loc[:, mask]` filters the DataFrame to keep only the unique columns, effectively removing the duplicate "ST_Name" columns.  The resulting DataFrame is shown in a table, displaying the "ST_Name", "HW", "Quiz", "Lab", "Exam1", and "Exam2" columns.  The purpose of this slide is to demonstrate how to remove duplicate columns from a DataFrame using boolean indexing.  The code snippets are essential for demonstrating the data cleaning process. The table is crucial for showing the result of the column filtering operation.
