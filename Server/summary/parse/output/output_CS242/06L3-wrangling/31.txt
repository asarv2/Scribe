# Slide 31

**One final replacement challenge**

Consider this smaller, but more complicated data frame

```
df_new
```

```
Temperature	Wind Speed	Weather
0	0	3	Snow
1	-999	0	0
2	45	5	Sunny
3	None	-999	Cloudy
```

Along with the obvious -999, we also want to replace 0 in the Weather column…

… but 0 is a valid value in Temperature and Wind Speed

So don’t use just a dictionary, use a dictionary of features and values!

```
df_new.replace({'Temperature': [-999, 'None'], 'Wind Speed': -999, 'Weather': 0}, np.NaN)
```

```
Temperature	Wind Speed	Weather
0	0.0	3.0	Snow
1	NaN	0.0	NaN
2	45.0	5.0	Sunny
3	NaN	NaN	Cloudy
```
