# Slide 32

```markdown
So much replacing
With a complicated data set, you may find the need to do a lot of data frame manipulation
Rather than something like
df_weather_clean = df_weather.replace(...)
df_weather_cleaner = df_weather_clean.replace(...)
dfw_clean = df_weather_cleaner.replace(...)
dfw_final = dfw_clean.repace(...)
dfw_newFinal = ...
Consider using the inplace parameter to update the current data frame without having to re-assign
df_weather.replace({-999:np.NaN, -1111:np.NaN, 'None':'N/A'}, inplace=True)
```

---

**Description of the Slide:**

This slide discusses the potential for extensive data frame manipulation when dealing with complex datasets.  It suggests an alternative approach using the `inplace=True` parameter within the `replace()` method to avoid repeatedly re-assigning variables.  The slide shows several example variable assignments, illustrating the typical repetitive nature of data cleaning tasks.  The final line, `df_weather.replace({-999:np.NaN, -1111:np.NaN, 'None':'N/A'}, inplace=True)`, emphasizes the use of `inplace=True` to modify the DataFrame directly, avoiding the need to create new variables at each step.  There are no figures on this slide.  The text is entirely text-based, focusing on the concept of data manipulation and efficiency.
