**Adding Records**

You may not want to lose the source of your data.  Or the name of the source might be data in itself.

```
df_A['Group'] = 'A'
df_B['Group'] = 'B'
df_All = pd.concat([df_A, df_B])
```

Two tables are shown, `df_A` and `df_B`.  Each table has columns for "Name", "HW", "Quiz", and "Lab".  Each row represents a student's scores.  `df_A` contains student scores labeled as group 'A', and `df_B` contains student scores labeled as group 'B'.  The tables are side-by-side, and the data in each table is likely a set of student scores for homework, quizzes, and labs.  The purpose of these tables is to provide example data for demonstrating how to combine DataFrames.

```
We can filter out one subset by using loc function
df_All.loc[df_All.Group == 'A', :]
```

This line of code filters the `df_All` DataFrame to include only the rows where the 'Group' column is equal to 'A'.  The result is a new DataFrame containing only the rows from group 'A'.

```
df_All.loc[df_All.Group == 'B', :]
```

This line of code filters the `df_All` DataFrame to include only the rows where the 'Group' column is equal to 'B'.  The result is a new DataFrame containing only the rows from group 'B'.
