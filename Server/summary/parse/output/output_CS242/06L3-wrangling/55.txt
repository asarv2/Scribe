**Applying Summary Functions**

Once you have grouped your data, summary functions produce an aggregated DataFrame.  Using `max`, you get the max in each column, with the `Symbol` as the index.  `grouped_stock.max()`

```
Symbol
Close      Volume
AAPL  455.61  50000000
GOOG  1500.10 1995400
MSFT  216.35 32656800
```

Whereas using `mean`, you only get the columns where a mean makes sense. `grouped_stock.mean()`

```
Symbol
Close      Volume
AAPL  446.770000  4.316667e+07
GOOG  1489.400000  1.850500e+06
MSFT  213.923333  2.976833e+07
```

These all return new DataFrames, and can be accessed as you can with any other DataFrame.
