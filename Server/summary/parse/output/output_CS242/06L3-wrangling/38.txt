**Timestamps and Re-indexing**

Check the 'Date' column for type
```python
type(df_weather.Date[0])
```
str
Convert this to a timestamp when reading in the data to gain some sorting and indexing advantages
```python
df_weather = pd.read_csv('weather_march2020.csv',
             parse_dates=['Date'])
```
```python
type(df_weather.Date[0])
```
pandas._libs.tlibs.timestamps.Timestamp
And now re-index
```python
df_weather.set_index(Date, inplace=True)
df_weather
```
