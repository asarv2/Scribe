**Adding Records**

Once again, we'll be using simple examples

```
display(df_A)
display(df_B)
```

Two tables are shown, labeled `df_A` and `df_B`.  Each table has three columns: "Name", "HW", and "Quiz".  Each row represents a student's scores.  The tables are side-by-side, and the data in each table is likely a set of student scores for homework, quizzes, and labs.  The purpose of these tables is to provide example data for demonstrating how to combine dataframes.

```
Combine directly
pd.concat([df_A, df_B])
```

This line of code shows how to combine `df_A` and `df_B` using the `pd.concat()` function.  The result of this concatenation is a new DataFrame that contains all the rows from both `df_A` and `df_B`.  The order of the rows will be the same as the order in the original DataFrames.

```
Be mindful of the duplicated index values, we can fix them
pd.concat([df_A, df_B], ignore_index=True)
```

This line of code shows how to combine `df_A` and `df_B` using the `pd.concat()` function, but with the `ignore_index=True` argument.  This argument will reset the index of the combined DataFrame to sequential integers, avoiding issues with duplicate indices.  The result of this concatenation is a new DataFrame that contains all the rows from both `df_A` and `df_B`, but with a new index.
