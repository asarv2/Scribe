**One-to-Many Relationships**

Consider the relationship of instructors to courses. One instructor teaches many courses. We have a DataFrame for instructors (`df_1`) and a separate one for courses (`df_2`). A course has a key, `InstructorID`, which allows us to reference the instructor data in `df_1`.  When we merge, pandas combines the instructor with every record sharing the same key.

```
pd.merge(df_1, df_2)
```

The following tables are shown:

**df_1 (Instructors):**

| InstructorID | Name |
|---|---|
| 111 | Jack |
| 589 | Cindy |
| 764 | Gary |


**df_2 (Courses):**

| InstructorID | Course |
|---|---|
| 111 | Math200 |
| 111 | CS200 |
| 111 | CS255 |
| 589 | CS101 |
| 764 | ChE101 |


**Result of pd.merge(df_1, df_2):**

| InstructorID | Name | Course |
|---|---|---|
| 111 | Jack | Math200 |
| 111 | Jack | CS200 |
| 111 | Jack | CS255 |
| 589 | Cindy | CS101 |
| 764 | Gary | ChE101 |
