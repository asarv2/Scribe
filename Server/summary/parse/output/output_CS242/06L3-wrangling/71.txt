**Mismatched Identifiers**

Column names don't always match.  This is especially true when combining data sets from different sources.  In these cases, you have to specify which columns to join on.

```
df_all = pd.merge(df_student, df_gpa, left_on='Student_ID', right_on='SID')
df_all.drop('SID', axis=1)
```

Three tables are shown: `df_student`, `df_gpa`, and `df_all`.

*   **`df_student`**: This table has columns for "Student ID", "Name", and "Email".  Each row represents a student's ID, name, and email address.

*   **`df_gpa`**: This table has columns for "SID" and "GPA".  Each row represents a student's ID and their corresponding GPA.

*   **`df_all`**: This table is the result of merging `df_student` and `df_gpa` based on the 'Student_ID' column from `df_student` and the 'SID' column from `df_gpa`.  The 'SID' column is dropped from the merged DataFrame.  The resulting table shows the combined data, with matching 'Student ID' values appearing in both tables.
