**Binning Data**

Binning data cuts an otherwise continuous numerical feature into a discrete category
First set cut boundaries, then cut your data
```
bins = [-1, 59, 69, 89, 110]
cats = pd.cut(df_final.Grade, bins)
print(cats)
print(pd.value_counts(cats))
```
