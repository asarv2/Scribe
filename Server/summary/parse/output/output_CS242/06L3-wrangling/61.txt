**Adding Features**

Sometimes we might have data divided in different files.
Perhaps a main gradebook and a list of scores passed back by the grader.

Use `axis=1` for side-by-side.

```
df_grades = pd.concat([df_no_exam, df_exam_1], axis=1)
```

What happens with a randomized, shorter exam 2 list?

```
pd.concat([df_grades, df_exam_2], axis=1)
```

**Description of the Slide:**

This slide demonstrates the concept of adding features to a dataset, specifically combining data from different files.  It shows how `pd.concat()` can be used to combine DataFrames, but highlights that simply concatenating DataFrames side-by-side might not be the desired outcome.  The example uses three DataFrames (`df_no_exam`, `df_exam_1`, and `df_exam_2`) representing different parts of a student's grade data.  The slide shows the individual DataFrames and then the result of concatenating `df_no_exam` and `df_exam_1` along the columns (`axis=1`).  The example illustrates that simply concatenating the DataFrames side-by-side doesn't always produce the desired result, as the data might not be aligned correctly.  The slide is part of a lecture on data manipulation and analysis, specifically focusing on combining data from different sources.  The code snippets are essential for demonstrating the data manipulation process. The tables are crucial for showing the input data and the expected output of the concatenation operation.  The tables are formatted to show the columns and rows of the DataFrames.
