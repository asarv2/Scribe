**Inner Joins - the default merge**

The default merge is an inner merge

```
df_join = pd.merge(df_student, df_gpa)
```

If no columns to merge on are specified, merge identifies columns with matching names.

The above example is the same as

```
df_join = pd.merge(df_student, df_gpa, how='inner', on='SID')
```
