**For even better estimates**

If your data is generally related from one element to the next, consider `interpolate`
Records with values are end points and missing values are filled in via linear methods
```python
df_weather.interpolate()  # # each record is equidistant
df_weather.interpolate(method='time')  # # spaced by time index
```
