**Filling Missing Values**

How is this missing data different than replacing data?
Ideally, you're able to find the data, and update it directly

# `df_grades` entries change
`df_grades.iloc[8, 4] = 50.0`
`df_grades.iloc[9, 4] = 35.0`
`df_grades.iloc[10, 4] = 40.0`
`df_grades.iloc[6, 5] = 70.0`
`df_grades.iloc[14, 6] = 65.0`

Can't we just drop a zero in and be done?
Yes. There's even a dedicated method to do so:
`df_grades.fillna(0)`

For this data set, if you don't have the grades a 0 would be appropriate. That's not true in all situations.
