**More Replacing**

Of course, why use a single value, when you can use a list...

```
df_weather.replace([-999, -1111, 'None'], np.NaN)
```

Or for custom values, use a dictionary

```
df_weather.replace({-999:np.NaN, -1111:np.NaN, 'None':'N/A'})
```
