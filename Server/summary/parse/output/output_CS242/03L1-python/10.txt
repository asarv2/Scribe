## Description of the Slide

This slide demonstrates Python code execution.  The title "Playing with Python" indicates the focus on interactive Python code examples.  The content is a series of Python expressions and their outputs, presented in a way that resembles an interactive Python interpreter session.  Each line starting with `>>>` represents a Python command entered at the interpreter prompt.  The following output shows the result of the command.  For example, `>>> 2+3` is followed by `5`, indicating that the sum of 2 and 3 is 5.  The examples cover basic arithmetic operations (addition, division), variable assignment, type conversion (integer conversion), and string manipulation (accessing characters and substrings).  The slide is designed to illustrate how to use Python interactively and to show the results of different operations.  The "Slides adapted from UPenn CIS530 python tutorial" line indicates the source of the examples.  There are no figures on this slide.
