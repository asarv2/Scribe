**if Statements**

Use of indentation for blocks, Colon (:) after boolean expression

```python
if x == 3:
    print("X equals 3.")
elif x == 2:
    print("X equals 2.")
else:
    print("X equals something else.")
print("This is outside the 'if'.")
```

Slides adapted from UPenn CIS530 python tutorial


## Description of the Slide

This slide presents a Python code example demonstrating the use of `if`, `elif`, and `else` statements.  The code uses indentation to define code blocks associated with each conditional statement.  The `if` statement checks if the variable `x` is equal to 3. If true, it prints "X equals 3."  The `elif` statement checks if `x` is equal to 2. If true, it prints "X equals 2."  The `else` block handles all other cases, printing "X equals something else."  Finally, a separate `print` statement outside the conditional block demonstrates code execution after the `if` statement.  The slide is designed to illustrate conditional logic in Python using the `if-elif-else` structure.  The source of the example is explicitly noted.  There are no figures on this slide.
