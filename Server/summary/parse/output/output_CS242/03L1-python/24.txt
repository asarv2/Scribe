# Slide 24

**Operations on lists**

Adding new elements to a list

```
>>> li = [1, 11, 3, 4, 5]
>>> li.append('a')  # Note the method syntax
>>> li
[1, 11, 3, 4, 5, 'a']
>>> li.insert(2, 'i')
>>> li
[1, 11, 'i', 3, 4, 5, 'a']
```

+ creates a fresh list (with a new memory reference)
extend operates on list `li` in place.

```
>>> li.extend([9, 8, 7])
>>> li
[1, 2, 'i', 3, 4, 5, 'a', 9, 8, 7]
```

## Description of the Slide

This slide demonstrates different ways to add elements to a Python list.  The title "Operations on lists" indicates the focus on list manipulation.  The content shows examples of using the `append()` and `insert()` methods to add elements to a list.  The `append()` method adds an element to the end of the list, while `insert()` adds an element at a specified index.  The examples use a list named `li` containing various data types (integers and strings).  The output shows the list after each operation, demonstrating the changes made to the list.  The slide also shows the `extend()` method, which adds multiple elements to the end of the list.  The text explains that `extend()` modifies the list in place, unlike `append()` which creates a new list.  The source of the examples is explicitly noted.  There are no figures on this slide.
