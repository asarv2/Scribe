# Slide 29

**Booleans**

True and False are constants in Python

Other values equivalent to True and False:

*   False: zero, None, empty container or object
*   True: non-zero numbers, non-empty objects

Comparison operators: ==, !=, <, <=, etc.

*   X and Y have same value: X == Y
*   Compare with: X is Y
*   X and Y are two variables that refer to the identical object

Slides adapted from UPenn CIS530 python tutorial


## Description of the Slide

This slide, part of a lecture on Introduction to Data Science, discusses the Boolean data type in Python.  The title "Booleans" clearly indicates the topic.  The content explains that `True` and `False` are the Boolean constants.  It then lists values that are considered equivalent to `True` and `False` (e.g., zero, `None`, empty containers are `False`; non-zero numbers and non-empty containers are `True`).  The slide also mentions comparison operators (==, !=, <, <=, etc.) and how to compare values for equality (`X == Y`) and identity (`X is Y`).  The final point clarifies that `X is Y` checks if `X` and `Y` refer to the same object in memory, not just if they have the same value.  The source of the information is explicitly noted.  There are no figures on this slide.  The slide's purpose is to explain Boolean values and comparisons in Python, which are fundamental to programming logic.
