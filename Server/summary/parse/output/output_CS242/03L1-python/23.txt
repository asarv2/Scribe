# Slide 23

**Lists and tuples**

We can change lists in place. The name li still points to the same memory reference when we're done.

```
>>> li = ['abc', 23, 4.34, 23]
>>> li[1] = 45
>>> li
['abc', 45, 4.34, 23]
```

You can't change a tuple. You can make a fresh tuple and assign its reference to a previously used name.

```
>>> tu = (23, 'abc', 4.56, (2, 3), 'def')
>>> tu[2] = 3.14
TypeError: 'tuple' object does not support item assignment
```

The immutability of tuples means they're faster than lists.
