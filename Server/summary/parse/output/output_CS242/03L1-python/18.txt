# Slide 18

**Sequence Types**

Tuples are defined using parentheses (and commas).
```
>>> tu = (23, 'abc', 4.56, (2, 3), 'def')
```
Lists are defined using square brackets (and commas).
```
>>> li = ["abc", 34, 4.34, 23]
```
Strings are defined using quotes ("", ', or """).
```
>>> st = "Hello World"
>>> st = 'Hello World'
>>> st = """This is a multi-line
string that uses triple quotes."""
```

The examples show that these data types can contain various data types (integers, strings, floats, and even other tuples or lists).  The slide is designed to illustrate the syntax for creating these fundamental data structures in Python.  There are no figures on this slide.
