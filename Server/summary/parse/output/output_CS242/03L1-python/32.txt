**while Loops**

```python
>>> x = 3
>>> while x < 5:
...     print(x, "still in the loop")
...     x = x + 1
3 still in the loop
4 still in the loop
>>> x = 6
>>> while x < 5:
...     print(x, "still in the loop")
>>>
```

Slides adapted from UPenn CIS530 python tutorial


## Description of the Slide

This slide demonstrates a `while` loop in Python.  The code initializes a variable `x` to 3.  The `while` loop continues as long as `x` is less than 5.  Inside the loop, it prints the current value of `x` followed by the string "still in the loop".  Then, it increments `x` by 1.  This process repeats until `x` becomes 5, at which point the loop terminates.  A second example shows what happens when `x` is initialized to 6.  In this case, the condition `x < 5` is false from the start, so the loop body is never executed.  The slide is designed to illustrate the syntax and behavior of a `while` loop in Python.  The output shows the values of `x` printed during each iteration of the loop.  The source of the example is explicitly noted.  There are no figures on this slide.
