# Playing with Python

```python
>>> x = ['a', 'b', 'c']
>>> x[1]
'b'
>>> x[1:]
['b', 'c']
>>> x[1] = 'd'
>>> x
['a', 'd', 'c']
>>> d = {'alice': 1234, 'bob': 5678, 'clare': 9012}
>>> d['bob']
5678
>>> d['bob'] = 7777
>>> d
{'clare': 9012, 'bob': 7777, 'alice': 1234}
>>> d.keys()
dict_keys(['clare', 'bob', 'alice'])
>>> d.items()
dict_items([('clare', 9012), ('bob', 7777), ('alice', 1234)])
>>> del d['bob']
```

Slides adapted from UPenn CIS530 python tutorial


## Description of the Slide

This slide, part of a lecture on Introduction to Data Science, presents interactive Python code examples.  The title "Playing with Python" indicates the focus on demonstrating Python's functionality through interactive code snippets.  The content is a series of Python commands and their outputs, formatted to resemble an interactive Python interpreter session.  Each line starting with `>>>` represents a Python command entered at the interpreter prompt.  The following output shows the result of the command.  The examples cover list manipulation (accessing elements, slicing, modifying elements), dictionary creation, access, modification, and deletion.  The examples are designed to illustrate how to use Python interactively and to show the results of different operations on lists and dictionaries.
