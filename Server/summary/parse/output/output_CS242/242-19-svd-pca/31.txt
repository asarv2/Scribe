**How to compute SVD in Python**

```python
import pandas as pd
import numpy as np
# read in data
data = pd.read_csv("iris.dat", header=None, sep=',')
X = data.iloc[:, 0:4].values  # Dataframe.values returns a matrix
X_shape = np.shape(X)
# do SVD decomposition
U, s, Vt = np.linalg.svd(X)
# U, Vt matrices
# s: vector of eigenvalues
# Combine s and Vt to simplify our latent factors
```

3. **Perform SVD:** The core of the code is `U, s, Vt = np.linalg.svd(X)`. This line computes the SVD of the matrix `X`, storing the left singular vectors in `U`, the singular values in `s`, and the right singular vectors in `Vt`.
