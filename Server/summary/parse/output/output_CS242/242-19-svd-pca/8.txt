# Slide 8

**Dimensionality Reduction**

If there are d dimensions (attributes) in the data, dimensionality reduction refers to methods that transform the data to fewer dimensions, i.e. d'<d

Why reduce the dimensionality?
* To discard irrelevant features
* To visualize high dimensional data
* To reflect "intrinsic" dimensionality of data, which may be smaller than the original number of attributes
