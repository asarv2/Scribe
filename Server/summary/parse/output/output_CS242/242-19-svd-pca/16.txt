The plot is oriented with the x-axis horizontally and the y-axis vertically.  The purpose of the plot is to visually illustrate the concept of principal component analysis (PCA). **Description:**

This slide, part of a lecture on Principal Component Analysis (PCA) within an Intro to Data Science course, visually demonstrates the concept of PCA.  The figure is a scatter plot showing a dataset and the principal components derived from it.  The red and blue lines represent the principal components, which are orthogonal to each other.  The interactive example link provides a way to explore PCA in more detail.  The slide is designed to help the audience understand how PCA finds directions that maximize the variance of the data, and how these directions can be used to project the data onto a lower-dimensional space.
