# Slide 14

**SVD vs PCA**

PCA and SVD are closely related

* SVD is a general operation defined on all matrices
* Principle component analysis (PCA) refers to a data analysis technique for dimensionality reduction. To apply PCA to matrix A, the task reduces to computing the SVD of A

We will see that SVD gives strictly more information than PCA, namely the matrix U
