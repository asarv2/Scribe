# Slide 21

**How to choose number of dimensions**

In PCA, each transformed dimension explains a 
proportion of the variance of the data  
As m (the number of components) increases the 
total explained variance cannot increase 
Look at the total proportion of variance explained 
by each dimension to choose number of 
dimensions 
Pick number that provides a good tradeoff 
between accuracy (large proportion of variance 
explained) and complexity (small number of 
dimensions)  

**(Figure):** A line graph is positioned in the lower-right portion of the slide.  The x-axis is labeled "principal component" and ranges from 0 to 25.  The y-axis is a logarithmic scale, labeled "10<sup>x</sup>", and ranges from approximately 10<sup>-6</sup> to 10<sup>2</sup>.  Two lines are plotted on the graph:

* **Blue line (dots):**  Represents the "explained variance ratio" for each principal component.  This line shows the proportion of variance explained by each individual principal component.  The values decrease as the principal component number increases.

* **Green line (dashed):** Represents the "cumulative explained variance ratio".  This line shows the cumulative proportion of variance explained by the first *m* principal components.  The values increase as the principal component number increases, but the rate of increase slows down as the number of components increases.

The graph visually displays how the proportion of variance explained by each principal component changes as the number of components increases.  The graph is used to help determine the optimal number of principal components to use for dimensionality reduction, balancing accuracy (large cumulative explained variance) and complexity (small number of components).


**Description:**

This slide, part of a lecture on Principal Component Analysis (PCA) in an Intro to Data Science course, discusses how to choose the optimal number of dimensions (principal components) to retain after applying PCA.  The figure is a line graph that plots the explained variance ratio and the cumulative explained variance ratio against the principal component number.  The graph is used to visually assess the trade-off between the amount of variance explained and the number of dimensions retained.  The goal is to select a number of principal components that captures a significant portion of the variance while keeping the dimensionality low.  The context of this slide is to follow up on the previous slides that discussed how to apply PCA and transform data, now focusing on how to choose the best number of components to use for dimensionality reduction.
