# Slide 18

**Applying PCA**

New data vectors are formed by projecting the data onto the first few principal components (i.e., top m eigenvectors)

x = [x<sub>1</sub>, x<sub>2</sub>, ..., x<sub>p</sub>] (original instance)

A = [a<sub>1</sub>, a<sub>2</sub>, ..., a<sub>p</sub>] (principal components)

x′<sub>1</sub> = a<sub>1</sub>x = Σ<sup>p</sup><sub>j=1</sub> a<sub>1j</sub>x<sub>j</sub>

...

x′<sub>m</sub> = a<sub>m</sub>x = Σ<sup>p</sup><sub>j=1</sub> a<sub>mj</sub>x<sub>j</sub> for m ≤ p

x′ = [x′<sub>1</sub>, x′<sub>2</sub>, ..., x′<sub>m</sub>] (transformed instance)

If m = p then data is transformed

If m < p then transformation is lossy and dimensionality is reduced

**Description:**

This slide, part of a lecture on Principal Component Analysis (PCA) in an Intro to Data Science course, details the application of PCA to transform data.  The slide shows the mathematical formulas used to project original data points (x) onto principal components (A) to create new transformed data points (x′).  The equations demonstrate how each component of the transformed data (x′<sub>m</sub>) is calculated by taking a weighted sum of the original data components (x<sub>j</sub>), where the weights are the elements of the principal component matrix (a<sub>mj</sub>).  The slide also explains the conditions under which the transformation is lossless (m = p) or lossy (m < p), and how dimensionality reduction occurs in the latter case.  There is no figure on this slide.  The context of the slide is to explain the practical application of PCA, following the theoretical explanation of the PCA algorithm in the previous slide.
