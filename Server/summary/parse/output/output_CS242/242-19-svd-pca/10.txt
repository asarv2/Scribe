# Slide 10

**Singular value decomposition**

A singular value decomposition (SVD) of an n × d matrix A expresses the matrix as the product of three "simple" matrices:

A = USV<sup>T</sup>

* U is an n × n orthogonal matrix
* V is a d × d orthogonal matrix
* S is an n × d diagonal matrix with nonnegative entries sorted from high to low
