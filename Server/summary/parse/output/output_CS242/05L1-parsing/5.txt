# Slide 5

**How to specify pattern to match**

The power of regular expressions comes in the ability to match flexibly over possible sequences of characters
Characters generally match themselves, for example...

a  This matches the character 'a'

Though there are exceptions:

.  This element matches any character except \n, to match a "." use "\."
[] This matches one character specified inside [], e.g. [aeiou]
[^] This matches one character NOT specified inside [] after ^, e.g. [^abc]
-  This matches one character in range inside []: e.g., [0-9] matches any digit
^ This matches beginning of line (when not used in [^])
$ This matches end of line (when not used in [] or [^])
