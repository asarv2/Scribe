**Regular Expressions: Examples**

```
sen = "This is a test that tests regular expression basics for numbers 1234 and letters A-Z."
# Match all single digits
pattern = re.compile(r"\d")
print(re.findall(pattern, sen))
['1', '2', '3', '4']
# Match all digits followed by a space
pattern = re.compile(r"\d\s+")
print(re.findall(pattern, sen))
['4 ']
# Did you perhaps want to match \d+\s+?
# Did you really want that space on the end?
```

**Description:**

This slide, part of a lecture on Intro to Data Science, provides examples of using regular expressions (RegEx) in Python to extract specific patterns from a string.  The example string `sen` contains a mix of text and numbers.

*   **First Example:** The code `pattern = re.compile(r"\d")` compiles a regular expression to match any digit.  `re.findall(pattern, sen)` finds all the digits in the string `sen` and prints them as a list: `['1', '2', '3', '4']`.

*   **Second Example:** The code `pattern = re.compile(r"\d\s+")` compiles a regular expression to match a digit followed by one or more whitespace characters.  `re.findall(pattern, sen)` finds the occurrences of this pattern in the string `sen` and prints them as a list: `['4 ']`.  The output shows that the pattern successfully matched the digit '4' followed by a space.
