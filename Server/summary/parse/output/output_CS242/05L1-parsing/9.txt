**Regular Expressions: Examples**

```python
sen = "This is a test that tests regular expression basics for numbers 1234 and letters A-Z."
# findall returns a list of matched substrings
pattern = re.compile(r"test.")
print(re.findall(pattern, sen))
['test ', 'tests']
# finditer returns an iterable collection of match objects
for match in re.finditer(pattern, sen):
    print(match.group(), match.span())
test  (10, 15)
tests (20, 25)
```

---

**Description:**

This slide demonstrates the use of the `findall` and `finditer` methods from the `re` module in Python, which are used for regular expression operations.  The code shows how to compile a regular expression pattern (`r"test."`) to find all occurrences of "test" (or "tests") within a given string (`sen`).

*   **`re.findall(pattern, sen)`:** This line uses the `findall` method to find all occurrences of the pattern "test" in the string `sen`. The output is a list containing the matched substrings: `['test ', 'tests']`.  The space after "test" in the output is part of the match because of the `.` in the pattern.

*   **`re.finditer(pattern, sen)`:** This line uses the `finditer` method to find all occurrences of the pattern "test" in the string `sen`. The output is an iterable set of `Match` objects.  The `for` loop iterates through these objects, and for each match, it prints the matched substring (`match.group()`) and the starting and ending positions of the match (`match.span()`).  The output shows the starting and ending indices of each match within the original string.
