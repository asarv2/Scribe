# Slide 7

```markdown
**SOME Regular expression methods in python**

match() Determine if the RE matches at the beginning of the string
search() Scan through string, look for any location where this RE matches
findall() Find all substrings the RE matches, return as a list
finditer() Find all substrings the RE matches, return as a iterable set of Match objects
```

---

**Description:**

This slide, part of a lecture on Intro to Data Science, lists several methods available in Python's `re` module for working with regular expressions (RegEx).  The title "SOME Regular expression methods in python" indicates that this is not an exhaustive list of all possible methods, but rather a selection of commonly used ones.  Each method is presented on a separate line, with a brief description of its functionality.  The descriptions explain what each method does:

*   `match()`: Checks if a pattern matches at the beginning of a string.
*   `search()`: Scans the entire string to find any location where the pattern matches.
*   `findall()`: Finds all occurrences of the pattern in the string and returns them as a list.
*   `finditer()`: Finds all occurrences of the pattern and returns an iterable set of `Match` objects, providing more detailed information about each match.

The slide's purpose is to introduce these important methods for using RegEx in Python code within the context of data science tasks.  The format is simple and direct, focusing on the function of each method.  The slide is a continuation of the previous slides, which introduced the concept of RegEx and how to specify patterns.
