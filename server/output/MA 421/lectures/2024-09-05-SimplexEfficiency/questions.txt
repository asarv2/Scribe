QUESTION 1
According to Dantzig, for a linear programming problem with $m < 50$ and $m + n < 200$, what is the typical number of iterations the simplex method requires?
A. Approximately $3m$
B. Usually less than or equal to $\frac{3m}{2}$
C. Always $2^n - 1$
D. Always $n$
E. Always $m+n$

ANSWER: B

EXPLANATION: 
A. Answer A is incorrect because while the number of iterations can rarely approach $3m$, it is not the typical case.
B. Answer B is correct because, according to the slide, the number of iterations is usually less than or equal to $\frac{3m}{2}$.
C. Answer C is incorrect because $2^n - 1$ is the number of steps for the largest coefficient rule in the Klee-Minty worst-case example, not the typical case.
D. Answer D is incorrect because $n$ is the number of steps for the smallest coefficient rule in the Klee-Minty worst-case example, not the typical case.
E. Answer E is incorrect because the number of iterations is not typically $m+n$.
