\text{Let } \hat{x} \text{ is (P)-feasible.} \\
\xi(\hat{x}) = c^T \hat{x} \\
\le c^T \hat{x} - y^T (A \hat{x} - b) - z^T (\hat{x} - u) \\
y \ge 0 \quad \le 0 \quad z \ge 0 \quad \le 0 \\
\le \max_x (c^T x - y^T (Ax - b) - z^T (x - u)) \\
:= \xi(y, z) \\
\text{Weak Duality} \quad \xi(\hat{x}) \le \xi(y, z) \\
x: \text{P-feasible} \implies \max_x \xi(x) \le \min_{y, z} \xi(y, z) \quad y, z \ge 0 \\
\xi^* \le \xi^*
</LATEX>

<DESCRIPTION>Slide 5 of 7 in a Linear Programming course demonstrates weak duality.  The slide starts by assuming $\hat{x}$ is a feasible solution to the primal problem (P).  It then defines $\xi(\hat{x}) = c^T \hat{x}$ and manipulates this expression using the constraints of the primal problem ($Ax \le b$ and $x \le u$) and the non-negativity of the dual variables $y$ and $z$.  The inequalities $y \ge 0$, $Ax - b \le 0$, $z \ge 0$, and $x - u \le 0$ are used to show that $\xi(\hat{x})$ is less than or equal to the expression $\max_x (c^T x - y^T (Ax - b) - z^T (x - u))$. This maximum is then defined as $\xi(y, z)$. The core concept of weak duality is then stated: $\xi(\hat{x}) \le \xi(y, z)$, meaning the objective function value of any feasible solution to the primal problem is less than or equal to the objective function value of any feasible solution to the dual problem.  The implication is shown: if $x$ is a feasible solution to the primal problem, then the maximum value of the primal objective function ($\xi^*$) is less than or equal to the minimum value of the dual objective function ($\xi^*$). The red arrows indicate the direction of the inequalities and implications. The context of the course is crucial for understanding the relationship between the primal and dual problems and the significance of weak duality in optimization.</DESCRIPTION>

(D) \quad \min_{Y, Z \ge 0} \quad \xi(Y, Z) \\
= \min_{Y, Z \ge 0} \quad c^T x - Y^T (Ax - b) - Z^T (x - u) \\
= \min_{Y, Z \ge 0} \quad (c^T - Y^T A - Z^T) x + Y^T b + Z^T u \\
= \begin{cases}
\min_{Y, Z \ge 0} \quad Y^T b + Z^T u & \text{if } c^T - Y^T A - Z^T = 0 \\
+\infty & \text{if } c^T - Y^T A - Z^T \ne 0
\end{cases}
</LATEX>

<DESCRIPTION>Slide 6 of 7 in a Linear Programming course shows the derivation of the dual linear program (D).  The slide starts with the Lagrangian function from the previous slide and proceeds to minimize it with respect to $x$. The expression $(c^T - Y^T A - Z^T)x$ is highlighted with a red underline. This result is a key step in deriving the dual problem, showing how the dual objective function and constraints arise from the primal problem's Lagrangian. <DESCRIPTION>Slide 7 of 7 in a Linear Programming course presents the final dual linear program (D). Building upon the previous slides' derivations using the Lagrangian function, this slide concisely states the dual problem. The objective function is to minimize $b^T y + u^T z$, subject to the constraints $A^T y + z = c$ and $y, z \ge 0$.  The boxed (D) indicates this is the dual problem. The superscript T denotes the transpose of a matrix or vector.  The variables $y$ and $z$ are the dual variables corresponding to the primal constraints $Ax \le b$ and $x \le u$ respectively. The equality constraint $A^T y + z = c$ arises from setting the gradient of the Lagrangian with respect to $x$ to zero. The non-negativity constraints $y, z \ge 0$ are inherited from the Lagrangian formulation.
