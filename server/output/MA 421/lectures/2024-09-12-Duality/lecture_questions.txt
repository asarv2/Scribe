QUESTION 1
Consider the primal problem (P): $\max \quad \xi(x) = c^T x$ subject to $Ax \le b, x \ge 0$, and its dual (D): $\min \quad \xi(y) = b^T y$ subject to $A^T y \ge c, y \ge 0$.  If the primal problem is feasible but unbounded, what can be concluded about the feasibility of the dual problem, and why?
A. The dual problem is also feasible and unbounded.
B. The dual problem is feasible and has an optimal solution.
C. The dual problem is infeasible.
D. The dual problem is unbounded.
E. There is not enough information to determine the feasibility of the dual problem.

ANSWER: C

EXPLANATION:
A. If the primal is unbounded, the dual cannot be feasible, let alone unbounded. Weak duality would be violated.
B. Similar to A, if the primal is unbounded, the dual cannot be feasible.
C. The dual problem is infeasible.  If the primal problem is feasible and unbounded, it means that the objective function can increase without bound while satisfying the constraints.  By weak duality, the objective function value of any feasible solution to the primal problem is less than or equal to the objective function value of any feasible solution to the dual problem. If the primal objective function is unbounded, then the dual problem cannot have a feasible solution, otherwise it would contradict weak duality.
D. The dual problem cannot be unbounded if the primal is unbounded.  Weak duality would be violated.
E. Weak duality provides sufficient information to determine the feasibility of the dual problem in this case.

A. The dual problem (D) is also unbounded.
B. The dual problem (D) is infeasible.
C. The dual problem (D) has an optimal solution.
D. The dual problem (D) may be feasible or infeasible; there is not enough information to determine its status.

ANSWER: B

EXPLANATION:
A. If the primal is unbounded, the dual must be infeasible.  An unbounded primal implies no feasible dual.
B. The dual problem (D) is infeasible. Weak duality states that for any feasible solution $x$ to (P) and any feasible solution $y$ to (D), the objective function value of (P) is less than or equal to the objective function value of (D): $c^T x \le b^T y$. If (P) is unbounded, meaning its objective function can be made arbitrarily large, then there cannot exist any feasible solution $y$ to (D). Otherwise, we would have a contradiction: an arbitrarily large value on the left side of the inequality, but a finite value on the right side.
C. If the primal is unbounded, the dual cannot have a solution.
D. Weak duality allows us to conclude the dual is infeasible.
E. The dual is a minimization problem, so it cannot be unbounded above. It would be unbounded below if it were unbounded.
