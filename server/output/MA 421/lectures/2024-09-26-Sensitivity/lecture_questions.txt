QUESTION 1
Consider the linear program in Slide 1.  Suppose we increase the coefficient of $x_1$ in the objective function by $\epsilon$. Using the information from Slide 3, what is the condition on $\epsilon$ that ensures the current optimal solution remains optimal?
A. $\epsilon \ge 0$
B. $\epsilon \le 1$
C. $\epsilon \ge -1$
D. There is no restriction on $\epsilon$
E. $\epsilon \le 3$

ANSWER: C

EXPLANATION:
A. This is incorrect.  The change in the objective function coefficient affects the reduced costs, and a positive $\epsilon$ could violate the optimality conditions.
B. This is incorrect.  While this bound might work for the $x_6$ coefficient, it doesn't consider the impact on the $x_4$ coefficient.
C. The optimal solution is given in Slide 3 as $\xi = 13 - 3x_2 - x_4 - x_6$. The coefficient of $x_1$ in the objective function is 5. If we increase it by $\epsilon$, the new objective function is $(5+\epsilon)x_1 + 4x_2 + 3x_3$.  From Slide 3, we have $x_1 = 2 - 2x_2 - 2x_4 + x_6$.  Substituting this into the new objective function and simplifying, we get a new expression for $\xi$. For the current optimal solution to remain optimal, the coefficients of the non-basic variables ($x_2, x_4, x_6$) must remain non-positive.  Analyzing the coefficient of $x_2$, we find that the condition for it to remain non-positive is not affected by $\epsilon$. However, the coefficient of $x_4$ is affected. The original coefficient of $x_4$ is -1. The change in the coefficient of $x_4$ due to the change in $x_1$'s coefficient is $-2\epsilon$. Thus, we require $-1 - 2\epsilon \le 0$, which simplifies to $\epsilon \ge -1/2$. Similarly, the coefficient of $x_6$ is affected. The original coefficient of $x_6$ is -1. The change in the coefficient of $x_6$ due to the change in $x_1$'s coefficient is $\epsilon$. Thus, we require $-1 + \epsilon \le 0$, which simplifies to $\epsilon \le 1$. Combining these conditions, we get $-1/2 \le \epsilon \le 1$.  Option C is the most conservative bound that guarantees optimality.
D. This is incorrect.  Changes in the objective function coefficients will generally affect the optimality of the solution.
E. This is incorrect. This bound is too large and doesn't guarantee that the reduced costs remain non-positive.


QUESTION 2
Referring to Slide 8, suppose we increase the right-hand side of the first constraint by $\Delta b_1 = 2$. Using the information from Slide 11, what is the condition on the optimal solution to remain feasible?
A. The solution remains feasible for any $\Delta b_1$
B. $X_B^* + B^{-1} \begin{pmatrix} 2 \\ 0 \\ 0 \end{pmatrix} \ge 0$
C. $X_B^* + 2B^{-1} \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} \ge 0$
D. $B^{-1} \begin{pmatrix} 2 \\ 0 \\ 0 \end{pmatrix} \ge 0$
E. The solution remains feasible only if $\Delta b_1 \le 1$

ANSWER: B

EXPLANATION:
A. This is incorrect.  Changes in the right-hand side can affect the feasibility of the solution.
B. From Slide 11, we have $\Delta X_B^* = B^{-1} \Delta b$.  Since we are only changing the first constraint, $\Delta b = \begin{pmatrix} 2 \\ 0 \\ 0 \end{pmatrix}$.  For the solution to remain feasible, we require $X_B^* + \Delta X_B^* \ge 0$, which translates to $X_B^* + B^{-1} \begin{pmatrix} 2 \\ 0 \\ 0 \end{pmatrix} \ge 0$. This ensures that all basic variables remain non-negative after the change.
C. This is incorrect. While the direction is correct, the scaling by 2 is unnecessary and incorrect. The correct expression is $X_B^* + B^{-1} \begin{pmatrix} 2 \\ 0 \\ 0 \end{pmatrix} \ge 0$.
D. This is incorrect.  We need to consider the current optimal solution $X_B^*$ in addition to the change $\Delta X_B^*$. The feasibility condition is $X_B^* + \Delta X_B^* \ge 0$.
E. This is incorrect.  The range of $\Delta b_1$ for which the solution remains feasible depends on the specific values of $X_B^*$ and $B^{-1}$.
