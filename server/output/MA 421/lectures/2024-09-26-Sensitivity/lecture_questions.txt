QUESTION 1
In the context of sensitivity analysis for the linear program presented in Slide 1, what condition must be met to ensure that the current optimal solution remains optimal after a change in the objective function coefficients?
A. The change in the objective function coefficients must be less than the absolute value of the reduced costs of the non-basic variables.
B. The updated reduced costs of all non-basic variables must remain non-negative.
C. The change in the objective function coefficients must not affect the feasibility of the current solution.
D. The optimal values of the basic variables must remain unchanged.
E. The objective function value must increase after the change in coefficients.

ANSWER: B

EXPLANATION:
A. While the magnitude of the reduced costs is relevant, this statement is not a complete or accurate condition for maintaining optimality. The correct condition involves the updated reduced costs, not just the original ones.
B. The condition $Z_N^* + \Delta Z_N^* \ge 0$, as shown in Slide 7, ensures that the updated reduced costs remain non-negative, which is a necessary condition for the current optimal solution to remain optimal after a change in the objective function coefficients.  If any reduced cost becomes negative, then the current solution is no longer optimal.
C. Feasibility is a separate condition.  The change in objective function coefficients might not affect feasibility, but it could still change the optimality of the solution.
D. The optimal values of the basic variables may change, but the current solution remains optimal as long as the updated reduced costs of the non-basic variables remain non-negative.
E. While an increase in the objective function value is desirable, it is not a sufficient condition for maintaining optimality. The solution might improve, but a different solution might yield an even better objective function value.

QUESTION 3
What is the primary difference between sensitivity analysis and parametric analysis in the context of linear programming, as illustrated by the slides?
A. Sensitivity analysis considers changes in multiple parameters simultaneously, while parametric analysis focuses on one parameter at a time.
B. Sensitivity analysis examines the impact of small changes in parameters, while parametric analysis studies the effect of larger, systematic changes.
C. Sensitivity analysis focuses on the objective function, while parametric analysis focuses on the constraints.
D. Sensitivity analysis uses the dual simplex method, while parametric analysis uses the primal simplex method.
E. Sensitivity analysis is qualitative, while parametric analysis is quantitative.

ANSWER: B

EXPLANATION:
A. Both sensitivity and parametric analysis can handle multiple parameters, although parametric analysis often focuses on one at a time for clarity.
B. Sensitivity analysis typically investigates the impact of small changes in parameters to determine the robustness of the optimal solution. Parametric analysis, on the other hand, systematically studies the effect of larger, controlled changes in one or more parameters, often by introducing a parameter into the model and analyzing the solution as the parameter varies over a range of values.
C. Both sensitivity and parametric analysis can examine changes in both the objective function and the constraints.
D. Both sensitivity and parametric analysis can utilize either the primal or dual simplex method, depending on the specific analysis being performed.
E. Both sensitivity and parametric analysis are quantitative methods; they involve numerical calculations and analysis.
