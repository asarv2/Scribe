\item Why is it necessary to introduce slack variables in the simplex method when dealing with inequality constraints?%
\begin{enumerate}%
\item \incorrect{Boundedness is a property of the problem itself, not something ensured by slack variables.  The simplex method can handle both bounded and unbounded problems.}%
\item Slack variables transform inequality constraints ($≤$) into equality constraints ($=$), a requirement for the simplex method's iterative process of moving between vertices of the feasible region.  The algorithm relies on this equality form to systematically explore the solution space.%
\item \incorrect{Slack variables do not directly simplify the objective function; they modify the constraints.}%
\item \incorrect{Slack variables don't guarantee feasibility; they are a tool used *after* the problem is formulated to make it solvable by the simplex method.  Feasibility is a property of the constraints themselves.}%
\item \incorrect{Slack variables *increase* the number of variables in the problem, not reduce them.}%
\end{enumerate}%
\vspace{1em}%
\item In the simplex method, what is the significance of the objective function's coefficients in determining the pivot column?%
\begin{enumerate}%
\item \incorrect{Feasibility is determined by the constraints, not the objective function coefficients.}%
\item The coefficients in the objective function guide the selection of the pivot column.  The column with the most positive coefficient (in maximization problems) indicates the variable whose increase will lead to the greatest improvement in the objective function value. This directs the algorithm's movement towards a better solution within the feasible region.%
\item \incorrect{The coefficients contribute to finding the optimal solution, but they don't determine it directly; the simplex method iteratively improves the solution.}%
\item \incorrect{The coefficients are crucial for selecting the pivot column, which is a fundamental step in the simplex method.}%
\item \incorrect{The number of iterations depends on the problem's structure and the algorithm's path, not solely on the objective function coefficients.}%
\end{enumerate}%
\vspace{1em}%
\item What is the role of the ratio test in the simplex method?%
\begin{enumerate}%
\item \incorrect{The entering variable is selected based on the objective function coefficients (in maximization problems, the most positive coefficient).}%

\item \incorrect{While the ratio test can indirectly help detect unboundedness (if no positive ratios exist), its primary purpose is to find the leaving variable.}%
\item \incorrect{Feasibility is maintained by the ratio test, but it's not the test's sole purpose; it's about selecting the leaving variable to maintain feasibility.}%
\item \incorrect{The optimal value is determined only after the simplex method has completed all iterations.}%
\end{enumerate}%
