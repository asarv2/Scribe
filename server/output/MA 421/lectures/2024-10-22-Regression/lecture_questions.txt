QUESTION 2

B. The linear program formulation allows for the use of efficient and robust linear programming algorithms to find the optimal solution, offering scalability and guaranteed optimality.

ANSWER: B

EXPLANATION:

These algorithms are highly optimized and can efficiently solve large-scale problems, guaranteeing an optimal solution.  Other methods might be faster for very small datasets, but they lack the scalability and optimality guarantees of linear programming.
C. The opposite is true. Linear programming solvers are designed to handle large datasets efficiently.
D. Linear programming provides the exact optimal solution, not an approximation.
E. Linear programming solvers are generally efficient and can handle large problems effectively.  While the initial formulation might seem more complex, the computational cost is often lower than other methods for larger datasets due to the efficiency of the solvers.

A. The $L^\infty$ regression minimizes the sum of squared errors, while $L^1$ and $L^2$ minimize the sum of absolute errors.
B. The $L^\infty$ regression minimizes the maximum absolute error, unlike $L^1$ and $L^2$ which focus on the sum of errors.
C. The $L^\infty$ regression is not suitable for linear programming formulation.
D. The $L^\infty$ regression is equivalent to $L^1$ regression when the data is normally distributed.

ANSWER: B

EXPLANATION:
A. This statement incorrectly swaps the characteristics of $L^2$ and $L^1$ regression.
B. The core difference is that $L^\infty$ regression aims to minimize the largest absolute error, a minimax approach.  $L^1$ and $L^2$ minimize the sum of absolute or squared errors, respectively.  In the linear program formulation, this difference is reflected in the objective function: $L^\infty$ minimizes a single slack variable representing the maximum error, while $L^1$ and $L^2$ minimize the sum of slack variables or a quadratic function of errors.
C. The $L^\infty$ regression can be effectively formulated as a linear program, as shown in the slides.
D. There's no such equivalence between $L^1$ and $L^\infty$ regression, regardless of data distribution.
E. The computational cost depends on the solver and the size of the problem.  The linear programming formulations of all three allow for efficient solution using specialized solvers.
