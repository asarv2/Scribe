L^2 \text{-Regression (Least Square)} \\
\min_{(x_1, \dots, x_n)} \sum_i \left[ \left( b_i - \sum_j a_{ij} x_j \right)^2 \right] \\

A^T A \hat{X} = A^T b \quad (\text{normal equation, always solvable}) \\

</LATEX>

<FIGURE [50.0, 50.0, 450.0, 450.0]>Handwritten notes showing the least squares regression problem and its solution. The title "L<sup>2</sup>-Regression (Least Square)" is underlined in red. The problem is formulated as minimizing the sum of squared errors, which is equivalent to minimizing the L2 norm of the residual vector $b - AX$. The normal equation $A^T A \hat{X} = A^T b$ is derived, which always has a solution if $(A^T A)^{-1}$ exists. The solution $\hat{X} = (A^T A)^{-1} A^T b$ is given. <DESCRIPTION>Slide 4 of 22 presents the least squares regression problem in the context of a linear programming course.  The slide begins by defining the problem as minimizing the sum of squared errors: $\min_{(x_1, \dots, x_n)} \sum_i \left[ \left( b_i - \sum_j a_{ij} x_j \right)^2 \right]$, where $b_i$ represents the observed values, $a_{ij}$ represents the attributes, and $x_j$ are the parameters to be estimated. This is equivalently expressed in matrix notation as $\min_X ||b - AX||_2^2$, where $b$ is a vector of observed values, $A$ is a matrix of attributes, and $X$ is a vector of parameters. The slide then shows that the system of equations $AX = b$ might not be solvable, leading to the derivation of the normal equation $A^T A \hat{X} = A^T b$, which always has a solution if the matrix $A^T A$ is invertible.  The solution is then given as $\hat{X} = (A^T A)^{-1} A^T b$, provided that the inverse exists. The parenthetical comments highlight the solvability conditions. The context of linear programming is relevant because the least squares problem can be formulated as a quadratic programming problem, a close relative of linear programming.  The slide lays the groundwork for later discussions on how linear programming techniques can be applied to solve or approximate solutions to least squares problems, especially in cases where the matrix $A^T A$ is not invertible or ill-conditioned.</DESCRIPTION>

<DESCRIPTION>Slide 5 of 22 introduces L1 regression, a type of regression analysis that minimizes the sum of the absolute differences between the observed and predicted values.  The slide first presents the problem as minimizing the L1 norm of the residual vector: $\min_X ||b - AX||_1$, where $b$ is the vector of observed values, $A$ is the matrix of attributes, and $X$ is the vector of parameters to be estimated.  This is equivalent to minimizing the sum of absolute errors: $\min_{(x_1, \dots, x_n)} \sum_i |b_i - \sum_j a_{ij} x_j|$.  The slide then shows how this problem can be reformulated as a linear program by introducing slack variables $t_i$ for each data point. The objective function becomes $\min_i \sum_{i=1}^m t_i$, and the constraints are $-t_i \le b_i - \sum_j a_{ij} x_j \le t_i$, which ensures that each $t_i$ is greater than or equal to the absolute error $|b_i - \sum_j a_{ij} x_j|$.  This reformulation is crucial because it allows the use of linear programming techniques to solve the L1 regression problem. The arrow points to the constraint that is derived from the absolute value. The context of the course (Linear Programming) is essential here, as the slide demonstrates how a seemingly non-linear problem (L1 regression) can be transformed into a linear program, making it solvable using linear programming algorithms.</DESCRIPTION>
