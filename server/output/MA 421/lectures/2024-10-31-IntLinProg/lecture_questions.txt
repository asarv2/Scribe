B. $x_1 = 0, x_2 = 5$

ANSWER: C

EXPLANATION:

D. This is a feasible solution to the relaxed LP problem, but not the optimal one.
E. This is a feasible integer solution, but not the optimal solution to the relaxed LP problem.


QUESTION 2
In the context of integer programming, why is simply solving the relaxed linear program (ignoring the integrality constraints) and then rounding the solution not a reliable method?
A. Rounding always yields an infeasible solution.
B. Rounding is computationally expensive and impractical for large problems.
C. The rounded solution may be infeasible, and the true optimal integer solution may be far from the rounded solution.
D. Rounding introduces significant errors that cannot be corrected.
E. Rounding only works for specific types of integer programming problems.

ANSWER: C

EXPLANATION:
A. Answer A is incorrect. While rounding can lead to an infeasible solution, it's not guaranteed.  The rounded solution might be feasible but suboptimal.
B. Answer B is incorrect. Rounding itself is a simple operation, but the problem lies in the fact that the rounded solution may not be optimal or even feasible.
C. Answer C is correct.  Rounding the solution of the relaxed linear program can lead to a solution that violates the constraints (infeasible) and, more importantly, the optimal integer solution can be significantly different from the rounded solution, resulting in a suboptimal solution.
D. Answer D is incorrect. While rounding can introduce errors, the primary issue is the potential for infeasibility and suboptimality, not just the magnitude of the error.
E. Answer E is incorrect. Rounding is unreliable regardless of the specific type of integer programming problem.


QUESTION 3
In the branch-and-bound algorithm, what is the purpose of "branching," and how does it contribute to finding the optimal integer solution?
A. Branching divides the problem into smaller, independent subproblems that can be solved in parallel.
B. Branching systematically explores the feasible region by adding constraints that partition the solution space, eliminating non-integer solutions.
C. Branching helps to improve the efficiency of the simplex method by reducing the number of iterations required.
D. Branching is a heuristic technique that attempts to find a good, but not necessarily optimal, integer solution.
E. Branching is used to convert an integer programming problem into a linear programming problem.

ANSWER: B

EXPLANATION:
A. Answer A is incorrect. While subproblems can be solved independently, the core purpose of branching is to systematically explore the solution space, not just to enable parallel processing.
B. Answer B is correct. Branching creates subproblems by adding constraints that partition the feasible region, systematically exploring the solution space and eliminating regions that do not contain integer solutions. This process continues until an optimal integer solution is found.
C. Answer C is incorrect. Branching doesn't directly improve the simplex method's efficiency; it's a technique used in conjunction with the simplex method (or other LP solvers) to solve integer programs.
D. Answer D is incorrect. Branch-and-bound is an exact algorithm, guaranteeing an optimal integer solution (if one exists) given sufficient computational resources.
E. Answer E is incorrect. Branching is used to solve integer programs, not to convert them into linear programs.  It works with the linear programming relaxation.


QUESTION 4
In the Gomory cut method, how does the generation of a cut help in finding an integer optimal solution, and what is the key property of the cut that ensures it doesn't eliminate any feasible integer solutions?
A. The cut is a hyperplane that separates the current non-integer optimal solution from the convex hull of integer feasible solutions.
B. The cut is a random hyperplane that is likely to eliminate non-integer solutions while preserving integer solutions.
C. The cut is a heuristic that attempts to eliminate non-integer solutions, but it may also eliminate some integer solutions.
D. The cut is derived from the dual problem and helps to improve the dual feasibility of the relaxed linear program.
E. The cut is a constraint that is only added if the current solution is already integer feasible.

ANSWER: A

EXPLANATION:
A. Answer A is correct.  Gomory cuts are carefully constructed to cut off the current non-integer optimal solution of the relaxed LP problem while preserving all integer feasible solutions.  The cut is a hyperplane that separates the non-integer solution from the convex hull of integer feasible solutions.
B. Answer B is incorrect. Gomory cuts are not random; they are systematically derived from the fractional parts of the optimal solution to the relaxed linear program.
C. Answer C is incorrect. Gomory cuts are not heuristic; they are designed to guarantee that no feasible integer solutions are eliminated.
D. Answer D is incorrect. Gomory cuts are derived from the primal problem's optimal simplex tableau, not the dual problem.
E. Answer E is incorrect. Gomory cuts are added precisely when the current solution is not integer feasible.

Furthermore, even if the rounded solution is feasible, the true optimal integer solution might be significantly different, leading to a suboptimal result.  Slides 2 and 4 illustrate this point.

D. Answer D is incorrect. While rounding can introduce errors, the primary reason for its unreliability is the potential for infeasibility and suboptimality.
E. Answer E is incorrect. The solution to the relaxed linear programming problem provides a valuable upper bound (for maximization problems) and is crucial for algorithms like branch and bound.
