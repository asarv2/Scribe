QUESTION 1
In the context of minimum-cost network flow problems, what is the significance of the rank of the incidence matrix A, and how does this relate to the number of independent flow conservation constraints?
A. The rank of A is always equal to the number of nodes in the network, implying that all flow conservation constraints are independent.
B. The rank of A is always equal to the number of arcs in the network, implying that all flow conservation constraints are independent.
C. The rank of A is one less than the number of nodes, indicating that there is one redundant flow conservation constraint.
D. The rank of A is one less than the number of arcs, indicating that there is one redundant flow conservation constraint.
E. The rank of A is always full rank, regardless of the network structure, implying that all flow conservation constraints are independent.

ANSWER: C

EXPLANATION:
A. Incorrect. The sum of rows in A is always zero, meaning there's at least one redundant constraint.
B. Incorrect. The rank is related to the number of nodes, not arcs.
C. The rank of the incidence matrix A is $m - 1$, where $m$ is the number of nodes. This is because the sum of all rows of A is a zero vector, indicating linear dependence among the rows. Therefore, only $m - 1$ of the flow conservation constraints are independent.
D. Incorrect. The redundancy is related to the number of nodes, not arcs.
E. Incorrect. The incidence matrix is always singular (non-full rank) for connected networks.


QUESTION 2
Explain how the complementary slackness condition is applied in the context of minimum-cost network flow problems, and how it relates to the primal and dual solutions.
A. Complementary slackness states that for any optimal primal solution, all dual slack variables must be zero.
B. Complementary slackness states that for any optimal dual solution, all primal variables must be zero.
C. Complementary slackness implies that for each arc, either the primal flow is zero or the dual slack variable is zero (or both).
D. Complementary slackness is not applicable to network flow problems because they are always feasible.
E. Complementary slackness implies that the sum of primal flows must equal the sum of dual variables.

ANSWER: C

EXPLANATION:
A. Incorrect.  It's not that *all* dual slacks are zero, but rather that for each arc, either the primal flow or the dual slack is zero.
B. Incorrect.  It's not that *all* primal variables are zero, but rather that for each arc, either the primal flow or the dual slack is zero.
C. In network flow problems, complementary slackness states that for each arc $(i, j)$, the product of the primal flow $x_{ij}$ and the dual slack variable $z_{ij}$ is zero: $x_{ij}z_{ij} = 0$. This means that if there is a positive flow on an arc ($x_{ij} > 0$), then the dual slack must be zero ($z_{ij} = 0$), and vice versa. This condition is crucial for verifying the optimality of a solution.
D. Incorrect. Complementary slackness is a fundamental concept in linear programming and applies to network flow problems as well.
E. Incorrect. Complementary slackness relates individual primal and dual variables on each arc, not their sums.


QUESTION 3
In a minimum-cost network flow problem, how is the initial basic feasible solution typically obtained using a spanning tree, and what is the significance of this approach?
A. The initial solution is obtained by setting all arc flows to zero, regardless of the network structure.
B. The initial solution is obtained by arbitrarily assigning flows to arcs until flow conservation is satisfied.
C. The initial solution is obtained by finding a spanning tree and setting flows on arcs in the tree to satisfy flow conservation, while setting flows on arcs outside the tree to zero.
D. The initial solution is obtained by solving the dual problem first and then using complementary slackness to find the primal flows.
E. The initial solution is obtained by using a random number generator to assign flows to each arc.

ANSWER: C

EXPLANATION:
A. Incorrect. This is not a feasible solution in general, as it may not satisfy flow conservation.
B. Incorrect. This approach is not systematic and may not lead to a basic feasible solution.
C. A spanning tree is a subgraph that connects all nodes without forming cycles.  By selecting a spanning tree, we can set the flows on the arcs in the tree to satisfy the flow conservation constraints at each node.  The flows on arcs not in the tree are set to zero. This provides a basic feasible solution, which can then be improved using the simplex method or other optimization algorithms.
D. Incorrect. While the dual problem can provide information, the initial basic feasible solution is typically found directly in the primal space using a spanning tree.
E. Incorrect. A random approach is not guaranteed to produce a feasible solution, let alone a basic one.


QUESTION 4
Suppose you have a minimum-cost network flow problem formulated as a linear program.  After solving the dual problem, you find that some dual slack variables are negative. What does this indicate about the current primal solution, and what method could be used to improve it?
A. The primal solution is optimal because the dual problem is feasible.
B. The primal solution is infeasible, and a Phase I method is needed.
C. The primal solution is not optimal, and the primal simplex method can be used to improve it.
D. The primal solution is unbounded, and the problem has no solution.
E. The primal solution is optimal, but the dual solution is not.

ANSWER: C

EXPLANATION:
A. Incorrect. Dual feasibility is a necessary but not sufficient condition for primal optimality. Negative dual slacks indicate that the primal solution can be improved.
B. Incorrect.  Negative dual slacks indicate non-optimality, not infeasibility.  A Phase I method is used to find an initial feasible solution, not to improve a non-optimal solution.
C. Negative dual slack variables indicate that the current primal solution is not optimal.  The primal simplex method can be applied to iteratively improve the solution by moving to adjacent basic feasible solutions until all dual slacks are non-negative (dual feasibility), which guarantees primal optimality.
D. Incorrect.  Negative dual slacks indicate non-optimality, not unboundedness.  Unboundedness occurs when the primal objective function can be made arbitrarily small.
E. Incorrect.  If the primal solution is optimal, then the dual solution must also be optimal, and all dual slacks must be non-negative.

ANSWER: D

EXPLANATION:

This approach ensures a basic feasible solution (a solution with at most $m-1$ non-zero flows, where $m$ is the number of nodes) that can be used as a starting point for optimization algorithms.

B. $n$
C. $m-1$
D. $n-1$

ANSWER: C

EXPLANATION:
A. Incorrect. The rank is not $m$ because the rows of the incidence matrix are linearly dependent. The sum of all rows is the zero vector.
B. Incorrect. The rank is not $n$ because the number of arcs ($n$) is not directly related to the number of independent flow conservation constraints.
C. The rank of the incidence matrix $A$ is $m-1$. This is because the sum of all rows of $A$ is a zero vector, indicating linear dependence among the rows. Therefore, only $m-1$ rows are linearly independent, representing $m-1$ independent flow conservation constraints.  One constraint is redundant because the total inflow must equal the total outflow in the network.
D. Incorrect. The rank is not $n-1$. While $n-1$ arcs form a spanning tree, the rank is determined by the number of nodes and the linear dependence of the rows.
E. Incorrect. The rank is not $m+n$. The rank is determined by the linear independence of the rows of the incidence matrix, which is related to the number of nodes, not the sum of nodes and arcs.
