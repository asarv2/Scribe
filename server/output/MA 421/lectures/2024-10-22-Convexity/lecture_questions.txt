QUESTION 1
What is the significance of the convexity of a set in the context of linear programming?
A. Convexity ensures the existence of a unique optimal solution.
B. Convexity guarantees that any local optimum is also a global optimum.
C. Convexity is not relevant to linear programming; it's only important in nonlinear programming.
D. Convexity simplifies the problem but is not essential for finding an optimal solution.
E. Convexity is a necessary condition for the application of many linear programming algorithms, ensuring the existence of an optimal solution within the feasible region.

ANSWER: B

EXPLANATION:
A. While convexity often leads to a unique optimal solution, it's not a strict requirement.  Multiple optimal solutions can exist in a convex feasible region.
B. A convex feasible region guarantees that any local optimum is also a global optimum. This is a crucial property exploited by linear programming algorithms, which often search for local optima and rely on this property to ensure they have found the global optimum.
C. Convexity is fundamental to linear programming. The feasible region of a linear program is always a convex set.  This property is essential for the correctness and efficiency of many algorithms used to solve linear programs.
D. Convexity is not merely a simplification; it's a fundamental property that underpins the theoretical foundation and algorithmic approaches of linear programming.  Without convexity, many algorithms would not be guaranteed to find an optimal solution.
E. While convexity is important for the existence of an optimal solution, it is not a necessary condition for the application of *all* linear programming algorithms.  Some algorithms might still find a solution even in non-convex cases, but they may not guarantee finding the global optimum.

B. A convex combination is a weighted average of points, with non-negative weights that sum to one.  This definition is directly tied to the definition of a convex set: a set is convex if and only if it contains all convex combinations of its points. This is a fundamental concept in convex analysis.
C. A convex combination can be formed from points whether or not they are in a convex set. The definition of a convex combination is independent of the concept of a convex set.
D. Convex combinations are not just for proving theorems; they are a fundamental concept in defining and understanding convex sets and their properties.
E. The coefficients in a convex combination must sum to one, not zero.


QUESTION 3

D. Carathéodory's Theorem is unrelated to the representation of points in the convex hull.
E. Every point in the convex hull can be expressed as a convex combination of infinitely many points from the set.

ANSWER: B

EXPLANATION:

B. Carathéodory's Theorem states that any point in the convex hull of a set in $\mathbb{R}^m$ can be expressed as a convex combination of at most $m+1$ points from the original set. This is a powerful result that limits the number of points needed for representation.
C. This is incorrect; it's not necessary to use all points in the set.  Carathéodory's Theorem provides a much more efficient representation.
D. Carathéodory's Theorem is precisely about the representation of points in the convex hull.

QUESTION 5
Explain the concept of a convex set and provide a real-world example that is not a geometric shape.
A. A convex set is a set where any line segment connecting two points within the set is entirely contained within the set.  Example: The set of all possible portfolios with a given risk tolerance.
B. A convex set is a set that is always symmetrical around its center. Example: A perfectly round ball.
C. A convex set is a set where the sum of any two points in the set is also in the set. Example: The set of all positive real numbers.
D. A convex set is a set that can be enclosed by a circle. Example: A set of points forming a circle.
E. A convex set is a set that is always connected. Example: A line segment.

ANSWER: A

EXPLANATION:
A. A convex set is correctly defined, and the portfolio example is a valid non-geometric illustration.  Different combinations of assets within a given risk tolerance will always result in a portfolio that also falls within that risk tolerance.
B. This describes a specific type of convex set (symmetrical), but not all convex sets are symmetrical.  A triangle is a convex set but not symmetrical.
C. This is incorrect; the sum of two points is not the defining characteristic of a convex set.  Consider a triangle; the sum of two vertices is generally outside the triangle.
D. This is incorrect; a convex set does not need to be enclosed by a circle.  A square is a convex set, but it cannot be enclosed by a circle that only touches its vertices.
E. Connectedness is not sufficient for convexity.  A horseshoe shape is connected but not convex.


QUESTION 6
A set $S \subseteq \mathbb{R}^m$ is convex if for any $z_1, z_2 \in S$, what condition must hold for $tz_1 + (1-t)z_2$?
A. $tz_1 + (1-t)z_2 \in S$ for all $t \in \mathbb{R}$
B. $tz_1 + (1-t)z_2 \in S$ for all $0 \le t \le 1$
C. $tz_1 + (1-t)z_2 \in S$ for some $0 \le t \le 1$
D. $tz_1 + (1-t)z_2 \in S$ for all $t > 1$
E. $tz_1 + (1-t)z_2 \in S$ only if $t = 0.5$

ANSWER: B

EXPLANATION:
A. Answer A is incorrect.  The condition must hold only for $0 \le t \le 1$, representing the line segment between the two points.  Extending it to all real numbers $t$ would include points outside the line segment.
B. Answer B is correct. This is the definition of a convex set:  the line segment connecting any two points in the set must also be entirely within the set.  The condition $0 \le t \le 1$ ensures that we are considering only points on the line segment between $z_1$ and $z_2$.
C. Answer C is incorrect. The condition must hold for \textit{all} $t$ in the interval $[0, 1]$, not just for some $t$ in that interval.
D. Answer D is incorrect. The condition only applies to the line segment between $z_1$ and $z_2$, which is defined by $0 \le t \le 1$.
E. Answer E is incorrect. The condition must hold for all $t$ in the interval $[0, 1]$, not just for $t = 0.5$.

C. Convexity is not relevant to linear programming; it is a concept used only in nonlinear optimization.
D. Convexity simplifies the search for an optimal solution by ensuring that the feasible region is a connected set.
E. Convexity is a necessary condition for the existence of a dual problem, but it is not directly related to the feasible region of the primal problem.

ANSWER: B

EXPLANATION:
A. Answer A is incorrect. While convexity is related to the properties of the feasible region, it does not guarantee boundedness. A linear program can have an unbounded feasible region and still have an optimal solution (or be unbounded).
B. Answer B is correct.  The feasible region of a linear program is always a convex set.  This crucial property ensures that any local optimum found within the feasible region is also a global optimum.  This simplifies the search for an optimal solution because we don't need to worry about getting stuck in local optima that are not global optima.
