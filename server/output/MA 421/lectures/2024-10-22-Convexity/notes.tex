\underline{Separation Theorem} \\
\textbf{THEOREM 10.4.} Let $P$ and $\widetilde{P}$ be two disjoint nonempty polyhedra in $\mathbb{R}^n$. Then \\
there exist disjoint half-spaces $H$ and $\widetilde{H}$ such that $P \subset H$ and $\widetilde{P} \subset \widetilde{H}$. \\
$P \ne \emptyset \quad P = \{x : Ax \le b \}, \quad \widetilde{P} = \{x : \widetilde{A}x \le \widetilde{b} \} $ \\
$P \cap \widetilde{P} = \emptyset \iff \begin{cases} Ax \le b \\ \widetilde{A}x \le \widetilde{b} \end{cases} \text{ has no solution} \\
\iff \text{There is a } y, \widetilde{y} \text{ s.t.} \\
\quad y^T A + \widetilde{y}^T \widetilde{A} = 0 \\
\quad y^T b + \widetilde{y}^T \widetilde{b} < 0 \\
\quad y, \widetilde{y} \ge 0 \\
(\text{Farka's Lemma})
%
\subsection{Description}%
This slide continues the discussion of the Separation Theorem (Theorem 10.4) and introduces Farka's Lemma.  It states that two disjoint nonempty polyhedra $P$ and $\widetilde{P}$ (defined by systems of linear inequalities $Ax \le b$ and $\widetilde{A}x \le \widetilde{b}$, respectively) can be separated by disjoint half-spaces if and only if the combined system of inequalities has no solution. This condition is then connected to Farka's Lemma, which provides an alternative way to express the infeasibility of the combined system. Farka's Lemma states that the system has no solution if and only if there exist vectors $y$ and $\widetilde{y}$ (both non-negative) such that $y^TA + \widetilde{y}^T\widetilde{A} = 0$ and $y^Tb + \widetilde{y}^T\widetilde{b} < 0$.  The notation $\widetilde{P}$ and $\widetilde{H}$ represents the second polyhedron and half-space, respectively. The double-headed arrow signifies the "if and only if" condition. The context of linear programming is essential here, as Farka's Lemma is a key result in duality theory and provides a certificate of infeasibility for systems of linear inequalities.%

\textit{Farkas' Lemma} \\
LEMMA 10.5. The system $Ax \le b$ has no solutions if and only if there is a $y$ such \\
that
\begin{align*} \label{eq:10.8} \tag{10.8} A^T y = 0 \\ y \ge 0 \\ b^T y < 0. \end{align*} \\
PROOF. Consider the linear program
\begin{align*} \text{maximize} \quad &0 \\ \text{subject to} \quad &Ax \le b \end{align*}
and its dual
\begin{align*} \text{minimize} \quad &b^T y \\ \text{subject to} \quad &A^T y = 0 \\ &y \ge 0. \end{align*}
%
\subsection{Description}%
This slide presents Farka's Lemma (Lemma 10.5) and the beginning of its proof. Farka's Lemma states that the system $Ax \le b$ has no solution if and only if there exists a vector $y$ such that $A^Ty = 0$, $y \ge 0$, and $b^Ty < 0$. The proof begins by considering a linear program with the objective function equal to 0 and the constraint $Ax \le b$.  The slide then presents the dual of this linear program. The dual program aims to minimize $b^Ty$ subject to $A^Ty = 0$ and $y \ge 0$. The context of linear programming is crucial here, as Farka's Lemma is a fundamental result in duality theory and provides a certificate of infeasibility for systems of linear inequalities. The proof connects the infeasibility of the primal problem ($Ax \le b$) to the properties of its dual.%
