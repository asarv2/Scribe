The term $E[\sum_j x_j \tilde{R_j}]$ represents the expected value of the portfolio's fluctuation, which is a measure of risk.  The parameter $\mu$ is a risk aversion parameter, balancing the trade-off between expected return and risk.  While the objective function involves expectations and random variables, the problem can be formulated as a quadratic program (a generalization of linear programming) by using the covariance matrix of the returns.
