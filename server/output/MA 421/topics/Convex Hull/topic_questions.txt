QUESTION 1
In the context of the B&N method, what is the primary motivation for transforming a general linear program into a form with only equality constraints and non-negativity restrictions on the variables?
A. To simplify the application of the simplex method.
B. To facilitate the derivation of the dual problem using the Lagrangian.
C. To ensure the feasibility of the primal problem.
D. To guarantee the uniqueness of the optimal solution.
E. To reduce the computational complexity of the problem.

ANSWER: B

EXPLANATION:
A. While the simplex method can be applied, this isn't the primary motivation of the transformation in the B&N method.
B. The B&N method uses the Lagrangian to derive the dual.  Having only equality constraints simplifies this process significantly.
C. The transformation doesn't inherently guarantee feasibility; feasibility is a separate concern.
D. The transformation doesn't guarantee uniqueness; multiple optimal solutions can still exist.
E. The transformation might reduce complexity in some cases, but it's not the primary goal of the B&N method.


QUESTION 2
In the B&N method, why is the Lagrangian function introduced, and what role does it play in deriving the dual problem?
A. The Lagrangian is used to find an initial feasible solution.
B. The Lagrangian simplifies the objective function.
C. The Lagrangian transforms the constrained primal problem into an unconstrained problem, allowing for easier derivation of the dual.
D. The Lagrangian is necessary to ensure the primal problem is convex.
E. The Lagrangian is used to prove the strong duality theorem.

ANSWER: C

EXPLANATION:
A. Finding an initial feasible solution is a separate concern, not the role of the Lagrangian in the B&N method.
B. The Lagrangian doesn't simplify the objective function; it incorporates the constraints into the objective function.
C. The Lagrangian is the key tool in the B&N method. By removing the constraints, it allows for a straightforward derivation of the dual problem.
D. Convexity is important in linear programming, but the Lagrangian's role in the B&N method is not directly related to ensuring convexity.
E. The Lagrangian is used in the derivation of the dual, but it doesn't directly prove strong duality.


QUESTION 3
What is the significance of the weak duality theorem in the context of the B&N method, and how does it relate to the optimal solutions of the primal and dual problems?
A. Weak duality guarantees the existence of an optimal solution for both the primal and dual problems.

QUESTION 4
Explain the concept of a convex hull and how it relates to the feasible region of a linear programming problem.
A. The convex hull is the smallest convex set containing all points in a given set; in linear programming, the feasible region is always a convex hull.
B. The convex hull is the largest convex set contained within a given set; the feasible region of a linear program is always a subset of its convex hull.
C. The convex hull is a non-convex set formed by connecting all points in a given set; the feasible region of a linear program is never a convex hull.
D. The convex hull is a set of points that are not necessarily connected; the feasible region of a linear program is sometimes a convex hull.
E. The convex hull is irrelevant to the feasible region of a linear programming problem.

ANSWER: A

EXPLANATION:
A. The convex hull of a set of points is the smallest convex set that contains all the points.  In linear programming, the feasible region, defined by the intersection of linear constraints, is always a convex set. Therefore, the feasible region is either itself a convex hull (if it's a polygon) or is contained within a larger convex hull that includes points outside the feasible region.
B. The convex hull is the *smallest*, not largest, convex set containing all points. The feasible region is a subset of its convex hull only if the feasible region is not itself a convex hull (e.g., if it's a bounded region).
C. A convex hull is, by definition, a convex set. The feasible region of a linear program is always a convex set.
D. The points in a convex hull are connected to form a convex set. The feasible region of a linear program is always a convex set.
E. The convex hull is fundamental to understanding the feasible region in linear programming because the feasible region is always a convex set.


QUESTION 5
Given the points $A=(1,1)$, $B=(3,1)$, $C=(2,3)$, and $D=(0,0)$ in $\mathbb{R}^2$, which of the following points is NOT in the convex hull of $\{A, B, C, D\}$?
A. $(1.5, 1)$
B. $(1, 2)$
C. $(2, 2)$
D. $(1, 0.5)$
E. $(2.5, 1.5)$

ANSWER: B

EXPLANATION:
A. $(1.5, 1)$ is the midpoint of AB, which is clearly in the convex hull.
B. The point (1,2) is not in the convex hull.  The convex hull is the smallest convex set containing all the points.  While (1,2) is above the line segment AC, it is not within the polygon formed by A, B, C, and D.
C. $(2, 2)$ is inside the quadrilateral ABCD, thus within the convex hull.
D. $(1, 0.5)$ lies on the line segment AD, and is therefore in the convex hull.
E. $(2.5, 1.5)$ lies inside the quadrilateral ABCD, thus within the convex hull.

QUESTION 9
What is the fundamental characteristic of a convex set, and how does this property relate to the feasible region in linear programming problems?
A. A convex set is a set where any line segment connecting two points within the set is entirely contained within the set.  This is crucial in linear programming because the feasible region is always a convex set, ensuring that any convex combination of feasible solutions is also feasible.
B. A convex set is a set that can be enclosed by a circle. This is important in linear programming because it simplifies the search for an optimal solution.
C. A convex set is a set with only straight lines as boundaries. This is relevant in linear programming because linear constraints define straight lines.
D. A convex set is a set that is always connected. This is important in linear programming because the feasible region must be a connected set.
E. A convex set is a set that contains its boundary. This is relevant in linear programming because the boundary of the feasible region is part of the feasible region.

ANSWER: A

EXPLANATION:
A. A convex set is defined as a set where any line segment connecting two points within the set is entirely contained within the set. This property is fundamental to linear programming because the feasible region of a linear program is always a convex set.  This convexity ensures that any weighted average (convex combination) of feasible solutions is also a feasible solution. This property is crucial for the development and analysis of algorithms that solve linear programming problems, as they often rely on the convexity of the feasible region to guarantee convergence to an optimal solution.
B. A convex set is not necessarily a set that can be enclosed by a circle.  Consider a convex polygon; it is a convex set but cannot always be enclosed by a circle. The shape of the feasible region is not restricted to being circular.
C. A convex set can have curved boundaries.  For example, a circle is a convex set, but its boundary is a curve. The feasible region can have curved boundaries in non-linear programming problems, but in linear programming, the boundaries are straight lines.
D. A convex set is not necessarily connected.  A disconnected set can still be convex if each of its connected components is convex.  The feasible region in linear programming is always a connected set.
E. A convex set does contain its boundary, but this is not the defining characteristic of a convex set. The defining characteristic is that the line segment between any two points in the set is also in the set.


QUESTION 10
Given the points $z_1 = (1, 2)$ and $z_2 = (3, 4)$ in $\mathbb{R}^2$, what is a convex combination of $z_1$ and $z_2$ where the resulting point has an x-coordinate of 2?
A. $2z_1 + 0z_2$
B. $0z_1 + 2z_2$
C. $0.5z_1 + 0.5z_2$
D. $0.25z_1 + 0.75z_2$
E. $0.75z_1 + 0.25z_2$

ANSWER: C

EXPLANATION:
A. This is not a convex combination because it does not use $z_2$.  A convex combination must use all points in the set.
B. This is not a convex combination because it does not use $z_1$. A convex combination must use all points in the set.
C. A convex combination is of the form $tz_1 + (1-t)z_2$ where $0 \le t \le 1$.  If the x-coordinate is 2, then $t(1) + (1-t)(3) = 2$, which simplifies to $t + 3 - 3t = 2$, so $-2t = -1$, and $t = 0.5$. Therefore, the convex combination is $0.5z_1 + 0.5z_2$.
D. This gives an x-coordinate of $0.25(1) + 0.75(3) = 2.5$, not 2.
E. This gives an x-coordinate of $0.75(1) + 0.25(3) = 1.5$, not 2.
