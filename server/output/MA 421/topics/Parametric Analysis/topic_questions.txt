QUESTION 1
In the context of parametric analysis, how does varying a single parameter in the objective function or constraints affect the optimal solution and the optimal objective function value, and how can this information be used to make better decisions?
A. Varying a parameter only affects the objective function value, not the optimal solution.
B. Varying a parameter can cause the optimal solution to change, but the objective function value remains constant.
C. Varying a parameter can lead to changes in both the optimal solution and the optimal objective function value, providing insights into the sensitivity of the solution to parameter changes.
D. Parametric analysis is only useful for objective function changes, not constraint changes.
E. Parametric analysis is not relevant to decision-making.

ANSWER: C

EXPLANATION:
A. Incorrect. Changes in parameters in the objective function or constraints can alter both the optimal solution and the objective function value.
B. Incorrect. Changes in parameters can affect both the optimal solution and the objective function value.
C. Parametric analysis systematically varies a parameter to observe its impact on the optimal solution and objective function value. This sensitivity analysis helps in understanding the robustness of the solution and making informed decisions under uncertainty.
D. Incorrect. Parametric analysis is applicable to both objective function and constraint parameter changes.
E. Incorrect. Parametric analysis provides crucial information for decision-making under uncertainty by revealing the sensitivity of the optimal solution to parameter variations.


QUESTION 2

A. Parametric analysis cannot handle multi-objective problems.
B. Parametric analysis can be used to systematically vary the weights assigned to different objectives in a weighted-sum approach, revealing the trade-offs between them.
C. Parametric analysis only considers one objective at a time.
D. Parametric analysis is only useful for single-objective problems.
E. Parametric analysis does not provide information about trade-offs.

ANSWER: B

EXPLANATION:
A. Incorrect; parametric analysis can be adapted to handle multi-objective problems, for example, by varying weights in a weighted-sum approach.
B. By treating the weights of different objectives as parameters, parametric analysis allows for the exploration of the Pareto frontier, revealing the trade-offs between objectives.
C. Incorrect; parametric analysis can simultaneously consider multiple objectives by varying parameters that affect their relative importance.
D. Incorrect; parametric analysis is a powerful tool for analyzing the sensitivity of solutions in both single and multi-objective problems.
E. Incorrect; the systematic variation of parameters in parametric analysis directly reveals the trade-offs between different objectives.
