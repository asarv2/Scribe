QUESTION 1
In the simplex method's matrix form, what does the matrix $A$ represent in the constraint inequality $Ax \le b$?
A. The vector of objective function coefficients.
B. The vector of constraint right-hand side values.
C. The matrix of technological coefficients representing resource consumption per unit of each variable.
D. The vector of decision variables.
E. The transpose of the constraint matrix.

ANSWER: C

EXPLANATION:
A. The objective function coefficients are represented by a separate vector, typically denoted as $c$ in the objective function $c^Tx$.
B. The right-hand side values of the constraints are represented by the vector $b$.
C. The matrix $A$ in $Ax \le b$ represents the technological coefficients. Each column corresponds to a variable, and each row corresponds to a constraint. The entries show how much of each resource is used per unit of each variable.
D. The decision variables are represented by the vector $x$.
E. The transpose of the constraint matrix, $A^T$, is used in the dual problem formulation, not the primal problem's constraint inequality.

QUESTION 9
In the context of the simplex method in matrix form, explain the significance of partitioning the constraint matrix A into basis matrix B and non-basis matrix N. How does this partitioning facilitate the iterative process of moving from one basic feasible solution to another?
A. The partitioning is merely a notational convenience and doesn't fundamentally affect the simplex method's iterative process.
B. The partitioning allows for the explicit representation of basic and non-basic variables, enabling efficient updates of the solution at each iteration.
C. The partitioning simplifies the calculation of the objective function value but doesn't directly impact the movement between basic feasible solutions.
D. The partitioning is necessary only for large-scale problems and is not relevant for smaller linear programs.
E. The partitioning is primarily used for theoretical analysis and doesn't significantly improve the computational efficiency of the simplex method.

ANSWER: B

EXPLANATION:
A. The partitioning is not merely a notational convenience; it is fundamental to the efficiency and structure of the matrix form of the simplex method.
B. The partitioning of matrix A into B and N is crucial because it allows us to explicitly represent the basic and non-basic variables.  The basic variables are those corresponding to the columns of B, and their values are directly determined by the current solution. The non-basic variables are those corresponding to the columns of N, and their values are set to zero.  This separation allows for efficient updates of the solution at each iteration of the simplex method.  We only need to update the values of the basic variables and the objective function value, which can be done using matrix operations involving B and N.  Moving from one basic feasible solution to another involves changing one basic variable for one non-basic variable, which is easily managed with this partitioning.
C. While the partitioning simplifies the calculation of the objective function value, its primary significance lies in its role in managing basic and non-basic variables and facilitating the iterative process of moving between basic feasible solutions.
D. The partitioning of the constraint matrix is a fundamental aspect of the simplex method, regardless of the problem's size.
E. The partitioning is essential for both theoretical analysis and computational efficiency of the simplex method.


QUESTION 10
In the simplex method's matrix form, given the primal problem in standard form:  Maximize $Z = c^Tx$ subject to $Ax \le b$, $x \ge 0$, and after introducing slack variables $s$, the equation becomes $Ax + s = b$. What does the matrix $A$ represent?
A. The vector of objective function coefficients.
B. The vector of constraint right-hand side values.
C. The matrix of technological coefficients representing the resource consumption per unit of each variable.
D. The vector of slack variables.
E. The identity matrix.

ANSWER: C

EXPLANATION:
A. Answer A is incorrect. The vector of objective function coefficients is represented by $c^T$.
B. Answer B is incorrect. The vector of constraint right-hand side values is represented by $b$.
C. Answer C is correct. The matrix A contains the technological coefficients, showing how much of each resource is used by each variable.
D. Answer D is incorrect. The vector of slack variables is represented by $s$.
E. Answer E is incorrect. The identity matrix is part of the augmented matrix after introducing slack variables, but A itself is not the identity matrix.
