QUESTION 1
In the context of weak duality, what is the relationship between the objective function values of the primal and dual problems?
A. The primal objective function value is always greater than or equal to the dual objective function value.
B. The primal objective function value is always less than or equal to the dual objective function value.
C. The primal and dual objective function values are always equal.
D. There is no relationship between the primal and dual objective function values.
E. The relationship between the primal and dual objective function values depends on the specific problem instance.

ANSWER: B

EXPLANATION:
A. This is incorrect. While it's true that the primal objective function value is greater than or equal to the dual objective function value at optimality (strong duality), this is not always the case for arbitrary feasible solutions. Weak duality only guarantees that the dual objective function value is a lower bound for the primal objective function value.
B. Weak duality states that the objective function value of any feasible solution to the dual problem is always less than or equal to the objective function value of any feasible solution to the primal problem.  This holds true regardless of whether the primal or dual problem is a maximization or minimization problem.
C. This is incorrect.  The primal and dual objective function values are only equal at optimality (strong duality), not for arbitrary feasible solutions. Weak duality only provides an inequality relationship.
D. This is incorrect. Weak duality establishes a specific relationship between the objective function values of the primal and dual problems.
E. This is incorrect. The relationship is consistent and defined by weak duality, regardless of the specific problem instance.


QUESTION 2
The Klee-Minty problem demonstrates that the simplex method can exhibit exponential time complexity in the worst case. What is the fundamental characteristic of the Klee-Minty problem that leads to this behavior?
A. The presence of many constraints.
B. The presence of many variables.
C. The highly skewed geometry of its feasible region.
D. The use of a specific pivot rule.
E. The use of a particular objective function.

ANSWER: C

EXPLANATION:
A. While the number of constraints can influence the runtime, it's not the fundamental reason for the exponential behavior in the Klee-Minty problem. The problem's structure, specifically the skewed geometry, is the key factor.
B. Similar to the number of constraints, the number of variables contributes to the problem's size, but the skewed geometry is the crucial element causing the exponential runtime.
C. The Klee-Minty problem's feasible region is a highly skewed polytope.  The simplex method, following certain pivot rules, can traverse a path along the boundary of this polytope that is exponentially long in the number of variables, leading to exponential time complexity.
D. While the choice of pivot rule affects the path taken by the simplex method, the inherent structure of the Klee-Minty problem's feasible region is the primary reason for its exponential complexity. Different pivot rules might lead to different paths, but the exponential length of the worst-case path is a property of the problem itself.
E. The objective function in the Klee-Minty problem is designed to interact with the skewed geometry of the feasible region to create the exponential path. However, the skewed geometry is the fundamental characteristic causing the exponential behavior.


QUESTION 3
What is the significance of weak duality in linear programming?
A. It guarantees the existence of an optimal solution.
B. It provides a bound on the optimal objective function value.
C. It ensures the uniqueness of the optimal solution.
D. It determines the choice of the pivot rule in the simplex method.
E. It is only relevant for problems with equality constraints.

ANSWER: B

EXPLANATION:
A. The existence of an optimal solution is not guaranteed by weak duality.  It's a separate concept related to the properties of the feasible region and the objective function.
B. Weak duality states that the objective function value of any feasible solution to the dual problem provides a lower bound (for maximization problems) or an upper bound (for minimization problems) for the optimal objective function value of the primal problem. This is significant because it allows us to assess the quality of feasible solutions without necessarily finding the optimal solution.
C. Weak duality does not address the uniqueness of the optimal solution. Uniqueness is a separate property that depends on the structure of the problem.
D. Weak duality is a theoretical concept that doesn't directly influence the choice of pivot rule in the simplex method. Pivot rules are algorithmic choices aimed at improving efficiency.
E. Weak duality applies to both problems with equality and inequality constraints. It's a fundamental relationship between primal and dual problems regardless of the type of constraints.


QUESTION 4
Empirical studies suggest that the average-case performance of the simplex method is polynomial.  What is the practical implication of this finding?
A. The simplex method is guaranteed to solve any linear program in polynomial time.
B. The simplex method is always faster than interior-point methods.
C. The simplex method is practically efficient for a wide range of real-world problems.
D. The worst-case exponential complexity of the simplex method is irrelevant.
E. All pivot rules for the simplex method have polynomial average-case complexity.

ANSWER: C

EXPLANATION:
A. This is incorrect.  The average-case performance being polynomial does not guarantee polynomial time for all instances. The Klee-Minty problem demonstrates that the worst-case complexity is exponential.
B. This is incorrect.  The relative efficiency of the simplex method and interior-point methods depends on the specific problem instance.  While the average-case complexity of the simplex method is polynomial, interior-point methods also have polynomial worst-case complexity.
C. The polynomial average-case complexity suggests that, in practice, the simplex method is efficient for most real-world linear programming problems.  While it has a worst-case exponential complexity, this worst-case scenario rarely occurs in practice.
D. This is incorrect.  While the worst-case scenario is rare, understanding the worst-case complexity is important for theoretical analysis and for identifying potential limitations.
E. This is incorrect.  The polynomial average-case complexity is observed for some pivot rules, but not all.  The Klee-Minty problem demonstrates that some pivot rules can lead to exponential time complexity in the worst case.

QUESTION 6

C. The dual problem has a finite optimal solution.
D. The dual problem is unbounded or infeasible.
E. There is no relationship between the primal and dual problems.

ANSWER: B

A. This is incorrect.  If the primal is unbounded, the dual must be infeasible.
B. If the primal problem is unbounded, meaning its objective function can be made arbitrarily large, then the dual problem must be infeasible. This is a direct consequence of weak duality ($Z \le W$), as an unbounded $Z$ would contradict a finite $W$.
C. This is incorrect.  If the primal is unbounded, the dual must be infeasible.
D. While the dual could be infeasible, it cannot be unbounded.  If the dual were unbounded, it would imply the primal is infeasible, which is not the case here.
