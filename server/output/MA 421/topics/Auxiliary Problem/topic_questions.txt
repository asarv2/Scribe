QUESTION 1
Why is the auxiliary problem necessary when the origin is not feasible in a linear programming problem?
A. The auxiliary problem provides a way to graphically solve the linear program.
B. The auxiliary problem transforms the problem into a dual problem, which is easier to solve.
C. The auxiliary problem ensures that the simplex method can start from a feasible solution.
D. The auxiliary problem simplifies the objective function, making it easier to optimize.
E. The auxiliary problem eliminates redundant constraints from the original problem.

ANSWER: C

EXPLANATION:
A. The auxiliary problem is an algebraic technique, not a graphical one.  Graphical methods are used for visualizing the feasible region but not directly for solving the auxiliary problem.
B. The auxiliary problem does not transform the problem into its dual. The dual problem is a different linear program related to the original one, but the auxiliary problem is a modification of the primal problem itself.
C. The auxiliary problem introduces a new variable and modifies the constraints to create a new problem that is always feasible, even if the original problem is not. This allows the simplex method, which requires a feasible starting point, to be applied.
D. The auxiliary problem's objective function is different from the original problem's objective function. It aims to find a feasible solution, not to directly simplify the original objective function.
E. The auxiliary problem does not eliminate constraints. It modifies the constraints to guarantee feasibility.


QUESTION 2
In the auxiliary problem, what is the significance of the optimal objective function value being zero?
A. It indicates that the auxiliary problem is unbounded.
B. It means the original problem is infeasible.
C. It implies that the original problem has a feasible solution.
D. It signifies that the auxiliary problem has multiple optimal solutions.
E. It suggests that the original problem's objective function is linear.

ANSWER: C

EXPLANATION:
A. An optimal objective function value of zero does not indicate unboundedness. Unboundedness means the objective function can be made arbitrarily large.
B. An optimal objective function value of zero indicates the opposite: that the original problem is feasible.  If the original problem were infeasible, the optimal value would be negative.
C. If the optimal value of the auxiliary problem is zero, it means that a feasible solution to the original problem exists, and the auxiliary variable $x_0$ can be set to zero, satisfying all constraints of the original problem.
D. While the auxiliary problem might have multiple optimal solutions, a zero optimal value specifically relates to the feasibility of the original problem.
E. The linearity of the original objective function is a given condition; the auxiliary problem's significance relates to feasibility, not the linearity of the objective function.


QUESTION 3
How does the auxiliary problem help in finding an initial feasible solution for the simplex method when the origin is infeasible?
A. It directly provides the optimal solution to the original problem.
B. It introduces a new variable that shifts the feasible region to include the origin.

D. It simplifies the constraints of the original problem, making it easier to find a feasible solution.
E. It changes the objective function to a linear function, making it easier to solve.

ANSWER: C

EXPLANATION:

B. The auxiliary problem doesn't shift the feasible region. It creates a new problem with a different feasible region that is guaranteed to contain a feasible solution.
C. The auxiliary problem modifies the constraints to guarantee a feasible solution, even if the original problem is infeasible.  The simplex method is then used to solve this modified problem, and the solution is used to find a feasible solution for the original problem.
D. The auxiliary problem doesn't simplify the constraints; it modifies them to ensure feasibility.
E. The objective function of the auxiliary problem is different from the original problem's objective function. The original problem's objective function's linearity is assumed.


QUESTION 4

D. A negative slack variable doesn't imply unboundedness. Unboundedness refers to an objective function that can increase infinitely.

QUESTION 5
Consider a linear programming problem where the origin (0,0) is not a feasible solution. Explain the purpose of the auxiliary problem in finding a feasible solution for the simplex method, and describe how the solution to the auxiliary problem helps in solving the original problem.
A. The auxiliary problem introduces artificial variables to convert inequality constraints into equalities, allowing the simplex method to proceed directly from the origin.
B. The auxiliary problem identifies redundant constraints in the original problem, simplifying it before applying the simplex method.
C. The auxiliary problem finds a feasible solution to the original problem by introducing a new objective function and constraints that guarantee feasibility, providing a starting point for the simplex method on the original problem.
D. The auxiliary problem computes the gradient of the objective function to determine the direction of steepest ascent, guiding the simplex method towards a feasible solution.
E. The auxiliary problem is used to check the feasibility of the original problem; if the origin is infeasible, the auxiliary problem is not needed.

ANSWER: C

EXPLANATION:
A. The auxiliary problem does not introduce artificial variables to convert inequalities to equalities.  Artificial variables are used in a different technique (two-phase method) to handle infeasibility, but the auxiliary problem's approach is different.
B. The auxiliary problem does not focus on identifying redundant constraints.  Redundant constraints are dealt with separately in pre-processing steps, not as part of the auxiliary problem's core function.
C. The auxiliary problem is designed to find a feasible solution for the original problem when the origin is infeasible. It does this by introducing a new objective function and constraints that guarantee feasibility.  The solution to this auxiliary problem then provides a starting point for the simplex method to be applied to the original problem.
D. The simplex method does not use gradient calculations. It's an iterative algorithm that moves from one feasible solution to another, improving the objective function at each step.
E. The auxiliary problem is precisely needed when the origin is infeasible.  It provides a way to find a feasible starting point for the simplex method.

QUESTION 8
Consider the auxiliary problem: max $\xi = -x_0$ subject to $w_1 = -1 + x_1 - x_2 + x_0$, $w_2 = -2 + x_1 + 2x_2 + x_0$, $w_3 = 1 - x_2 + x_0$, $x_1, x_2, x_0, w_1, w_2, w_3 \ge 0$. If we set $x_1 = x_2 = x_0 = 0$, which constraint is most violated?
A. $w_1 \ge 0$
B. $w_2 \ge 0$
C. $w_3 \ge 0$
D. All constraints are satisfied.
E. The objective function is maximized.

ANSWER: B

EXPLANATION:
A. While $w_1$ is negative, $w_2$ is more negative, indicating a greater violation.
B. With $x_1 = x_2 = x_0 = 0$, we have $w_1 = -1$, $w_2 = -2$, and $w_3 = 1$.  $w_2 = -2$ represents the most significant violation of the non-negativity constraint.
C. $w_3$ is positive and satisfies the constraint.
D. The constraints $w_1 \ge 0$ and $w_2 \ge 0$ are violated.
E. The objective function is not maximized; a negative value of $x_0$ would indicate a better solution.

B. 1
C. 2
D. 3

D. Answer D is incorrect because if $x_0 = 3$, then $w_2 = 1$, which is feasible, but we are looking for the value of $x_0$ that makes $w_2 = 0$.
E. Answer E is incorrect because if $x_0 = 4$, then $w_2 = 2$, which is feasible, but we are looking for the value of $x_0$ that makes $w_2 = 0$.
