QUESTION 1
In the context of the simplex method, what distinguishes a basic variable from a non-basic variable, and how do these classifications relate to the vertices of the feasible region?
A. Basic variables are those with zero values, while non-basic variables can have any non-negative value.  These classifications are unrelated to the vertices of the feasible region.
B. Basic variables are those associated with the columns forming an identity matrix in the simplex tableau, while non-basic variables are set to zero at each iteration.  The values of the basic variables define the coordinates of a vertex of the feasible region.
C. Basic variables are always positive, while non-basic variables are always zero.  The vertices of the feasible region are defined by the intersection of constraints, independent of basic and non-basic variable classifications.
D. Basic and non-basic variables are interchangeable terms; their values determine the position within the feasible region, but not specifically the vertices.
E. Non-basic variables are those with zero values, while basic variables can have any non-negative value.  The vertices of the feasible region are determined solely by the constraints, not by the basic/non-basic variable distinction.

ANSWER: B

EXPLANATION:
A. This option incorrectly states that basic variables have zero values. Basic variables define the solution at each iteration of the simplex method and are not necessarily zero.
B. A basic variable corresponds to a column in the simplex tableau that forms part of an identity matrix.  Non-basic variables are set to zero.  The values of the basic variables at each iteration define the coordinates of a vertex of the feasible region, representing a corner point of the feasible solution space.
C. This option incorrectly states that basic variables are always positive and non-basic variables are always zero.  Basic variables can be zero, and non-basic variables are set to zero only for convenience in the simplex method.
D. Basic and non-basic variables are distinct classifications with specific roles in the simplex method.  Their values determine the current solution point within the feasible region, and the basic variables specifically define the vertices.
E. This option incorrectly states that non-basic variables have zero values.  While non-basic variables are set to zero during iterations, this is a choice made for computational convenience, not an inherent property.


QUESTION 2
Why is the concept of basic and non-basic variables crucial in the simplex method?
A. It simplifies calculations by reducing the number of variables to consider at each iteration, but it doesn't affect the overall solution.
B. It allows for a systematic exploration of the feasible region, ensuring that all possible solutions are considered before reaching the optimal solution.
C. It provides a way to represent the solution at each iteration as a vertex of the feasible region, enabling efficient movement towards the optimal solution.
D. It is essential for converting inequality constraints into equality constraints, but it doesn't directly impact the efficiency of finding the optimal solution.
E. It is a necessary mathematical construct but doesn't have a significant impact on the practical application or efficiency of the simplex method.

ANSWER: C

EXPLANATION:
A. While it simplifies calculations, the concept is crucial for the method's ability to systematically explore the feasible region and find the optimal solution.
B. The simplex method doesn't guarantee consideration of *all* possible solutions; it efficiently explores the vertices of the feasible region.
C. The classification of variables as basic or non-basic is fundamental to the simplex method because it allows the algorithm to represent the current solution as a vertex of the feasible region.  By systematically changing which variables are basic and non-basic, the simplex method efficiently moves from one vertex to another, improving the objective function until the optimal solution is reached.
D. While slack variables are used for converting inequalities to equalities, the basic/non-basic variable distinction is crucial for the iterative process of moving between vertices.
E. The concept is central to the algorithm's efficiency and its ability to systematically find the optimal solution by moving between vertices of the feasible region.

B. The simplex method's geometric interpretation is that it moves from one vertex of the feasible region to another, improving the objective function at each step.  Basic variables define the coordinates of the current vertex, while non-basic variables are set to zero.  By changing which variables are basic, the algorithm moves to adjacent vertices.
C. This option incorrectly describes the roles of basic and non-basic variables.  They don't represent constraints or the objective function directly but define the solution point.
D. The identification of basic and non-basic variables directly corresponds to the vertices of the feasible region, which is a key part of the geometric interpretation.

QUESTION 4
In the context of the simplex method, what characterizes a non-basic variable, and how does its role relate to the geometric interpretation of the simplex method?
A. A non-basic variable is always zero and plays no role in the geometric interpretation.
B. A non-basic variable has a value greater than zero and represents a point inside the feasible region, away from the vertices.
C. A non-basic variable is set to zero at each iteration, representing the movement along the edges of the feasible region connecting vertices.
D. A non-basic variable can have any value and represents the direction of movement within the feasible region.
E. A non-basic variable is always equal to one and represents a specific vertex of the feasible region.

ANSWER: C

EXPLANATION:
A. Non-basic variables are set to zero for computational convenience, but they are crucial for defining the vertices and the movement between them.
B. Non-basic variables are set to zero; a point inside the feasible region would be represented by non-zero values for all variables.
C. In the simplex method, non-basic variables are set to zero at each iteration.  Geometrically, this means the algorithm is always at a vertex of the feasible region.  The process of moving to a new vertex involves changing a non-basic variable to a basic variable (and vice-versa), effectively moving along an edge of the feasible region.
D. Non-basic variables are set to zero; the direction of movement is determined by which variable enters the basis.
E. Non-basic variables are set to zero, not one.  A vertex is defined by the values of the basic variables.


QUESTION 5
In the context of the simplex method, what is a basic variable?
A. A variable that is set to zero in a given iteration.
B. A variable whose value is determined by the values of other variables in the system of equations.
C. A variable that is always positive in the optimal solution.
D. A variable that is chosen arbitrarily to enter the basis in each iteration.
E. A variable whose coefficient in the objective function is the largest.

ANSWER: B

EXPLANATION:
A. Non-basic variables are set to zero. Basic variables are determined by the system of equations.
B. A basic variable is one whose value is determined by the values of other variables.  In the simplex tableau, basic variables correspond to columns with a single '1' and the rest zeros.
C. Basic variables can be zero in the optimal solution.  The optimal solution determines the values of all variables, including basic ones.
D. The entering variable is chosen strategically, not arbitrarily.
E. The entering variable is chosen based on the largest coefficient in the objective function row, but this is not the definition of a basic variable.

QUESTION 7
How do basic and non-basic variables relate to the vertices of the feasible region in the simplex method?
A. Basic variables correspond to the axes, and non-basic variables correspond to the vertices.
B. Each vertex of the feasible region corresponds to a unique set of basic variables set to non-zero values, with all non-basic variables set to zero.
C. Basic variables define the hyperplanes, and non-basic variables define the vertices.
D. There is no direct relationship between basic/non-basic variables and the vertices of the feasible region.
E. Basic variables are always positive at vertices, while non-basic variables are always zero.

ANSWER: B

EXPLANATION:
A. This is incorrect; basic variables are not necessarily associated with axes.  The assignment of basic and non-basic variables is determined by the simplex algorithm.
B. Each vertex represents a basic feasible solution where a subset of variables (basic variables) are non-zero and determine the values of the remaining variables (non-basic variables), which are set to zero.
C. This is incorrect; basic variables do not define hyperplanes.  Constraints define hyperplanes.
D. There is a direct and fundamental relationship between basic/non-basic variables and the vertices of the feasible region.
E. Basic variables can be zero at vertices.  The key is that non-basic variables are zero at vertices.


QUESTION 8
Why is the concept of basic and non-basic variables crucial in the simplex method?
A. It simplifies the calculations by reducing the number of variables to consider in each iteration.
B. It allows for a systematic way to explore the feasible region by moving from one vertex to another.
C. It ensures that the solution remains feasible throughout the iterations.
D. It guarantees that the algorithm will converge to the optimal solution in a finite number of steps.
E. It provides a way to easily identify the optimal solution without performing any calculations.

ANSWER: A

EXPLANATION:
A. By setting non-basic variables to zero, the simplex method simplifies the system of equations, making it easier to solve for the basic variables and move towards the optimal solution.
B. While the simplex method does move from vertex to vertex, this is a consequence of the basic/non-basic variable manipulation, not the reason for its importance.
C. Feasibility is maintained through the minimum ratio test, not directly through the basic/non-basic variable distinction.
D. The simplex method's convergence is not guaranteed in a finite number of steps in all cases (Klee-Minty problem).
E. The optimal solution is found through iterative calculations, not directly identified without computation.


QUESTION 9
In the context of the simplex method, what is the fundamental distinction between a basic variable and a non-basic variable, and how do these classifications relate to the geometric representation of the feasible region?
A. Basic variables are those with zero values, while non-basic variables can have any value within the feasible region.
B. Basic variables correspond to the vertices of the feasible region, while non-basic variables are free to vary within the constraints.
C. Basic variables are always positive, while non-basic variables are always zero.
D. Basic variables define the current solution point within the feasible region, while non-basic variables are set to zero to define that point.
E. Basic and non-basic variables are interchangeable; their classification depends on the chosen pivot rule.

ANSWER: D

EXPLANATION:
A. Answer A is incorrect.  Non-basic variables are set to zero, while basic variables can have any non-negative value that satisfies the constraints at a given vertex.
B. Answer B is incorrect.  While basic variables are associated with vertices, non-basic variables are not "free" but are constrained to be zero in a given basic feasible solution.
C. Answer C is incorrect. Basic variables can be zero (at degeneracy), and non-basic variables are always zero in a given basic feasible solution, but can become non-zero in subsequent iterations.
D. Answer D is correct.  In each iteration of the simplex method, a basic feasible solution is defined by setting the non-basic variables to zero. The values of the basic variables then determine the coordinates of a vertex in the feasible region.  The method iteratively moves from one vertex (basic feasible solution) to another by changing which variables are basic and non-basic.
E. Answer E is incorrect. The classification of basic and non-basic variables is crucial and directly determines the current solution point and the direction of movement in the simplex method.  The pivot rule determines *which* variables change classification, not the fundamental definition of basic and non-basic.


QUESTION 10
In the context of the simplex method, what is a basic variable?
A. A variable that is set to zero in a basic feasible solution.
B. A variable whose value is determined by the constraints in a basic feasible solution.
C. A variable that can take any non-negative value in a basic feasible solution.
D. A variable that is always included in the objective function.
E. A variable that is not included in the constraints.

ANSWER: B

EXPLANATION:
A. Non-basic variables are set to zero in a basic feasible solution. Basic variables are determined by the constraints.
B. A basic variable is one whose value is determined by the constraints in a basic feasible solution.  In the simplex tableau, these correspond to variables associated with columns that form an identity matrix.
C. Non-basic variables are set to zero; basic variables' values are determined by the constraints.
D. Variables in the objective function may or may not be basic variables.
E. All variables in a standard form linear program are included in the constraints (after introducing slack variables).
