QUESTION 1
In the context of sensitivity analysis, how does a change in the objective function coefficient of a non-basic variable affect the optimal solution and the optimal objective function value?
A. It always changes the optimal solution and the optimal objective function value.
B. It never changes the optimal solution or the optimal objective function value.
C. It may change the optimal objective function value, but it never changes the optimal solution.
D. It may change the optimal solution, but it never changes the optimal objective function value.
E. It may or may not change the optimal solution and the optimal objective function value, depending on the magnitude of the change and the reduced cost of the non-basic variable.

ANSWER: E

EXPLANATION:
A. Incorrect.  The optimal solution and objective function value remain unchanged if the change in the objective function coefficient is within the range of optimality.
B. Incorrect.  If the change in the objective function coefficient is large enough to make the reduced cost of the non-basic variable negative, the optimal solution will change, and consequently, the objective function value will also change.
C. Incorrect. If the change in the objective function coefficient is large enough to make the reduced cost of the non-basic variable negative, the optimal solution will change, and consequently, the objective function value will also change.
D. Incorrect. If the change in the objective function coefficient is large enough to make the reduced cost of the non-basic variable negative, the optimal solution will change, and consequently, the objective function value will also change.
E. A change in the objective function coefficient of a non-basic variable might or might not change the optimal solution and objective function value.  If the change is small enough and the reduced cost is sufficiently large, the current basis remains optimal. However, if the change is large enough to make the reduced cost negative, the optimal solution will change.


QUESTION 2
How does sensitivity analysis help in assessing the robustness of an optimal solution to changes in the right-hand side (RHS) values of the constraints?
A. Sensitivity analysis is not relevant to changes in the RHS values.
B. Sensitivity analysis directly provides the new optimal solution for any RHS change.
C. Sensitivity analysis determines the range of RHS changes that maintain the current optimal basis, and it provides shadow prices indicating the impact of RHS changes on the objective function value.
D. Sensitivity analysis only works for small changes in the RHS values.
E. Sensitivity analysis only provides information about the objective function value, not the optimal solution.

ANSWER: C

EXPLANATION:
A. Incorrect. Sensitivity analysis is a crucial tool for evaluating the impact of changes in the RHS values on the optimal solution.
B. Incorrect. Sensitivity analysis identifies the range of RHS changes that maintain the current optimal basis, but it doesn't directly provide the new optimal solution outside this range.
C. Sensitivity analysis helps determine the range of RHS changes that leave the optimal basis unchanged.  Shadow prices (dual variables) quantify the change in the optimal objective function value for each unit change in the RHS values.
D. While the formulas are often derived assuming small changes, the concept of the range of optimality extends beyond small changes.
E. Incorrect. Sensitivity analysis provides information about both the objective function value and the optimal solution (specifically, the range of changes that maintain the current optimal basis).
