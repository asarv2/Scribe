QUESTION 1
In the linear program presented on Slide 1, what are the basic variables when $x_1$ and $x_2$ are set to 0?
A. $x_1, x_2, w_1$
B. $w_1, w_2, w_3$
C. $x_1, w_2, w_3$
D. $w_1, x_2, w_3$
E. $x_1, x_2, x_3$

ANSWER: B

EXPLANATION:
A. This answer incorrectly includes $x_1$ and $x_2$ as basic variables, even though they are set to 0.  The basic variables are those expressed on the left-hand side of the equations.
B. When $x_1$ and $x_2$ are both 0, the equations on Slide 1 become $w_1 = 12$, $w_2 = 8$, and $w_3 = 10$.  Therefore, $w_1$, $w_2$, and $w_3$ are the basic variables.
C. This answer incorrectly includes $x_1$ as a basic variable.  When $x_1 = 0$, $x_1$ is a non-basic variable.
D. This answer incorrectly includes $x_2$ as a basic variable. When $x_2 = 0$, $x_2$ is a non-basic variable.
E. This answer incorrectly lists only variables from the original problem statement.  Slack variables are also considered in determining basic variables.


QUESTION 2
In the context of the Simplex Method, what does it mean for a variable to be "basic"?
A. A variable that is always set to zero in the simplex tableau.
B. A variable that is used to convert inequality constraints into equality constraints.
C. A variable whose value is determined by the values of other variables in the system of equations.
D. A variable that has a positive coefficient in the objective function.
E. A variable that is always present in the final optimal solution.

ANSWER: C

EXPLANATION:
A. Non-basic variables are set to zero to obtain a basic feasible solution. Basic variables are not always zero.
B. Slack variables are used to convert inequality constraints into equality constraints.  Being basic is a property of variables within the simplex method's iterative process.
C. A basic variable's value is determined by the values of the non-basic variables.  In the simplex tableau, basic variables correspond to columns with an identity matrix structure.
D. The coefficient in the objective function influences the selection of entering variables, but it doesn't define whether a variable is basic or not.
E. While basic variables are part of the solution at each iteration, they are not guaranteed to be in the final optimal solution.  The final optimal solution contains a specific set of basic variables.


QUESTION 3
Why is the concept of basic and non-basic variables crucial in the simplex method?
A. It simplifies the calculation of the objective function.
B. It allows for a systematic exploration of the feasible region's vertices.
C. It ensures the non-negativity of all variables.
D. It guarantees the convergence of the algorithm.
E. It helps in identifying the constraints that are binding.

ANSWER: B

EXPLANATION:
A. While it simplifies calculations at each iteration, the core reason for the distinction is the exploration of vertices.
B. By systematically setting non-basic variables to zero and solving for basic variables, the simplex method efficiently moves from one vertex of the feasible region to another, searching for the optimal solution.
C. Non-negativity is a constraint of the problem, not a direct consequence of basic/non-basic variables.
D. Convergence is a property of the algorithm, but the basic/non-basic distinction is the mechanism that enables it.
E. While the simplex method implicitly identifies binding constraints, the core role of basic/non-basic variables is the systematic exploration of vertices.


QUESTION 4
How does the identification of basic and non-basic variables relate to the geometric interpretation of the simplex method?
A. Basic variables define the objective function's slope.
B. Non-basic variables represent the constraints' intercepts.
C. Each basic feasible solution corresponds to a vertex of the feasible region.
D. Basic variables determine the feasible region's boundaries.
E. Non-basic variables indicate the direction of improvement in the objective function.

ANSWER: C

EXPLANATION:
A. The objective function's slope is determined by the coefficients in the objective function, not the basic variables.
B. Constraints' intercepts are determined by the constants in the constraints, not the non-basic variables.
C. Setting non-basic variables to zero and solving for basic variables yields a basic feasible solution, which geometrically corresponds to a vertex of the feasible region. The simplex method iteratively moves between these vertices.
D. The feasible region's boundaries are defined by the constraints, not the basic variables.
E. The direction of improvement is determined by the coefficients of the non-basic variables in the objective function, but this is not the primary geometric interpretation of basic/non-basic variables.


QUESTION 5
In the linear program presented on Slide 1, if we set $x_1 = 0$ and $x_2 = 0$, what are the values of the basic variables $w_1$, $w_2$, and $w_3$?
A. $w_1 = 12, w_2 = 8, w_3 = 10$
B. $w_1 = 0, w_2 = 0, w_3 = 0$
C. $w_1 = -12, w_2 = -8, w_3 = -10$
D. $w_1 = 1, w_2 = 1, w_3 = 1$
E. $w_1 = -3, w_2 = -1, w_3 = 1$

ANSWER: A

EXPLANATION:
A. Answer A is correct.  Substituting $x_1 = 0$ and $x_2 = 0$ into the equations on Slide 1 gives $w_1 = 12 + 0 - 0 = 12$, $w_2 = 8 - 0 - 0 = 8$, and $w_3 = 10 - 0 + 0 = 10$.
B. Answer B is incorrect. This would only be true if the right-hand side of all constraints were 0.
C. Answer C is incorrect.  The slack variables represent the difference between the left and right sides of the constraints, and they must be non-negative.
D. Answer D is incorrect. There is no basis for these values.
E. Answer E is incorrect. These values are not consistent with the given constraints.


QUESTION 6
On Slide 8, we increase $x_1$ while keeping $x_2 = 0$.  Which constraint determines the maximum feasible value of $x_1$?
A. $w_1 \ge 0$
B. $w_2 \ge 0$
C. $w_3 \ge 0$
D. $x_1 \ge 0$
E. $x_2 \ge 0$

ANSWER: C

EXPLANATION:
A. Answer A is incorrect.  The constraint $w_1 \ge 0$ leads to $x_1 \ge -12$, which is not a limiting constraint.
B. Answer B is incorrect. The constraint $w_2 \ge 0$ leads to $x_1 \le 8$, which is less restrictive than $x_1 \le 5$.
C. Answer C is correct. The constraints $w_2 \ge 0$ and $w_3 \ge 0$ give $x_1 \le 8$ and $x_1 \le 5$ respectively. Since $x_1 \le 5$ is the more restrictive constraint, $w_3 \ge 0$ determines the maximum feasible value of $x_1$.
D. Answer D is incorrect.  $x_1 \ge 0$ is a non-negativity constraint, but it does not limit the increase of $x_1$ in this case.
E. Answer E is incorrect. Since we are keeping $x_2 = 0$, this constraint is not relevant in determining the maximum value of $x_1$.

QUESTION 9
In the context of the Simplex Method, what is a basic variable, and how does its role relate to the vertices of the feasible region?
A. A basic variable is a variable that is set to zero in the initial feasible solution, and it corresponds to a point within the feasible region.
B. A basic variable is a variable that is always non-zero and corresponds to a vertex of the feasible region.
C. A basic variable is a variable that is non-zero in a basic feasible solution and corresponds to a vertex of the feasible region; non-basic variables are set to zero at each vertex.
D. A basic variable is a variable that is set to one in the initial feasible solution, and it corresponds to a point on the boundary of the feasible region.
E. A basic variable is any variable in the problem, and its value determines the location within the feasible region.

ANSWER: C

EXPLANATION:
A. Incorrect. While some basic variables might be zero in *some* basic feasible solutions, they are not necessarily zero in the initial solution, and a basic feasible solution always corresponds to a vertex, not just a point within the region.
B. Incorrect. Basic variables are not always non-zero; they can be zero at certain vertices.  Also, the correspondence is to a vertex, not just any point.
C. A basic variable is a variable that is non-zero in a basic feasible solution.  In the geometric interpretation of the simplex method, each basic feasible solution corresponds to a vertex of the feasible region.  The non-basic variables are set to zero at each vertex, defining the coordinates of that vertex in terms of the basic variables.
D. Incorrect. Basic variables are not necessarily set to one. The value of a basic variable is determined by the constraints and the values of the non-basic variables.
E. Incorrect. Basic variables are a subset of all variables; only the basic variables determine the location of a vertex in the feasible region when the non-basic variables are set to zero.


QUESTION 10
In the linear program on Slide 1, if we set $x_1 = 0$, what is the value of the basic variable $w_2$ when $x_2 = 4$?
A. 4
B. 8
C. 12
D. 0
E. 4

ANSWER: D

EXPLANATION:
A. This answer incorrectly assumes $w_2$ is equal to $x_2$.
B. This answer incorrectly uses the value of 8 from the equation for $w_2$ without considering the values of $x_1$ and $x_2$.
C. This answer is incorrect; it uses a value unrelated to the problem.
D. The equation for $w_2$ is given by $w_2 = 8 - x_1 - x_2$.  Substituting $x_1 = 0$ and $x_2 = 4$, we get $w_2 = 8 - 0 - 4 = 4$.
E. This answer is a repeat of option A.
