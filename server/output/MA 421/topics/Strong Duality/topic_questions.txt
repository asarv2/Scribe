QUESTION 1
According to strong duality, what is the relationship between the optimal objective function values of the primal and dual problems?
A. The optimal objective function value of the primal problem is always greater than or equal to the optimal objective function value of the dual problem.
B. The optimal objective function value of the primal problem is always less than or equal to the optimal objective function value of the dual problem.
C. The optimal objective function values of the primal and dual problems are always equal, provided both problems have optimal solutions.
D. There is no guaranteed relationship between the optimal objective function values of the primal and dual problems.
E. The optimal objective function value of the primal problem is always greater than the optimal objective function value of the dual problem.

ANSWER: C

EXPLANATION:
A. This describes weak duality, not strong duality. Weak duality states that the primal objective function value is always greater than or equal to the dual objective function value for any feasible solutions.
B. This describes weak duality, but reversed. Weak duality states that the primal objective function value is always greater than or equal to the dual objective function value for any feasible solutions.
C. Strong duality states that if both the primal and dual problems have feasible solutions, then their optimal objective function values are equal.  This is a fundamental theorem in linear programming.
D. This is incorrect; strong duality establishes a precise relationship between the optimal objective function values under certain conditions.
E. This is incorrect; strong duality states that the optimal objective function values are equal, not that one is strictly greater than the other.


QUESTION 2
The Klee-Minty problem highlights a worst-case scenario for the simplex method. What key characteristic of this problem leads to its exponential time complexity?
A. The presence of many constraints.
B. The large magnitude of the coefficients in the objective function.
C. The highly skewed and elongated geometry of its feasible region.
D. The use of a specific pivot rule.
E. The number of variables being very large.

ANSWER: C

EXPLANATION:
A. While the number of constraints can influence runtime, it's the specific structure of the constraints and the resulting geometry that causes the exponential behavior in the Klee-Minty problem.
B. While large coefficients can affect the numerical stability of the simplex method, the exponential complexity of the Klee-Minty problem is primarily due to the geometry of the feasible region.
C. The Klee-Minty problem's feasible region is a highly skewed polytope. The simplex method, following certain pivot rules, can traverse a path along the boundary of this polytope that is exponentially long in the number of variables.
D. The choice of pivot rule is important, and different rules can lead to different numbers of iterations. However, the Klee-Minty problem demonstrates exponential complexity even with specific pivot rules, highlighting the inherent problem structure.
E. The number of variables is a factor, but the exponential complexity arises from the interaction between the number of variables and the specific geometry of the feasible region.


QUESTION 3
In the context of strong duality, what can we conclude if the primal problem is unbounded?
A. The dual problem is also unbounded.
B. The dual problem is infeasible.
C. The dual problem has an optimal solution.
D. The dual problem is unbounded in the opposite direction.
E. There is no relationship between the primal and dual problems in this case.

ANSWER: B

EXPLANATION:
A. If the primal is unbounded, the dual cannot be unbounded.  If both were unbounded, strong duality would be violated.
B. If the primal problem is unbounded (its objective function can be made arbitrarily large), then the dual problem must be infeasible. This is a direct consequence of strong duality.
C. If the primal is unbounded, the dual cannot have an optimal solution.  Strong duality would be violated.
D. The dual problem's unboundedness would be in the same direction as the primal (minimizing instead of maximizing).
E. Strong duality provides a relationship between the primal and dual problems even in cases of unboundedness or infeasibility.


QUESTION 4
Why is smoothed analysis considered a more realistic measure of the simplex method's performance than worst-case analysis?
A. Smoothed analysis considers only average-case scenarios, ignoring worst-case instances.
B. Smoothed analysis accounts for the fact that real-world problems are rarely perfectly structured to trigger worst-case behavior.
C. Smoothed analysis focuses solely on the number of iterations, ignoring computational time per iteration.
D. Smoothed analysis is computationally simpler than worst-case analysis.
E. Smoothed analysis always provides polynomial bounds on the runtime of the simplex method.

ANSWER: B

EXPLANATION:
A. Smoothed analysis does not ignore worst-case scenarios; it incorporates them into a broader framework that considers perturbations of the input data.
B. Worst-case analysis focuses on the most unfavorable input, which is often artificially constructed and rarely encountered in practice. Smoothed analysis acknowledges that real-world problems have some randomness or imperfections, making the worst-case scenario less likely.
C. Smoothed analysis considers the overall runtime, which includes both the number of iterations and the computational cost per iteration.
D. Smoothed analysis is generally more complex than worst-case analysis because it involves probabilistic considerations.
E. Smoothed analysis provides probabilistic bounds, not guaranteed polynomial bounds, on the runtime of the simplex method.  The bounds depend on the magnitude of the perturbations.
