QUESTION 1
In the context of the primal problem (Slide 1), explain the concept of a basic feasible solution (BFS) and its relationship to the vertices of the feasible region.
A. A BFS is any feasible solution to the primal problem, and it corresponds to a point within the feasible region.
B. A BFS is a feasible solution where the number of non-zero variables is equal to the number of constraints, and it corresponds to a vertex of the feasible region.
C. A BFS is a solution that satisfies all constraints but may not maximize the objective function, and it can be any point within the feasible region.
D. A BFS is a feasible solution where all variables are non-negative, and it corresponds to a point on the boundary of the feasible region.
E. A BFS is any solution that maximizes the objective function, regardless of whether it satisfies all constraints, and it corresponds to a vertex of the feasible region.

ANSWER: B

EXPLANATION:
A. This definition is too broad. A BFS is a specific type of feasible solution, not just any feasible solution.
B. A basic feasible solution (BFS) is a feasible solution where the number of non-zero variables is at most equal to the number of constraints.  In a geometric interpretation, these solutions correspond to the vertices (corner points) of the feasible region.  If the number of non-zero variables is strictly less than the number of constraints, it is a degenerate BFS.
C. A BFS must satisfy all constraints and is a candidate for the optimal solution, but it doesn't necessarily maximize the objective function.
D. While a BFS has non-negative variables, it doesn't necessarily lie on the boundary; it specifically corresponds to vertices.
E. A BFS is not necessarily an optimal solution; optimality is determined by the objective function value.

QUESTION 3
Consider the primal problem presented on Slide 1: Maximize $\zeta = 3x_1 + 2x_2$ subject to $-x_1 + 3x_2 \le 12$, $x_1 + x_2 \le 8$, $2x_1 - x_2 \le 10$, and $x_1, x_2 \ge 0$. Explain the significance of the slack variables $w_1, w_2, w_3$ introduced in the slack variable form of the problem, and how they relate to the feasible region graphically represented in Slide 5.
A. The slack variables represent the distance of a feasible solution from the origin.
B. The slack variables represent the amount by which each constraint is satisfied; a value of zero indicates the solution lies on the constraint boundary.
C. The slack variables represent the amount by which each constraint is violated; a positive value indicates infeasibility.
D. The slack variables represent the surplus resources available after satisfying the constraints.
E. The slack variables are arbitrary variables added to make the problem solvable; they have no direct relation to the feasible region.

ANSWER: B

EXPLANATION:
A. Slack variables do not represent the distance from the origin; they represent the slack in each constraint.
B. The slack variables $w_1, w_2, w_3$ represent the difference between the left-hand side and the right-hand side of each constraint.  If $w_i = 0$, the corresponding constraint is binding (the solution lies on the constraint boundary).  If $w_i > 0$, the constraint is non-binding (the solution is within the feasible region, away from the constraint boundary).
C. A positive slack variable indicates that the constraint is satisfied, not violated.  A negative slack variable would indicate a violation.
D. Slack variables represent the unused resources, not the surplus resources.
E. Slack variables are crucial for converting inequalities to equalities, which is essential for the simplex method.

QUESTION 5
Consider the primal linear program (P) and its dual (D) as defined on Slide 1.  Explain the relationship between the feasibility and boundedness of the primal and dual problems, covering all four possible scenarios. For each scenario, describe the implications for the optimal objective function values of both problems.
A. If the primal problem (P) is feasible and bounded, the dual problem (D) is infeasible.
B. If the primal problem (P) is infeasible, the dual problem (D) is unbounded.
C. If the primal problem (P) is unbounded, the dual problem (D) is infeasible, and vice versa.
D. If the primal problem (P) is infeasible, the dual problem (D) can be either infeasible or unbounded.
E. If both the primal problem (P) and the dual problem (D) are feasible, then both must have optimal solutions with equal objective function values.

ANSWER: C

EXPLANATION:
A. Answer A is incorrect. If the primal problem is feasible and bounded, the dual problem is also feasible and bounded, and their optimal objective function values are equal.
B. Answer B is incorrect. If the primal problem is infeasible, the dual problem is either infeasible or unbounded.
C. Answer C is correct.  The strong duality theorem states that if one problem is feasible and bounded, the other is also feasible and bounded, and their optimal objective function values are equal. If one problem is infeasible, the other is either infeasible or unbounded.  This covers all four possibilities: (1) both feasible and bounded, (2) primal feasible and unbounded, dual infeasible, (3) dual feasible and unbounded, primal infeasible, (4) both infeasible.
D. Answer D is incorrect.  If the primal is infeasible, the dual is either infeasible or unbounded, but not both.  The dual cannot be both infeasible and unbounded simultaneously.
E. Answer E is incorrect. While it's true that if both are feasible and bounded, they have equal optimal objective function values, this doesn't cover all possibilities.  One or both problems could be infeasible or unbounded.
