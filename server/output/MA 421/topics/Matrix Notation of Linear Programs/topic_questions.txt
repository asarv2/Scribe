QUESTION 1
In the matrix notation of a linear program, what does the matrix $A$ represent?
A. The coefficients of the objective function.
B. The constraint coefficients.
C. The right-hand side values of the constraints.
D. The variables of the problem.
E. The slack variables.

ANSWER: B

EXPLANATION:
A. The coefficients of the objective function are represented by a separate vector, typically denoted as $c$ or $c^T$.
B. The matrix $A$ in the matrix notation of a linear program represents the coefficients of the variables in the constraints. Each row corresponds to a constraint, and each column corresponds to a variable.
C. The right-hand side values of the constraints are represented by a separate vector, typically denoted as $b$.
D. The variables of the problem are represented by a separate vector, typically denoted as $x$.
E. Slack variables are added to convert inequality constraints to equalities, and they are represented by a separate vector, often denoted as $s$ or $w$.


QUESTION 2

B. It allows for a more concise representation of the problem.
C. It provides a structured format suitable for efficient computation.
D. It improves the understanding of the problem's feasibility.
E. It makes the problem easier to visualize graphically.

ANSWER: C

EXPLANATION:
A. While matrix notation can aid in interpreting the solution, its primary benefit lies in its suitability for computation.
B. Conciseness is a benefit, but the key advantage is the structured format for algorithms.
C. Matrix notation provides a structured format that is easily processed by computational algorithms.  The compact representation allows for efficient implementation of algorithms like the simplex method.
D. Feasibility is determined by the problem's constraints, not directly by the notation.
E. Graphical visualization is independent of the matrix notation; it's a separate approach to understanding the problem.

QUESTION 4
In the standard matrix form of a linear program,  $Ax \le b$, $x \ge 0$, what does the inequality $Ax \le b$ represent?
A. The objective function to be maximized or minimized.
B. The non-negativity constraints on the variables.
C. The set of equality constraints in the problem.
D. The set of inequality constraints in the problem.
E. The optimal solution to the linear program.

ANSWER: D

EXPLANATION:
A. The objective function is typically represented separately, often as $c^Tx$ where $c$ is a vector of coefficients.
B. The non-negativity constraints are represented separately as $x \ge 0$.
C. Equality constraints would be represented as $Ax = b$.
D. The inequality $Ax \le b$ represents the system of inequality constraints in the linear program.  Matrix $A$ contains the coefficients, vector $x$ contains the variables, and vector $b$ contains the right-hand side values.
E. The optimal solution is the result of solving the linear program, not a part of its representation.
