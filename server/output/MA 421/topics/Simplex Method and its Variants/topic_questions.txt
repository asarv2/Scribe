QUESTION 1
In the simplex method, if all entries in the objective row are non-negative (for a maximization problem), what does this indicate about the current solution?
A. The current solution is infeasible.
B. The current solution is optimal.
C. Another iteration is needed.
D. The problem is unbounded.
E. The problem is degenerate.

ANSWER: B

EXPLANATION:
A. An infeasible solution would be indicated by negative values in the solution vector (after introducing slack variables) or by a violation of constraints.
B. A non-negative objective row in a maximization problem indicates that the current solution is optimal because no further improvement in the objective function value is possible by introducing any non-basic variable into the basis.
C. If all entries are non-negative, no improvement is possible, so no further iteration is needed.
D. An unbounded problem would have a situation where the objective function can be increased indefinitely without violating constraints.
E. Degeneracy refers to a situation where a basic variable has a value of zero.  The objective row does not directly indicate degeneracy.


QUESTION 2
Explain the concept of degeneracy in the simplex method and its potential implications for the algorithm's performance.
A. Degeneracy occurs when a basic variable has a value of zero, potentially leading to cycling.
B. Degeneracy occurs when the objective function value remains unchanged for multiple iterations, leading to slow convergence.
C. Degeneracy occurs when the constraints are linearly dependent, leading to an unbounded solution.
D. Degeneracy occurs when the initial feasible solution is not a vertex of the feasible region, leading to infeasibility.
E. Degeneracy is a condition where the optimal solution is not unique, leading to multiple optimal solutions.

ANSWER: A

EXPLANATION:
A. Degeneracy in the simplex method occurs when a basic variable has a value of zero. This can lead to cycling, where the algorithm repeatedly visits the same set of basic feasible solutions without making progress towards the optimal solution.  While not always causing cycling, it increases the risk.
B. While degeneracy can sometimes lead to slow convergence, the primary issue is the potential for cycling, not necessarily a stagnant objective function value.
C. Linearly dependent constraints lead to redundancy, not necessarily degeneracy.  An unbounded solution is a separate issue.
D. The initial feasible solution being non-vertex is not directly related to degeneracy. Infeasibility is a separate issue.
E. Multiple optimal solutions are possible even without degeneracy. Degeneracy is about zero values for basic variables.


QUESTION 3
What is the primary purpose of the two-phase simplex method, and how does it address limitations of the standard simplex method?
A. The two-phase method is used to solve problems with unbounded solutions by finding a bounded subproblem.
B. The two-phase method is used to handle problems with multiple optimal solutions by identifying all optimal vertices.
C. The two-phase method is used to find an initial basic feasible solution when the origin is not feasible.
D. The two-phase method is used to improve the efficiency of the simplex method by reducing the number of iterations.
E. The two-phase method is used to solve problems with degenerate solutions by preventing cycling.

ANSWER: C

EXPLANATION:
A. The two-phase method doesn't directly address unboundedness; that's handled by other techniques within the simplex method itself.
B. Finding all optimal vertices is not the primary purpose; the two-phase method focuses on finding *an* optimal solution.
C. The two-phase simplex method is designed to find an initial basic feasible solution when the origin (0,0,...0) is not feasible in the original problem. The first phase finds a feasible solution, and the second phase optimizes the objective function starting from that feasible solution.
D. While it can sometimes lead to fewer iterations overall, the primary goal is to handle infeasible origins, not necessarily speed.
E. Preventing cycling in degenerate problems is addressed by techniques like Bland's rule, not the two-phase method itself.


QUESTION 4

A. The primal simplex method starts with a feasible solution and iteratively improves it, while the dual simplex method starts with an infeasible solution and iteratively moves towards feasibility.
B. The primal simplex method is more efficient for problems with many constraints, while the dual simplex method is more efficient for problems with many variables.
C. The primal simplex method is always guaranteed to find an optimal solution, while the dual simplex method may fail to converge.
D. The primal simplex method is better suited for post-optimality analysis, while the dual simplex method is not.
E. Both methods are identical in their approach, differing only in the way they handle degeneracy.

ANSWER: A

EXPLANATION:
A. The primal simplex method begins with a feasible solution and iteratively improves it, maintaining feasibility at each step. The dual simplex method starts with an infeasible but optimal solution and iteratively moves towards feasibility while maintaining optimality.  The primal method is generally preferred for finding an initial feasible solution, while the dual method is useful in post-optimality analysis and when dealing with changes in constraints.
B. Efficiency depends on the specific problem structure; neither method is universally superior based solely on the number of constraints or variables.
C. Both methods, when implemented correctly, are guaranteed to find an optimal solution if one exists.  Convergence issues are related to degeneracy and cycling, not inherent to the method itself.
D. Both methods can be used for post-optimality analysis, though the dual simplex method is often more efficient for certain types of changes (e.g., changes in constraints).
E. The primal and dual simplex methods are fundamentally different in their approach to maintaining feasibility and optimality.
