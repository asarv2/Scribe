QUESTION 1
What is the fundamental difference between the worst-case and average-case performance of the simplex method, as discussed in the lecture slides?
A. The worst-case scenario always occurs in practice, while the average-case scenario is a theoretical ideal.
B. The worst-case performance is exponential, while the average-case performance is often observed to be polynomial.
C. The worst-case performance is determined by the size of the problem, while the average-case performance is independent of the problem size.
D. The worst-case and average-case performances are identical for all linear programming problems.
E. The worst-case performance is only relevant for very small problems, while the average-case performance is more relevant for large problems.

ANSWER: B

EXPLANATION:
A. The worst-case scenario is a theoretical bound, not a guarantee of practical performance. The average-case performance is based on observations from many problem instances.
B. The Klee-Minty problem demonstrates that the simplex method can have exponential worst-case complexity. However, empirical studies and observations from practical applications suggest that the average-case performance is often polynomial, meaning the number of iterations grows polynomially with the problem size.
C. Both worst-case and average-case performances are influenced by problem size, but the relationship is different (exponential vs. often polynomial).
D. The worst-case and average-case performances are distinct and can differ significantly.
E. Both worst-case and average-case performances are relevant for problems of all sizes, but the average-case behavior is more indicative of typical performance.


QUESTION 2
The Klee-Minty problem is a crucial example in the study of the simplex method. What key characteristic of this problem leads to its exponential worst-case time complexity?
A. The problem's objective function is highly non-linear.
B. The problem involves a large number of constraints compared to the number of variables.
C. The problem's feasible region is highly skewed and elongated, causing the simplex method to traverse many vertices.
D. The problem's constraints are highly correlated.
E. The problem's optimal solution is located at a vertex far from the origin.

ANSWER: C

EXPLANATION:
A. The objective function in the Klee-Minty problem is linear.
B. While the number of constraints can influence the runtime, the key factor in the Klee-Minty problem is the shape of the feasible region.
C. The Klee-Minty problem is specifically constructed to create a highly skewed and elongated feasible region. This forces the simplex method, using certain pivot rules, to visit an exponential number of vertices before reaching the optimal solution.
D. The constraints in the Klee-Minty problem are designed to create a specific geometric structure, not necessarily high correlation.
E. The location of the optimal solution is a consequence of the skewed feasible region, not the primary cause of the exponential runtime.


QUESTION 3

EXPLANATION:

D. There is no inverse relationship between the number of iterations and total computation time.  A smaller number of iterations can still result in a longer total runtime if the iterations are more complex.

QUESTION 9

B. $Z \le W$
C. $Z = W$
D. $Z > W$
E. $Z < W$

ANSWER: B

EXPLANATION:

B. Weak duality states that the objective function value of the primal problem is always less than or equal to the objective function value of the dual problem, regardless of feasibility.  This means that any feasible solution to the primal problem provides a lower bound for the optimal solution of the dual problem, and vice versa.
C. This equality only holds at optimality, when strong duality applies. Weak duality is a broader concept that applies to any feasible solutions.
D. This inequality is not always true. Weak duality states that $Z \le W$ for any feasible solutions.
E. This inequality is not always true. Weak duality states that $Z \le W$ for any feasible solutions.
