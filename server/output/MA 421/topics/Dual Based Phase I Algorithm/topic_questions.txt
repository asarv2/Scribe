QUESTION 1
In the Dual Based Phase I Algorithm, why is it beneficial to transform the general linear program into a form with only equality constraints and non-negativity restrictions on the variables before applying the dual simplex method?
A. This transformation simplifies the calculation of the initial basic feasible solution.
B. This form allows for a direct application of the dual simplex method, which is more efficient for problems with equality constraints.
C. This transformation ensures the problem's feasibility, which is a prerequisite for the dual simplex method.
D. This form simplifies the derivation of the dual problem, making it easier to apply the dual simplex method.
E. This transformation is not necessary; the dual simplex method can be applied directly to general linear programs.

ANSWER: D

EXPLANATION:
A. While the transformation can indirectly simplify finding an initial feasible solution, it's not the primary reason. The focus is on the structure that allows for a direct application of the dual simplex method.
B. The dual simplex method is not inherently *more* efficient for problems with equality constraints.  The efficiency gain comes from the simplified structure of the problem after the transformation.
C. The transformation doesn't guarantee feasibility; it's a structural change to facilitate the application of the dual simplex method. Feasibility is checked separately.
D. The transformation simplifies the derivation of the dual problem, making it easier to apply the dual simplex method.  The dual simplex method is most naturally applied to problems in standard form (equality constraints and non-negativity). Transforming the primal problem into this form simplifies the process of constructing and solving the dual problem.
E. The transformation is crucial.  Applying the dual simplex method directly to a general linear program is significantly more complex.


QUESTION 2
In the context of the Dual Based Phase I Algorithm, what is the primary role of the auxiliary problem, and how does its solution inform the solution of the original problem?
A. The auxiliary problem identifies the optimal solution to the original problem directly.
B. The auxiliary problem provides an initial feasible solution for the dual simplex method applied to the original problem.
C. The auxiliary problem determines whether the original problem is feasible or infeasible.
D. The auxiliary problem simplifies the constraints of the original problem, making it easier to solve.
E. The auxiliary problem is not essential; the dual simplex method can be applied directly to the original problem.

ANSWER: C

EXPLANATION:
A. The auxiliary problem does not directly provide the optimal solution to the original problem. It only helps determine feasibility and provides a starting point for solving the original problem.
B. The auxiliary problem doesn't directly provide a feasible solution for the *dual* simplex method applied to the original problem. It determines feasibility and, if feasible, provides a starting point for the dual simplex method on a modified problem.
C. The auxiliary problem determines whether the original problem is feasible or infeasible. If the auxiliary problem has an optimal objective function value of zero, then the original problem is feasible, and its optimal solution can be found using the dual simplex method. If the auxiliary problem has a positive optimal objective function value, then the original problem is infeasible.
D. The auxiliary problem doesn't simplify the constraints of the original problem. It introduces a new problem to determine feasibility.
E. The auxiliary problem is essential for handling cases where the origin is not feasible in the original problem.

EXPLANATION:

B. Weak duality provides a bound on the objective function value, aiding in the algorithm's termination condition.  The algorithm terminates when the objective function value of the auxiliary problem reaches zero, indicating feasibility of the original problem. Weak duality ensures that the objective function value of the dual problem provides an upper bound on the primal problem's objective function value, which is used to check for optimality.
C. Weak duality is fundamental to the algorithm's design and termination condition.
D. Weak duality doesn't directly ensure the feasibility of the dual problem.  Feasibility is checked through the solution of the auxiliary problem.
E. Weak duality is relevant regardless of the original problem's feasibility. It provides a bound on the objective function value.
