QUESTION 1
In the context of complementary slackness, what is the relationship between the primal and dual variables if a constraint in the primal problem is binding (i.e., the inequality holds with equality)?
A. The corresponding dual variable is zero.
B. The corresponding dual variable is positive.
C. The corresponding primal variable is zero.
D. There is no specific relationship between the primal and dual variables.
E. Both the corresponding primal and dual variables are zero.

ANSWER: B

EXPLANATION:
A. Incorrect. A zero dual variable implies the constraint is non-binding.
B. If a primal constraint is binding, it means the inequality holds with equality.  Complementary slackness states that if a primal constraint is binding, then the corresponding dual variable must be positive.  This is because the dual variable represents the shadow price or marginal value of relaxing that constraint. If the constraint is already at its limit (binding), then relaxing it has value, hence a positive dual variable.
C. Incorrect.  Complementary slackness relates primal constraints to dual variables, not primal variables.
D. Incorrect. Complementary slackness defines a specific relationship between primal constraints and dual variables.
E. Incorrect. While it's possible for both to be zero in degenerate cases, it's not a general rule for binding constraints.


QUESTION 2
Explain the concept of complementary slackness and how it helps in verifying the optimality of solutions in linear programming.
A. Complementary slackness states that the optimal objective function values of the primal and dual problems are equal.
B. Complementary slackness states that at optimality, either a primal variable or its corresponding dual slack variable must be zero, and similarly for dual variables and primal slack variables.
C. Complementary slackness is a method for finding an initial feasible solution for the simplex method.
D. Complementary slackness is a pivot rule used in the simplex method to select the entering variable.
E. Complementary slackness is a condition that must be met for a linear programming problem to be feasible.

ANSWER: B

EXPLANATION:
A. This describes strong duality, not complementary slackness.
B. Complementary slackness provides a necessary and sufficient condition for optimality in linear programming. It states that at the optimal solution, for each pair of a primal variable and its corresponding dual slack variable (or a dual variable and its corresponding primal slack variable), at least one of the two must be zero. This condition helps verify the optimality of a proposed solution by checking if this condition holds for all primal and dual variables and their corresponding slack variables. If it does, then the solution is optimal.
C. This describes a different technique used in linear programming.
D. This describes a different aspect of the simplex method.
E. Feasibility is determined by whether a solution satisfies all constraints, not complementary slackness.


QUESTION 3
Suppose you have solved a primal linear programming problem and its dual and found optimal solutions. How can complementary slackness be used to verify the optimality of the solutions?
A. Check if the optimal objective function values of the primal and dual problems are equal.
B. Check if all constraints in both the primal and dual problems are binding.
C. Check if, for each constraint in the primal problem, either the constraint is binding or the corresponding dual variable is zero, and vice versa for the dual problem.
D. Check if all variables in both the primal and dual problems are non-negative.
E. Check if the sum of the primal and dual objective function values is zero.

ANSWER: C

EXPLANATION:
A. This checks for strong duality, which is a necessary but not sufficient condition for verifying optimality using complementary slackness.
B. Not all constraints need to be binding at optimality.
C. Complementary slackness states that for each constraint in the primal problem, either the constraint is binding (holds with equality) or the corresponding dual variable is zero.  The same holds true for the dual problem: for each constraint, either it is binding or the corresponding primal variable is zero.  Checking this condition for all constraints in both problems verifies the optimality of the solutions.
D. Non-negativity is a condition for feasibility, not optimality via complementary slackness.
E. There's no such condition in complementary slackness.


QUESTION 4
What is the practical implication of complementary slackness in sensitivity analysis of linear programming problems?
A. It helps determine the optimal solution to the dual problem.
B. It helps determine the range of changes in the objective function coefficients that maintain the current optimal basis.
C. It helps determine the range of changes in the right-hand side values that maintain the current optimal basis.
D. It helps identify which constraints are binding at the optimal solution and how changes to those constraints affect the optimal solution.
E. It helps determine the optimal solution to the primal problem.

ANSWER: D

EXPLANATION:
A. While complementary slackness is related to the dual problem, it doesn't directly determine its optimal solution.
B. This is related to sensitivity analysis but not directly to complementary slackness.
C. This is related to sensitivity analysis but not directly to complementary slackness.
D. In sensitivity analysis, we examine how changes in the problem's parameters affect the optimal solution. Complementary slackness helps identify which constraints are binding at the optimal solution.  If a constraint is non-binding, small changes to it won't affect the optimal solution. However, changes to binding constraints will directly impact the optimal solution.  Therefore, complementary slackness helps understand the sensitivity of the optimal solution to changes in the constraints.
E. Complementary slackness doesn't directly determine the primal optimal solution; it verifies its optimality given a primal and dual solution.


QUESTION 5
Explain the concept of complementary slackness in the context of linear programming and its significance in verifying the optimality of solutions to primal and dual problems.  Illustrate your explanation with a simple example.
A. Complementary slackness states that if a primal variable is positive, its corresponding dual slack variable must be zero, and vice versa. This condition holds for both primal and dual problems simultaneously.  It helps verify optimality because if both primal and dual solutions satisfy complementary slackness, then both are optimal.
B. Complementary slackness is a theorem that proves the existence of an optimal solution for both the primal and dual problems. It states that if one problem has a feasible solution, the other must also have a feasible solution.  It doesn't directly help in verifying optimality.
C. Complementary slackness is a condition that must be met only for the primal problem to be optimal. It states that if a constraint is binding (holds with equality), then the corresponding dual variable must be zero. It doesn't consider the dual problem's optimality.
D. Complementary slackness is a method for solving linear programming problems by iteratively improving the primal solution until it satisfies a set of conditions. It doesn't directly relate to the dual problem or optimality verification.
E. Complementary slackness is a concept that only applies to problems with equality constraints. It states that the optimal values of the primal and dual variables must be equal. It doesn't apply to problems with inequality constraints.

ANSWER: A

EXPLANATION:
A. Complementary slackness is a crucial concept in linear programming duality. It states that for an optimal primal solution and its corresponding dual solution, if a primal variable is strictly positive, then the corresponding dual constraint must be binding (i.e., the slack variable is zero), and vice versa.  Similarly, if a dual variable is strictly positive, then the corresponding primal constraint must be binding, and vice versa.  This condition provides a powerful way to verify the optimality of solutions. If a primal and dual feasible solution satisfy complementary slackness, then both are optimal.  For example, consider the primal problem: max $z = x_1 + 2x_2$ subject to $x_1 + x_2 \le 4$, $x_1 \le 3$, $x_2 \le 2$, $x_1, x_2 \ge 0$.  Suppose we find a primal solution $x_1 = 2, x_2 = 2$ with $z = 6$. The corresponding dual problem is: min $w = 4y_1 + 3y_2 + 2y_3$ subject to $y_1 + y_2 \ge 1$, $y_1 + y_3 \ge 2$, $y_1, y_2, y_3 \ge 0$.  If we find a dual solution $y_1 = 1, y_2 = 0, y_3 = 1$ with $w = 6$, then complementary slackness is satisfied because $x_1 > 0$ and the first dual constraint is binding ($y_1 + y_2 = 1$), $x_2 > 0$ and the third dual constraint is binding ($y_1 + y_3 = 2$), and $y_1 > 0$ and the first primal constraint is binding ($x_1 + x_2 = 4$).  Since both solutions are feasible and satisfy complementary slackness, they are optimal.
B. This option incorrectly states that complementary slackness proves the existence of optimal solutions. While it's a consequence of strong duality, it's not its primary purpose.  Complementary slackness is a condition that helps verify the optimality of *already found* solutions.
C. This option incorrectly limits complementary slackness to only the primal problem.  It's a condition that must hold for *both* primal and dual solutions simultaneously to guarantee optimality.
D. This option mischaracterizes complementary slackness as a solution method. It's not an algorithm but a condition used to verify optimality after a solution has been found.
E. This option incorrectly restricts complementary slackness to problems with only equality constraints.  It applies equally to problems with inequality constraints, as illustrated in the correct answer.


QUESTION 6
In the context of complementary slackness, if the $i$-th constraint in the primal problem is binding (i.e., the inequality holds with equality), what can we say about the corresponding dual variable $y_i$?
A. $y_i$ must be zero.
B. $y_i$ must be positive.
C. $y_i$ can be zero or positive.
D. $y_i$ must be negative.
E. $y_i$ can be any real number.

ANSWER: B

EXPLANATION:
A. This is incorrect.  Complementary slackness states that if a primal constraint is binding, the corresponding dual variable is positive. If the primal constraint is not binding, then the dual variable is zero.
B. If the $i$-th primal constraint is binding, then the corresponding dual variable $y_i$ must be positive. This is a direct consequence of complementary slackness.
C. This is incorrect.  Complementary slackness dictates that only one of the pair (primal slack, dual variable) can be non-zero.  Since the primal constraint is binding, the slack is zero, thus the dual variable must be positive.
D. Dual variables are non-negative in the standard form of the dual problem. A negative dual variable would violate the dual problem's constraints.
E. Dual variables are non-negative.  Complementary slackness further restricts their values based on the primal solution.

Suppose an optimal solution is $x_1 = 4, x_2 = 4$ with $Z = 20$. The corresponding dual problem has an optimal solution $y_1 = 1, y_2 = 1, y_3 = 0$. QUESTION 10
In the context of complementary slackness, if the $i$-th constraint in the primal problem is binding (i.e., the inequality holds with equality), what can we say about the corresponding dual variable $y_i$?
A. The corresponding dual variable $y_i$ must be zero.
B. The corresponding dual variable $y_i$ must be positive.
C. The corresponding dual variable $y_i$ can be either zero or positive.
D. The corresponding dual variable $y_i$ must be negative.
E. There is no relationship between the primal constraint and the dual variable.

ANSWER: C

EXPLANATION:
A. Incorrect.  While it's possible for $y_i$ to be zero, it's not mandatory. Complementary slackness allows for $y_i$ to be positive when the constraint is binding.
B. Incorrect.  While $y_i$ can be positive, it's not always the case.  Complementary slackness allows for $y_i$ to be zero when the constraint is binding.
C. The corresponding dual variable $y_i$ can be either zero or positive.  Complementary slackness states that either the primal constraint is binding ($a_i^Tx = b_i$) or the corresponding dual variable is zero ($y_i = 0$), but not both. If the constraint is binding, $y_i$ can be zero or positive.
D. Incorrect.  Dual variables associated with less-than-or-equal-to constraints in a maximization problem are non-negative. Therefore, $y_i$ cannot be negative.
E. Incorrect. Complementary slackness establishes a direct relationship between primal constraints and dual variables.
