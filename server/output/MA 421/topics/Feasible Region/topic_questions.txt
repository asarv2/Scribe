QUESTION 1
Given the constraints $x_1 \ge 0$, $x_2 \ge 0$, $-x_1 + 3x_2 \le 12$, $x_1 + x_2 \le 8$, and $2x_1 - x_2 \le 10$, what are the coordinates of vertex B of the feasible region, as shown in the provided slides?
A. (0, 0)
B. (5, 0)
C. (6, 2)
D. (0, 4)
E. (10, 0)

ANSWER: C

EXPLANATION:
A. This is the origin (0,0), which is vertex O.
B. This is vertex A, found by setting $x_2 = 0$ and solving $2x_1 - x_2 = 10$.
C. The coordinates of vertex B are found by solving the system of equations $x_1 + x_2 = 8$ and $2x_1 - x_2 = 10$ simultaneously. Adding the two equations gives $3x_1 = 18$, so $x_1 = 6$. Substituting this into $x_1 + x_2 = 8$ gives $6 + x_2 = 8$, so $x_2 = 2$. Therefore, the coordinates of vertex B are (6, 2).
D. This point lies on the line $-x_1 + 3x_2 = 12$, but it is not a vertex of the feasible region.
E. This point is not within the feasible region because it violates the constraint $x_1 + x_2 \le 8$.


QUESTION 2
What is the feasible region in a linear programming problem, and why is it important to identify it?
A. The feasible region is the set of all points that satisfy at least one constraint. It is important because it helps visualize the possible solutions.
B. The feasible region is the set of all points that satisfy all constraints simultaneously. It is important because it represents the set of all possible solutions to the problem.
C. The feasible region is the set of all points that maximize the objective function. It is important because it identifies the optimal solution.
D. The feasible region is the set of all points that minimize the objective function. It is important because it identifies the optimal solution.
E. The feasible region is the set of points that violate at least one constraint. It is important because it helps identify infeasible solutions.

ANSWER: B

EXPLANATION:
A. This is incorrect because the feasible region must satisfy *all* constraints, not just one.
B. The feasible region is indeed the set of all points satisfying all constraints simultaneously.  Identifying it is crucial because only points within this region are valid solutions to the linear programming problem.  The optimal solution must lie within the feasible region.
C. This is incorrect; the feasible region contains all possible solutions, not just the optimal one. The optimal solution is a specific point *within* the feasible region.
D. This is incorrect; similar to option C, the feasible region contains all possible solutions, and the optimal solution is a specific point within the feasible region, whether it's a maximization or minimization problem.
E. This describes the *infeasible* region, the opposite of the feasible region.


QUESTION 3
Explain the geometric interpretation of the simplex method in relation to the feasible region.
A. The simplex method randomly searches the feasible region for the optimal solution.
B. The simplex method iteratively moves from one vertex of the feasible region to an adjacent vertex, improving the objective function at each step until the optimal vertex is found.
C. The simplex method finds the center of the feasible region and determines if it is the optimal solution.
D. The simplex method calculates the area of the feasible region to determine the optimal solution.
E. The simplex method identifies all vertices of the feasible region and then selects the vertex with the highest objective function value.

ANSWER: B

EXPLANATION:
A. The simplex method is not a random search; it's a systematic algorithm.
B. The simplex method systematically explores the vertices of the feasible region. It starts at one vertex and moves to a neighboring vertex that improves the objective function value. This process continues until no further improvement is possible, indicating that the optimal solution has been found at a vertex.
C. The optimal solution is not necessarily at the center of the feasible region. It's usually located at a vertex.
D. The area of the feasible region is irrelevant to finding the optimal solution.
E. While the optimal solution is at a vertex, the simplex method doesn't explicitly check every vertex; it efficiently moves between adjacent vertices.


QUESTION 4
How does the concept of "basic" and "non-basic" variables relate to the vertices of the feasible region in the simplex method?
A. Basic variables are always zero at a vertex, while non-basic variables can take any value.
B. Non-basic variables are always zero at a vertex, while basic variables determine the coordinates of that vertex.
C. Basic and non-basic variables are interchangeable and have no specific relationship to vertices.
D. Basic variables determine the objective function value at a vertex, while non-basic variables are irrelevant.
E. The number of basic variables equals the number of constraints, while the number of non-basic variables is arbitrary.

ANSWER: B

EXPLANATION:
A. This is the opposite of the correct relationship.
B. At each vertex of the feasible region, a subset of variables (the non-basic variables) are set to zero. The remaining variables (the basic variables) then define the coordinates of that specific vertex within the feasible region.
C. The distinction between basic and non-basic variables is fundamental to the simplex method's operation and its geometric interpretation.
D. Both basic and non-basic variables contribute to the objective function value, though non-basic variables are zero at a vertex in a given iteration.
E. The number of basic variables is equal to the number of constraints (assuming no degeneracy), and the number of non-basic variables is determined by the total number of variables minus the number of basic variables.
