\textbf{Spanning Trees and Bases}

The above computation suggests that spanning trees are related to bases in the simplex method.  Let us pursue this idea. Normally, a basis is an invertible square submatrix of the constraint matrix. But for incidence matrices, no such submatrix exists. To see why, note that if we sum together all the rows of $A$, we get a row vector of all zeros (since each column of $A$ has exactly one $+1$ and one $-1$). Of course, every square submatrix of $A$ has this same property and so is singular. In fact, we shall show in a moment that for a connected network, there is exactly one redundant equation (i.e., the rank of $A$ is exactly $m-1$).

Let us select some node, say, the last one, and delete the flow balance constraint associated with this node from the constraints defining the problem (since it is redundant anyway). Let us call this node the root node. Let $A$ denote the incidence matrix $A$ without the row corresponding to the root node (i.e., the last row), and let $\tilde{b}$ denote the supply/demand vector with the last entry deleted. The most important property of network flow problems is summarized in the following theorem:

\textbf{THEOREM 14.1} A square submatrix of $\tilde{A}$ is a basis if and only if the arcs to which its columns correspond form a spanning tree.

We can now apply the primal simplex method to the problem.  The steps are as follows:

\begin{enumerate}
    \item Identify the entering variable.  This is the variable corresponding to the arc with the most negative reduced cost.
    \item Identify the leaving variable.  This is the variable corresponding to the arc that is part of the cycle formed by the entering variable and the spanning tree.
    \item Update the spanning tree by replacing the leaving variable with the entering variable.
    \item Update the primal and dual variables.
    \item Repeat steps 1-4 until all dual slacks are nonnegative.
\end{enumerate}
