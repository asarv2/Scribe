\textbf{Sparse Solutions of Linear System}

\newline
\textit{[EMG] p. 167}

\newline
Sparse solution of underdetermined system of linear equations

\newline
Given an $m \times n$ matrix $A$ with $m < n$, a vector $b \in \mathbb{R}^m$, and an integer $r$, find an $x \in \mathbb{R}^n$ such that $Ax = b$ and $|supp(x)| \le r$

\newline
if one exists.

\newline
($|supp(x)| = \# \{i: x_i \ne 0\}$)

\newline
$\min \|x\|_1$

\newline
s.t.
\newline
$Ax = b$


\textbf{Description:}

This slide presents a linear programming formulation for finding a sparse solution to an underdetermined linear system.  The problem is to find a solution vector $x$ to the equation $Ax = b$, where $A$ is an $m \times n$ matrix with $m < n$, $b$ is a given vector, and the solution $x$ must be sparse, meaning that it has at most $r$ non-zero elements.  The objective function $\min \|x\|_1$ aims to minimize the $l_1$ norm of the solution vector $x$, which is the sum of the absolute values of its components.  This formulation is a crucial step in solving the sparse solution problem using linear programming techniques.  The slide is likely part of a lecture or presentation explaining how to use linear programming to recover a sparse signal from a noisy observation, now in the context of minimizing the $l_1$ norm of the solution.
