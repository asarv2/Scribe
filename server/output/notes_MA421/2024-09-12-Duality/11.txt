Slide 11

\textbf{Strong Duality Theorem}

If (P) has an optimal solution ($x_j^*$)
\newline
Then (D) also has an optimal solution ($y_i^*$)
\newline
and
\newline
$(\mathcal{S}^* = \sum_{j} c_j x_j^* = \sum_{i} b_i y_i^* (\mathcal{S}^*))$
\newline
i.e. duality gap = 0
\newline
(The proof gives a formula for $y_i^*$)

\textbf{Description:}

This slide states the Strong Duality Theorem for linear programming.  It asserts that if the primal problem (P) has an optimal solution, then the dual problem (D) also has an optimal solution, and the optimal values of the objective functions for both problems are equal.  This is a stronger result than the Weak Duality Theorem, which only guarantees an upper bound on the dual objective function value.  The slide likely follows a discussion of the simplex method and the negative transpose property, and now introduces the concept of strong duality, which is a fundamental result in linear programming.  The notation $\mathcal{S}^*$ represents the optimal value of the objective function for the primal problem.  The notation $x_j^*$ and $y_i^*$ represent the optimal values of the primal and dual variables, respectively. The final statement suggests that the proof of the theorem provides a way to calculate the optimal dual variables given the optimal primal variables.
