\textbf{Description:}

This is slide 7 of a 15-slide lecture on Linear Programming.  It continues the sensitivity analysis of the primal problem, specifically examining how a change in the right-hand side of a constraint affects the optimal solution. The slide shows the calculation of how the optimal solution ($x_1^*$, $x_2^*$) changes when the constraint $x_1 + 30x_2 \le 4000$ is modified to $x_1 + 30x_2 \le 4000 + t$.  The result is expressed as a function of the parameter $t$.  The calculation uses the inverse of the basis matrix ($B^{-1}$) to determine the new values of the basic variables ($x_1$, $x_2$).  The inequality $-300 \le t \le 1000$ indicates the range of permissible changes in the constraint's right-hand side that will maintain the current optimal basis.  This range is crucial for determining the sensitivity of the optimal solution to changes in the constraint.
