$M_3: \quad \zeta_{new} = 40 x_1^* + 70 x_2^* = 6250$

\begin{equation*}
\begin{aligned}
\zeta_{new} &= y_1^* (x_1^* + x_2^*) + y_2^* (10 x_1^* + 50 x_2^*) \\
&= y_1^* (100) + y_2^* (4000 + t) \\
&= 100 y_1^* + 4000 y_2^* + y_2^* t \\
&= 6250 + 0.75 t
\end{aligned}
\end{equation*}

\textbf{Description:}

This is slide 9 of a 15-slide lecture on Linear Programming.  It continues the sensitivity analysis of the primal problem, specifically examining how a change in the right-hand side of a constraint affects the optimal solution. The slide shows a third method ($M_3$) for calculating the new optimal objective function value ($\zeta_{new}$) when the constraint $x_1 + 30x_2 \le 4000$ is modified to $x_1 + 30x_2 \le 4000 + t$.  This method uses the optimal dual variables ($y_1^*$, $y_2^*$) to calculate the new objective function value.  The result is expressed as a function of the parameter $t$, showing how the optimal objective function value changes linearly with $t$.  The calculation explicitly shows the relationship between the optimal dual variables and the change in the constraint's right-hand side.  The result is $\zeta_{new} = 6250 + 0.75t$.  This method is a direct application of the dual problem to calculate the change in the objective function.
