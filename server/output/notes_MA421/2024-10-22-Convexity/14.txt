\underline{\text{Separation Theorem}} \\
\text{THEOREM 10.4. Let } P \text{ and } \bar{P} \text{ be two disjoint nonempty polyhedra in } \mathbb{R}^n \text{. Then} \\
\text{there exist disjoint half-spaces } H \text{ and } \bar{H} \text{ such that } P \subset H \text{ and } \bar{P} \subset \bar{H}. \\
P \ne \emptyset, \quad P = \{ x : Ax \le b \}, \quad \bar{P} = \{ x : \bar{A}x \le \bar{b} \} \\
\text{There is a } y, \bar{y} \text{ s.t.} \begin{cases} y^T A + \bar{y}^T \bar{A} = 0 \\ y^T b + \bar{y}^T \bar{b} < 0 \\ y, \bar{y} \ge 0 \end{cases} \\
\text{Define } H = \{ x : y^T Ax \le y^T b \}, \quad \bar{H} = \{ x : \bar{y}^T \bar{A}x \le \bar{y}^T \bar{b} \} \\
H \cap \bar{H} = \emptyset, \quad P \subseteq H, \quad \bar{P} \subseteq \bar{H}
</LATEX>

The theorem states that two disjoint nonempty polyhedra, $P$ and $\bar{P}$, in $\mathbb{R}^n$ can be separated by disjoint half-spaces $H$ and $\bar{H}$.  The polyhedra are defined as $P = \{x : Ax \le b\}$ and $\bar{P} = \{x : \bar{A}x \le \bar{b}\}$. Using these vectors, two half-spaces $H$ and $\bar{H}$ are defined, and it is shown that $H \cap \bar{H} = \emptyset$, $P \subseteq H$, and $\bar{P} \subseteq \bar{H}$.  This completes the proof.
