\underline{\text{Separation Theorem}} \\
\text{THEOREM 10.4. Let } P \text{ and } \bar{P} \text{ be two disjoint nonempty polyhedra in } \mathbb{R}^n \text{. Then} \\
\text{there exist disjoint half-spaces } H \text{ and } \bar{H} \text{ such that } P \subset H \text{ and } \bar{P} \subset \bar{H}. \\
P \ne \emptyset, \quad P = \{ x : Ax \le b \}, \quad \bar{P} = \{ x : \bar{A}x \le \bar{b} \} \\
P \cap \bar{P} = \emptyset \iff \begin{cases} Ax \le b \\ \bar{A}x \le \bar{b} \end{cases} \text{ has no solution} \\
\iff \text{There is a } y, \bar{y} \text{ s.t.} \\
y^T A + \bar{y}^T \bar{A} = 0 \\
y^T b + \bar{y}^T \bar{b} < 0 \\
y, \bar{y} \ge 0 \\
\underline{\text{Farkas' Lemma}} \\
\text{LEMMA 10.5. The system } Ax \le b \text{ has no solutions if and only if there is a } y \text{ such that} \\
(10.8) \quad A^T y = 0 \iff \begin{cases} A^T y = 0 \\ y \ge 0 \\ y^T b < 0 \end{cases}
</LATEX>

<DESCRIPTION>This slide presents the Separation Theorem (Theorem 10.4) and its proof using Farkas' Lemma. The theorem states that two disjoint nonempty polyhedra, $P$ and $\bar{P}$, in $\mathbb{R}^n$ can be separated by disjoint half-spaces. The polyhedra are defined as $P = \{x : Ax \le b\}$ and $\bar{P} = \{x : \bar{A}x \le \bar{b}\}$. The proof uses the equivalence between the disjointness of $P$ and $\bar{P}$ ($P \cap \bar{P} = \emptyset$) and the non-existence of a solution to the system $Ax \le b$ and $\bar{A}x \le \bar{b}$.  This is then linked to Farkas' Lemma (Lemma 10.5), which provides conditions for the non-existence of solutions to a system of inequalities.  Specifically, the non-existence of a solution to $Ax \le b$ is equivalent to the existence of a vector $y$ such that $A^Ty = 0$, $y \ge 0$, and $y^Tb < 0$.  The slide shows this equivalence using a double implication arrow. The underlining highlights key parts of the theorem and the proof. The context of linear programming is crucial because the separation theorem is a fundamental result used in duality theory and the development of algorithms for solving linear programs.</DESCRIPTION>
