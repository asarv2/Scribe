\underline{\text{Farkas' Lemma}} \\
\text{LEMMA 10.5. The system } Ax \le b \text{ has no solutions if and only if there is a } y \text{ such that} \\
\underline{A^T y = 0} \\
y \ge 0 \\
b^T y < 0 \\
\text{PROOF. Consider the linear program} \\
\text{maximize } 0 \\
\text{subject to } Ax \le b \\
\text{and its dual} \\
\text{minimize } b^T y \\
\text{subject to } A^T y = 0 \\
y \ge 0
</LATEX>

<DESCRIPTION>This slide presents Farkas' Lemma (Lemma 10.5), a fundamental result in linear programming, and its proof. The lemma states that a system of linear inequalities $Ax \le b$ has no solution if and only if there exists a non-negative vector $y$ such that $A^Ty = 0$ and $b^Ty < 0$. The proof uses linear programming duality.  A primal linear program is constructed with an objective function of 0 and constraints $Ax \le b$.  Its dual linear program is then presented, with an objective function of minimizing $b^Ty$ subject to $A^Ty = 0$ and $y \ge 0$. The proof then argues that the primal problem is infeasible (has no solution) if and only if the dual problem is unbounded below, which is equivalent to the existence of a $y$ satisfying the conditions stated in Farkas' Lemma.  The underlining highlights key parts of the lemma and its proof. The context of linear programming is crucial because Farkas' Lemma is a powerful tool used in various aspects of linear programming theory, including duality theory and the development of algorithms.</DESCRIPTION>
