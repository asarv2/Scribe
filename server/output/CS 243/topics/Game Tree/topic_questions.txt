QUESTION 1
According to the lecture, what is the primary purpose of searching over game trees in the context of AI game playing?
A. To memorize all possible game states
B. To identify the optimal sequence of moves leading to a win
C. To randomly select moves to confuse the opponent
D. To create a visual representation of the game

ANSWER: B

EXPLANATION:
A. Answer A is incorrect because memorizing all possible game states is not feasible for complex games due to the size of the search space.
B. Answer B is correct because the primary goal of searching over game trees is to find the best sequence of moves that will lead to a win.
C. Answer C is incorrect because randomly selecting moves is not a strategic approach to game playing.
D. Answer D is incorrect because while game trees can be visualized, the primary purpose is not visualization.
E. Answer E is incorrect because while probabilities can be used, the primary purpose is to find the optimal sequence of moves.
