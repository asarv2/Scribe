\textbf{Clustering terminology}

\textbf{Hierarchical clustering}
\begin{itemize}
    \item clusters form a hierarchy
    \item computed bottom-up or top-down fashion
\end{itemize}

\textbf{Flat clustering}
\begin{itemize}
    \item no inter-cluster structure
\end{itemize}

\textbf{Hard clustering}
\begin{itemize}
    \item items are assigned to a single unique cluster
\end{itemize}

\textbf{Soft clustering}
\begin{itemize}
    \item items are assigned to one or more clusters
    \item membership often expressed as a real-valued function
\end{itemize}

Kmeans is flat, hard clustering approach

\textbf{The K-means Algorithm}

\textbf{Input:} Dataset $D$, number of clusters $k$

\textbf{Output:} Set of cluster representatives $C$, cluster membership vector $m$

\textbf{\# Initialize cluster representatives $C$}

Randomly assign $k$ data points from $D$ into each cluster

Initialize $C$ such that $c_i$ is mean of points in $i^{th}$ cluster

\textbf{while} not converged

\textbf{\# Data Assignment}

Reassign points in $D$ to closest cluster mean

Update $m$ such that $m_i$ is cluster ID of the $i^{th}$ point in $D$

\textbf{\# Relocation of means}

Update $C$ such that $c_i$ is mean of points in $i^{th}$ cluster
%
\subsection{Description}%
This slide presents the K-means clustering algorithm.  It outlines the steps involved in the algorithm, clearly defining the input (a dataset $D$ and the number of clusters $k$) and the output (a set of cluster representatives $C$ and a cluster membership vector $m$).  The algorithm begins by initializing the cluster representatives $C$ by randomly selecting $k$ data points from the dataset $D$ to be the initial cluster centers.  The algorithm then iteratively performs two steps:  Data Assignment and Relocation of means.  In the Data Assignment step, each data point in $D$ is reassigned to the closest cluster mean.  The cluster membership vector $m$ is updated to reflect these assignments.  In the Relocation of means step, the cluster representatives $C$ are updated by recalculating the mean of the data points assigned to each cluster.  The algorithm continues these steps until it converges, meaning that the cluster assignments no longer change significantly between iterations.  The context of the course, "Artificial Intelligence Basics," suggests that this slide is part of a module on clustering algorithms and their applications in various AI tasks.%

\textbf{Evaluation via Class Labels: Purity}

Purity: a measure of the extent to which cluster/groups (G) contain objects of a particular class (C)

\begin{itemize}
    \item Each cluster is assigned the class according to the most numerous class of its elements
    \item The purity of each cluster $i$ in $G$ is determined by the number of examples of class $j$ ($N_j$) inside each cluster:
    \[
    \text{purity}(C, G) = \frac{1}{N} \sum_{i=1}^{K} \max_{j} N_j, \quad N_j \in G_i
    \]
\end{itemize}

High purity is easy to achieve when the number of clusters is large

The slide explains that each cluster is assigned the class corresponding to the most frequent class within that cluster.  The purity of a cluster is then calculated as the ratio of the number of examples of the most frequent class within that cluster to the total number of examples in that cluster.
