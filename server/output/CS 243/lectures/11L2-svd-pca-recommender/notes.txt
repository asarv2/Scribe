\textbf{Low Rank Matrix Approximations}

Consider an $n \times d$ matrix $X$, which represents a set of $n$ examples, each with $d$ attributes.  
What's a good notion of dimensionality reduction for these matrices?  
Reduce the rank of the matrix (from $d$ to $k < d$):  
Linear algebra—the following are equivalent definitions for the rank of a matrix $X$ to be $k$: 
\begin{itemize}
    \item The largest linearly independent subset of columns of $X$ has size $k$,  
    i.e. all $d$ columns of $X$ arise as linear combinations of only $k$ different $n$-vectors 
    \item The largest linearly independent subset of rows of $X$ has size $k$,  
    i.e. all $n$ rows of $X$ arise as linear combinations of only $k$ different $d$-vectors 
    \item $X$ can be written as the product of a $(n \times k)$ matrix $A$ and a $(k \times d)$ matrix $B$. 
\end{itemize}
</LATEX>



<DESCRIPTION>This slide discusses low-rank matrix approximations, a dimensionality reduction technique.  It starts by defining the input: an $n \times d$ matrix $X$, representing $n$ examples with $d$ attributes each.  The slide then asks what a good dimensionality reduction method would be for such matrices.  The answer is to reduce the rank of the matrix from $d$ to $k$, where $k < d$.  The slide then presents three equivalent linear algebra definitions for the rank of a matrix to be $k$: 

1. The largest linearly independent subset of columns of $X$ has size $k$.  This means all $d$ columns of $X$ can be expressed as linear combinations of only $k$ different $n$-dimensional vectors.

2. The largest linearly independent subset of rows of $X$ has size $k$.  This means all $n$ rows of $X$ can be expressed as linear combinations of only $k$ different $d$-dimensional vectors.

\textbf{Singular value decomposition}

A singular value decomposition (SVD) of an $n \times d$ matrix $A$ expresses the matrix as the product of three "simple" matrices:

$A = USV^T$

\begin{itemize}
    \item $U$ is an $n \times n$ orthogonal matrix
    \item $V$ is a $d \times d$ orthogonal matrix
    \item $S$ is an $n \times d$ diagonal matrix with nonnegative entries sorted from high to low
\end{itemize}
</LATEX>

* $U$ is an $n \times n$ orthogonal matrix.  This means its columns are orthonormal.
* $V$ is a $d \times d$ orthogonal matrix.  This also means its columns are orthonormal.
* $S$ is an $n \times d$ diagonal matrix with nonnegative entries.  Crucially, the entries on the diagonal are sorted in descending order.

\textbf{PCA: High level approach}

Given data matrix $X$ with $p$ dimensions (attributes)

\begin{itemize}
    \item Mean center each column of $X$ (i.e. subtract from each attribute value the mean of that attribute)
    \item Compute the $p \times p$ covariance matrix: $\Sigma = X^TX$
    \item Find eigenvectors and eigenvalues of the symmetric covariance matrix $\Sigma$
    The eigenvectors correspond to the principle components of $X$
    \item Select the $m$ eigenvectors with largest eigenvalues to reduce dimensionality
\end{itemize}
</LATEX>



<DESCRIPTION>This slide outlines a high-level approach to Principal Component Analysis (PCA).  It describes the steps involved in applying PCA to a data matrix $X$.  The input data is represented by a matrix $X$ where each column represents a variable (attribute) and each row represents an observation.  The slide first emphasizes centering the data by subtracting the mean of each attribute from its corresponding values.  Then, it describes computing the covariance matrix $\Sigma$, which is a $p \times p$ matrix where $p$ is the number of attributes.  The covariance matrix is calculated as the product of the transpose of the data matrix $X$ and the data matrix $X$ itself ($X^TX$).  Next, the slide instructs to find the eigenvectors and eigenvalues of the symmetric covariance matrix $\Sigma$.  The eigenvectors are the principal components, which represent the directions of maximum variance in the data.  Finally, the slide indicates selecting the top $m$ eigenvectors with the largest eigenvalues to reduce the dimensionality of the data.  The context of the course (Artificial Intelligence Basics) suggests that this slide is part of a lecture on dimensionality reduction techniques, providing a summary of the PCA algorithm.</DESCRIPTION>

\textbf{Applying PCA}

New data vectors are formed by projecting the data onto the first few principal components (i.e., top $m$ eigenvectors)

$\mathbf{x} = [x_1, x_2, \dots, x_p]$ (original instance data)

$\mathbf{A} = [a_1, a_2, \dots, a_p]$ (principal component vectors)

$x_1' = a_1 \mathbf{x} = \sum_{j=1}^p a_{1j} x_j$

$\dots$

$x_m' = a_m \mathbf{x} = \sum_{j=1}^p a_{mj} x_j \quad \text{for } m \le p$

$\mathbf{x}' = [x_1', x_2', \dots, x_m']$ (transformed instance)

If $m = p$ then data is transformed

If $m < p$ then transformation is lossy and dimensionality is reduced
</LATEX>



<DESCRIPTION>This slide details the application of Principal Component Analysis (PCA).  It describes how new data vectors ($\mathbf{x}'$) are created by projecting the original data vectors ($\mathbf{x}$) onto the first few principal components (the top $m$ eigenvectors, denoted by $\mathbf{A}$).  The original data $\mathbf{x}$ is a vector of $p$ dimensions.  The principal components are also vectors of $p$ dimensions.  The slide shows the mathematical formula for projecting the data onto the first $m$ principal components, where $m$ can be less than or equal to $p$.  The formula for $x_m'$ shows a weighted sum of the original data points ($x_j$) using the weights from the $m^{th}$ principal component vector ($a_{mj}$).  The slide emphasizes that if $m$ is equal to $p$, the transformation is complete, but if $m$ is less than $p$, the transformation is lossy, meaning some information is discarded to reduce the dimensionality of the data.  The context of the course (Artificial Intelligence Basics) suggests that this slide is part of a lecture on dimensionality reduction techniques, specifically illustrating how PCA transforms data to a lower-dimensional space.</DESCRIPTION>

from sklearn import preprocessing
